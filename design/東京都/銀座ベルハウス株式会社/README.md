# 銀座ベルハウス株式会社 — トップページ リニューアル案

現行サイト（http://www.ginbell.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **本文が文字化けしています** | 文字コードが **UTF-16LE**。実ブラウザで「おいしい**《**」「後継者**上**在」「**上**器用」のように表示され、**確認できただけで9箇所**あります |
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **982px**。ブラウザが全体を約 **38%** に縮小して表示します |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **メタディスクリプションが無い** | 検索結果の説明文をGoogleが本文から拾って生成している状態です |
| 画像のalt属性 | 画像7点中 **6点に alt が無い** |
| 最終更新 | 新着情報の最新が **2017年11月** |

### 文字化けが、この提案の最大の論点です

**代表メッセージが読めません。**

> 「おいしい**《**の笑顔を未来へ」
> 「生産者の高齢化と後継者**上**在による技術の**上**継承」
> 「**上**器用でも素直で、誠実に、正直な資質を高める」

正しくは「おいしい**」**の笑顔」「後継者**不**在」「**不**継承」「**不**器用」です。
UTF-16LE で配信されているため、一部の文字が別の文字として表示されています。

**食品を扱う会社の、理念を語るページがこの状態であることは、
取引先の信用に直接関わります。**
リニューアルの有無にかかわらず、**まずこの点をお伝えすべき**と考えます。

## 設計上の判断

### 署名的装置 ── 流通の位置

代表メッセージの「つくる人・つかう人・つなぐ人」を、そのまま図にしました。
左に仕入先（約400社）、右にお取引先（約200社）、
**中央に自社を一回り大きく**置いています。

3つの円は x=64 / 160 / 256 の等間隔に配置し、
中央のみ半径を 30→34px に大きくしています。
実描画は PC 406×254px（円は 76 / 86 / 86 / 76px）。

### 配色 ── 臙脂

現行サイトから画素採取した臙脂 `#770000` = `oklch(35.7% .147 29.2)` が基準です。
面 `oklch(38% .122 29)`、文字 `oklch(33% .112 29)`。**色相差 0.2°**、彩度のみ抑制。

同じく採取した紺 `#134d99`（hue 257）は既存提案に多い青域のため採りませんでした。
**29° は既存提案に無い色域です。**
食品の卸なので、地もわずかに暖色（hue 60 側）へ振り、
売場に近い温度にしています。

### 見出し

「つくる人と、つかう人のあいだに立つ。」を h1 にしました。
現行サイトのトップは**メニューの羅列**で、
何を扱う会社かがトップページに書かれていません
（メタディスクリプションもありません）。
