# 株式会社上島熱処理工業所 — トップページ リニューアル案

現行サイト（http://www.kamijima.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで **横溢れ 54px** |
| **フレーム構成** | 会社概要・業務・技術の3ページが `<frameset>`。ページ内に「このサイトは、フレームの機能を使用しています。**推奨IE4.0以上**」と表示される |
| 文字コード | Shift_JIS |
| Copyright | `© 2002` |
| レイアウト | テーブル組み。トップページの本文はほぼ1枚の表 |
| 設備仕様が日本語ページに無い | 炉の寸法・温度・台数の表は**英語ページ（/eng/）にしか無い** |
| 名工3名が埋もれている | 「現代の名工」受章の記載が、お知らせの時系列の中に散っている |

### フレームは、検索とスマホの両方に効く

`gaiyou1.htm` `gyoumu1.htm` `gijutu1.htm` はいずれも中身を持たず、
`menu.htm` と `gaiyou2.htm` 等を読み込む枠だけのファイルです。
このため **検索結果に出るのは枠のURL**で、そこに本文はありません。
スマホでは横スクロールが二重に発生します。

## 設計上の判断

### 署名的装置 ── 名工の台帳

熱処理は、同じ炉・同じ材料でも結果が変わる仕事です。
この会社の最も強い資産は炉ではなく**人**でした。

現行サイトでは「現代の名工」3名の受章が、
2012年・2013年・2018年の**お知らせの行に分散**しており、
3人揃っていることが誰にも分かりませんでした。

本案は氏名・受章年・褒章を**全幅の台帳**にまとめ、
幕開けの直後に置いています。数は3人・10人・46人の3つだけに絞りました。

地は**淡い緑のパネル**（`--salt-wash` = `oklch(97% .014 150)`）です。
初版では暗い緑の全幅帯にしていましたが、明るいページの中の
暗い一区画は「穴」に見えるため、淡いパネルに直しています。

なお **関東熱処理（埼玉）で「炉の台帳」を使っている**ため、
同じ熱処理業でも装置を意図的に変えています。あちらは炉のカード、
こちらは人の台帳です。炉の仕様は第2節に落としました。

### 緑を採った理由

現行サイトの実効色を採取したところ、**面として使われている色は緑だけ**でした。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#009933` | 現行 `<font>` / 罫 | `oklch(57.4% .157 148)` | **採用**（面 `oklch(43% .1 150)`、色相差 +2°） |
| `#ccffcc` | 表の地 | `oklch(94.6% .06 145)` | 不採用（淡すぎて面にならない） |
| `#0000ee` | リンク | — | **不採用。ブラウザ既定色であり、この会社が選んだ色ではない** |

彩度は `.157 → .10` に落としました。`.157` は白地の広い面では
「新緑」に寄り、1300℃の炉の会社の声に合わないためです。

### 本バッチ2社目の緑であることへの対処

| 軸 | 既存の緑（143°） | 上島熱処理 |
|---|---|---|
| 地の色相 | — | **冷たい灰（hue 230）** ＝ 緑の補色側。緑を「炉の緑」に見せる |
| 第二色 | なし | **炉温の橙〜赤**（1300℃／900℃／650℃の帯） |
| 書体 | — | **Zen Old Mincho**（明朝）。1956年創業・褒章の会社の声 |
| 角丸 | — | **2px**（ほぼ無し。図面・仕様書の声） |
| 署名的装置 | — | **名工の台帳** |

### 埋もれていた設備仕様を日本語で出した

炉の寸法・常用温度・台数の表は、現行サイトでは
**英語ページ（`/eng/business.html`）にしか存在しません**。
日本語の `gyoumu2.htm` は「２．熱処理可能寸法」の途中で切れています。

本案は英語ページの数値を**日本語に起こして**第2節に置きました。
これは今回のリニューアルで最も効く SEO 上の変更です
（「熱処理 450×450×1500」「真空炉 1250℃」等で引ける状態になる）。

## データの出所

設備・認証・沿革・技能者はすべて**現行サイトから取得した実データ**です。

- 会社概要・沿革・営業品目・名工3名 … `gaiyou2.htm`（日本語）
- 炉の寸法・常用温度・台数 … `/eng/business.html`（英語ページのみに存在）
- 表面改質の膜厚・処理温度・可能寸法 … `/eng/business_02.html`
- 摩擦圧接の径・設備 … `/eng/business_03.html`
- 交通案内 … `gaiyou2.htm` 末尾
- 受賞・認証の時期 … トップページのお知らせ欄

### 確認が必要な項目

- **所在地は東京都大田区**です。見込み客リストでは埼玉の走査結果に
  混ざっていましたが、本社・工場とも大田区仲池上です
- 従業員数46名・資本金1千万円は `gaiyou2.htm` の記載。**更新時期の記載がありません**
- 「金属熱処理特級技能士10名」は日本語ページの記載。
  英語ページでは "eight advanced metal heat treatment experts"（8名）と
  **数が食い違っています**。本案は日本語の10名を採用しました
- 現代の名工は日本語ページで「3名」と明記。ただし
  1996年に工場長・足助清雄氏が労働大臣表彰を受けた記載もあり、
  **現役3名という意味かどうかは未確認**です。本案は氏名が
  明記されている3名（伊川・文珠川・安河内）のみ掲載しています
- ISO 9001 の取得は日本語ページで「平成10年7月」＝1998年。
  英語ページの本文では ISO 9001 と JIS Q 9100 の記述が混在しています
- 営業時間・定休日の記載が現行サイトにないため、JSON-LD に入れていません
- ソルトバスの「焼入用 500〜550℃ ×3基」「焼入・焼戻用 140〜500℃ ×4基」は
  英語ページにありますが、紙面の都合で主要6行のみ掲載しています
  （`llms.txt` には全行を記載）
