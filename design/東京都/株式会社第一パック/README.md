# 株式会社第一パック — トップページ リニューアル案

現行サイト（http://www.daiichipack.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで **横溢れ 216px** |
| 文字コード | Shift_JIS |
| 書体指定 | `Times`（日本語に効かない指定） |
| レイアウト | テーブル組み。会社概要は**表の中に表**が入れ子 |
| **トップページに本文が無い** | `innerText` が空。中身は下層ページだけにある |
| 地図が別ページ | `map.html` は読み込みタイムアウト（20秒超） |
| CSSに色が無い | 本文は黒、リンクはブラウザ既定の青のみ。**色はすべて画像の中** |

### トップページに本文が無い

現行のトップページはテキストを持たず、画像とリンクだけで構成されています。
検索エンジンから見ると**トップページに読む内容がない**状態です。
会社の紹介文（企業理念）、事業内容、事業所、沿革、受賞歴はすべて
下層ページにあり、トップからは要約されていませんでした。

## 設計上の判断

### 署名的装置 ── 形式で選ぶ箱の索引

包装の相談は「どの形式か」から始まります。

現行サイトの `danbo-ru.html` には6つの形式（A式／仕切一体ケース／
エアプレーン式／組仕切／特殊設計2種）が説明されていますが、
**画像を並べた表の中に埋もれ**、どれが受賞作かも読み取れませんでした。

本案は6形式を**通し番号つきの索引**にし、形式名・特徴・
向く用途を1行ずつ並べています。コンテスト受賞作の2形式には
**金の印**を付け、受賞名と実用新案登録番号を併記しました。

### 色 ── CSSに色が無いので画像の画素から採った

現行サイトの CSS には色指定がありません（本文は黒、リンクは
ブラウザ既定の `#0000ee`）。ヘッダ画像 `images/1.jpg`（946×68px）の
画素を集計して採取しました。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#185898` | ヘッダ画像の最頻出画素（2,262px） | `oklch(45.6% .122 252.5)` | **採用**（面 `oklch(41% .118 252)`、色相差 -0.5°） |
| `#183878` | 帯画像 `images/25.jpg` | `oklch(35.7% .116 262)` | 不採用（同系のため分離に使えない） |
| `#0000ee` | リンク | — | 不採用。ブラウザ既定色 |

### 青が何社目かであることへの対処

同時期・同地域の中小サイトは同じ青に寄るため、**色相では分離できません**。
4軸で分けています。

| 軸 | 他の青系社 | 第一パック |
|---|---|---|
| 地の温度 | 冷たい灰 または 白 | **板紙の色（hue 80 の暖かいオフホワイト）**。段ボール屋なので地そのものを紙にした |
| 署名的装置 | 台帳・比較表・レンジのバー | **形式で選ぶ箱の索引**（通し番号＋受賞印） |
| 書体 | 角ゴ／丸ゴ／UD明朝 | **Shippori Mincho**。1946年創業の声 |
| 第二色 | 赤・橙（炉温・警告） | **受賞の金（hue 85）**。受賞の印にだけ使う |
| 罫 | 1px ヘアライン | **2px の製図罫**。箱の展開図の声 |

地を純白（`#fff`）にせず `oklch(99.2% .006 80)` としたのは、
段ボール・板紙を扱う会社の紙面が真っ白なのは不自然なためです。

## データの出所

会社概要・沿革・受賞歴・箱の形式はすべて**現行サイトから取得した実データ**です。

- 商号・創業・設立・資本金・代表者・事業内容 … `naiyou.html`
- 事業所（本社・白岡・掛川）の住所と電話 … `zigyousyo.html`
- 沿革（1946〜2024）とコンテスト受賞歴 … `enkaku.html`
- 箱の6形式と受賞作の説明 … `danbo-ru.html`
- 設計の考え方（環境・使いやすさ・コスト） … `kaihatu.html`
- 企業理念 … `rinen.html`
- 環境方針 … `kankyou.html`

### 確認が必要な項目

- **本社は東京都北区**です。見込み客リストには「第一パック 白岡工場」として
  埼玉の走査結果に入っていましたが、白岡は3工場のうちの1つです
- **大船工場の住所が現行サイトに番地まで記載されていません**
  （沿革に「神奈川県鎌倉市」とあるのみ）。本案では地図を付けていません
- **従業員数の記載が現行サイトにありません**
- 川崎出張所・藤沢出張所桐原作業センター・那須センターは
  沿革に開設の記載がありますが、**住所・電話の記載がありません**。
  本案では所在地の節に名称と開設年のみ記載しています
- 神奈川営業グループは2024年6月に本社内へ移転済みですが、
  `zigyousyo.html` の見出しは「本社・神奈川営業グループ」のままです。
  本案もその表記に合わせています
- 環境方針の制定日は2000年7月1日、最終改訂は**2025年3月1日**です。
  沿革の最終記載は2024年6月なので、**沿革が1年分古い**可能性があります
- 「創業以来、70年超」は `rinen.html` の記載です。1946年創業から
  数えると80年になるため、**本案では年数表記を使わず「SINCE 1946」**としています
- 受賞歴の年は元号のみの記載（H3・H4…）で、月の記載がありません
