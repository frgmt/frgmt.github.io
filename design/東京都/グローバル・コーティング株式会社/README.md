# グローバル・コーティング株式会社 — トップページ リニューアル案

現行サイト（http://www.globalcoat.com）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで縮小表示（等倍では収まらない） |
| 文字コード | Shift_JIS |
| Copyright | `Copyrights 2008` |
| **全14ページのタイトルが同一** | すべて「グローバル・コーティング」。ページ名すら付いていない |
| **トップページに本文がない** | 各節の1行紹介文とリンクのみ |
| 3つの処理の使い分けが読めない | 技術案内が長文で、どの問題にどれを使うかが分からない |

### 全14ページのタイトルが「グローバル・コーティング」

`business.html`（事業内容）、`skill.html`（技術案内）、`company.html`（会社案内）、
`quality.html`（品質）、`flow.html`（ご依頼の流れ）── **すべて同じ `<title>`** です。
検索結果には同じ見出しが14個並ぶことになります。

## 設計上の判断

### 署名的装置 ── どの問題を、どの処理で解くか

表面処理は「**何の問題を解きたいか**」で選ばれます。

現行サイトの `skill.html` には、樹脂含浸・プラテクト・乾性潤滑・防錆被膜の
説明が**長い散文**で書かれています。内容は良質なのですが、
「切削できない焼結金属をどうにかしたい」という具体的な悩みを持つ発注者が、
**どの処理を選べばいいのか**が読み取れませんでした。

本案は**処理・何をするか・解ける問題・主な用途**の4列にまとめました。
「解ける問題」の列には効果を印で並べ、その下に散文の要点を残しています。
「機械加工性」「表面封孔性」「シール性」「音鳴き抑制」──
発注者が検索する言葉で引けるようにしました。

### 「月3,000万個のうち数百万個」を数の一枚にした

現行サイトの `business02.html` に、こう書かれています。

> エンジンのシリンダーヘッドには必ず使用されている部品で、
> 国内では月３０００万個あるうちの数百万個にグローバル・コーティングの
> 技術が用いられています。

**従業員37名の会社が国内シェアの一角を占めている**という、
極めて強い事実です。導入事例ページの本文中に埋もれていたので、
署名的装置の直下に独立した一枚として置きました。

### 色

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#0068b7` | 現行 CSS | `oklch(51.1% .148 250.8)` | **採用**（面 `oklch(43% .14 251)`、色相差 +0.2°） |
| `#cccccc` | 罫 | — | 無彩色 |

彩度 `.148` は上限 .16 以内なので据え置き、明度のみ落として AA を取りました。

### hue 250 が5社目であることへの対処

第一パック（252）、協栄金型（253）、日新精機（249）、篠原製作所（250）と同じ帯です。

| 軸 | 他の hue 250 系 | グローバル・コーティング |
|---|---|---|
| 地の温度 | 板紙(80)・紫み灰(300)・鋳肌(265)・緑み灰(130) | **紫みの灰（hue 320）**。協栄の300より赤寄り |
| 署名的装置 | 箱の索引・磨き番手・納期の物差し・仕事の幅 | **3つの処理と、解ける問題の対応** |
| 書体 | Shippori Mincho／Zen Antique Soft／M PLUS 1／M PLUS 2 | **Noto Sans JP を見出しにも使い、字間を広く取る**。化学処理の会社なので装飾を持たせない |
| 第二色 | 受賞の金／なし／納期の赤／試験機の赤 | **効果の緑**（解ける問題の印） |
| 幕開けの造り | 斜めの縞／放射／点描／水平の層 | **細かい網点2層**（素材の中の目に見えない空孔） |
| 角丸 | 3px／10px／1px／5px | **2px** |

## データの出所

処理の内容・事例・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- 樹脂含浸・ロックタイト・プラテクトシールの説明 … `skill.html`
- エンジンバルブシート「月3,000万個のうち数百万個」 … `business02.html`
- ドアロック部品・ブレーキ用スプリング … `business02.html`
- 会社概要・沿革・取引先・仕入先・関連会社 … `company02.html`
- 所在地3か所 … `company03.html`
- ご依頼の流れ4段階 … `flow.html`
- 品質管理（紫外線での付着検査・全数検査） … `quality.html`

### 確認が必要な項目

- **本社は東京都千代田区**です。見込み客リストには
  「グローバル・コーティング 上尾事業所」として埼玉の走査結果に
  入っていましたが、第一〜第四工場が埼玉県上尾市にあります
- **第二工場・第三工場の電話番号の記載がありません**（住所のみ）
- **ISO 9001 の認証機関・登録番号の記載がありません**（取得年のみ）
- 資本金1,000万円・従業員37名は**時点の記載がありません**
- 沿革に「2007年 鴻巣工場を開設」「2011年 鴻巣工場を閉鎖」とあります。
  短期間での開設・閉鎖の経緯は記載がありません
- **「デルタコート」は2007年に鴻巣工場で開始**した処理です。
  鴻巣工場の閉鎖後にどの工場へ移ったかの記載がありません
- 2025年開始の**抗菌塗料**について、現行サイトに詳細の記載がありません
  （沿革に一行あるのみ）。本案でも名称のみ触れています
- 現行サイトの `company.html` に代表挨拶がありますが、
  **現社長（鈴木 敦・2022年就任）のものか、前社長のものか判別できません**。
  本案では代表挨拶を掲載していません
