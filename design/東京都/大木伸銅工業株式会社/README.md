現行サイト（http://www.ohkishindo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

## 設計上の判断

### 署名的装置 ── 押出成形の断面

伸銅品メーカーの本質は「溶かした金属を、決まった断面の棒にする」ことです。
ファーストビュー右側に、**ビレットがダイスを通り、丸・六角・角の断面になって
出てくる図**をインラインSVGで置きました。

六角形は目分量ではなく `cx + r×cos(60i−30)` で頂点を算出しています
（辺長の差 0.014px、重心も指定どおり）。
断面だけは真鍮色にして、金属そのものであることを示しました。
実描画は PC 406×254px（丸 61×61px／六角 57×66px）。

### 配色 ── 青は継承し、地を真鍮に寄せる

現行サイトから画素採取した青 `#07579e` = `oklch(45.5% .134 252.5)` が基準です。
面 `oklch(40% .114 252)`、文字 `oklch(34% .104 252)`。**色相差 0.5°**、彩度のみ抑制。

252° は既存提案に最も多い青域です。そこで**地の温度**で分けました。
黄銅・りん青銅のメーカーなので、地を純白ではなく
現行サイトにあるベージュ `#f0efea`（hue 97）側へ寄せた `oklch(98.8% .006 97)` とし、
**青（企業色）と真鍮色の地**という二温度構成にしています。
数値（創業年・在庫種類数・従業員数）はすべて真鍮色で置きました。

### 見出し

「溶かすところから、棒になるまで。」を h1 にしました。
現行サイトのトップは「創立100年を超える」という題のあと、
すぐ製品3種の説明に入ります。**一貫生産であることが最大の強み**なので、
それをそのまま見出しにしています。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

六角形の頂点は**式から生成し、6辺の長さが等しいことを計算で照合**しています。
目分量で置くと歪んだ六角形になりますが、小さく描かれているため
見た目では気づきにくく、検査もすべて通ってしまいます。
**六角棒は実在する製品規格なので、歪んだ六角形を描くことは
製品の誤った表現になります。**
