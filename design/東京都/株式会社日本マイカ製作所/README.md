# 株式会社 日本マイカ製作所 — トップページ リニューアル案

現行サイト（https://www.japanmica.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| **テーブルレイアウト `<table>` 92個** | **今回調査した中で最多**です。トップページの構造がすべて表で組まれています |
| **見出しタグが1つも無い** | `<h1>` **0個**。文書構造が検索エンジンに伝わりません |
| **メタディスクリプションが無い** | 検索結果の説明文をGoogleが本文から拾って生成している状態です |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| 最終更新 | **2022年9月14日** |

**HTTPSには対応済みです。**
問題は、**1910年創立という題材の強さに対して、
サイトがそれをまったく伝えていないこと**に尽きます。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは980px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── マイカの積層断面

マイカは「薄い層が積み重なった鉱物」で、この会社は「その層を漉いて紙にする」会社です。
ファーストビュー右側に、**9層の積層と、上2層が剥がれて浮いている断面**を
インラインSVGで描きました。

層は **11px等間隔**で配置し、実測でも9層すべてが同一幅で描かれることを確認しています。
実描画は PC 406×254px（層11枚、うち本体9層はすべて同幅）。

### 配色 ── 雲母の色

**現行サイトには採取できる色がありません。**
有彩色はブラウザ既定のリンク青 `#0000ff` のみで、実質白紙のスタイルです。

そこで**雲母そのものの色**——薄く剥がれる鉱物の真珠光沢に寄せた
藤色 `oklch(40% .092 296)` を面に、`oklch(34% .086 296)` を文字に採りました。
彩度は低く抑えています。**296° は既存提案に無い色域です。**

### 構成 ── 「層」

区画は薄い層の重なりとして示し、境界は極細の罫のみにしています。
年表は1910年から連続する層として途切れさせていません。

### 見出し

「剥がれる鉱物を、漉いて紙にした。」を h1 にしました。
現行サイトのトップは「日本マイカ製作所のサイトにようこそ」で、
**何をつくる会社かが書かれていません。**

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトの画像は9点のみです。
  **マイカの実物（剥がれる様子）とマイカ紙の写真は、
  この提案の核である「漉いて紙にした」を裏づける最重要素材**です。
  元データのご提供をお願いします
- **JT-60・リニアモーターカーへの採用実績を前面に出しています**
  （現行サイトの沿革の記載どおり）。**掲載継続の可否をご確認ください。**
  納入先の公表可否は取引先の意向によるため、特に慎重な確認が必要です
- **創立年の扱い。**沿革では1910年に合資会社として創立、
  会社概要では設立1938年11月7日（株式会社への改組）となっています。
  本提案では**創立1910年を前面に出し、1938年は注記**としました
- **「日本で初めて」の根拠となる特許番号が記載されていません。**
  1956年に製造特許を取得とありますが、番号があれば明記をお勧めします
- **主要取引先・納入実績の一覧がありません**
- **売上高の記載がありません**
- **技術資料がID・パスワード制になっています。**
  引き合いの入口としては障壁が高いため、
  概要版を公開する運用をご検討いただくとよいかもしれません
- メールアドレスが「mica99■japanmica.co.jp（■を＠に変更）」という
  スパム対策表記になっています。**問い合わせフォームの設置をお勧めします**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。

仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。
