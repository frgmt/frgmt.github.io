# 株式会社シマデン — トップページ リニューアル案

現行サイト（https://www.shimaden.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,200px**。ブラウザが全体を約 **31%** に縮小して表示します。**今回調査した中で最大級の縮小率**です |
| **jQuery 1.8.3** | **2012年11月**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |

**この会社のサイトは、内容も作りも良いものです。**
HTTPSに対応し、h1が1つあり、**画像48点すべてにalt属性**があります。
メタディスクリプションも適切で、英語版・中国語版も用意されています。
アプリケーション事例は5件が個別ページで解説されています。

**問題は viewport タグの欠落に、ほぼ集中しています。**

### 1,200pxを375pxに押し込むということ

viewportタグが無いため、iPhoneはPC用の1,200px幅のページを375pxの画面に縮小します。
横スクロールは発生しませんが、**文字が約1/4以下のサイズ**になります。
**「SR23」「SRS14A」「SRS13A」といった型番が読めません。**
産業機器では型番こそが問い合わせの起点になります。

## 設計上の判断

### 署名的装置 ── 制御の応答曲線

調節計メーカーの本質は「設定値に合わせ込むこと」です。
ファーストビュー右側に、**制御開始から設定値（SV）へ収束していく
測定値（PV）の応答曲線**をインラインSVGで描きました。

曲線は目分量ではなく
`v = 100(1−e^(−t/18))(1+0.06·e^(−t/25)·sin(t/9))` から21点を算出し、
**始点が軸上（y=150）にあること、終端が設定値との差0.5px以内に収束すること、
全区間で単調であることを計算で照合**しています。
実描画は PC 406×254px（曲線 328×126px）。

### 配色 ── 「収束」で分ける

現行サイトから画素採取した紺 `#004d89` = `oklch(41.5% .119 250.5)` が基準です。
面 `oklch(38% .108 250)`、文字 `oklch(33% .100 250)`。**色相差 0.5°**、
元の彩度がほぼ適正なため明度のみ調整しました。

250° は既存提案に最も多い青域です。そこで**構成で分けました**。
温度を設定値に合わせ込む会社なので、
区画は上から下へ**幅の広い情報から狭い情報へ収束**させる順に並べています。

### 見出し

「設定した温度に、合わせ込む。」を h1 にしました。
現行サイトのキャッチは「温度をつくるシマデン。」で、
**印象的ですが、何をする機器なのかが伝わりません。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

応答曲線は**式から生成し、制御として意味の通る形になっているかを計算で照合**しました。
**設定値に収束しない曲線を「制御機器メーカーの図」として置くことは、
製品の否定になります。**
