# 日新精機株式会社 — トップページ リニューアル案

現行サイト（http://nissin-sk.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで **横溢れ 23px** |
| Copyright | `© 2013` |
| WordPress | 6.5.10（テーマは `cloudtpl_355`） |
| `<title>` がキーワードの羅列 | 「ダイカスト \| 亜鉛ダイカスト \| アルミダイカスト \| 金型鋳造 \| daicast \| 金型部品 \| 日新精機株式会社 nissin-sk.co.jp」 |
| 全ページ同一タイトル | 会社概要も設備も特徴も**すべて同じ `<title>`** |
| 誤記 | 「亜鉛ダイカ**ト**」「25t鋳造機を新設**あ**しました」 |

### 全ページが同じタイトルになっている

`company.html` `equipment.html` `point.html` `products.html` のいずれも
`<title>` が同一です。検索結果ではどのページも同じ見出しで並ぶため、
**ページの区別がつきません**。これは今回の提案で最も直接的に効く修正です。

## 設計上の判断

### 署名的装置 ── 納期の物差し

この会社が現行サイトで**唯一「数字で」語っているのが納期**です。

> 現状確定注文が３日前のお客さまや、内示なしで１週間の短納期注文の
> お客さまに対応しています。イレギュラーな場合では当日出荷にも対応しております。
> （`point.html` より）

ところがこの一文は「量産製品の短納期対応」という見出しの下の
**説明文の3行目**に埋もれていました。

本案は3つの型（当日／3日前確定／内示なし1週間）を短い順に並べ、
**2週間を全幅とする帯**を添えています。当日出荷だけロゴの赤にしました。

同業他社との差は「何トンあるか」ではなく「何日で出るか」です。
だから台数ではなく日数を先頭の装置にしました。

### 台数の帯は「トン数」ではなく「台数」

鋳造機19台の内訳（40t×1／25t×3／15t×8／8t×1／7.5t×6）も出しますが、
これは**第2の図**として設備の節に置いています。
**帯の長さは台数**であり、トン数ではありません（誤読を防ぐため注記を添えています）。

大和プレスの「トン数のはしご」（対数目盛にトン数を並べる）、
ベニー精工の「径ごとの台数分布」とは、意図的に軸を変えています。

### 色 ── ロゴは二色だった

現行サイトの CSS には `#3366ff`（ブラウザ既定に近い純青）しかありません。
ロゴ画像 `logo.png`（400×68px）の画素を集計したところ、
**青と赤がほぼ同量**で入っていました。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#0878c8` | ロゴ画素 316px | `oklch(56.1% .151 248.7)` | **採用**（面 `oklch(43% .13 249)`、色相差 +0.3°） |
| `#a83828` | ロゴ画素 299px | `oklch(50.1% .150 31)` | **第二色に採用**。納期の緊急度にのみ使う |
| `#3366ff` | CSS のヘッダ帯 | `oklch(57.3% .234 265)` | 不採用。ブラウザ既定に近い純青 |

明度を 56.1% → 43% に落としたのは、白地の面と文字の両方で AA を取るためです。

### 青が何社目かであることへの対処

| 軸 | 他の青系社 | 日新精機 |
|---|---|---|
| 地の温度 | 暖かい灰／冷たい灰／板紙 | **鋳肌のグレー（hue 265・やや紫み）**。亜鉛ダイカストの梨地の色 |
| 署名的装置 | 台帳・比較表・レンジのバー | **納期の物差し**（日数） |
| 書体 | 明朝／角ゴ／丸ゴ | **M PLUS 1**（幾何学的サンセリフ）。金型・CADの声 |
| 第二色 | 炉温の橙／警告の赤／受賞の金 | **ロゴの赤を納期の緊急度にのみ** |
| 角丸 | 0〜8px | **1px**。ほぼ直角だが完全な角ではない（鋳物のRの感じ） |

## 検証結果（実測）

```
verify-site.mjs:
✅ 横溢れ 0px — 320〜1920 の全10幅
✅ コントラスト 全AA達成／見出し階層 h1×1／タップ対象44px以上
✅ スキップリンク フォーカス時 51px（"本文へ移動"）
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（3,710文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在

lib/audit.mjs:
✅ カナリア: 判定関数は正常
✅ 帯 16本すべて描画あり（最小 39px）
✅ 段階表示の残留なし（375/768/1440）／節の余白は非ゼロ
✅ 地図 1080×320（埼玉県入間郡三芳町大字竹間沢78-1）
✅ hover すべて AA以上（最小 9.29:1）

個別測定:
✅ 台数の帯は台数に比例（8台=939px / 6台=705px / 3台=352px / 1台=117px）
```

途中で 375px・414px・600px に 4〜9px の横溢れが出ました。原因は
台数列の「1台 ヒシヌマ」で、`white-space:nowrap` のまま 3.4rem の
固定列に押し込んでいたためです。**どの要素も viewport をはみ出しておらず**
（`getBoundingClientRect` では検出できず）、`scrollWidth > clientWidth` で
親をたどって特定しました。列を `minmax()` にして修正しています。

## データの出所

設備・沿革・材質・納期はすべて**現行サイトから取得した実データ**です。

- 鋳造機のトン数別台数、加工・検査設備 … `equipment.html`
- 会社概要・沿革・環境方針・ごあいさつ … `company.html`
- 四つの特徴、納期の記述 … `point.html`
- 製品分野、金型技術 … `index.html`
- 営業品目（材質記号） … 全ページ共通のサイドバー

### 確認が必要な項目

- **資本金・従業員数・設立年（法人化の年）の記載が現行サイトにありません**。
  1953年は「創業」であり、法人設立の年は不明です
- **ISO 9001／14001 の認証機関・登録番号の記載がありません**
- 沿革の2008年に「ダイカストマシン25t 1台増設(計16台)」とありますが、
  設備ページの合計は **19台**です。2009年に40t 1台、2012年に25t 1台を
  増設した記載があるので 16+2=18台となり、**1台分が沿革から追えません**。
  本案は設備ページの19台（各行の合計）を採用しています
- 「亜鉛ダイカ**ト**」は現行サイトの誤記です（正しくは亜鉛ダイカスト）。
  本案では修正しています
- トップページの「トピックス」と会社概要の「沿革」で
  **同じ出来事の年が食い違う箇所**があります（太陽光発電が
  トピックスでは2013年決定・2014年導入、沿革では2013年と2014年の両方に記載）。
  本案は沿革側に合わせています
- 現行サイトに**アルミダイカストの設備記載がありません**（材質記号のみ）。
  鋳造機19台はすべて「亜鉛ダイカスト鋳造機」と明記されています
