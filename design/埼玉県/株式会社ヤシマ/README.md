# 株式会社ヤシマ — リニューアル提案サイト

埼玉県八潮市の機械工具商社。既存サイト <http://www.yashimanet.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 100点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- テーブルレイアウト、`<FONT>` タグ、大文字の HTML タグ（HTML 4.01 Transitional）
- 文字コードが Shift_JIS
- ページ内に `Last Update 2004.10.12`、Copyright も 2004 年のまま
- Copyright 行が `Copyright (c) 2004. Copyright (c) 2004.` と二重に出力されている

## デザイン方針

### 色 — 原サイトからの継承
原サイトの見出し・罫の色 `#333366` を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#333366` | `34.9% .087 280.9` | — |
| 本提案 `--iris` | `36% .088 281` | **0.1°** |

**隣の案件との差別化について。** 同じ埼玉の山一精機（275°）と色域が近いため、
色だけでは見分けがつきません。そこで地の灰にわずかな暖色を混ぜ（`oklch(97.6% .0035 70)`）、
青系の地を使う他案件と温度差をつけました。角丸も 2px と最小にし、
字間を広くとった見出しで「商社の資料」らしい硬さを出しています。

### 構成の軸 — 品揃えと信用
メーカーではなく商社なので、見せるべきものが違います。

- **取扱メーカー**を最初のセクションに。「特約店」「MORI会 会員」といった
  契約の種類そのものが信用の証明なので、バッジとして明示しました
- **営業品目**を4列に整理。原サイトでは全角スペース区切りの一続きの文章でした
- **対応エリア**を独立させ、「約200社」を数字として立てました。
  地域密着の商社にとって、範囲と件数は最も強い訴求です

### 写真の扱い
原サイトの加工写真5点は **120×90px** と小さく、主役には使えません。
そこで**全幅の細い帯**として配置し、彩度をわずかに落として背景的に扱いました。
小さい原画でも破綻しない使い方です。ロゴ・見出し画像（GIF）は不使用です。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001）／ LocalBusiness（`areaServed` に6市区）／ WebSite ／ FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
