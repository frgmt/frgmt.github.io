# 三伸機械工業株式会社 — リニューアル提案サイト

埼玉県志木市の精密機械加工。既存サイト <http://www.sanshin-kikai.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 90点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- 外部 CSS ファイルなし。レイアウトはすべてテーブルと `<font>` 相当の直書き
- ナビゲーションが画像（`b_company_n.gif` / `b_company_o.gif` の2枚差し替え式ロールオーバー）
- Copyright 表記が 2007 年のまま
- **主要設備ページが1枚の JPEG 画像のみ**（本文テキストがゼロ）
- メールアドレスが画像。「お手持ちのメーラーソフトに手動で打ち込み、ご使用ください」

## この案件で最も価値のある変更：設備表を HTML にした

原サイトの「主要設備」ページは、**設備一覧の表がまるごと 485×723px の JPEG 画像**でした。
本文テキストはナビゲーションと著作権表示だけです。

本提案では画像から**生産設備21行＋検査設備6行をすべて書き起こし**、`<table>` として
実装しました。これにより次が可能になります。

- 「森精機 NH6300」「オークマ MB-66VB」などの型式で検索に載る
- 「X1500」「φ420」といった加工範囲の数値が読み取れる
- スマートフォンで拡大せずに読める（横スクロール可能な表として実装）
- 発注側が型式をコピーして社内で共有できる

機械加工の外注先を探す担当者は、**まず型式と加工範囲で絞り込みます。**
その情報が画像に閉じ込められている限り、検索では見つかりません。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの見出しと罫に使われている `#546076` を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#546076` | `48.7% .038 262.5` | — |
| 本提案 `--st` | `42% .045 262` | **0.5°** |

彩度 `.038` という非常に低い青灰です。他案件のように鮮やかにはせず、
**そのまま低彩度を保ちました。**この抑えた色調は、
派手さより確かさを見せたいこの会社の姿勢に合っています。

差し色の `--acc`（`oklch(52% .17 27)`）は原サイトの `#cc0000` 由来で、
検査設備表の見出し1箇所にのみ使用しています。原サイトの画像内でも
生産設備が青、検査設備が赤で色分けされていたため、その区別を引き継ぎました。

### 構成の軸 — 「ピン1本から三次元加工まで」
社長あいさつの中に、この会社を一言で説明する文がありました。

> 弊社の特徴は、「ピン1本から三次元加工までを幅広くこなす」ことです。

原サイトではこれが挨拶文の後半に埋もれていましたが、
**見出しそのもの**に引き上げました。小物1点と大物三次元加工の両方を
こなせることは、外注先を選ぶ側にとって明確な判断材料になります。

社長あいさつは全文を掲載しています。「小さな事から始めよ」「チャレンジ＆トライ」など、
書き手の人柄が出ている文章で、書き換えるより残すほうが価値があると判断しました。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 設備一覧27行は、原サイトの画像 `Images/table.jpg` を拡大して1行ずつ書き起こしました
- 「生産設備21台」は、書き起こした行の台数を合計した値です（原サイトに合計値の記載はありません）
- **ISO認証番号について。**原サイトには「ＩＳＯ９００１：０５３８６認証取得」とあります。
  「9001:0538 6」は規格年（2000/2008/2015）ではなく登録番号と思われますが判別できないため、
  本提案では**番号を記載せず「ISO 9001」とのみ表記**しました。**公開前にご確認ください。**
- 銀行名「東京三菱UFJ」を現在の商号「三菱UFJ銀行」に更新しました
- 設備概況の面積表記「４９４,５３平方メートル」は、カンマを小数点と解釈し
  「494.53m²」としました（建物も同様）
- メールアドレスは原サイトで画像化されているため、本提案では**電話とFAXのみ**を
  連絡手段としています

## 画像の扱い
原サイトの写真は3点のみで、うち2点（本社工場外観、設備の6面montage）を採用しました。
ナビゲーション用の GIF ボタン類とタイトル画像は不使用です。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。レイアウトに `<table>` は使用していません
  （データの表としてのみ `<table>` を使用）
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001）／ LocalBusiness ／ WebSite ／ FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- 横スクロール 0px（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上
- JavaScript 無効時も全テキストが読める
- 内部リンクはすべて相対パス
