# 株式会社 練馬工業 — トップページ リニューアル案

現行サイト（http://www.nerima-kogyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **トップページの本文が短い** | 実質 **164文字**。特色も設備も別ページで、トップからは何ができる会社か分かりません |
| Copyright表記 | **2021年**のまま |

**この会社のサイトは、下層ページの内容が良く書かれています。**
h1が1つあり、画像11点すべてにaltがあり、メタディスクリプションも適切です。
**問題はスマホ対応と、その良い内容がトップから見えないことです。**

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 型締力レンジ

ダイカストは「何トンの機械があるか」で受けられる仕事が決まります。
ファーストビュー右側に、**50t〜1,000tの対数目盛の上に90t〜650tの帯**を
インラインSVGで置きました。

座標は `x = 46 + (log10(t) − log10(50)) / (log10(1000) − log10(50)) × 250` で算出し、
**帯の両端（95.1px / 260.1px）と目盛5点すべてが式と一致することを計算で照合**しています。
実描画は PC 406×254px（帯 209×38px）。

### 構成 ── 同業他社と型を分ける

現行サイトから画素採取した黄緑 `#9eb606` = `oklch(73.2% .171 118.8)` が基準です。
面 `oklch(50% .132 119)`、文字 `oklch(43% .118 119)`。**色相差 0.2°**、明度を落として可読域へ。

119° は同時期に作成した**エスコウィンズ（124°）と近い色域**です。
あちらは「減る」（削減量）を構成原理にしたので、
**こちらは「幅」——数値を必ず下限〜上限の範囲として示す**構成にしました。

### 見出し

「90tから650tまで、同じ工場で受けられます。」を h1 にしました。
現行サイトのトップには**キャッチコピーがなく**、
いきなり会社情報が並びます。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには画像が11点ありますが
  小さいため、元データのご提供が必要です。
  **鋳造機と製品の写真は必須**です
- **ISO認証の日付が2ページで食い違っています。**
  「品質・環境への取組み」ページでは ISO 14001の取得が **2008年3月30日**、
  2015年版への移行が **2020年3月5日**。
  一方「沿革」ページでは取得が **平成21年（2009年）3月**、
  移行が **平成30年（2018年）3月** となっています。
  **本提案では取組みページの日付を主として記載し、
  食い違いがあることをページ上に明記しました。**正しい日付をご確認ください
- **設立が「令和2年2月10日」と記載されていますが、創業は昭和38年です。**
  令和2年4月に株式会社サンコーと事業継承して現体制になったためと思われます。
  本提案では**創業年（1963年）を前面に出し、設立日は注記**としました。
  この扱いでよいかご確認ください
- **鋳造機の台数・機種の記載がありません。**
  型締力のレンジは書かれていますが、各サイズが何台あるかが不明です。
  **引き合いの際に必ず聞かれる項目**なので、明記をお勧めします
- **自社専売の材料について、材質名・特性値の記載がありません。**
  「耐摩耗性があり、より薄肉」とのみ書かれています。
  **具体的な数値があれば、この提案の最大の武器になります**
- 売上高の記載がありません
- プログレスグループの構成会社が記載されていません

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 作成中に見つけて直した誤り

**ISO認証の年を、2ページの記述を混ぜて書いていました。**
最初の版では ISO 14001の取得を「2009年3月」（沿革ページの値）、
2015年版への移行を「2018年3月」（同）と書きつつ、
ISO 9001の日付は取組みページの値を使っていました。
**出典の異なる数値を1つのリストに混ぜると、どちらの記録とも一致しない
第三の年表ができてしまいます。**
両ページを突き合わせて食い違いを確認し、
**取組みページに統一したうえで、食い違いの存在自体をページに明記**しました。
