# 有限会社山一精機 — リニューアル提案サイト

埼玉県朝霞市の精密切削加工業。既存サイト <http://www.wk-works.com/yamaichi/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 100点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- テーブルレイアウト（`<table width="700">` 固定幅）、ナビゲーションが `usemap` の画像マップ
- `description` / `keywords` の中身が全角スペース1文字（実質未設定）
- 文字コードが Shift_JIS。会社概要・設備ページには `charset` 宣言そのものがない
- Copyright 表記が 2008 年のまま

## デザイン方針

### 色 — 原サイトからの継承と、隣の案件との差別化
原サイトは `#000066`（264°）と `#ccccff`（285°）を使っています。
この2色は同じ制作元と思われる**吉野プレス工場**の配色と完全に一致しており、
そのまま採ると2案件が見分けのつかない仕上がりになります。

そこで主色を両者の**中間 275°** に置きました。原サイトのどちらの色からも
±11°以内に収まる位置です。

| | OKLCH | 主色との色相差 |
|---|---|---|
| 原サイト `#000066` | `23.1% .160 264.1` | 10.9° |
| 原サイト `#ccccff` | `86.2% .070 284.8` | 9.8° |
| 本提案 `--ind` | `36% .115 275` | — |

さらに版面のつくりで差をつけています。吉野プレスが**能力バー**なのに対し、
本案は**目盛り（スケール）** を主役に据え、等幅数字と細い罫で構成しました。

### 構成の軸 — 「寸法」
この工場の特徴は、受けられる仕事の範囲がはっきりしていることです（5.0φ〜100.0φ、
長さ100mmまで）。問い合わせる側にとって最も知りたい情報なので、**加工範囲を
最初のセクション**に置き、目盛りとして図示しました。

原サイトの製品写真はすべて**スケール（ものさし）を添えて撮影**されています。
これは4人の工場が意図せず持っていた強みで、写真だけで実寸が伝わります。
この特徴をそのまま設計の主題に採用しました。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

**⚠️ 数値の食い違いが1件あります。**
原サイトのトップページには「加工径は５mm〜８０mm」、設備ページには
「加工径 5.0φ〜100.0φ」と、**異なる上限値**が書かれています。
本提案では設備一覧に併記されている後者（100.0φ）を採用しましたが、
**公開前に正しい値の確認が必要です。**

- 検査器メーカー「三豊」は現社名の「ミツトヨ」に表記を統一しました
- 取引先9社は原サイトの一覧どおり。原文の「㈱」は「株式会社」に展開しています
- メールアドレスは原サイトに記載がないため、連絡手段は電話とFAXのみとしています

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
