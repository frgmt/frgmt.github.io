# 株式会社内田製作所 — リニューアル提案サイト

埼玉県春日部市の金属加工業。既存サイト <http://www.uchida-seisakusho.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 100点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- 文字コードが Shift_JIS
- ページ名が `newpage1.htm` 〜 `newpage7.htm`（ホームページ・ビルダーの初期名のまま）
- **主要設備・製品例・営業品目の3ページが、中身のない画像だけのページ**

## この案件で最も価値のある変更：画像内の文字を HTML にした

原サイトの「主要設備」ページは、設備一覧の**表がまるごと1枚の JPEG 画像**でした。
「営業品目」ページも同様に、事業内容が GIF 画像に焼き込まれています。

この状態では次のことが起きます。

- 検索エンジンが「シャーリング 10mm 4050mm」「半自動溶接機」などの語を認識できない
- スクリーンリーダーが読み上げられない
- 画像が拡大できず、スマートフォンでは判読が困難
- コピー＆ペーストで型番を引用できない

本提案では、画像から**16行の設備一覧をすべて書き起こし**、`<table>` として実装しました。
営業品目の2項目も同様にテキスト化しています。
リニューアルによる検索流入の改善が最も見込めるのは、この部分です。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの見出しに使われている `#4f725b` を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#4f725b` | `51.8% .054 155.3` | — |
| 本提案 `--moss` | `43% .062 155` | **0.3°** |

明度だけ下げています（51.8% → 43%）。原サイトでは大きな見出し文字に使われていた色を、
本提案では小さな文字やボタンにも使うため、白地とのコントラストを確保する必要がありました。

### 構成の軸 — 写真
この案件は**写真が主役**です。原サイトの製作写真は 750×525px あり、
本プロジェクトで扱った他社サイトのなかで最も高解像度でした（多くは 120×90 〜 230×173px）。

そこで製作事例を**全幅のタイル壁**として21点並べています。
架台や機械フレームは一点ずつ見ても違いが分かりにくいのですが、
まとめて並べると「これだけの数と大きさをこなしている」ことが一目で伝わります。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 設備一覧16行は、原サイトの画像 `p22.jpg` を拡大して1行ずつ書き起こしました
- 営業品目は画像 `eigyouhin1.gif` の記載どおりです
- **溶接機「17台」**は、原サイトの数値（電気4＋半自動10＋TIG3）を合計した値です。
  原サイトに合計値の記載はありません
- 「JR大宮駅 東口方面」は住所（大宮区吉敷町）から導いた一般的な案内で、
  原サイトの記載ではありません。**正確な道順は確認が必要です**
- 創業年・資本金・従業員数は原サイトに記載がないため、掲載していません

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization ／ LocalBusiness **2件**（本社・工場を別エンティティとして記述）／ WebSite ／ FAQPage
- MEO 対応: 本社と工場それぞれに Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- 横スクロール 0px（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上
- JavaScript 無効時も全テキストが読める
- 内部リンクはすべて相対パス
