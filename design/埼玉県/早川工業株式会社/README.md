# 早川工業株式会社 — トップページ リニューアル案

現行サイト（http://www.hayakawa-k.com）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで縮小表示（等倍では収まらない） |
| **jQuery 1.1.2** | 2007年リリース。今回調べた候補の中で最も古い |
| 新着情報が2008年5月で止まっている | 「中古パイプベンダー購入！」が最新 |
| 板厚の数値が説明文に埋もれている | 材質ごと・工法ごとの上限が**文章の中**にあり比較できない |
| **板厚の記載に矛盾がある** | トップ「ステンレス12㎜まで」／事業内容「ステンレス1ミリまで」 |

### この会社の一番の売りが、文章の中に沈んでいる

板金の相談は**材質と板厚**で決まります。現行サイトには
その数値がきちんと書かれています ── ただし、こういう形で。

> 通常のクリーンカットでも安定した切断を、板厚、鉄19ミリ、
> ステンレス1ミリまで、ワーク範囲2438×1219ミリ）まで行えます。

3つの工法それぞれに同種の文があり、**横断して比べることができません**。

## 設計上の判断

### 署名的装置 ── 材質×工法の板厚マトリクス

材質（鉄・ステンレス・アルミ）× 工法（タレパン・厚板パンチ・レーザー）の
**3×3の表**にまとめました。

| 材質 | タレパン | 厚板パンチ | レーザー |
|---|---|---|---|
| 鉄 | 0.8〜2.3 | 〜6 | **〜19**（軟鋼） |
| ステンレス | 0.6〜2.0 | 〜4 | **〜12** |
| アルミ | 0.8〜3.0 | — | — |

さらに全7条件を**軟鋼19mmを全幅とした帯**で並べ、
レーザーが他の工法と桁違いであることを見せています。
レーザーの2本だけロゴの緑にして「ここが強い」を示しました。

「アルミ×レーザー」は現行サイトに記載がないため、
**空欄にして「現行サイトに記載なし」と明記**しています。
表を埋めるために推測で数値を入れていません。

### 色 ── 現行CSSの青緑を主色、ロゴの緑を「対応可」の印に

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#068097` | 現行 CSS（大面積） | `oklch(55.3% .097 216.4)` | **採用**（面 `oklch(43% .095 216)`、色相差 -0.4°） |
| `#38c808` | ロゴ `header-logo.png` の画素 1,686px | `oklch(72.8% .235 140.6)` | **第二色に採用**（`oklch(45% .13 140)`）。彩度 .235 は sRGB の端で面に使えないため、**「対応可」の印にだけ** |
| `#086898` | ロゴの青 | `oklch(49.3% .109 239.4)` | 不採用（主色と近すぎて分離に使えない） |

主色の彩度は `.097` のまま（既に上限以下）。明度のみ 55.3% → 43% に
落として白地で AA を取りました。

### hue 216 は色相で分離できている

ヒノデメタル（185）と **31°離れており**、他社は 239〜265 の青か
140〜150 の緑です。色相だけで既に分離できていますが、
装置と書体も重ねました。

| 軸 | 選択 |
|---|---|
| 地 | **白**。暗い全幅帯なし |
| 署名的装置 | **材質×工法の板厚マトリクス**（3×3の表＋7本の帯） |
| 書体 | **BIZ UDPGothic**（UDゴシック）。数表が主役なので可読性を優先 |
| 第二色 | **ロゴの緑を「対応可」の印にだけ**（レーザーの2行と帯2本） |
| 角丸 | **3px** |

```
verify-site.mjs:
✅ 横溢れ 0px — 320〜1920 の全10幅
✅ コントラスト 全AA達成／見出し階層 h1×1／タップ対象44px以上
✅ スキップリンク フォーカス時 51px（"本文へ移動"）
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（3,784文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在

lib/audit.mjs:
✅ カナリア: 判定関数は正常
✅ 帯 14本すべて描画あり（最小 96px）
✅ 段階表示の残留なし（375/768/1440）／節の余白は非ゼロ
✅ 地図 1080×320（埼玉県春日部市樋堀85番地）
✅ hover すべて AA以上（最小 9.82:1）

_font.mjs:
✅ --ff-d = BIZ UDPGothic が実際に読み込まれている
```

初版では CSS に `BIZ UDPGothic` と書きながら**webfont の読み込みを
忘れていました**。`font-family` は「無ければ次を使う」ため表示は崩れず、
検査もすべて通ってしまいます（黙って別の書体になる）。
`_font.mjs` を追加して、`--ff-d` の先頭書体が
`document.fonts` に入っているかを測るようにしました。
**今回の11社すべてで確認済み**です。

## データの出所

板厚・設備・実績・会社概要はすべて**現行サイトから取得した実データ**です。

- 材質ごとの板厚上限、工法の説明 … `workmenu.html`
- レーザー加工機の仕様、ブリリアントカット … トップページ／`workmenu.html`
- 主要設備一覧表（21行） … `equipment.html`
- 加工実績6分野 … `workresult.html`
- 会社概要・沿革・経営理念・取引銀行 … `company-outline.html`

### 確認が必要な項目

- **ステンレスのレーザー切断板厚に矛盾があります**。
  トップページは「12㎜のステンレス鋼までの加工が可能」、
  `workmenu.html` は「ステンレス1ミリまで」。
  本案は**12mmを採用**しました（1ミリは12ミリの誤記と判断）。
  **必ず確認してください**
- **電話番号・FAX・メールアドレスの記載が現行サイトにありません**。
  問い合わせは `inquiry.html` のフォームのみです。
  本案でも電話番号を書いていません
- **郵便番号の記載がありません**（住所は「埼玉県春日部市樋堀85番地」まで）
- **新着情報が2008年5月で止まっています**。18年分の設備投資・実績が
  反映されていません。Copyright だけが 2026 に更新されています
- **社名の表記が揺れています**。会社概要は「早川工業株式会社」、
  Copyright は「Hayakawa Kougyousyo」（＝早川工業所）、
  沿革では「早川工業所」→「有限会社早川工業所」。
  株式会社への改組時期の記載がありません
- BBチェアの意匠登録（登録第1316226号）は
  **アイエムエフ株式会社との共同**である旨が記載されています
- 設備表の「三本ロール 2000〜200mm」は原文のままです
  （2000mm〜200mm と読めますが単位の説明がありません）
- **ISO等の認証取得の記載がありません**。日本溶接協会の
  ステンレス鋼溶接適格証明書は取得者が在籍する旨の記載があります
