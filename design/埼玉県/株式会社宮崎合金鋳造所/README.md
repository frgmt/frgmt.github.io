# 株式会社宮崎合金鋳造所 — リニューアル提案サイト

埼玉県川口市のアルミ砂型鋳物メーカー。既存サイト <http://www.miyazaki-goukin.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 93点）
- HTTPS 未対応
- **`<frameset>` によるフレーム構成**（HTML5 で廃止された仕様）
  - 上部 `menu.html` / 中央 `top.html` / 下部 `address.html` の3分割
  - 個別ページの URL がブラウザのアドレスバーに出ないため、共有もブックマークもできない
  - 検索エンジンにはフレーム内のページが単体で登録され、メニューのない状態で表示される
- `viewport` メタタグなし
- 文字コードが Shift_JIS
- Copyright 表記が 2003 年のまま
- 材質データが `material-data/` 以下の別ページに分散し、比較できない

## デザイン方針

### 色 — 原サイトからの継承
原サイトの `link` 属性に指定された `#191970`（ミッドナイトブルー）を主色としました。
フレームセット・全ページで一貫して使われている、事実上のコーポレートカラーです。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#191970` | `28.8% .144 272.8` | — |
| 本提案 `--mid` | `33% .125 273` | **0.2°** |

### 構成の軸 — 数値
この会社は**写真が1枚もありません**（原サイトの画像はロゴ・地図・郵便マークの3点のみ）。
一方で、他社にはない資産を持っています。**第三者機関による試験成績書**です。

そこで材質3種の実測値を1枚の比較カードに集約し、引張強さの棒グラフを添えました。
原サイトでは DZ-T6 / 4CH-T6 / 7A-F が別々のページに置かれており、
見比べるには行ったり来たりする必要がありました。

もうひとつの軸が「**7075 削り出しの代替**」という提案です。
原サイトの「取扱商品」ページには、鋳物に置き換える利点が4点書かれていました。
これは技術営業そのものの内容ですが、本文中に埋もれていたため、独立したセクションに引き上げています。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 材質データは原サイトの試験成績書ページから転記した実測値です
  （DZ-T6: 平成14年、4CH-T6: 平成13年12月、7A-F: 平成13年 の試験）
- **原サイトの「取扱商品」ページには引張強さ「430 n/m?」という記載がありますが、
  試験成績書の実測値は 443 N/mm² です。**本提案では試験成績書の値を採用しました。
  430 は概数、あるいは別ロットの値と思われます。**公開前にご確認ください。**
- 硬度も同様に、取扱商品ページの「130HB（当社試験）」に対し、
  試験成績書は 136HB です。本提案では第三者機関の値（136HB）を採用しています
- 資本金・従業員数・代表者名は原サイトに記載がないため、掲載していません
- 「製品紹介」ページは原サイトでも中身が空でした

## 写真について
原サイトに製品写真はありません。本提案も**写真なしで構成**しています。
実装時に鋳物の写真をご提供いただければ、材質カードの上部と冒頭に配置できる構造にしてあります。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。フレームは使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
