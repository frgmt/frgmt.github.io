# 有限会社ミトミ — リニューアル提案サイト

埼玉県蓮田市の精密プレス加工。既存サイト <http://www.mitomi-mfg.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 90点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- jQuery + Vegas（背景スライドショープラグイン）に依存
- ナビゲーションが画像（`btnhome.png` / `btncampany.png` など）
- 見出しも画像（`mojicompanyinfo.png` / `mojiourworks2.png` など）
- 「スマートフォンサイトはこちら」という**別サイトへの導線**がある
  → PC版とスマホ版の二重管理になっており、レスポンシブ化すれば一本化できます
- ファイル名の綴りが `campany.html`（company の誤り）

## この案件で最も価値のある発見：埋もれていた物語

原サイトの「Our Works」ページに、次の記述がありました。

> 弊社の技術力の始まりは、ハーモニカの音を出す弁作りでした。
> （中略）昭和40年に材料供給装置も無い時代に丸弁自動製作に成功しました。
> （中略）ピーク時は月産500万個生産しておりました。
> （中略）最近ではサッカーのJリーグでラッパの音が鳴り響いていました。
> その音を出していましたのがこの丸弁です。

**これは強力な材料です。**「精密プレス加工」という説明では伝わらない技術力が、
具体的な物と数字と情景で語られています。しかし原サイトでは、
画像見出しの下に流し込まれた小さな本文の一段落に過ぎませんでした。

本提案では**独立したセクション「丸弁の話」**として引き上げ、
ナビゲーションからも直接飛べるようにしました。見出しは
「ハーモニカから、Jリーグへ。」としています。

## デザイン方針

### 色 — ロゴから採色しました
原サイトの CSS は Vegas プラグインのものだけで、ブランド色の指定がありません。
そこでロゴ画像 `logo.png` をピクセル解析し、最頻色を採色しました。
製品写真の枠線にも同じ緑が使われており、これが実質のコーポレートカラーです。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ実測 `rgb(48,112,64)` | `49.0% .101 149.5` | — |
| 本提案 `--gr` | `43% .098 150` | **0.5°** |

**同じ緑系の他案件との差別化について。** 埼玉の内田製作所も緑（155°）です。
色相差は 5.5° しかないため、**版面の性格で分けました。**
内田は角丸6px・直線的な表組み中心の硬い版面、
本案は**角丸14px・円形の写真枠・ピル型のボタン**と、丸みを基調にしています。
「丸弁」という主題にも合っています。

差し色の `--amber`（`oklch(70% .13 72)`）は丸弁の真鍮色から採りましたが、
最終的に使用箇所がなかったため、トークンとしてのみ残してあります。

### 冒頭の構成を作り直しました
初稿では左に文章・右に写真の2分割としていましたが、同時期に制作した八光電機製作所と
**版面の骨格が同じ**になってしまいました（同じ2分割、同じ数値帯、同じ位置のラベル）。
色が違っても、構造が同じだと同じ会社の別ページに見えます。

そこで本案は**中央に丸弁を置いた縦組み**に変更しました。円形の主題に合わせて
写真をハロー付きの円で扱い、数値帯も罫だけの帯からカード型に改めています。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 設備3点（アマダ TP45T、ファナック10軸、ダイヘンTIG）は原サイトの記載どおりです
- 取引先9社＋「その他25社」は原文のまま。「三和シャッター工業」は正式表記の
  「三和シヤッター工業」に改めました
- **「防衛庁」は現在の「防衛省」に改称されています**（2007年）。認定は平成6年の
  出来事なので沿革では当時の「防衛庁」表記を維持し、FAQでは「防衛庁（現・防衛省）」
  と併記しています
- 原サイトの誤字「危機の定期導入」（機器の定期導入と思われる）は引用していません
- 従業員数13名は、原サイトの内訳（代表1・専務1・従業員4・パート7）の合計です。
  原サイトに合計値の記載はありません
- **依頼の流れは、原サイトの図（`nagareimage.png` / `kaihatuseisakunagare.png`）を
  参考にした一般的な進め方です。**図の文字が判読しきれなかったため、
  各ステップの文言は本提案で書き起こしています。**公開前に実際の流れをご確認ください。**

## 画像の扱い
原サイトの画像から、開閉装置3点、丸弁1点、社屋1点を採用しました。
ロゴ・ボタン・見出しの画像（文字を焼き込んだPNG）は不使用です。
社屋写真は掲載スペースの都合で今回は未使用としましたが、`assets/img/site.png` に
用意してあります。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。jQuery / Vegas は使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001/14001）／ LocalBusiness ／ WebSite ／ FAQPage
- MEO 対応: 第一製造に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
