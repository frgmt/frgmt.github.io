# 株式会社 ミクロ精工 — トップページ リニューアル案

現行サイト（http://www.microseiko.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,010px**。ブラウザが全体を約 **37%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **メタディスクリプションが無い** | 検索結果の説明文をGoogleが本文から拾って生成している状態です |
| 画像のalt属性 | 画像21点中 **16点に alt が無い** |
| **Copyright表記が「20XX」のまま** | テンプレートのプレースホルダが置き換えられずに公開されています |
| **トップページの本文が短い** | 実質 **526文字**。設備も工程も別ページにあり、トップからは何ができる会社か分かりません |

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは1,010px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。
**特に設備表の型式（YBM640V、J110AD-180H など）が読めなくなります。**

## 設計上の判断

### 署名的装置 ── 金型の合わせ面

この会社の価値は「金型からつくれること」です。
ファーストビュー右側に、**上型（キャビティ）と下型（コア）が閉じ、
その空隙が製品になる断面図**をインラインSVGで置きました。

上下の型は**本体厚46px・凹み20pxで完全に対称**に配置し、
合わせ面（y=100）が製品部の中心と一致することを計算で照合しています。
実測でも上下の型が同じ 335×84px で描かれることを確認しました。

### 配色 ── 青緑

現行サイトから画素採取した青緑 `#006666` = `oklch(46.2% .079 194.8)` が基準です。
面 `oklch(42% .086 195)`、文字 `oklch(36% .078 195)`。**色相差 0.2°**。
元の彩度が低い（.079）ため、わずかに上げて面として成立させました。

**195° は既存提案に無い色域です**（最も近いのはヒノデメタルの185°）。
色で十分に分かれるため、構成は工程を《途切れない帯》として素直に組んでいます。

### 見出し

「金型からつくるから、成形品まで責任を持てます。」を h1 にしました。
現行サイトのキャッチは「夢は、マクロ。金型制作から成形品までお応えいたします」で、
**社名（ミクロ）との対比は効いていますが、発注側の利点になっていません。**

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには加工製品例の写真がありますが
  小さいため、元データのご提供が必要です
- **「2020年10月 35周年」の起算点が不明です。**
  沿革では1970年創業（2020年で50年）、1981年法人設立（2020年で39年）であり、
  どちらとも合いません。**正しい創業年をご確認ください。**
  本提案では沿革の記載に従い「1970年創業／1981年株式会社設立」としています
- **検査設備の「実体顕微鏡 ニコン 5台」が、現行サイトに同じ行で2回記載されています。**
  合計10台なのか、重複掲載なのか判断できないため、
  本提案では**「5＋5」と原文どおり**に記載しました。正しい台数をご教示ください
- **従業員数23名は「30年5月現在」（2018年5月）**の記載です。最新値をご教示ください
- **Copyright表記が「20XX」のままです。**リニューアル有無にかかわらず、
  現行サイトの修正をお勧めします
- **対応可能な樹脂材質の記載がありません。**
  射出成形の引き合いでは必ず確認される項目です。明記を強くお勧めします
- **成形可能な製品サイズ・ショット数の目安がありません**
- 「加工製品例」の写真はありますが、**具体的な製品分野（自動車部品／電機部品など）が
  書かれていません**。可能な範囲でご教示ください

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

金型の断面図は**上下対称であることを計算で照合**しています。
射出成形金型は上下が合わさって製品をつくるものなので、
**非対称に描くと構造そのものの誤った説明になります。**
数pxのずれは見た目では気づけず、検査もすべて通ってしまうためです。
