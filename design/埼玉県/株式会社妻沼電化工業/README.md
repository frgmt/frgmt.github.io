# 株式会社 妻沼電化工業 — トップページ リニューアル案

現行サイト（http://www.platec-group.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## 対象について

スキャナの一覧では「（株）妻沼電化工業」として登録されていますが、
URL はグループ会社である**プラテックの統合サイト**を指しています。

現行サイトはプラテックグループ全体のサイトで、妻沼電化工業は
その中の「金属めっき部門」として `original6.html` 内に紹介されています。

本案は**妻沼電化工業を主語にした単独ページ**として構成しました。
グループの他2拠点は「グループ」の節で紹介し、樹脂めっきの依頼は
太田事業所へ取り次げることを明示しています。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで埼玉県内 **同率1位（107点）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |

現行サイトの中身は充実しています（社長メッセージ、詳細なライン一覧、
グループ沿革）。**内容ではなく器の問題**です。

## 設計上の判断

### 署名的装置 ── めっきラインの一覧表

めっきを依頼する側が決めるのは三点です。

1. どの浴で処理するか（シアン／ジンケート／カニゼン）
2. どの仕上げにするか（3価／6価、有色／黒色）
3. **その寸法が槽に入るか**

現行サイトにもこの表はありますが、`original3.html` の下部にあり、
グループ全体の説明文に埋もれていました。
本案では**幕開けの直後に置き**、有効主槽サイズを等幅で組んでいます。

### 「μmの薄膜」を、罫の細さで表す

この会社には先代社長から引き継いだスローガンがあります。

> 工業製品の付加価値アップを、表面処理というコア技術を使って、
> **μmの薄膜**で実現する。

これを受けて、本案は**極細の罫（1px）と広い行間**で組みました。
区画の分離に地色をほとんど使わず、罫の粗密だけで切っています。
角丸は 2px、ボタンの枠線も 1px です。

### 中央総業・アンド化工と同じ青紫域であることへの対処

| | 中央総業 | アンド化工 | 妻沼電化工業 |
|---|---|---|---|
| 色相 | 260° | 270° | **268°** |
| 彩度 | .155 | .150 | **.148** |
| 罫 | 1px | 1px | **1px（ただし区画も罫のみ）** |
| 署名的装置 | 全幅の資格台帳 | 三加工の段差 | **めっきライン表** |
| 行間 | 1.85 | 1.85 | **1.9（広め）** |

色相も彩度も近いので、**構成と余白**で差を付けています。
中央総業は全幅の暗い帯、アンド化工は段差のあるカード、
本案は地色を使わない罫だけの構成です。

### 色 — ロゴから採取

| 採取元 | 値 |
|---|---|
| ロゴ画像 `logo1.jpg` の画素（最頻出 1,307px） | `#1818a8` = `oklch(35.5% .213 268.5)` |

`--plate: oklch(40% .148 268)` — **色相差 0.5°**。彩度 .213 → .148。

## データの出所

ライン仕様・沿革・拠点情報はすべて
**現行サイトから取得した実データ**です。

- めっきライン一覧 … `original3.html` より
- 妻沼電化工業の会社概要・グループ各工場 … `original6.html` より
- ステンレス整面処理の説明 … `original3.html` より
- スローガン・社長メッセージ … `company.html` より
- グループ沿革 … `original6.html` より

### 確認が必要な項目

- **代表者名を妻沼電化工業単独としては記載していません**。
  現行サイトに載っているのはグループ代表（野澤剛史）で、
  妻沼電化工業の代表者が同一かどうか確認できませんでした
- 「プラテック つくば工場」（2006年開設）は沿革に記載がありますが、
  現在の工場紹介ページには載っていないため、**沿革にのみ残しています**
- 「Cライン」が一覧に無く A・B・D・N のみでした。現行サイトの記載どおりです
- ISO等の認証（記載が無いため未掲載）
- 営業時間（記載が無いため JSON-LD にも入れていません）
