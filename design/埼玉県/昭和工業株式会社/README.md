# 昭和工業株式会社 — トップページ リニューアル案

現行サイト（http://www.showa-kogyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **トップページに本文が無い** | `innerText` の長さ **0文字**。画像とテーブルだけで、検索エンジンが読む文章が存在しない |
| viewportタグ無し | スマホ実機UA（375px）で `scrollWidth` **980px**。等倍では収まらず縮小表示される |
| 文字コード | **Shift_JIS** |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| `<h1>` が無い | 全ページで **0個**。見出しの階層が機械に伝わらない |
| テーブルレイアウト | 会社案内ページで `<table>` **6個**。CSS以前の組み方 |

**「はみ出し 0px」は健全という意味ではありません。**viewportタグが無いため、
ブラウザが980px幅のページを375pxに縮小して表示しているだけです（shrink-to-fit）。
文字は小さく、指で拡大しないと読めません。

## 設計上の判断

### 写真を優先、図はその補助

現行サイトにあった**実際の工程写真2点**（コーティング加工機、加工後のロール）を
事業紹介の冒頭に置きました。実物の写真がある場合は、図よりも写真を優先しています。
ただし元画像が小さいため、拡大せず原寸に近い大きさで配置しています。

### 署名的装置 ── コーティングの断面

この会社の仕事は「基布に薬品を塗り、熱で被膜にする」ことです。
ファーストビュー右側に、**基布・樹脂被膜・熱処理の断面図**を線画で置きました。
ロール間を布が走り、上から薬品が落ち、被膜ができる——という工程そのものです。

インラインSVG。`stroke="currentColor"` なので配色に追随します。

### 構成 ── 縦の年表ではなく「層」

コーティングが層を重ねる仕事であることに合わせ、
数値も沿革も**横に伸びる帯**として積みました。
1934年から2017年までを等間隔の層として見せています。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真は現行サイトの2点のみです。**コーティング加工機（264×189px）と
  加工後のロール（189×129px）を借用しました。**いずれも解像度が低く、
  原寸のまま小さく置いています**（拡大するとぼやけるため）。
  大きく使える工程写真をご提供いただくか、撮影（別途お見積り）をご検討ください
- 「4拠点」は草加本社＋香港＋東莞＋ラヨーンの4つとして数えました。
  香港は販売会社のため、拠点の数え方はご確認ください
- 従業員数「約40名」は本社のみ。海外各社も各約40名と記載がありますが、
  合算すべきかは未確認です
- タイ拠点の正式名称が現行サイトに記載されていません
- 「27万m/月」は東莞150,000m＋ラヨーン120,000mの単純合計です

## 検証

実ブラウザで測定済み。

| 項目 | 結果 |
|---|---|
| 横はみ出し（1280 / 768 / 375 / 320px） | すべて **0px** |
| コントラスト（WCAG AA） | 不足 **0件** |
| タップ領域 44px（スマホ375px・320px） | 不足 **0件** |
| JavaScriptエラー | **0件** |
| インラインSVGの実描画 | **描画あり**（`getBoundingClientRect` で確認） |

コントラスト検査は、既知の値（白×黒=21／同色=1／#999×白=2.85）で
検査自体が機能していることを確認してから測っています。
