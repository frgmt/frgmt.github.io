# ヒノデメタル株式会社 — トップページ リニューアル案

現行サイト（http://hinodeco.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで縮小表示（等倍では収まらない） |
| 文字コード | Shift_JIS |
| jQuery | 1.8.1（2012年リリース） |
| TOPICSが最新2021年6月 | 5年間更新がない |
| 実績24点が画像の格子 | 材質と重量が**画像に焼き込まれておらず本文にはあるが、比較できない並び** |
| 全角の英数字 | 「ＦＣ・ＦＣＤ・ＦＣＶ」「ＩＳＯ　9001」 |

### 24点の実績が「並んでいるだけ」

`product.html` には自動車部品12点・建設機械部品12点の計24点が、
材質（FC250 / FCD400 / FCD450 / FCD500 / FCD700 / FCV350）と
重量（0.5kg〜50kg）つきで掲載されています。**データとしては良質です**。

しかし画像の格子に順不同で並んでいるため、
**「うちの部品（FCD450・20kg）は引けるか」**という問いに答えられません。

## 設計上の判断

### 署名的装置 ── 材質別の鋳造重量レンジ（対数目盛）

24点を材質ごとに集計し、**1本の対数目盛**（0.4kg〜60kg）の上に重ねました。

| 材質 | 重量域 | 点数 |
|---|---|---|
| FCD500 | 0.5 〜 15 kg | 4 |
| FCD400 | 0.8 〜 1.5 kg | 2 |
| FCD450 | 0.9 〜 35 kg | 5 |
| FCD700 | 1.2 〜 15 kg | 5 |
| FCV350 | 2 〜 5 kg | 2 |
| FC250 | 6 〜 50 kg | 6 |

FCD450 が最も広い域（0.9〜35kg）を覆い、FC250 が重い側（6〜50kg）を
担当していることが読み取れます。**帯の位置と長さは実重量から計算**しており、
装飾ではありません。

「この範囲外もご相談ください」と明示しています。掲載24点は実績の一部であり、
図が上限を意味すると誤読されないようにするためです。

24点の一覧そのものも、**軽い順に並べ替えた表**として第2節に残しています
（材質・英名・重量・分野の4列）。現行サイトは画像だったため、
テキストで持つこと自体が検索面で効きます。

### 色 ── CSSとロゴの両方で裏付けが取れた青緑

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#00847a` | 現行 CSS | `oklch(55.2% .097 185.6)` | **採用**（面 `oklch(44% .097 185)`、色相差 -0.6°） |
| `#088878` | ロゴ `img/title.png` の最頻出画素（4,348px） | `oklch(56.3% .100 180.6)` | 同系。上の裏付けとして使用 |
| `#0000ee` | リンク | — | 不採用。ブラウザ既定色 |

彩度は `.097` のままです（既に上限 .16 以下）。明度だけ 55.2% → 44% に
落として、白地の面と文字の両方で AA を取りました。

### hue 185 は本バッチで唯一

他社は 196〜228 の青か、145〜150 の緑です。**色相だけで既に分離できています**が、
装置と書体も重ねました。

| 軸 | 選択 |
|---|---|
| 地 | **白**。暗い全幅帯なし。節の区切りは淡い青緑のパネル |
| 署名的装置 | **材質別の鋳造重量レンジ（対数目盛）** |
| 書体 | **Noto Serif JP**（明朝）。1918年創業の声。丸ゴシックは「やまと工業」で使用済みのため避けた |
| 第二色 | **なし**。青緑一色で通す（鋳鉄の会社に色を足す理由がない） |

## データの出所

設備・実績・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- 実績24点（材質・重量・分野） … `product.html`
- 主要機械設備（溶解〜検査試験） … `machinery.html`
- 会社概要・沿革・関連企業・取引先 … `overview.html`
- ISO 9001 の登録番号と取得日 … `index.html` の TOPICS 欄
- 生産能力450t／月、工場規模 … `overview.html`

### 確認が必要な項目

- **設立年（法人化の年）の記載がありません**。1918年11月は「創業」で、
  当時の名称は「旭出工場」です
- **2006年6月「福山鋳造㈱が引継ぎ再スタート」**とあり、
  資本関係の変更があったと読めますが、詳細の記載がありません。
  本案では沿革にそのまま記載しています
- 従業員60名・資本金3,000万円は**時点の記載がありません**
- TOPICS の最新は2021年6月です。**2021年以降の設備投資や
  認証更新があれば追記が必要**です
- ISO 9001 の登録番号 QAIC/JP/0854 は2010年11月18日付です。
  **更新審査の記載がありません**
- 小林マシン株式会社は**資本金・設立年・業務内容の記載がありません**
  （住所と電話のみ）
- 実績24点のうち「コンパニオン」「ケーシング」は
  **同名で重量違いが2点ずつ**あります。原文のまま両方載せています
- 造型ラインの寸法「600×800×200/200」の後半（200/200）は
  上型／下型の高さと解釈しましたが、**原文に説明がありません**。
  本案では原文の表記をそのまま載せています
