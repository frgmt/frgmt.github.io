# KN村田産業株式会社 — コーポレートサイト リニューアル案

現行サイト: http://knms.co.jp/
（大阪府岸和田市に本社／埼玉県内に久喜工場・杉戸工場）

## この会社について

1938年8月創立。線材を切って成形し、釘とねじを起こす会社です。
あわせて木造住宅用の建築金物を製造し、自社の防錆処理（デュラルコート）を
施しています。木造住宅用建築金物のカナイグループの一員で、
商品の販売と問い合わせはグループの株式会社カナイが窓口となります。

年商83億円（2022年度決算）、従業員163名（2023年11月15日現在）。
会社としての数字は新しく、規模もあります。

## 現行サイトで見つかったこと

すべて実機（Playwright、iPhone 13 の UA）で測っています。

### 1. スマートフォンで 40% に縮む

`<meta name="viewport">` タグがありません。iPhone 13（画面390px）で開くと
980px 幅のまま表示され、実表示は **40%**。本文はほぼ読めない大きさになります。

```
viewport: なし
innerWidth: 980 / screen.width: 390 → 40%
```

### 2. トップの4ボタンのうち半分がどこにも着かない

トップに大きく4つのボタンが並んでいますが、自社のページに着くのは
そのうち2つだけです。

| トップのボタン | 実際の飛び先 |
|---|---|
| 会社情報 | `/company/index.html` — 生きている |
| 商品ラインナップ | `http://knms.co.jp/` — トップに戻るだけ |
| 採用情報 | `/company/recruit.html` — 生きている |
| お問い合わせ | `https://ssl.alpha-prm.jp/` — 接続を拒否される |

フッターのリンクはさらに外へ出ていきます。

| フッター | 飛び先 |
|---|---|
| 商品ラインナップ | `www.fujinittei.co.jp`（KNフジニッテイ） |
| お問い合わせ | `ssl.alpha-prm.jp/fujinittei.co.jp/inquiry.html` |

`/item/` `/contact/` はいずれも 404 を返します。
つまり自社サイトに、自社の製品一覧も問い合わせ窓口もありません。
製品を見ようとした人は、社名の違う会社のサイトへ送られます。

### 3. 更新が2016年で止まっている

ニュースリリースの最新は2016年1月15日（ZN90釘の着色変更）。
サイト自体は2013年11月のリニューアルとあります。
一方、会社概要に載っている数字は2022年度決算・2023年11月現在と新しく、
**中身は更新されているのに、それを載せる器が10年以上前のまま**です。

## この提案でしたこと

### 内容

現行サイトに散っている情報を1ページに集約しました。
会社概要は表を丸ごと転記し、営業品目・加盟団体・PL法補償・取引金融機関・
グループ会社まで残しています。ここは検索から見つかる情報の中心です。

工程（線材の受け入れ → 成形 → 表面処理 → 検査 → 出荷）は、
現行サイトに工程の説明がなかったため、事業内容の記載と
（公財）日本住宅・木材技術センター認定品への言及から組み立てています。
数値や固有名詞は足していません。

**久喜工場・杉戸工場の所在地は書いていません。**
現行サイトに記載がなく、推測で補うと誤りになるためです。
地図は本社（岸和田市松風町11-2）のみを表示しています。

### 見た目

- 現行サイトのブランド緑 `rgb(0,104,61)` をそのまま継ぎました。
  OKLCH に直すと `45.5% .109 157`。白地でコントラスト AA を満たすよう
  明度だけ `42%` に寄せ、**色相 157 は動かしていません**。
- 地はわずかに温かい紙色（`oklch(98.8% .005 85)`）。
  同じ緑系の既存提案（島野精機 153 / 東洋電源機器 162）とは
  地の温度と見出し書体（明朝）で区別しています。
- 署名的装置は「一本の線」。工程を縦一本の線と節で表しています。
  線材から一本の釘を起こす会社なので、線をそのまま図にしました。

### 写真

現行サイトから取得した実写を使っています（新規に作図していません）。

| ファイル | 出所 | 使いどころ |
|---|---|---|
| `factory-line.jpg` | `/common/images/mainvisual.jpg` | 冒頭 |
| `company.jpg` | `/company/images/idx_img01.jpg` | 製品 |

いずれも原寸で開いて内容を確かめたうえで alt を書いています。
再圧縮はしていません（元が小さく、かけると逆に太るため）。

## 検証

`docs/prospect-scanner/verify-site.mjs` で全項目通過。

- 横溢れ 320〜1920px すべて 0px
- コントラスト 全 AA
- タップ対象 すべて 44px 以上
- JS 無効時も全文（2,120文字）が読める
- reduced-motion 指定時も内容はすべて可視
- Web フォント 3種すべて `document.fonts` で loaded を確認
- 掲載した数値・固有名詞 17項目を、元サイトの本文と機械的に突き合わせ、
  **元サイトに無い主張は0件**

### 途中で直したこと

320px 幅でヘッダーが崩れ、社名が1文字ずつ縦に割れていました
（ヘッダー高 304px）。横溢れは 0px だったため自動チェックは通過しており、
実機幅のスクリーンショットを見て初めて分かったものです。
社名の折り返しを禁じ、430px 以下では英字併記と電話番号を畳むようにして
ヘッダー高 60px に収めました。
