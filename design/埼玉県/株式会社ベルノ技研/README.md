# 株式会社ベルノ技研 — リニューアル提案サイト

埼玉県新座市の光学・精密機器設計製作。既存サイト <http://www.verno-giken.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 90点）

このサイトは一見すると新しく見えます。HTML5 で書かれ、OGP も設定され、
WordPress で運用されており、URL も `/company` のようにきれいです。
**問題はスマートフォンです。**

- HTTPS 未対応
- **`viewport` メタタグなし** → スマートフォンで PC 版が縮小表示される
- **横スクロールが 616px 発生**（幅390pxで実測）。指で横に振らないと読めない
- レイアウトに `<table>` を16個使用
- jQuery 依存

つまり「PC で見れば普通のサイトだが、スマートフォンでは実質使えない」状態です。
問い合わせの多くがスマートフォン経由になっている現在、これは機会損失に直結します。

## デザイン方針

### 色 — ロゴから採色しました
CSS 内には目立ったブランドカラーの指定がありません（最頻色は `#000000`）。
そこでロゴ画像 `logo_png.png` をピクセル解析し、最頻色を採色しました。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ実測 `rgb(32,80,208)` | `48.5% .204 264.2` | — |
| 本提案 `--bl` | `45% .19 264` | **0.2°** |

**同じ色相の他案件との差別化について。** 同じ埼玉の吉野プレス工場も 264° ですが、
あちらは彩度 `.125` の落ち着いた紺です。本案は**彩度 `.19` を保った明快な青**とし、
「町工場の紺」ではなく「技術会社の青」として読めるようにしました。
色相が同じでも、彩度が違えば別の会社に見えます。

### 構成の軸 — 対応範囲
この会社の強みは、光学系の仕事で通常は分業される
**設計・製造・組立の3つを社内に持っている**ことです。

そこで「対応範囲」を最初のセクションに置き、4工程を矢羽根でつないだ帯にしました。
そのうえで「設計のみ／試作のみ／フルサポート」と、**途中で切れること**も明記しています。
原サイトではこの情報が業務内容ページの末尾の説明文に埋もれていました。

技術セクションでは、対応できる形状・材料・寸法をそのまま列挙しています。
問い合わせる側が最初に確かめたいのは「うちの仕様が通るか」だからです。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

**⚠️ 原サイトの資本金の記載に矛盾があります。**
沿革には「1980年5月 設立（資本金3500000円）」「1984年5月 株式会社に変更（資本金1000000円）」
とあり、**株式会社化で資本金が350万円から100万円へ減少**したことになります。
桁の誤記と思われるため、本提案では**1984年の資本金額を記載していません**。
会社概要欄の現在額（8,738万円）のみ掲載しています。**公開前にご確認ください。**

そのほか、銀行名を現在の商号に更新しました。

| 原サイトの表記 | 現在の商号 |
|---|---|
| 東京都民銀行 朝霞支店 | きらぼし銀行 朝霞支店（2018年統合） |
| 三菱東京UFJ銀行 新座志木支店 | 三菱UFJ銀行 新座志木支店（2018年改称） |

- 取引先8社は原サイトの一覧どおりです。ただし「ソニーセミコンダクタ株式会社」は
  現在のグループ体制と名称が異なる可能性があります（要確認）
- 従業員数15名と資本金は2008年時点の記載です

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。jQuery は使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- **横スクロール 0px**（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
  ※ 原サイトは幅390pxで616pxの横溢れ
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上
- JavaScript 無効時も全テキストが読める
- 内部リンクはすべて相対パス
