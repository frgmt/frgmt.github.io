# エスコウィンズ株式会社 — トップページ リニューアル案

現行サイト（http://www.escowinz.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| **画像が1枚もありません** | トップページの `document.images` が **0**。製品も事例も文字だけです |
| **メタディスクリプションが無い** | 代わりに**キーワードの羅列が本文の2行目に置かれています**（「エスコウィンズ,小俣,エスコ,ESCO,エネルギー管理…」）。これは2000年代のSEO手法で、現在は逆効果になり得ます |
| Copyright表記 | **2001-2016** のまま |

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 負荷曲線

この会社の仕事は「必要な分だけ回す」ことに尽きます。
ファーストビュー右側に、**24時間の消費電力**を
定速運転（破線・常に一定）とインバータ制御（実線・負荷追従）で対比し、
**その差の面積を塗った図**をインラインSVGで置きました。
塗られた面積が、そのまま削減量です。

座標は24時間を x=36〜296px、負荷0〜100%を y=160〜48px に線形写像して算出しています。
実描画は PC 406×254px（制御曲線 330×71px、削減面積 330×81px）。
定速線は水平なので高さ0pxで正しく描かれています。

### 配色 ── 黄緑を主役に

現行サイトから画素採取した黄緑 `#779801` = `oklch(63.2% .156 123.7)` が基準です。
面 `oklch(48% .126 124)`、文字 `oklch(41% .112 124)`。**色相差 0.3°**、明度を落として可読域へ。

同じく採取した青 `#006699`（hue 241）は既存提案に多い青域のため主役には採らず、
**署名的装置の枠にのみ**使いました。
**124° は既存提案に無い色域です。**

### 構成 ── 「減る」

省エネの会社なので、**数値は必ず「減った量」として示し**、
区画は上から下へ**粗い情報から細かい実測値へ絞り込む**構成にしています。

### 見出し

「ポンプとファンの回し方で、年600万円変わりました。」を h1 にしました。
現行サイトのキャッチは「確かな技術と自由な発想　新しい省エネルギーをご提案します」で、
**実績の数字が既にあるのに、それを使っていません。**

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトにも画像が1枚もないため、
  **コントローラ・インバータの実物写真、施工現場の写真をご提供いただく必要があります。**
  制御盤の写真があるだけで、説得力が大きく変わります
- **導入事例が2件のみです。**2001年創業でこの実績数は少ないと思われるため、
  掲載可能な事例の追加をお勧めします
- **下田海中水族館の削減金額600万円は「推定」と明記されています。**
  本提案でもその旨を併記しました
- **沿革の年が2ページで食い違っています。**
  産業技術総合センターへの移転が、会社方針ページでは2002年5月、
  会社概要ページでは2003年5月です。**本提案では2002年を採用しました**が、
  正しい年をご確認ください
- **従業員数の記載がありません**
- **キーワード羅列が本文の2行目に置かれています。**
  現在の検索エンジンでは効果がないばかりか、
  **読み手には意味不明な文字列に見えます。**リニューアル有無にかかわらず削除をお勧めします
- 「導入事例」ページのファイル名が `recruit.html`（採用情報）になっています。
  リンク切れではありませんが、**検索エンジンに誤解を与える可能性**があります

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 数値の照合

本ページに書いた数値は、すべて現行サイトの本文に実在することを機械的に確認しています。

- 郵便番号 334-0059 ／ ぶなの木5,090本 ／ 250万円 ／ 600万円 ／
  CO₂ 56トン ／ CO₂ 132トン ／ 電気工事業許可番号（般19第061796号）

**「ぶなの木5,090本」については、当方でも検算しました**
（56,000kg ÷ 11kg/本 = 5,091本。サイト記載と一致）。

### 作成中に見つけて直した誤り

**署名的装置のaria-label（読み上げ用の説明文）に、
キリル文字が1語混入していました**（「電力消費」と書くべき箇所）。
**目視では日本語に見えるため気づきにくく、
読み上げ環境でのみ破綻します。**
リポジトリ内の全ビルドをキリル文字の正規表現で走査し、
他に混入が無いことも確認しました。
