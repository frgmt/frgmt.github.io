# 株式会社大門機械 — トップページ リニューアル案

現行サイト（http://www.ohkado.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## 設計上の判断

### 署名的装置 ── 加工可能寸法の入れ子

大型加工の相談は**「そのワークが入るか」**で決まります。

現行サイトの設備表は門型6行・横型6行・縦型1行に分かれた数値の羅列で、
X8,500 という数字は書いてあっても、**それがどれくらい大きいのか**が
伝わりませんでした。

本案は最大機（三菱 MVR-40／X8,500 × Y4,400）を外枠とし、
主要4機の加工範囲を**実寸比で入れ子**に描いています。
図の縦横比も 8500:4400 に合わせているため、
図そのものが縮尺図として読めます。

あわせて**吊れる重さ**（天井クレーン 50t／20t／18t／15t／10t×2／5t×3）を
帯で示しました。大型加工では「入るか」と「吊れるか」が対になります。

### 色 ── 黒地から白地へ反転した

現行サイトの地は**黒**（`body { background:#000 }`）で、
唯一の色がオレンジ `#ff6600` です。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#ff6600` | 現行 CSS | `oklch(69.6% .204 43.5)` | **採用**（面 `oklch(52% .16 44)`、色相差 +0.5°） |
| `#f86808` | 見出し画像 `h2_news.gif` の画素 | `oklch(68.8% .195 44.7)` | 同系。上の裏付け |

**地を黒から白へ反転しています。** 2000年代の黒地は、
大型加工の寸法図を見せる用途に合いません。ただし反転すると
黒地で成立していた色がすべて壊れるため、灰は全部引き直しました
（`--ink` 系・`--rule` 系を白地基準で組み直し）。

彩度は `.204 → .16`（上限）、明度は `69.6% → 52%` に落として
白地で AA を取っています。

### hue 44 が2社目であることへの対処

エステックが `.155`／`.14` で同じ色相を使っています。

| 軸 | エステック | 大門機械 |
|---|---|---|
| 署名的装置 | 「どう考えて削ったか」（記述の装置） | **加工可能寸法の入れ子**（図の装置） |
| 書体 | — | **IBM Plex Sans JP**。数表が主役なので字面が均質なものを選ぶ |
| 地の温度 | — | **中立の灰（hue 250・青み）**。オレンジの補色側に置いて締める |
| 角丸 | — | **0px**。門型機のテーブルの角 |

## データの出所

設備・沿革・取引先・営業品目はすべて**現行サイトから取得した実データ**です。

- 門型・横型・縦型の全設備表 … `equipment.html`
- 営業品目11項目、装置製作実績5件 … `item.html`
- 会社概要・取引先・取引銀行 … `outline.html`
- 沿革（1961〜2009） … `history.html`
- 理念 … `concept.html`

### 確認が必要な項目

- **東芝 TSS20/40（NC複合ターニング φ4,000×2,600H）に
  「2009年7月導入予定」と注記されています**。16年以上前の記載であり、
  導入済みかどうかが判断できません。本案では設備一覧に載せていますが、
  **導入の可否を確認してください**
- **沿革の最終記載が2009年**です。以降16年分の設備投資・認証更新が
  反映されていません
- **ISO 9001 の認証機関・登録番号・更新状況の記載がありません**
- 従業員数34名・資本金3,000万円は**時点の記載がありません**
  （資本金は2005年の増資額）
- 天井クレーンの設置工場が「新工場」「N4」「N2」「N3」「S2」「S1」と
  記号で書かれていますが、**工場の呼称の説明がありません**。
  本案では原文の記号のまま載せています
- 5t クレーンは原文で「N4、S1、N4」と **N4 が2回**書かれています。
  3基という台数はそのままに、本案では「N4・S1」と記載しました
- 横型機の KBT11WDX-A は原文で Z軸が空欄です。本案でも「—」としています
- **代表者の交代**：1988年に大門倉世氏、2003年に大門俊之氏が就任した
  記載があります。現在の代表者は大門俊之氏です
