## 設計上の判断

### この会社の名刺は「温度の幅」である

装置メーカーに問い合わせる人が最初に確かめるのは、
**「うちの試験温度に届くか」**です。−70℃ から ＋300℃ という幅そのものが商品です。

そこで署名的装置を**「温度レンジの帯」**にしました。数値を並べるのではなく、
低温側の青から高温側の赤へ抜ける帯を引き、両端に −70 と ＋300 を置いています。
スクロールで帯が左から満ちます。

### 納入実績を隠さない

現行サイトでは会社案内ページの奥に「会社沿革」として埋もれていた
**28年分の納入記録**を、独立した節として表に起こしました。
アメリカ・中国・台湾向けの納入には「海外」の印を付けています。

装置メーカーにとって、これは説明文より強い証拠です。

### セクション構成

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 短い宣言 |
| 01 | 温度レンジ帯 | **グラデーションの帯**（署名的装置） |
| 02 | 取扱製品 | **仕様シート行**（`<dl>` を各行に埋め込む） |
| 03 | 納入実績 | **年表の表**（海外印つき） |
| 04 | 会社概要 | 仕様書的 `<dl>` |
| 05 | 問い合わせ | `<details>` + 地図 |

前回（潮工業）は「数値対の暗い帯」「編集的二段組」「縦のレール」でした。
今回は「グラデーション帯」「仕様シート行」「年表の表」。カード網は 0 個です。

### 色 — ロゴから採取

現行サイトの CSS には色指定がほぼ無いため、**ロゴ帯の画像
（`img/tit_01.gif`）を画素単位で解析**し、最頻出の有彩色を採りました。

| 採取元 | 値 |
|---|---|
| ロゴ帯のオレンジ | `#f04800` = `oklch(63.8% .213 37)` |

`--heat: oklch(58% .16 37)` / `--heat-ink: oklch(46% .148 37)` — **色相差 0°**。

**2トークンに分けた理由**：採取値 `#f04800` は白地に置くと **3.73:1** で
AA に届きません。面や罫には使えても、文字には使えない値です。
そこで面用（`--heat`）と文字用（`--heat-ink`、白地 6.0:1）を分けました。
1トークンで兼ねると小さな文字が必ず不足します。

補助として低温側に `--cold`（青）を置いていますが、温度レンジ帯と
ヘッダーの「−70℃」表示だけに限定しています（アクセントは1色のまま）。

地は純白。区画は暖かみのある `--sand`（97%）で分離しています。

### 動き（3種）

1. **進入** — スクロールで段階的に立ち上がる
2. **状態** — ヘッダーの影、罫が左から伸びるホバー、年表の行ホバー、`<details>` の矢印
3. **スクロール連動** — 温度レンジ帯が `clip-path` で左から満ちる

`prefers-reduced-motion` で帯は最初から全幅表示、内容は可視のまま。
