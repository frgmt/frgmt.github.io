**この会社の現行サイトは内容が非常に良い**という点を先に書きます。
最終更新は2026年1月21日で、令和8年の設備入れ替えまで反映されています。

**内容はそのまま活かせます。**

## 設計上の判断

### 署名的装置 ── 回転数とトルクの対

金型加工では「速く回す」と「太く削る」が両立しません。
そして**この会社の4台は、まさにその対の両端に置かれています**。

| 機械 | 回転数 | トルク |
|---|---|---|
| V300 | 20,000 min⁻¹ | 45.7 N·m |
| V33i | 20,000 min⁻¹ | 45.7 N·m |
| V77 | 12,000 min⁻¹ | 151 N·m |
| GF6 | 8,000 min⁻¹ | **575 N·m** |

GF6 のトルクは V300／V33i の **12.6倍**です。
現行サイトはこの数値を機械ごとの箇条書きで書いており、
**4台を持つ理由**（仕上げは速い機械、荒取りは力のある機械）が
読み取れませんでした。

本案は各機に**回転数とトルクの2本の帯**を並べ、
速い側を赤（標語の色）、力のある側を紺で塗り分けています。
V300 と GF6 を並べると、帯の形が反転しているのが一目で分かります。

### 色 ── 紺と赤、両方とも現行サイトから

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#000066` | 社名の文字色 | `oklch(23.1% .160 264.1)` | **主色に採用**（面 `oklch(38% .13 264)`、色相差 -0.1°） |
| `#cf0002` | 標語「日本の金型は世界一！」／リンク色 | `oklch(53.7% .220 29.1)` | **第二色に採用**（`oklch(50% .155 29)`、彩度 .220→.155） |

主色の明度を `23.1% → 38%` に**上げて**います。23% は白地では
「黒」に見えてしまい、色として機能しないためです
（暗すぎる主色は無彩色として読まれます）。

赤は**標語と「速さ」側の帯**にだけ使い、面には使っていません。

### hue 264 が青系で何社目かであることへの対処

| 軸 | 他の青系社 | 野口金型 |
|---|---|---|
| 地の温度 | 暖灰(40/60)・冷灰(230/250)・板紙(80)・鋳肌(265)・緑灰(150) | **わずかに黄みの灰（hue 95）**。紺の補色側 |
| 署名的装置 | 台帳・比較表・レンジ・入れ子図・分岐図 | **回転数とトルクの対**（1機に2本の帯） |
| 書体 | 明朝／角ゴ／丸ゴ／幾何学／可変 | **Shippori Mincho B1**（太めの明朝）。昭和元年創業の声 |
| 第二色 | 炉温・警告・受賞・納期・なし | **標語の赤を「速さ」側にだけ** |

### 確認が必要な項目

- **創業は「昭和元年頃」**と現行サイトに記載されています。
  「頃」がついているため、正確な創業年は不明です
- **資本金1,000万円は昭和45年の法人改組時の額**です。以降の記載がありません
- **従業員数の記載がありません**
- **ISO等の認証取得の記載がありません**
- 牧野フライス **FNC106-A20** は機種名のみで、
  **回転数・トルクの記載がありません**。本案では署名的装置の図に含めず、
  設備一覧にのみ記載しています
- V300 の導入は沿革に「令和8年」とあります。**令和8年は2026年**であり、
  最終更新日（2026年1月21日）と整合しています
- 現行サイトの `links.html` と `recruit.html` は本案では扱っていません
  （トップページのみの提案のため）
- 「昭和40年代の埼玉工場」の写真が `company.html` にあります。
  **社史の資産として使える**ため、実装時には掲載を推奨します
