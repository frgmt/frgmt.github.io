# 株式会社 潮工業 — トップページ リニューアル案

現行サイト（http://www.usio-co.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで埼玉県内 **同率1位（107点）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | **スマホでは980px幅の画面として描かれ、全体が約38%に縮小表示される**（後述） |
| テーブルレイアウト | CSS以前の組み方 |
| CSS | `style.css` は **159バイト**。実質レイアウトが無い |

### 「はみ出していない」が「読めない」— 実機での測定

端末のUAで再測定したところ、**横のはみ出しは0px**でした。
しかしこれは問題が無いという意味ではありません。

`viewport` タグが無いページをスマホのブラウザで開くと、
**幅980pxの仮想的な画面としてレイアウトしてから、画面幅に合わせて縮小**します。

| 測定項目 | 実測値 |
|---|---|
| 指定した表示幅 | 375px |
| 実際の `window.innerWidth` | **981px** |
| 表示倍率 | 375 / 981 ≒ **38%** |

つまり全体が **38%に縮んで**表示されます。はみ出さないのは
「画面に収まっている」からではなく「縮小されているから」です。

## 設計上の判断

### この会社の名刺は「寸法」である

問い合わせる人が最初に知りたいのは、値段でも技術説明でもなく
**「うちの品物が入るのか」**です。現行サイトでもこの数字は書かれていますが、
トップページと専用ページで**記載が食い違っていました**。

- トップページ … 「長さ７ｍ 高さ２ｍ 幅５５ｃｍ」
- 電気亜鉛メッキ専用ページ … 「長さ 7000mm × 高さ 1600mm × 奥行 550mm」

本案は**専用ページの値（1,600mm）を採用**しています。より詳細な専用ページの方が
新しい・正確である可能性が高いためですが、**提案時に要確認**です。

そこで署名的装置を**「寸法票」**とし、暗い帯の中に4つの数値だけを大きく置きました。
カードでも表でもなく、`key`と`value`が対になった寸法の一覧です。

### セクション構成

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 短い宣言（3行の見出し） |
| 01 | 寸法票 | **暗い帯の中の数値対**（署名的装置） |
| 02 | 三部門 | **編集的二段組**（見出しが左に張り出す） |
| 03 | JIS等級 | **実際の表**（当社基準の行を網掛け） |
| 04 | 沿革 | **縦のレール** |
| 05 | 会社概要 | 仕様書的 `<dl>` |
| 06 | 問い合わせ | `<details>` + 地図 |

中央総業（前回）と重ならないようにしています。前回は「全幅の表」「番号付き縦索引」
「横スクロール帯」でしたが、今回は「数値対の帯」「編集的二段組」「縦のレール」。
カード網は今回も 0 個です。

### 色 — 現行サイトから採取

現行サイトはロゴ画像を持たず、CSS も 159 バイトでほぼ白紙でした。
HTML 内で唯一の有彩色 **`#1489f5`** = `oklch(62.9% .187 253)` を採取しています。

`--zinc: oklch(44% .128 253)` — **色相差 0°**。明度を下げたのは、
採取値のままでは白地の文字として 4.5:1 に届かないためです（面と文字で
`--zinc` / `--zinc-ink` の2トークンに分けています）。彩度は .187 → .128。

地は純白。区画の分離は淡い青みの `--pool`（96.8%）で行い、
暗い帯は寸法票の1箇所だけに絞っています。

### 動き（3種）

1. **進入** — スクロールで段階的に立ち上がる
2. **状態** — ヘッダーの影、罫が左から伸びるホバー、`<details>` の矢印回転
3. **スクロール連動** — 寸法の数値に下線が伸びる（`animation-timeline: view()`）

`prefers-reduced-motion` で停止、内容は可視のまま。初期の `opacity:0` は
`.js` が有る時だけ適用し、2.6秒の保険タイマーで必ず可視化します。

## データの出所

掲載した数値・沿革・役員名・設備はすべて
**現行サイト（http://www.usio-co.com/）から取得した実データ**です。

- 会社概要・役員・資本金・従業員数・取引銀行・車両 … `goaisatu.html` より
- 最大寸法・JIS等級・電気亜鉛メッキの説明 … `mekki.html` より
- 創業年・沿革 … トップページおよび `goaisatu.html` より

### 確認が必要な項目

- **最大高さ 1,600mm か 2,000mm か**（前述のとおり現行サイト内で不一致）
- 郵便番号 335-0032（戸田市笹目北町の番地から補完。**要確認**）
- 営業時間（記載が無いため JSON-LD にも入れていません）
- 「創業50年」— 現行サイトは1976年起点で50年と記しています。
  1957年創立から数えると69年。本案は原文の趣旨どおり
  「大物・長物への特化から50年」と表記しました
