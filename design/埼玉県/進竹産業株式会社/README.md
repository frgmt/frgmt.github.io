# 進竹産業株式会社 — トップページ リニューアル案

現行サイト（http://www.shintake.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

### 選定に必要な二値が、6ページに散っている

高周波コネクタの選定は「50Ωか75Ωか」「何GHzまで保証されるか」で
ほぼ決まります。ところが現行サイトでは、この二値が
`smb_connector.html` `f_connector.html` `iec_connector.html`
`pin_jack.html` `sp_connector.html` `cable_assembly.html` の
**6ページに分かれて**おり、比較するには6ページを往復する必要がありました。

## 設計上の判断

### 署名的装置 ── インピーダンスと帯域で選ぶ表

6ページ分の「主な特性」を**1枚の表**に統合しました。
インピーダンスは 50Ω／75Ω を色チップで示し、
VSWR 保証帯域は **4GHz を全幅とした帯**で並べています。

帯は装飾ではなく凡例です。SMB の 4GHz が最も広く、
IEC の 860MHz が最も狭いことが、数字を読まずに分かります。

**5本の帯はすべて同じ長さのトラックに載せています。**
初版では行ごとに独立したグリッドにしていたため、
ラベルの文字数でトラック幅が 344px と 462px に割れ、
**棒の長さが比較できない状態**になっていました（実測で発見）。
`display:contents` で全行を親グリッドの同じ列に載せて修正しています。

### 赤を主色にした

現行サイトで**意図的に選ばれている色は電話番号の深紅 `#950700` だけ**でした。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#950700` | `span.tel`（電話番号・罫） | `oklch(42.3% .17 29.9)` | **採用**（面 `oklch(41% .155 30)`、色相差 0°） |
| `#000099` | ヘッダ帯 | `oklch(30.9% .214 264)` | 不採用。ブラウザ既定に近い純青で、面としての意図が薄い |
| `#fff47f` | 見出しの蛍光マーカー | `oklch(95.3% .139 104)` | ヘッダ帯の強調にのみ使用 |

彩度は `.17 → .155` に僅かに落としました。`.17` は白地の広い面では
「警告」に寄るためです。この会社の赤は警告ではなく看板です。

### hue 30 が2社目であることへの対処

| 軸 | ウチヤ・サーモスタット | 進竹産業 |
|---|---|---|
| 赤の使い方 | **警告の一箱に限定**（安全部品メーカーゆえ） | **罫・見出し・帯の全面**（看板の赤） |
| 地の色相 | — | **わずかに青みの灰（hue 250）**＝赤の補色側 |
| 署名的装置 | 動作温度で選ぶ比較表 | **インピーダンスと帯域で選ぶ表** |
| 書体 | — | **Zen Kaku Gothic New**（角ゴ）。電子部品の仕様書の声 |
| 角丸 | — | **0px**。完全な直角。コネクタ寸法図の声 |

## データの出所

特性値・材質・めっき・会社概要はすべて**現行サイトから取得した実データ**です。

- 主な特性（電気・機械特性） … `/parts/smb_connector.html` ほか5ページ
- シェル材料・めっき・型番 … 各製品ページの表
- 三つの強み（01〜03）の本文 … トップページ
- 会社概要・経営理念・品質環境方針 … `/profile/`
- 創業年・沿革 … `/profile/` のごあいさつ

### 確認が必要な項目

- **英語ページの電話番号がシンガポール（+65）になっています**。
  日本語版は 048-982-1118 です。本案は日本語版を採用しましたが、
  海外拠点の有無は現行サイトから判別できません
- **従業員数・工場所在地・設備一覧の記載が現行サイトにありません**
- ISO 9001 は取得と明記されていますが、**認証機関・登録番号・取得年の記載がありません**。
  ISO 情報ページ（`/iso/`）はナビにありますが、本文が空でした
- タイトルの「高周波コネクタ一筋40年」は下層ページの `<title>` の記載です。
  創業1960年から数えると65年になるため、**表記の更新が必要**と思われます。
  本案では年数表記を使わず「SINCE 1960」としています
- 代表者「進藤 有子」は `/profile/` の記載。就任年の記載はありません
- 寿命性の回数（SMB 500回／F 1000回／IEC 50回）は各製品ページの
  「主な特性」の代表値です。**個別品番で異なる旨が原文に注記**されており、
  本案でも同じ注記を表のキャプションに残しています
- PIN Jack と特殊コネクタには VSWR の記載がないため、表では「—」としています
