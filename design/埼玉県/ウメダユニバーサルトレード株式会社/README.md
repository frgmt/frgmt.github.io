現行サイト（http://www.gr-n.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。

## 設計上の判断

### 署名的装置 ── 集めて、出す

この会社の価値は、**買える場所を持っていること**と、
**いま手元にあること**の2つです。

そこで、7か国 → 上尾の事業所（1万本+） → 当日発送（15:00締切）という
流れをインラインSVGで1枚にしました。

**図に出したのは、現行サイトに国名が明記されている7か国だけです。**
原文は「米国等」と末尾に「等」がついているため、
**これがすべてではないことを図の中と説明文の両方に書いています。**
勝手に国を足していません。

原文から国名を機械的に抽出し、図に書いた7つと突き合わせて
**完全一致することを確認**しました。

### 配色 ── 227だが、地と罫で分ける

主色は現行サイトから画素採取した青緑 `rgb(0,120,155)` =
`oklch(53.4% .103 227)`。白地用に `oklch(42% .092 227)`。**色相差 0°**。

**この色相は既存提案の大谷技研（226・白地・`oklch(48% .105 226)`）と
ほぼ同じです。**どちらも現行サイトから採った色なので動かしません。
代わりに次の軸で分けました。

- 地を純白ではなく**紙寄りの温白色** `oklch(98.8% .005 88)` に
- 事業内容を**罫を詰めた「台帳」の行**として組む（大谷技研は表とカード）
- 版面を **1080px**（他より狭く）にして、卸売の帳票らしい密度にする

### 見出し

「7か国から集めて、15時までなら今日出す。」を h1 にしました。
現行サイトのキャッチは「印字装置用消耗品輸入卸売業のスペシャリスト」ですが、
**「スペシャリスト」は自称であって、確認できる事実ではありません。**
在庫本数と締切時刻は確認できます。

### SVG内の文字について

前回の案で、グラデーションの上に置いた白文字が
**検査を通過しながら実際には読めない**という不具合を出しました。
今回はハブの矩形を**単色**にし、位置によってコントラストが変わらないようにしています。

そのうえで、**SVG内の4種類の文字色すべてについて手で計算**しました
（検査ツールは SVG 内の文字を見ないため）。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。
