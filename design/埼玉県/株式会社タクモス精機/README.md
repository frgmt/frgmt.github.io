# 株式会社タクモス精機 — リニューアル提案サイト

埼玉県大里郡寄居町の省力化機器メーカ。既存サイト <http://www.takmos.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## この案件の特徴：下請けではなくメーカ

これまで扱った加工業と違い、この会社は**自社ブランド製品を持つメーカ**です。

- **クリーンパンチ**（1975年〜）— 板金金型の標準化をいち早く実現した金型システム。
  来年で発売50年になります
- **TDシリーズ**（1978年初期型〜）— サーミスタの温度特性選別装置。
  国内サーミスタメーカ各社に数十台の納入実績

しかも**特許7件・実用新案3件・意匠登録6件**を保有しています。
下請け加工業のサイトなら設備と加工範囲が主役ですが、
メーカのサイトは**製品が主役**です。構成をそこから変えました。

## デザイン方針

### 色 — ロゴと製品の色
主色はロゴから採色した `rgb(48,112,176)`（`oklch 53.5% .12 251.1`）です。
**TDシリーズの機体そのものがこの青で塗装されており**、サイトの色と
製品写真の色が一致します。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ・機体実測 `rgb(48,112,176)` | `53.5% .12 251.1` | — |
| 本提案 `--bl-br`（罫・面） | `53.5% .12 251` | **0.1°** |
| 本提案 `--bl`（文字） | `45% .115 251` | 0.1° |

**最初から2トークンで設計**し、自動検証を初回で全項目通過しています。
差し色の `--am`（琥珀）は原サイトの `#ffaa00` 由来で、クリーンパンチ側の
カード上辺と冒頭の菱形マークにのみ使っています。

### 構成の軸 — 二つのロングセラー
見出しは「半世紀売れている道具と、40年選び続ける機械。」。
クリーンパンチと TDシリーズを対のカードで並べ、
上辺の色（琥珀／青）で区別しました。

TDシリーズは**仕様表が原サイトに揃っていた**ため、測定精度 0.3%（実績0.1%）、
処理能力 50〜90個/分といった数値をそのまま定義リストにしています。
検査装置を探す技術者は、この数字で判断します。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- TDシリーズの仕様6項目は原サイトの表のままです
- 設備一覧31行は原サイトの表を転記しました。**原サイトでは板金加工設備の
  見出しが「放電加工設備」と誤記されていた**（放電加工の見出しが2回出現する）ため、
  内容から判断して「板金加工」に改めています
- 「クリーンパンチ50年目」は 1975年発売からの経過年数（2026年時点で51年目に入るため、
  正確には「50年を超えた」）として冒頭の数字に使っています
- 沿革・年表は原サイトになく、掲載していません
- **クリーンパンチの詳細仕様（型式・寸法・価格）は原サイトの深い階層にあり
  今回未取得**のため、概要のみの紹介としています

## 画像の扱い
原サイトの製品写真は TDシリーズ本体の1点のみ使用しました（黒背景で撮影されて
いるため、黒地のフレームで馴染ませています）。ナビゲーション・見出しの画像は
不使用です。クリーンパンチの製品写真は原サイトから取得できませんでした。
