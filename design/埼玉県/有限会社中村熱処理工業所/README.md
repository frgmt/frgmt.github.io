## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |

| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個**。文書構造が検索エンジンに伝わりません |
| テーブルレイアウト | `<table>` **5個** |
| 画像のalt属性 | 画像13点中 **5点に alt が無い** |
| Copyright表記 | **2009年**のまま |
| **トップページが休業日のお知らせだけ** | 8件の新着情報がすべて営業日・休業日の告知で、**何ができる会社なのかがトップに書かれていません** |

## 設計上の判断

### 熱処理の提案は3件目です

既に**関東熱処理株式会社**（色相60°）と**株式会社上島熱処理工業所**（230°）の
提案があります。本件は264°で色は分かれますが、業種が同じなので構成でも分けました。

この会社の特徴は「**4工場・22処理・8社認定**」という受け皿の広さです。
そこで、**すべてを数えられる表として組み**、
区画は必ず**4分割か2分割**にしています（奇数分割を使わず、4工場に揃える）。

### 署名的装置 ── 温度帯

熱処理は処理ごとに温度域が違います。
ファーストビュー右側に、**−150℃〜1,250℃の1本の軸に6つの処理の温度域を帯で**
描きました。サブゼロが左端、真空焼入が右端に来ます。

座標は `x = 42 + (T + 150) / 1400 × 258` で機械的に算出しています。
熱の側（高周波・浸炭・真空）だけ暖色にし、他は基準色の濃淡で分けました。
実描画は PC 412×258px、帯6本が 19 / 119 / 10 / 24 / 12 / 24px（実測）。

### 配色

現行サイトから画素採取した濃紺 `#000040` = `oklch(16.8% .116 264.1)` が基準です。
ただし**暗すぎて面に使えない**ため、同色相のまま明度を上げ、
面 `oklch(35% .108 264)`、文字 `oklch(30% .100 264)` としました。**色相差 0.1°**。

### 見出し

「−80℃から1,100℃まで、4つの工場で受けます。」を h1 にしました。
現行サイトのトップには**見出しに相当する文がありません**
（メタディスクリプションには「あらゆる熱処理と確かな技術」とあります）。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した誤り

1. **熱処理認定の社数を「7社」と誤って書いていました。**
   沿革から認定取得の行を機械的に抽出して数え直したところ、
   **正しくは8社**でした（東京計器を数え落としていた）。
   見出し・数値・メタディスクリプションの3箇所を修正しています。
   **この数字は会社の信用を示すものなので、少なく書くことは実績の過小申告になります**
2. **温度帯の目盛が0℃始まりでは、サブゼロ処理（−80℃）の帯が幅0pxになっていました。**
   軸の下限を−150℃に広げて解消しています。
   計算で全6帯の幅を出して確認しなければ、
   「帯が1本描かれていない」ことに気づけませんでした
