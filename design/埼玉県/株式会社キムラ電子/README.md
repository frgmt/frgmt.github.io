# 株式会社キムラ電子 — トップページ リニューアル案

現行サイト（http://www.kimuradenshi.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

### `©20XX` と `newpage1.htmlへのリンク`

現行サイトのフッターには **`copyright©20XX`** とあり、
テンプレートのプレースホルダがそのまま残っています。
同じくフッターに `newpage1.htmlへのリンク` `newpage3.htmlへのリンク` という
**リンクテキストを書き換え忘れた項目**が3つ露出しています。

これは中身の問題ではなく仕上げの問題ですが、
取引先が最初に見る画面としては損をしています。

## 設計上の判断

### 署名的装置 ── 電圧制御が効く3つの市場

この会社の構造は珍しく単純です。**技術は1つ（電圧制御）、出口が3つ**。

- 2輪車 … レギュレーター／レクティファイア、電子ウィンカーリレー
- 汎用（船舶・発電機） … トラマグ、レギュレーター／レクティファイア
- 家電（インバーターモータ） … IPM、アクティブフィルタパワーモジュール

現行サイトは製品名の箇条書きで並んでいるだけで、
**なぜこの3分野なのか**が見えませんでした。

本案は「電圧制御」を中央の一枠に置き、そこから3つのカードに分岐させています。
2輪車のバッテリー電圧を安定させる技術が、そのまま船舶へ、
そしてインバーターエアコンへ広がった ── その筋が図で読めます。

IPM の **15〜50A**、アクティブフィルタの **1.5〜3kW** は、
この会社が公開している数少ない定量値なので帯で添えました。

### 色 ── サイト名の水色

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#6b99e0` | サイト名 `KIMURA ELECTRONICS.LTD.` の文字色 | `oklch(68.0% .117 258.8)` | **採用**（面 `oklch(45% .115 259)`、色相差 +0.2°） |
| `#666666` | 本文 | — | 無彩色 |

彩度は `.117` のまま据え置きです（既に上限 .16 以下）。
明度だけ `68% → 45%` に落として、白地の面と文字で AA を取りました。

### 青が何社目かであることへの対処

| 軸 | 他の青系社 | キムラ電子 |
|---|---|---|
| 地の温度 | 暖灰(40/60)・冷灰(230/250)・板紙(80)・鋳肌(265) | **わずかに緑みの灰（hue 150）**。青の反対側に置く |
| 署名的装置 | 台帳・比較表・レンジのバー・入れ子図 | **1つの技術から3つの市場への分岐図** |
| 書体 | 明朝／角ゴ／丸ゴ／幾何学サンセリフ | **Murecho**（可変ゴシック）。基板の実装図のような均質な字面 |
| 第二色 | 炉温・警告・受賞・納期 | **なし**。水色一色 |
| 角丸 | 0〜6px | **8px**。基板のコーナーR |

## データの出所

製品仕様・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- IPM の 15〜50A、アクティブフィルタの 1.5〜3kW … `service.html`
- 会社概要・取引先・関連会社・取引銀行 … `company.html`
- 社是「先見積極」・品質方針・基本理念・社長挨拶・沿革 … `concept.html`
- 設備の導入時期（チップマウンター等） … `concept.html` の沿革と `index.html` の NEWS

### 確認が必要な項目

- **従業員97名は2022年3月現在**の記載です
- **NEWS の最新は2022年5月**（チップマウンター増設）。
  以降3年分の設備投資・出来事が反映されていません
- **ISO等の認証取得の記載が現行サイトにありません**
- **工場の所在地・棟数の一覧がありません**。沿革から
  第1〜第3工場、倉庫棟、資材倉庫棟の存在は読めますが、
  現在の構成（2001年に第1・3工場棟と事務所棟を併合）が明示されていません
- 関連会社「株式会社ファースト」はサービス付き高齢者向け住宅
  「カーサファースト」を運営しており、**現行サイト内（`newfolder3/`）に
  そのページが同居**しています。本案は電装品事業のみを扱い、
  関連会社として名前のみ記載しました。**別サイトへの分離を推奨**します
- 取引銀行の記載に「群馬銀行**銀行**深谷支店」という重複があります。
  本案では「群馬銀行 深谷支店」としています
- 現行サイトの `law.html`（特定商取引法に関する記述）は
  **通信販売を行う場合に必要な表示**です。電装品のB2B製造業で
  掲載が必要かどうかは確認が要ります
