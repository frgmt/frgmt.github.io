# 株式会社省栄プリント製作所 — トップページ リニューアル案

現行サイト（http://syoeiprint.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **995px**。ページ全体が **38%** に縮小されて表示されます |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |

**このサイトは、中身の手入れが行き届いています。**
jQuery は **3.7.1**（現行系列）で、設備の導入履歴も **2023年7月**まで更新されています。
h1 も1つ、メタディスクリプションも適切です。

**取り残されているのは、スマホ対応だけです。**

### 38%に縮小されるということ

viewportタグが無いため、iPhoneは995px幅のページを375pxの画面に押し込みます。
横スクロールは出ませんが、**文字がおよそ3分の1のサイズ**になります。

プリント基板の発注担当者が確認したいのは、
**「両面2日」「4層3日」「175μ」「0.6mm」「1200mm」**といった数値です。
これらが読めない大きさで表示されています。

### www の有無でリンク先が分かれています

`www.syoeiprint.co.jp` を開くと、ページ内のリンクはすべて
`www` の無い `syoeiprint.co.jp` を指しています。
**クローラから見ると同じ内容が2つのアドレスに存在する状態**です。
どちらかへ 301 リダイレクトで統一することをお勧めします。

## 設計上の判断

### 署名的装置 ── 4層基板の層構成

プリント基板の本質は、銅箔・プリプレグ・コアを積層して1枚の板にすることです。
ファーストビュー右側に、4層貫通基板の断面をインラインSVGで描きました。

**コアとプリプレグの厚みの比（5対1）は実寸どおりです。**
ただし銅箔35μm、レジスト20μm をそのまま同じ縮尺で描くと 1.8px となり、
**線としても見えません。**そこで表示上の最小の厚みを与え、
**その事実を図の下に明記しています。**

| 検証項目 | 結果 |
|---|---|
| 9層の高さの合計 | 想定 180px に対し **180.0px（一致）** |
| コア／プリプレグの描画比 | 5.012（実寸比 5.000 と**一致**） |
| 実描画（PC） | 418×344px、**矩形13個すべてが実サイズで描画** |
| 320px 時の最薄層 | 4.4px（**視認可能**） |

### 配色 ── レジスト緑

主色は現行サイトから画素採取した深緑 `rgb(0,104,55)` =
`oklch(45.4% .115 153.9)` が基準です。白地で読ませるため
`oklch(40% .102 154)` に。**色相差 0.1°**。

これは**ソルダーレジストの緑そのもの**で、この業種にとって必然の色です。
緑域（143〜162）は既存提案に5社ありますが、いずれも地は白系で共通のため、
**署名的装置の「型」で分けました**。他社が波形・時計回り・層といった
運動や単層を扱うのに対し、ここは**積層の断面**です。

層の色分けには銅の色（hue 62）を使い、緑一色にしていません。

### 構成

**何ができるか（納期）→ どこまで対応できるか（仕様）→ 困ったとき（基板復元）
→ どう作るか（工程）→ 何で作るか（設備）**の順に、外側から内側へ積んでいます。

「データを頂いて、両面2日。」を h1 にしました。
現行サイトの h1 は「プリント基板の試作・量産なら埼玉県所沢市の
省栄プリント製作所におまかせください。」ですが、
**これは検索語の羅列であって、読み手への約束ではありません。**
