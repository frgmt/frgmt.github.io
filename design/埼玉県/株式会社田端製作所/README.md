現行サイト（http://www.tbmfg.co.jp/tabata/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

このサイトは、他社とは**不具合の型が違います**。viewportタグはあります。
問題はその中身です。

```
width=device-width, initial-scale=1.0, minimum-scale=1.0,
maximum-scale=1.0, user-scalable=no
```

**ピンチズームが禁止されています。**

| シグナル | 実測 |
|---|---|
| **ズーム禁止** | `maximum-scale=1.0, user-scalable=no` |
| **表が画面に入らない** | 設備ページの表は最大 **708px**。iPhone 13 の表示幅は **390px** |
| **本文 13.12px / 最小 10.1px** | 小さいうえに、拡大できません |
| **HTTPS完全未対応** | `www.tbmfg.co.jp` `tbmfg.co.jp` のどちらも https で接続できません |

### 「読めない」と「拡大できない」が重なっています

ズーム禁止だけなら軽微です。表が画面より広いだけでも、
普通は指で広げれば読めます。

しかしこの2つが重なると、**読む手段がなくなります**。

そして読めなくなっているのは、この会社の最も強い情報です。

- 日立精機 HG400-11APC：400角パレット**11面**、工具**120本**
- オークマ MC561V：傾斜円テーブル付き**5軸制御**
- マシニングセンター7台・NC旋盤7台の型式と加工範囲

WCAG 1.4.4（テキストの拡大）の観点でも、`user-scalable=no` は避けるべき指定です。
本提案では**この指定を外し**、表は横スクロールする器に入れました。

## この提案で変えたこと

### 1. 「11面」を図にする

400角パレット11面という設備は、この規模の会社では珍しいものです。
けれど文字で「11個の400角パレット」と書かれても、何のことか伝わりません。

**11個のパレットを円周上に等間隔で配置した図**を冒頭に置きました。
割出角度は 360° ÷ 11 = **32.7273°**。図もその角度で描いています。

### 2. 夜間無人運転を主題にする

現行サイトの事業内容ページには、こう書かれています。

> 11個の400角パレットに治具建てすることにより、夜間をユージアリーとしています。
> 生産準備に若干の時間を要するものの原価低減には絶大な威力を発揮しており、
> お客様のコストダウンに貢献できます。

これは発注側にとって**単価の話**です。ページの中ほどではなく、
見出しに持ち出しました。

### 3. 設備表を、横スクロールする表として組み直す

マシニングセンター7台・NC旋盤7台・研磨機・測定器を、
型式・主軸回転数・加工範囲・備考・メーカーまで含めて転記しました。
スマホでは表だけが横にスクロールし、ページ本体は動きません。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（4,011文字）
- **ピンチズームは禁止していません**（`user-scalable=no` を使っていません）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
  （設計時の配色計算では最小 6.10:1、図中のパレットは白地に対して 5.79:1）
- タップ対象はすべて44px以上

## 配色について

基調の青は、**現行サイトで実際に使われている色**
`rgb(29,79,144)` = `oklch(43.1% 0.120 256.5)` から採りました。
この色は白地で 8.23:1 あり、そのままAAを満たすため、
明度・色相ともほぼ変えずに使っています。
地の白は暖色（hue 70）へ振りました（既存の青系ビルドがいずれも
無彩の地を使っているため、色相ではなく地の温度で分けています）。
