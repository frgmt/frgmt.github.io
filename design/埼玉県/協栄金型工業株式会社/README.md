### この会社は「作りが良い」側の候補です

先に書いておくと、**現行サイトの構成そのものは悪くありません**。
会社案内動画があり、製品ギャラリーがあり、生産フローの図があり、
Copyright も 2026 に更新されています。今回調べた候補の中では
最も手が入っているサイトです。

問題は2点に絞られます。**viewport タグが無いためスマートフォンで
縮小表示になること**と、**HTTPS 非対応**であること。
この2つは中身の良さと関係なく、訪問者の第一印象を確実に損ないます。

## 設計上の判断

### 署名的装置 ── 磨き番手と二次加工の対応表

リフレクター金型は**磨きの番手**で決まります。

現行サイトの `products.html` には6つの実績が、それぞれ
「磨き #14,000 鏡面磨き／二次加工 直接蒸着／特記 キャビ駒 真空焼入れ材」
のようにカード形式で書かれています。**データとしては良質です**。

しかしカードが縦に並んでいるだけなので、
**「#3,000 と #14,000 で何が違うのか」**が読み取れません。

本案は部位・磨き・二次加工・型材の4列にまとめました。
表にすると、**#14,000 は必ず直接蒸着とセットで、
そのときキャビ駒に真空焼入れ材を使う**という規則が見えます。
#3,000 は間接蒸着で、型材の指定がありません。

番手の比を帯でも添えました（#14,000 を全幅、#3,000 は 21.4%）。

### 確認が必要な項目

- **従業員数の記載が現行サイトにありません**
- **ISO等の認証取得の記載がありません**（自動車部品の金型メーカーとしては
  IATF 16949 等の有無が問われる可能性があります）
- **沿革が1992年で止まっています**。34年分の設備投資が反映されていません。
  設備表には iQ500・V33i・hyper CAD-S など明らかに1992年以降の機械が
  並んでいるため、**沿革の更新が必要**です
- 敷地・総建築面積が現行サイトで **「905m3」「854m3」** と
  体積の単位で書かれています。**面積（m²）の誤記**と判断し、
  本案では ㎡ としました
- 創業者は「関 猛」、現代表取締役社長は「関 則幸」です。
  **就任年の記載がありません**
- 「40年以上プラスチック金型の業務に携わって」は社長挨拶の記載です。
  1972年創立から数えると54年になるため、**表記の更新が必要**と思われます。
  本案では年数表記を使わず「SINCE 1972」としています
- CAD/CAM の TAM-BOY と DMCシステム スーパー平次は
  現行サイトで**「(旧)」と付記**されています。本案でもそのまま残しました
- 本社（浦和区常盤）と工場（岩槻区上野）が離れています。
  **本社に電話番号の記載がありません**（記載は工場の番号のみ）
