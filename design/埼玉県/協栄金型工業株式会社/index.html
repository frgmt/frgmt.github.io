どこまで磨くかで、型が変わります

リフレクター金型は磨きの番手で決まります。#3,000 と #14,000 では別物であり、蒸着が直接か間接かで型材の要件も変わります。現行サイトでは製品カードの中に散らばっていた条件を、1枚の表にまとめました。

01 — STRENGTHS選ばれる4つの理由

01 — PRECISION

R0.1〜R0.3レベルの高精度加工

複雑な3次元曲面形状も、小径の刃物で高精度・高品質の磨きレス加工を実現します。反射や屈折が光学設計により緻密に計算された製品として機能させるため、レンズ金型は高精度である必要があります。さらなる高精度金型の製作に力を入れています。

02 — COMPLEXITY

複雑形状への対応力

新製品の開発段階から関わる金型では複雑形状のご要望を多くいただきます。長年培った金型のプロの目線から成立性の検討やご提案をさせていただき、複雑困難な製品も金型として完成させる自信があります。デザイン性の高い製品にも対応します。

03 — INTEGRATED

設計から自主トライまで

設計から自主トライ、納品まで一貫生産で金型製作をサポートしています。一貫生産をすることで、お客様には安心して金型製作を委託いただいています。射出成形機（東洋機械金属 Si-350-6S）を自社に備え、自主トライを行います。

04 — TRACK RECORD

信頼と安心

創業から複雑な自動車照明部品の金型製作に携わってきました。常に「高精度」「高品質」「複雑形状の成立」を求められてきました。こうした長い経験を生かした金型を製作することで、お客様に信頼と安心を提供し続けています。

05 — CONTACTお問い合わせ

開発段階からのご相談も歓迎します。成立性の検討からお手伝いします。

どのくらい細かい形状に対応できますか？

R0.1〜R0.3レベルの高精度加工に対応します。複雑な3次元曲面形状も、小径の刃物で高精度・高品質の磨きレス加工を実現します。反射や屈折が光学設計により緻密に計算された製品として機能させるためには、レンズ金型は高精度である必要があるためです。

鏡面磨きの番手はどこまで対応できますか？

#3,000 と #14,000 の実績があります。#14,000 鏡面磨きは直接蒸着を行うリフレクターやベゼルに用い、キャビ駒に真空焼入れ材を使用します。#3,000 鏡面磨きは間接蒸着のリフレクターに用いています。蒸着面にシボ加工を施した実績もあります。

どんな製品の金型を作っていますか？

プラスチックレンズ金型（ヘッドライトレンズ、リヤコンビライトレンズ、導光インナーレンズ、フォグランプレンズ、室内灯レンズ）、ランプ関連部品金型（エクステンション、リフレクター、ベゼル、ハウジング）、その他の自動車用部品の金型（ドアミラー部品、ワイパー部品、内装部品（ピラー等）、FAN）です。

設計から納品まで頼めますか？

設計から自主トライ、納品まで一貫生産で金型製作をサポートしています。生産フローは、製品データ → 金型設計 → 加工 → 金型仕上げ・組立（ASSY）・調整 → 検査／測定 → 自主トライ → 納品です。設計から自主トライまでの工程表もご説明しています。

焼入れ金型も作れますか？

作れます。ドアミラーステーの実績では、樹脂材がガラス入りのため型材質をすべて STAVAX とした総焼き入れ型を製作しました。硬度 HRC52、型構造は4方向スライド構造です。

複雑な形状でも相談できますか？

新製品の開発段階から関わる金型では複雑形状のご要望を多くいただきます。長年培った金型のプロの目線から成立性の検討やご提案をさせていただき、複雑困難な製品も金型として完成させます。デザイン性の高い製品にも対応します。
