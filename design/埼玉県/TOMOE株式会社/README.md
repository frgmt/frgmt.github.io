# TOMOE株式会社 — トップページ リニューアル案

現行サイト（http://www.tomoe-toso.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **スマホ実表示 25%** | 実機UA（375px）で `scrollWidth` **1,500px**。**これまで調査した114社の中で最も小さい表示**です |
| **`<html>` 自体が幅固定** | viewportタグは書かれていますが、`<html>` 要素に `width:1500px` が指定されています |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |

### タグはあるのに、効いていません

`width=device-width` と宣言されているため、
**ブラウザは「スマホ対応済み」と判断して縮小をやめます。**
ところが `<html>` が1500px固定なので、レイアウトビューポートが1500pxに広がり、
**PCの画面をそのまま375pxに押し込んだ状態**になります。

実機のスクリーンショットで確認しました。
**4工場の電話番号も、事業紹介の本文も、読める大きさではありません。**

**`<html>` に直接幅を指定しているのは、この型の中でも最も重い例**です。
CSS の1行を消せば直る類のものではなく、レイアウト全体の組み直しが必要です。

## 設計上の判断

### 署名的装置 ── 3工場・合計19ライン

この会社の強みは「ラインの数」です。
そこで、工場ごとの列に**ライン1本＝棒1本**で積みました。

描画後の実測で、**棒が19本あり、x座標ごとに 8／4／7 に分かれること**を
確認しています。**原サイトの番号（1〜19、欠番なし）と一致**します。

### 配色 ── 既存の赤と、どう分けたか

主色は現行サイトから画素採取した赤 `rgb(224,18,4)` =
`oklch(57.4% .229 29.8)`。白地用に `oklch(46% .185 30)`。**色相差 0.2°**。

**この色相は、既存提案の北陸軽金属工業（hue 28）とほぼ同じです。**
どちらも現行サイトから採った色なので、色は動かしません。
代わりに次の軸で分けました。

| 軸 | 北陸軽金属工業 | TOMOE |
|---|---|---|
| 地 | ほぼ白 `.004 28` | **明確な暖色** `.010 50` |
| 署名的装置 | 消える工程（引き算） | **並ぶライン（足し算）** |
| 構成の中心 | 技術の説明 | **お客様の声を大量に並べる** |

### 見出し

「3工場に、19本の塗装ライン。」を h1 にしました。
現行サイトのキャッチは
「創業70年『金属焼付塗装』と『建築塗装』のことなら」ですが、
**年数と業種だけでは、他社との違いが分かりません。**
