# 関東熱処理株式会社 — トップページ リニューアル案

現行サイト（http://kannetu.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか

見込み客スキャナで **103点（Aランク）** と判定されています。
現行サイトには「2026年1月 リニューアルしました」との記載がありますが、
**技術的な陳腐化シグナルは残ったまま**です。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |

## 設計上の判断

### 署名的装置 ── 炉の台帳

熱処理を依頼する側が最初に確かめるのは
**「その寸法が炉に入るか」「その温度が出せるか」**の二点です。

現行サイトではこの情報が工場ごとの3ページに分散しており、
比較するには3ページを行き来する必要がありました。
本案は**6つの炉を1画面に集め**、有効寸法と常用温度を並べています。

温度は数字だけでなく**帯**でも示しました。これは装飾ではなく凡例で、
スクロールすると帯が左から満ちます。

### 北進産業と色相が近いことへの対処

採取色 `#006699` は色相 **240.8°**、直前に作った北進産業は **235°** で、
わずか 6° 差です。スキルの指示どおり色相は動かさず（±10°以内が原則）、
**別の軸で差を付けました**。

| | 北進産業 | 関東熱処理 |
|---|---|---|
| 地の温度 | 冷たい青み（hue 235） | **暖かいグレー（hue 60）** |
| 署名的装置 | 暗い帯の設備台帳（表） | **炉のカード＋温度帯** |
| 書体 | Zen Kaku Gothic | **BIZ UD明朝＋ゴシック** |
| 副色 | なし | **炉温を示す fire 系3色** |

熱処理屋なので地に赤みを一滴入れています。同じ「青の会社」でも
並べれば別会社に見えます。

## データの出所

炉の仕様・沿革・取引先はすべて**現行サイトから取得した実データ**です。

- 炉の有効寸法・温度・熱源 … `toda.html` / `toch1.html` / `toch2.html` より
- 会社概要・取引先 … `infor.html` より
- 沿革 … `histo.html` より
- 部門の技術説明 … `princ.html` より
- ISO認証範囲 … `iso.html` より

### 確認が必要な項目

- **本社の郵便番号に現行サイト内で不一致**があります。
  `infor.html` は 335-0022、`toda.html` は 355-0022。
  戸田市の郵便番号は 335 で始まるため **335-0022 を採用**しましたが、要確認です。
- 「48年」は創業1977年から2026年時点での年数です
- 溶体化炉4基・時効炉5基（`princ.html` 記載）と、
  `toda.html` の炉別内訳（溶体化1+2+1=4基、時効2+2+1=5基）は一致しています
- 沿革の平成17年・29年・令和4年の項目は現行サイトで内容が
  途切れていたため**掲載していません**
- 営業時間（記載が無いため JSON-LD にも入れていません）
