## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。**鉄道の安全に関わる会社のサイトが「保護されていない通信」と表示されます** |
| **トップページの本文が短い** | 実質 **278文字**。事業内容ページも339文字で、**実質的な情報はすべて「ビジョン」ページ（4,123文字）に集中**しています |

**この会社のサイトは、内容そのものは良く書かれています。**
h1が1つあり、画像2点ともalt属性があり、メタディスクリプションも適切です。
Copyright表記も2026年で最新です。
**問題は、スマホ対応と、良い内容がトップから見えないことです。**

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 現示と閉塞区間

鉄道信号の会社なので、**3灯式信号機と閉塞区間**の模式図を
ファーストビュー右側にインラインSVGで置きました。
第2閉塞に列車がいるため、その手前の信号は進めない——という
**信号保安の最も基本的な原理**を1枚にしています。

3灯は**36px等間隔**、閉塞区間は24〜296pxを**3等分（各90.7px）**に
機械的に配置しました。実測でも3灯がすべて同じ直径（PC 20px）で
描かれることを確認しています。

### 型 ── 「現示」を見出しに置く

現行サイトから画素採取した青 `#006699` = `oklch(48.7% .113 240.8)` が基準です。
面 `oklch(42% .108 241)`、文字 `oklch(36% .098 241)`。**色相差 0.2°**。
元の彩度がほぼ適正なため、明度のみ調整しました。

**すべての見出しの左に、進行現示を表す緑の点を1つ**置いています
（実測 9×9px）。信号の3色は装置の色なので、
**本文の配色には使わず、署名的装置と見出しの点にのみ**限定しました。

### 見出し

「信号が正しく現示することを、ひとつずつ確かめる。」を h1 にしました。
現行サイトのキャッチは「『安全』『技術』『価値ある商品とサービス』」で、
**3つの価値観は分かりますが、何をする会社かが分かりません。**
