## 設計上の判断

### 署名的装置 ── 世代の重なり

この会社を一言で表すと「**設備が入れ替わらず、重なっている**」ことです。
数十年前のカム式6軸自動機58台が、2015年導入のNC自動機と同じ工場で動いています。

そこで、設備の世代を横軸＝年の帯として描きました。

**帯の左端をぼかしているのには理由があります。**
現行サイトには6軸自動機とNC旋盤の**導入年が書かれていません。**
分からないものを分かったように描かないため、
左端をグラデーションで減衰させ、**その旨を図の中に明記**しています。
年の目盛は、沿革に記載のある年（1961・1971・1997・2006・2015）だけを取りました。

### 配色 ── 緑域だが、省栄プリント製作所とは別の軸で分ける

主色は現行サイトから画素採取した深緑 `rgb(0,110,56)` =
`oklch(47.2% .122 152.9)`。白地用に `oklch(41% .105 153)`。**色相差 0.1°**。

**同じセッションで作った省栄プリント製作所も緑域（154）で、色相差は約1°しかありません。**
どちらも現行サイトから採った色なので、色を動かすほうが不誠実です。
そこで**色以外のすべての軸で分けました**。

| 軸 | 省栄プリント製作所 | 島野精機 |
|---|---|---|
| 署名的装置 | 断面の積層（空間） | 世代の重なり（時間） |
| 地 | 緑を帯びた白 `.003 154` | **無彩の白** `0 0` |
| 字送り | .02em | **.03em** |
| 主要な情報の形 | カード | **表（5つ）** |

### 見出し

「機械を使って金属を削る。1935年から。」を h1 にしました。
これは**代表者あいさつの冒頭をほぼそのまま使っています**。

### グラデーションの上の文字は、検査では捕まりません

**初回、帯のラベルは白文字でコントラスト 1.45:1 でした。**
それでも `verify-site.mjs` は「コントラスト全AA達成」と報告します。
**SVG の中の文字は検査の対象外**であり、加えて
**背景がグラデーションだと「背景色」という単一の値が存在しない**ためです。

そこで手で計算しました。
帯は左端で不透明度 0.15、30%地点で 1.0 になります。
文字は帯の左端から 2.4% の位置にあり、**実効不透明度はまだ 0.22** でした。
白地と混色されて、ほとんど読めない状態です。

2つ直しました。

1. **文字位置を x=52 から x=128 へ移動**（グラデーションが完全に不透明になる x=121 以降）
2. **`--g-mid` を `oklch(58%)` から `oklch(52%)` へ**
   （58% では完全不透明でも白文字が 4.10:1 で AA に届かないため）

修正後は 8.40:1 と 5.26:1。**スクリーンショットでも読めることを目視で確認しています。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。

### 数値の照合

**設備表は、5表すべてについて掲載した明細の和が合計と一致することを
プログラムで確認しています**（58 / 56 / 159 / 163 / 103）。
**記載の合計値そのものが原文に存在すること**も併せて確認しました。

ページ冒頭の「加工設備436台」は**58+56+159+163 から算出した値**で、
現行サイトにこの数字は書かれていません。**そのため本文でも
「加工設備436台、精密測定機103台」と内訳が分かる形で書いています。**
