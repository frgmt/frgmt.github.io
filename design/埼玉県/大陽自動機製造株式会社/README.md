# 大陽自動機製造株式会社 — トップページ リニューアル案

現行サイト（https://www.taiyou-jidouki.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,001px**。ブラウザが全体を約 **37%** に縮小して表示するため、本文がそのままでは読めません |
| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個**。文書構造が検索エンジンに伝わりません |
| テーブルレイアウト | `<table>` **21個**。レイアウトを表で組む、CSS以前の構造 |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| 画像のalt属性 | 画像33点中 **12点に alt が無い** |

**HTTPSには対応済みです。**
メタディスクリプションも設定されており、SEOへの意識はあります。
問題は**スマホ対応と文書構造**に集中しています。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは1,001px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 埋もれていた情報

現行サイトの本文から拾い出し、前に出したもの。**すべて現行サイトに記載があります。**

- **「製品加工用のコイリングマシン・フォーミングマシン等は、当社の機械生産課にて
  生産された自社製を使用」** … 会社案内ページの事業内容欄、

  **ばね屋が、ばねをつくる機械そのものを自社でつくっている。**
  これがこの会社で最も特異な点なので、h1に持ち上げました

  工場紹介ページの表の中。**合計213台という規模が伝わっていません**。

- **対応業界が16業種挙げられている** … トップの説明文中に読点で列挙されているだけ。
  タグとして並べました
- **3工場が製品種別で分かれている**（本社＝ばね／ムサシ＝部品・機械／宮寺＝シャフト）…
  会社案内と工場紹介に分散しています。どの工場が何をつくるかを1箇所にまとめました
- 連続式熱風テンパー炉・投影機・自動ばね試験機 … 工場紹介の写真キャプションのみ

## 設計上の判断

### 同じ「ばね屋」でも、川口スプリング製作所とは型を変えています

本提案と同時期に、同じ埼玉県のばねメーカーである
**株式会社川口スプリング製作所**（色相249°）の提案も作成しています。
色域が近く（本件は262°）、業種も同じであるため、**構成原理を明確に分けました**。

| | 川口スプリング製作所 | 大陽自動機製造（本件） |
|---|---|---|
| 構成原理 | **巻き**（等間隔の反復） | **台数**（設備を数える） |
| 罫の使い方 | 見出し左に**破線**の縦罫 | **実線1本のみ**。破線は使わない |
| 数値の見せ方 | 圧縮率などの比 | **大きな数字を4つ並べる** |
| 署名的装置 | 圧縮コイルばね（自由長→たわみ） | コイリングマシンの成形部 |

### 署名的装置 ── コイリングの成形部

「まっすぐな線がばねになる瞬間」を描きました。
左から線材が入り、送りローラー4個と成形工具（クイル）を通って、
右でコイルになります。

コイル部の座標は目分量ではなく**14px等間隔**で置き、
y値が上下2値のみであることを検算して確認しています。
実描画サイズは PC 406×254px（コイル部 178×61px、ローラー4個）／
スマホ375 302×189px／スマホ320 248×155px（実測）。

### 配色

現行サイトから画素採取した濃紺 `#0f244c` = `oklch(26.9% .079 261.8)` が基準です。
面 `oklch(33% .088 262)`、文字 `oklch(28% .080 262)`。**色相差 0.2°**。
元の彩度が低い（.079）ため、**彩度を下げるのではなく明度を上げて**
面として使えるようにしました。

### 見出し

「ばねをつくる機械から、自分たちでつくります。」を h1 にしました。
現行サイトのキャッチは「大きな社会を支える小さな部品製造」で、
悪くはありませんが**この会社だけが言えることではありません**。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトの工場紹介ページには
  自社製コイリングマシン・フォーミングマシンの写真があります。
  **「自社でつくった機械」の写真はこの提案の核なので、元データを必ずご提供ください**
- **設備213台は、部署別台数（81+81+35+16）を当方で合算した値です。**
  現行サイトに合計値の記載はありません。正しいかご確認ください
- **従業員数の記載が現行サイトにありません。**設備213台に対する人員規模は
  発注側が必ず気にする点なので、掲載をお勧めします
- **線径・自由長などの対応範囲が記載されていません。**
  ばねの引き合いでは最初に確認される項目です。明記を強くお勧めします
- ISO等の認証取得の記載がありません
- 現行サイトの「お知らせ」欄は空です
- 主要取引先の記載がありません。16業種への実績があるとの記述のみです
- グループ会社（大陽ステンレススプリング）との役割分担が
  「機械製造部門として独立し設立」とのみ記載されています。
  **発注先としてどちらに問い合わせるべきかが分かりにくい**ため、整理をお勧めします

| **コイル座標の等間隔性** | x間隔すべて14px・y値は上下2値のみ（**計算で照合**） |

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

コイルの座標は**等間隔であることを計算で照合**しています。
目分量で置くとピッチが不揃いになりますが、見た目では気づけず、
検査もすべて通ってしまうためです。
SVG内の文字は検査ツールが見ないため、コントラスト比も別途計算しています。
