現行サイト（https://www.cttakahata.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個**。文書構造が検索エンジンに伝わりません |
| テーブルレイアウト | `<table>` **14個**。レイアウトを表で組む、CSS以前の構造 |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| 画像のalt属性 | 画像31点中 **31点すべてに alt が無い**。読み上げ環境と画像検索から内容が読めません |
| Copyright表記 | **2008年**のまま |

**HTTPSには対応済みです**（他社と違い、ここは問題ありません）。
メタディスクリプションとキーワードも設定されており、
**SEOへの意識はある一方、土台がそれに追いついていない**状態です。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは980px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 従来炉と自社炉の対置

この会社の主張は「従来炉25分 → 自社炉8分」という一点です。
ファーストビュー右側に、**炉体の長さそのものを比で描いた図**を
インラインSVGで置きました。上が従来炉（288px幅・25分）、
下が高圧熱風乾燥炉（150px幅・8分）で、**炉長が短くなること自体を絵にしています**。

実描画サイズは PC 424×252px（従来炉の枠 381×45px／自社炉の枠 199×45px）／
スマホ375 302×179px（272×32px／142×32px）。

### 構造 ── ページ全体を Before / After で組む

配色は現行サイトから採取した淡緑 `#ccffcc` = `oklch(95.2% .086 144.9)` が基準です。
ただしこの値は淡すぎて文字に使えないため、同色相のまま明度を落とし
面 `oklch(44% .112 145)`、文字 `oklch(38% .104 145)` としました。**色相差 0.1°**。

145° は既存提案（日祥梱包倉庫143°・キムラ電子150°ほか）と近い色域です。
そこで**構造で分けました**。実証値の節では、
数値を必ず「従来炉（取り消し線・灰）→ 自社炉（緑・太字）」の2つ1組で並べます。
他の提案には無い型です。

### 見出し

「25分かかっていた乾燥が、8分で終わります。」を h1 にしました。
現行サイトのトップは「地球に優しい環境技術」で始まり、
**何がどれだけ良くなるのかが数字で出てきません**（表の中にはあります）。

  写真がありますが小さいため、元データのご提供が必要です

  掲載継続の可否をご確認ください
- **特許番号が現行サイトに記載されていません。**「(PAT)」「（特許）」の表記のみです。
  登録番号をご教示いただければ記載します（他社提案では番号を明記しています）
- 実証値の3例が**いつ時点のものか記載がありません**。
  「※内容は弊社実績値です」とのみあります
- 取引銀行・協力会社は現行サイトに記載がありますが、本ページには掲載していません
- 現行サイトには吉田松陰の名言の引用がありますが、本ページには含めていません
- 「バイオ24」「消臭・抗菌」「洗浄剤」「健康（サプリメント）」「ラミネートフィルム」は
  別ページがあるため、トップでは事業内容の欄にまとめるに留めました。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した不具合

- **「従来炉」側の数値3件が 4.16:1 でAA基準（4.5:1）に届いていませんでした。**
  取り消し線つきの灰色を「弱く見せる」ために明度を上げすぎていたためです。
  `oklch(58%)` → `oklch(50%)` に落として解消しました
- **SVG内の文字は検査ツールが見ません。**この装置は色をCSS変数でなく
  ハードコードしているため、3つのラベルすべてについて
  コントラスト比を別途手計算で検証しています（5.88 / 11.84 / 7.63:1）
