# 株式会社 協同（モーリアンヒートパック）— トップページ リニューアル案

現行サイト（http://www.morians.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| ニュースの最新が2022年 | トップの「ニュース&トピックス」5件のうち最新が **2022/06/01**、以下2021・2020・2016・2016年 |

**縮小表示であって、横スクロールではありません。**
viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めない状態です。

なお現行サイトは、この年代のサイトとしては作りが良いほうです。
h1が1つあり、画像22点すべてにalt属性があり、文字コードもUTF-8です。
**問題はほぼ「スマホ対応がされていない」の一点に集約されます。**
逆に言えば、直すべき箇所が明確です。

## 設計上の判断

### 署名的装置 ── 昇温カーブ

この会社の価値は「急に上げて、そのまま保てる」ことです（生石灰は上げられても保てない）。
ファーストビュー右側に、**反応開始から98℃で安定するまでの曲線**を
インラインSVGで置きました。98℃の位置に破線のガイドを引いています。
文章を読む前に、この製品の挙動が伝わります。

`stroke="currentColor"` で配色に追随します。
実描画サイズは PC 416×260px / スマホ375 302×189px / スマホ320 248×155px（実測）。

### 配色 ── 現行サイトの橙を主役に、紺を「非火気」の側に置く

現行サイトから画素採取した橙 `#e26c02` = `oklch(66.1% .172 50.7)` を基準にしました。
面 `oklch(58% .148 51)`、文字 `oklch(47% .124 51)`。**色相差 0.3°**、彩度のみ抑制。

現行サイトには濃紺 `#274bbd`（hue 266）も使われていますが、
266° は既存提案に最も多い色域のため主役には採らず、
**「火を使わない」側＝冷たい面**として特許の節にだけ低彩度で当てました。
熱（橙）と非火気（紺）の対比そのものを構成に使っています。

### 見出し

「火を使わずに、98℃をつくる。」を h1 にしました。
現行サイトのキャッチは「いざ！という時にもあたたかい食事が食べたい。」で、
用途は伝わりますが、**何ができる製品なのかが数値で示されていません**。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには製品写真・工場写真・
  自衛隊での使用例・飲食店での使用例など多数ありますが、
  解像度が低いため、元データのご提供が必要です。
  **特に「なだ万様の厨房での使用例」は強い素材**なので、掲載許諾の状況をご確認ください
- **納入先の企業名・官公庁名をそのまま掲載しています**（現行サイトの記載どおり）。
  掲載継続の可否、特に外国軍の記載についてご確認ください
- 発熱剤仕様書は「**2012年9月1日現在**」の数値です。現在値をご確認ください
- 沿革は平成24年（2012年）で止まっています。以降の実績をご教示ください
- **「社歴45年」は会社案内ページの記載ですが、昭和41年創業から逆算すると
  執筆時点は2011年頃と思われます。**現在は創業60年目にあたるため、
  本ページでは年数表記を使わず「昭和41年創業」としました
- 取引銀行は現行サイトに記載がありますが、本ページには掲載していません
- ISO等の認証取得の記載は現行サイトにありません
- 「秩父湧水」は別ページがあるため、トップでは会社概要の製品欄に記載するに留めました

## 検証

実ブラウザで測定済み。

| 項目 | 結果 |
|---|---|
| 横はみ出し（320〜1920px の10幅） | すべて **0px** |
| 横はみ出し（実機UA・320 / 375px） | すべて **0px** |
| コントラスト（WCAG AA） | 不足 **0件** |
| タップ領域 44px | 不足 **0件** |
| JavaScriptエラー | **0件** |
| **JS無効時の本文可視** | **3,306文字すべて可視** |
| スクロール後の未表示要素 | **0件**（PC / 375px / 320px） |
| Webフォント実ロード | Zen Kaku Gothic New / Noto Sans JP / Roboto Mono の**3書体とも `document.fonts` で確認** |
| インラインSVGの実描画 | PC 416×260px（曲線パス 341×152px）／スマホ375 302×189px |

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した不具合

- **幅320pxでヘッダーの電話番号が7pxはみ出していた** — 検査は
  「`a.hd__tel`, `table.st`, `caption`」の3つを報告しましたが、
  `table.st` と `caption` は `overflow-x:auto` のスクロール領域の内側にあり、
  **横スクロールの原因ではありません**（スクロール容器を除外して再測定し確認）。
  実際に画面外へ出ていたのは `.hd__tel` のみで、
  360px以下でヘッダーを折り返す指定を追加して解消しました
