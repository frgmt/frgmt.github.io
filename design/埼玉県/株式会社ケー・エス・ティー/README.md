# 株式会社 ケー・エス・ティー（KST）— トップページ リニューアル案

現行サイト（http://k-s-t.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| 画像のalt属性 | 画像15点中 **12点に alt が無い** |
| Copyright表記 | **2010年**のまま |
| **仕様が5ページに分散** | 加工機の仕様が `product_01`〜`product_05` に1機ずつ置かれ、**トップページには要約しか載っていません**。比較して選べません |

**縮小表示であって、横スクロールではありません。**
viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

なお現行サイトは `<h1>` が1つ、`<h2>` が5つあり、メタディスクリプションも
設定されています。**構造への意識はある一方、スマホ対応だけが抜けている**状態です。

## 設計上の判断

### 署名的装置 ── 塗布量のレンジ帯

この会社の価値は「どこからどこまで対応できるか」の幅です。
ファーストビュー右側に、**4つの加工機の塗布量の範囲を対数目盛の帯**で描きました。
1〜1,000g/㎡を1本の軸に取り、機械ごとに下限から上限までを塗っています。
「試作機は薄いところから、粉体封入機は厚いところまで」が一目で分かります。

`fill="currentColor"` で配色に追随します。
実描画は PC 424×265px、帯4本が 336 / 249 / 286 / 189 × 16px（実測）。

### 配色と構造 ── 「幅」で分ける

現行サイトから画素採取した緑 `#1da15e` = `oklch(62.6% .148 154.6)` が基準です。
面 `oklch(47% .118 155)`、文字 `oklch(40% .108 155)`。**色相差 0.4°**、彩度のみ抑制。

155° は同時期に作成したシーティータカハタ（145°）と近い色域です。
あちらは Before / After の**対置**で組んだので、こちらは**レンジ（幅）**で分けました。
数値は単独で置かず、必ず「下限—上限」の帯か範囲として示しています。

### 見出し

「通気性を殺さずに、貼る。」を h1 にしました。
現行サイトのキャッチは「環境にやさしいホットメルト・ラミネートの加工技術を提供し、
次世代の接着加工技術の開発を目指します」で、**何が他社と違うのかが分かりません**。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには加工機の写真がありますが
  小さいため、元データのご提供が必要です
- **設備表とスプレー加工機ページで塗布量の下限が食い違っています。**
  設備一覧では「1〜100g/㎡」、製品ページでは「3〜100g/㎡」です。
  本ページは製品ページ側（3g/㎡）を採用し、設備表は原文どおり1g/㎡と記載しました。
  正しい値をご確認ください
- **設備表とロールコーターページで加工幅が食い違っています。**
  設備一覧は「1,450mm」、製品ページは「1,600mm」です。両方を原文どおり記載しています
- 現行サイトに「**高粘度・高融点対応塗工機、平成23年導入予定**」とありますが、
  導入済みかどうか未確認のため記載していません
- **本社所在地の表記が現行サイトにありません。**東京営業所・八潮工場・第二工場の
  3拠点のみです。登記上の本社をご教示ください
  （本ページでは構造化データに八潮工場の住所を入れています）
- 取引銀行は現行サイトに記載がありますが、本ページには掲載していません
- 主要取引先・納入実績の記載が現行サイトにありません。可能な範囲でご教示ください

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した不具合

1. **署名的装置の帯3本が、実際の対応範囲より短く描かれていました。**
   目分量で座標を置いていたためです。対数目盛の式で全4本を計算し直したところ、
   試作機（218→254px）・パウダー加工機（152→188px）・粉体封入機（180→216px）が
   ズレていました。**この装置は会社の対応範囲を主張するものなので、
   短く描くことは実力を過小に伝えることになります。**
   目で見て気づける種類の誤りではないため、計算で照合しました
2. 幅380px以下でロゴのタップ領域が31pxになっていました
   （ヘッダーを折り返す際に `min-height` を解除したため）
