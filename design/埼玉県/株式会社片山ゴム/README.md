# 株式会社片山ゴム — トップページ リニューアル案

現行サイト（http://www.katayama-gomu.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで縮小表示（等倍では収まらない） |
| 文字コード | Shift_JIS |
| 新着情報が2件だけ | `2012/12/10 英語版ホームページをオープン` `2010/01/26 ホームページをオープン` |
| 設備が工場別の縦並び | 加硫プレスの**能力別の厚み**が読み取れない |
| トップに数値が無い | 「創業より40余年」以外に具体的な数字が出てこない |

### 設備の一覧はあるが、比較できない

現行サイトの `facilities/index.html` には2工場の設備が
**工場ごとに縦一列**で並んでいます。加硫プレスは
川里が 80/100/150TON の3行、福島が 100/150/200TON の3行に分かれており、
**同じ能力で何台あるか**を比べるには2つの表を目で往復する必要がありました。

## 設計上の判断

### 署名的装置 ── 加硫プレスの能力別台数（2工場の比較）

ゴム部品の相談で決まるのは**「その型がプレスに載るか」と「何台流せるか」**です。

本案は 80〜200TON を**1つの軸**に集め、2工場を色で分けて並べました。
福島の 150TON が30台で最も厚いこと、200TON は福島にしか無いこと、
80TON は川里にしか無いことが一目で分かります。

**帯の長さは台数**です（トン数ではありません）。誤読を防ぐため注記を添えています。
最多の「福島150TON・30台」を全幅としました。

現行サイトには合計台数の記載がありません。各行を合計すると
**加硫プレス89台**（川里27台＋福島62台）になります。
これは中小のゴム成形メーカーとしては相当な規模で、
トップページで最初に伝えるべき数字だと判断しました。

### 色 ── ロゴの緑と赤

現行サイトの CSS にある `#0066ff` はブラウザ既定に近い純青なので採りません。
ロゴ画像 `asset/img/ui/logo.jpg`（226×42px）の画素を集計しました。

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#38a848` | ロゴ画素 300px | `oklch(64.7% .169 145.7)` | **採用**（面 `oklch(45% .13 146)`、色相差 +0.3°） |
| `#c82838` | ロゴ画素 43px | `oklch(54.4% .194 22)` | **第二色に採用**（`oklch(48% .155 22)`）。福島工場の識別にだけ使う |
| `#0066ff` | CSS のリンク | — | 不採用。ブラウザ既定に近い純青 |

彩度は緑 `.169 → .13`、赤 `.194 → .155` に落としています（上限 .16）。
明度は緑 `64.7% → 45%` に落として、白地の面と文字の両方で AA を取りました。

**地は白**（`oklch(100% 0 0)`）。暗い全幅帯は置いていません。

### 緑が2社目であることへの対処

上島熱処理（150°）と色相がほぼ同じなので、4軸で分けます。

| 軸 | 上島熱処理 | 片山ゴム |
|---|---|---|
| 地の温度 | 冷たい灰（hue 230） | **暖かい灰（hue 70）** |
| 署名的装置 | 名工の台帳（人） | **加硫プレスの能力別台数（設備・2工場比較）** |
| 書体 | Zen Old Mincho（明朝） | **Zen Kaku Gothic New**（角ゴ） |
| 第二色 | 炉温の橙〜赤（グラデーション） | **ロゴの赤を福島工場の識別にだけ**（単色） |
| 角丸 | 2px | **4px**（ゴムの弾性感） |
| 幕開けの造り | 淡いグラデーション | **横罫**（加硫プレスの盤の段）＋見出しを緑地に白抜き |

## データの出所

設備・製品・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- 加硫プレスほか全設備（2工場＋金型工場） … `facilities/index.html`
- 製品10種と用途、使用ゴム材料 … `products/index.html`
- 会社概要・沿革・ごあいさつ・取引先 … `company/index.html`
- 郵便番号（〒365-0001／〒963-6302） … `recruit/index.html`
- 従業員数の内訳（川里27名／福島82名） … `company/index.html`

### 確認が必要な項目

- **郵便番号は会社案内ページに無く、採用情報ページにのみ記載**されていました。
  本案では 〒365-0001（川里）／〒963-6302（福島）を採用しています
- **資本金2,000万円は2000年3月の増資時の額**です。以降の記載がありません
- 従業員数109名は**2022年1月現在**の記載です
- ISO 9001 は「平成13年11月取得」「平成15年10月 ISO9001（00版）取得」と
  2行に分かれています。**認証機関・登録番号の記載がありません**
- **加硫プレスの合計台数は現行サイトに記載がありません**。
  本案の89台は設備一覧の各行を合計した数です
- 現行サイトのトップに「創業より40余年」とありますが、
  1961年創業から数えると65年になります。**表記の更新が必要**と思われます。
  本案では年数表記を使わず「SINCE 1961」としています
- 「作業工程」の図（加硫接着品の代表的な工程）が `products/index.html` に
  ありますが**画像のみでテキストがない**ため、本案には起こせていません。
  工程名がテキストで得られれば、第2の図として使えます
- 福島工場の住所に番地「40」までは記載がありますが、
  地図は字名（南須釜）までで検索しています
