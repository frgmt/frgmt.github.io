## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| `<h1>` が無い | **0個**（`<h2>` も0個。見出しタグが1つも使われていません） |
| テーブルレイアウト | `<table>` **14個**。レイアウトを表で組む、CSS以前の構造 |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| 画像のalt属性 | 画像35点中 **35点すべてに alt が無い**。読み上げ環境と画像検索から内容が読めません |
| Copyright表記 | **2008年**のまま |
| ページ本文の更新表記 | 「**2008.10.19更新**」 |
| Last-Modified | **2014年8月2日** |

**縮小表示であって、横スクロールではありません。**
viewportタグが無いため、iPhoneは980px幅のページを375pxの画面に押し込んで表示します。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めない状態です。

## 設計上の判断

### 署名的装置 ── 膜厚の断面

メッキ工場の価値は「どれだけ均一に、指定の厚みで乗せられるか」です。
ファーストビュー右側に、**素地・下地ニッケル・仕上げ層の断面**をインラインSVGで置きました。
左に µm の目盛を添えています。何を売っている会社かが、文章を読む前に伝わります。

`fill="currentColor"` で配色に追随します。
実描画サイズは PC 399×249px / スマホ 302×189px（実測）。

### 配色 ── 現行サイトの青を継承しつつ、地の温度で分ける

現行サイトのリンク青 `#0000ee` を画素採取し、`oklch(42.9% .297 264)` を基準にしました。
面 `oklch(41% .132 264)`、文字 `oklch(35% .124 264)`。**色相差 0°**、彩度のみ抑制しています。

264° は既存提案に多い青域です（中央総業260°・妻沼電化268°ほか）。
そこで**地の温度**で分けました。地を純白ではなく銀に寄せた冷たい灰 `oklch(99.1% .002 264)` とし、
見出しの一点だけ金の暖色（hue 85）を差す二温度構成です。
金・銀・錫・ニッケルを扱う工場なので、地そのものを「銀」に寄せています。

### 見出し

「変形しやすい極小のピンから、2mのブスバーまで。」を h1 にしました。
現行サイトのキャッチは「Welcome to YOSHIDA SYOUTEN」で、何の会社か分かりません。

検索エンジンとAI検索から読める形になります。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した不具合

この検証は形式的なものではなく、以下を実際に検出して修正しています。

1. **JS無効時に本文が消えていた** — フェードイン用の `opacity:0` が
   JSの有無に関わらず効いていたため、JSを切ると本文が全く見えませんでした。
   `.js` クラスが付いたときだけ隠す方式に変更
2. **画面より背の高い要素が永久に表示されなかった** — IntersectionObserver の
   `threshold: 0.08` は、ビューポートを覆い尽くす長い表や沿革では
   「面積の8%が見えた」状態に決してならず、スクロールしても表示されないままでした。
   `threshold: 0` に変更し、さらに読み込み後の無条件表示を保険として追加
3. **SVG内の文字が opacity で減光されていた** — 合成後の色が測れずコントラスト検査が
   素通りしてしまうため、実色（`#5b5f6b` / `#2b3040`）に置き換え
4. タップ領域が44px未満のリンクが5箇所（ヘッダーナビ・フッター・電話番号・ロゴ）
