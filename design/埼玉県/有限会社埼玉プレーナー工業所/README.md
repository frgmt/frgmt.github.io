# 有限会社埼玉プレーナー工業所 — トップページ リニューアル案

現行サイト（http://www.planers.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | iPhone実機UAで縮小表示（等倍では収まらない） |
| テーブルレイアウト | `<table>` 4つでページを組んでいる |
| ナビが全角パイプ区切り | `HOME ｜ 会社案内 ｜ 金属加工事例 ｜ …` |

### 25社の取引先が、会社概要ページの奥にある

現行サイトの `gaiyou.html` には、株式会社IHI、株式会社ニコン、
本田技研工業株式会社、日本原子力研究開発機構、住友重機械工業、
セイコーエプソン、日立ハイテク ── **25社の実名**が並んでいます。

社員12名の会社としては極めて強い信用の裏付けですが、
トップページからは2クリック先で、しかも表の中に埋もれていました。

## 設計上の判断

### 署名的装置 ── 材質×機械の加工可能寸法

難削材の大物加工は「**その材質を、その大きさで受けられるか**」で決まります。

現行サイトでは、材質の一覧（トップページ）、加工事例（`seihin/` 配下5ページ）、
設備の一覧（`setubi/`）が**それぞれ別のページ**にありました。
「ハステロイを2m角で削れるのか」を知るには3ページを往復する必要がありました。

本案は**材質・性質・主な用途・主に使う機械**の4列にまとめました。
さらに機械6台の加工可能サイズを**面積比の帯**で並べています。

帯を面積比にしたのは、この会社の機械が
**「幅が広い機械（プラノミラー 2,500mm）」と
「長さが長い機械（複合プレーナー 6,000mm）」に分かれている**ためです。
どちらか一方の寸法で並べると、この構造が消えます。注記で明示しました。

### 「どう考えて削ったか」をそのまま活かした

現行サイトの加工事例には、町工場のサイトでは珍しい記述があります。

> この際に内部に蓄積された応力により「ねじれ」や「反り」がなどの歪みが
> 生じています。その内部応力の「曲がり」「そり」「ねじれ」を
> 最終仕上げ加工で無くしていくか？が弊社の築いてきた技術となります。

> 切粉のはけが悪い形状なのですが、使用工具、クーラントのあてかたで
> 仕上がり精度を大きく向上させています。

こうした記述は**発注者が読みたいもの**なので、削らずに構成し直しました。

### 色 ── ロゴの臙脂

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#880808` | ロゴ画像 `saitamap2.gif` の最頻出画素（30,200px） | `oklch(39.8% .157 28.5)` | **採用**（面 `oklch(38% .145 28)`、色相差 -0.5°） |
| `#800000` | 現行 CSS | — | 同系。上の裏付け |
| `#3366cc` | リンク | — | 不採用。ブラウザ既定に近いリンク青 |

彩度は `.157 → .145`（上限 .16 以内）。明度は 39.8% でほぼ据え置き
（この明度で白地の AA が出るため）。

### hue 28 が進竹産業（30）と近いことへの対処

色相は近いのですが、**色の性格が違います**。

| | 進竹産業 | 埼玉プレーナー |
|---|---|---|
| 色 | 看板の朱赤 `oklch(41% .155 30)` | **臙脂** `oklch(38% .145 28)` |
| 印象 | 電子部品の仕様書 | **錆・鋳物・古い町工場** |
| 書体 | Zen Kaku Gothic New（角ゴ） | **Zen Old Mincho**（明朝） |
| 罫 | 1px | **2px**（図面の声） |
| 幕開けの造り | 右上からの同心円（同軸コネクタ） | **細い横縞**（プレーナーの削り目） |
| 署名的装置 | インピーダンスと帯域で選ぶ表 | **材質×機械の加工可能寸法** |

## データの出所

設備・加工事例・取引先・会社概要はすべて**現行サイトから取得した実データ**です。

- 機械6台の加工可能サイズ、クレーン、トラック … `setubi/index.html`
- 会社概要・取引先25社・経営指針・加入団体 … `gaiyou.html`
- バッキングプレートの工程と技術 … `seihin/backing.html`
- ハステロイの加工（公差・主軸トルク） … `seihin/semicon.html`
- 真空チャンバー（ビビリ・切粉・クーラント） … `seihin/sus304.html`
- 材質一覧・加工の種類 … トップページ
- 担当者（専務 鈴木） … `rennrakusaki.html`

### 確認が必要な項目

- **東京支店（港区海岸・東京ポートシティ竹芝）に電話番号の記載がありません**
- **創立1961年に対し「有限会社」のままです**。組織変更の予定があれば
  社名表記の確認が要ります
- **ISO等の認証取得の記載がありません**。原子力関連部品や半導体製造装置部品を
  扱う会社としては、認証の有無が問われる可能性があります
- 加工事例の「真空成型金型（アルミ）」「製缶物（SS400）」「キー溝」
  「スパッタリングターゲット」は**トップページのメニューにあるものの、
  個別ページの本文が薄い**（または未作成）状態でした。
  本案では名称のみ「そのほかの加工事例」に含めています
- **ナイロン（樹脂）の加工事例・寸法の記載がありません**。
  材質一覧にのみ登場するため、表では用途・機械を「—」としました
- 主要取引先25社は現行サイトに実名で掲載されているものをそのまま転記しました。
  **掲載可否は先方との取り決めをご確認ください**
- 横中ぐり盤（東芝 BFT-11C）とラジアルボール盤（オークマ 1,600mm）は
  **加工可能サイズが他の機械と異なる形式**で書かれているため、
  面積比の帯には含めていません（設備一覧には記載）
