## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ページ全体が **38%** に縮小されて表示されます |
| **h1 が無い** | トップページに見出し要素が1つもありません |
| **画像の alt 欠落** | 74点中 **15点** に alt がありません |
| **jQuery のバージョンが不明** | `jQuery.fn.jquery` が **`@VERSION`** と返します |

HTTPS には対応済みです。

### jQuery が「@VERSION」を返します

`common/js/lib/jquery.js` を読み込んでいますが、
**バージョン文字列が `@VERSION` のまま**です。

これは jQuery のソースに含まれるプレースホルダで、
本来はビルド時に実際の番号（`1.11.2` など）へ置換されます。
**置換前のファイルをそのまま配置している状態**です。

実害として、**どのバージョンなのか特定できないため、
既知の脆弱性に該当するかどうかも判断できません。**
セキュリティ診断を受ける機会があれば、指摘される箇所です。

## 設計上の判断

### 署名的装置 ── 年間おおよその受注検体数

この会社の実力を最も端的に示すのが、**扱っている検体の数**です。

そこで、6区分の年間検体数を**同一尺度の帯**で並べました。
描画後の実測で、**6本すべてが `178 × 検体数/70,000` と
小数第1位まで一致する**ことを確認しています。

**合計の約158,100検体は、現行サイトに記載がありません。**
6区分を合算した値であることを、図の中とページ本文の両方に明記しました。

**「1日あたり約645検体」という換算も検討しましたが、採用しませんでした。**
年間営業日数が現行サイトに書かれておらず、
**私どもの仮定が入ってしまう**ためです。

### 配色 ── 234だが、地と形で分ける

主色は現行サイトから画素採取した青 `rgb(0,134,185)` =
`oklch(58.5% .123 234.3)`。白地用に `oklch(43% .098 234)`。**色相差 0.3°**。

同じセッションで作った細谷製作所（232）と近い色相です。
あちらは地に青を薄く含ませているので、こちらは**地を無彩の白**にし、
**登録・認定を「資格の一覧」として大量に並べる形**を主要な形にして分けました。

### 見出し

「年間15万検体を、正確に、迅速に。」を h1 にしました。
現行サイトには h1 がなく、
**「正確・迅速・親切」という創業以来のコンセプトと、
実際の検体数を組み合わせた**ものです。

`min-block-size:44px` を付けて解消しています。

確認した上で本番を測定しました。
