## この提案で変えたこと

### 1. 「容器から中身まで、ぜんぶ自社で」を見出しにする

容器を成型し、水をつくり、調合し、充填し、検査し、自社倉庫から出す。
**この全工程を1社で持っていること**が、この会社の芯です。

現行サイトには各工程の写真が揃っているので、**工程の順に6枚並べました**。
文章で「一貫製造」と書くより、目で追えるほうが早く伝わります。

| | 工程 | 保有設備 |
|---|---|---|
| 01 | 容器を成型する | PE・PET・PP 成型機28台 |
| 02 | 水をつくる | 逆浸透膜純水装置、超純水製造装置 |
| 03 | 調合する | 原料タンク、大型ブレンダー、乳化製造設備 |
| 04 | 充填する | 自動充填ライン32基（50mL〜1,000L） |
| 05 | 検査・分析する | 自社の分析機器 |
| 06 | 出荷する | 自社物流センター、自動倉庫2,701パレット |

### 2. 御社の写真をそのまま使いました

現行サイトの写真12点を使用しています。**図やイラストは使っていません。**

成型機、逆浸透膜純水装置、原料タンク、充填ライン、分析機器2点、
危険物倉庫、物流センター、製品3点。

※ 実際に公開される際は、写真の使用可否をご確認ください。

### 3. 沿革24項目をそのまま載せる

1963年、茨城県古河市の自動車用品販売から始まっています。
埼玉に移って製造を始め、容器成型工場（1984）、JIS認定（1985）、
充填ライン新設（1986）、化粧品製造業許可（1998）、ISO9001（2005）、
ブレーキ液JIS認証（2009）、第4工場稼働（2022）。

**できることを一つずつ増やしてきた記録**であり、
一貫製造がどう組み上がったかがそのまま読めます。

## 現行サイトで気づいた点

### 工場のご案内ページで設備名が3回繰り返されています

`/factory/` の本文を読むと、「成型機／原料タンク／逆浸透膜純水装置／…」という
リストが**3回**出力されています。JSのカルーセルが同じリストを複製しているためと
思われます。読みにくいうえ、検索エンジンにも重複として渡ります。

### 会社案内の詳細ページが辿りにくい状態です

沿革（`/company/company3/`）と会社概要（`/company/company4/`）は
中身の濃いページですが、トップページからは階層が深く、
通常のクロールでは到達できませんでした。

## 事実の扱いについて

本文の数値・固有名詞69項目は、現行サイトの記述と照合済みです。

なお物流センターの「3,000t」は、当初「製品受入量」と書いていましたが、
出典を読み直すと**物流センターの規模**を指す記述でした。修正しています。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,558文字）
- 写真12点は**すべてaltを記述**、`width`/`height` 指定つき（合計約824KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の青は、**現行サイトで実際に使われている色**
`rgb(0,57,145)` = `oklch(37.5% 0.155 260.2)` から採りました。
ほぼそのまま（明度38%・彩度0.135）使える色でした。
地はごく淡い青灰にして、工場写真のステンレス色と地続きにしています。
