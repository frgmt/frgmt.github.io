# 埼玉部品工業株式会社 — トップページ リニューアル案

現行サイト（http://www.spc-net.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで **103点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |
| ホームページビルダー | `sitetheme/hpb9tm10_1.css`（既製テーマのまま） |

## 設計上の判断

### 「どちらに頼めばよいか」を最初に解く

この会社は**さいたま市の本社**と**新潟の浦佐工場**の二拠点で、
役割が明確に分かれています。

- 本社 … 試作・少量（小型マウンター）
- 浦佐工場 … 量産（3ライン＋検査設備）

現行サイトではこの分担が会社概要ページの本文に埋もれており、
「試作を1枚だけ頼めるのか」が読み取れませんでした。
これは問い合わせの入口として最も重要な情報です。

そこで署名的装置を**二拠点の役割分担**とし、幕開けの直後に
左右の対で置きました。それぞれに「試作・少量」「量産」と大きく掲げています。

### 上限値を1行だけ強調する

「できること」の一覧では、**最大510×415mm** の行だけ地色を変えています。
実装を頼む側が最初に確かめる制約値だからです。
他の項目と同列に並べると埋もれます。

### セクション構成

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 短い宣言 |
| 01 | 二拠点 | **役割分担の対**（署名的装置） |
| 02 | できること | **平坦な索引**（1行だけ強調） |
| 03 | 浦佐工場の設備 | 表 |
| 04 | 社歴 | **横スクロールの帯** |
| 05 | 会社概要 | 仕様書的 `<dl>` |
| 06 | 問い合わせ | `<details>` + 地図×2 |

### 色 — 現行サイトから採取

現行サイトはホームページビルダーの既製テーマで、ヘッダー画像も無彩色でした。
CSS 内で唯一の有彩色 **`#66669a`** を採取しています。

`--sol: oklch(48% .095 283)` / `--sol-ink: oklch(41% .09 283)` — **色相差 0.3°**。

**彩度をわずかに上げています**（.081 → .095）。通常は下げる方向ですが、
採取値は白地に置くとほぼ灰色に見え、ブランド色として機能しないためです。
色相＝識別子は動かしていません。

これまでの4社と色相で分離：中央総業 260°、潮工業 253°、
アイテック 37°、北進産業 235°、本案 283°。

### 動き（3種）

1. **進入** — スクロールで段階的に立ち上がる
2. **状態** — ヘッダーの影、罫が伸びるホバー、表の行ホバー、`<details>` の矢印
3. **スクロール連動** — 「試作・少量」「量産」の見出しに下線が伸びる

## データの出所

会社概要・社歴・設備・取引先はすべて
**現行サイトから取得した実データ**です。

- 会社概要・社歴・取引先 … `gaiyou.html` より
- できること・最大寸法 … `product.html` より
- 浦佐工場の設備 … `urasa.html` より
- CO2排出量・エコステージ認証 … トップページより

### 確認が必要な項目

- 営業時間（記載が無いため JSON-LD にも入れていません）
- 代表者名（現行サイトに記載が無いため未掲載）
- 取引先は現行サイトの記載を五十音順のまま採録。**全社ではありません**
  （現行サイトも「他」で結んでいます）
- 浦佐工場の緯度経度は住所からの概算値です
