# 株式会社東北車輛製造所 — トップページ リニューアル案

現行サイト（http://www.touhoku-caster.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか

このサイトには、他社が持っていない資産があります。
**タイヤ材質7種を10項目で比べられる物性表**です。

材質を選ぶ側にとって、これ以上に役立つ情報はありません。
油のかかる工場ならウレタン以上、水洗いする現場ならナイロン以上、
150℃までならダクタイル——**その判断が1枚で終わります**。

### その表が、画像に焼かれています

| | 現状 |
|---|---|
| 項目名（反発弾性・耐摩耗性…） | 本文テキスト ✅ |
| **評価（優/良/可/不可）** | **画像の中** ❌ |
| **温度（80℃／−40℃ など）** | **画像の中** ❌ |

70マスの評価がすべて画像です。つまり——

- 「ウレタン 耐油性」で検索しても出てきません
- 「MCナイロン 耐熱 120℃」でも出てきません
- 読み上げソフトでは何も読まれません

本提案では、**この70マスをすべてHTMLの表として書き起こしました**（画像0枚）。
評価は色ではなく文字（優/良/可/不可）で持たせているので、
色が見分けにくい方にも伝わります。

### その他の実測値

| シグナル | 実測 |
|---|---|
| **ズーム禁止** | `maximum-scale=1.0` でピンチズームができません |
| **HTTPS未対応** | `https://www.touhoku-caster.com/` は接続できません |
| alt属性の欠落 | 画像6点のうち **5点** に alt がありません |

## この提案で変えたこと

### 1. 物性表を主役にする

7材質×10項目の表を、ページの最初の節に置きました。
冒頭の図も同じ格子の形にしてあり、「濃いほど高評価」で
**ゴム系は油とガソリンに弱く、ウレタン以上は強い**という
全体の傾向が一目で分かります。

### 2. 試験データを表にする

アムスラー試験機による圧縮試験を、**12行すべて**転記しました。
150BR・150Kそれぞれに2系列の測定値があります。
元素分析表（C 3.80／Si 2.81 ほか）も同様です。

自社で鋳造しているからこそ出せるデータであり、
「本当に強いのか」を確かめたい相手に対する最も直接的な答えです。

### 3. AGV対応を前に出す

TSRシリーズは「①AGVに使用可能 ②動力牽引可能 ③重荷重用」。
無人搬送車が普及していく局面で、これは探されている製品です。
現行サイトではトップページの新製品欄に埋もれています。

## 事実の扱いについて

本文の数値・固有名詞74項目は、現行サイトの記述と照合済みです。
物性表の70マスは、画像を目視で読み取って転記しました。

### 転記しなかった表が1つあります

現行サイトの `detail_quality.html` には「引張り試験」の表がありますが、
**その数値がすぐ上の「元素分析表」と完全に同一**です。

| | 値 |
|---|---|
| 元素分析表 | C **3.80** ／ Si **2.81** ／ Mn **0.34** ／ P **0.0022** ／ S **0.0012** |
| 引張り試験 | 直径 **3.80** ／ 標点距離 **2.81** ／ 荷重 **0.34** ／ 強さ **0.0022** ／ 伸び **0.0012** |

直径3.80mm・荷重0.34kg という試験片は物理的にありえず、
伸び0.0012% は同じページの「**伸び20〜24%**」とも矛盾します。
コピー時の複製ミスと考えられます。

本提案では**この表を転記せず**、本文に
「正しい試験値をご提供いただければ掲載します」と記載しました。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（約4,900文字）
- **ピンチズームは禁止していません**
- 物性表に画像は使っていません（評価は文字、色は補助）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の紺は、**現行サイトで実際に使われている色**
`rgb(3,60,131)` = `oklch(37.0% 0.131 257.6)` から採りました。
副色には同じサイトのサーモン `rgb(221,135,114)`（hue 34.5）を、
白地でAAに届く明度52%まで落として使っています。
物性表の「不可」をこの副色で示すため、紺一色では足りませんでした。
