# 株式会社八光電機製作所 — リニューアル提案サイト

情報通信用接続機器メーカー。本社は東京都中央区、工場が埼玉県吉川市にあります。
既存サイト <http://www.hachiko-denki.co.jp/> の公開情報のみを使って再構成した、
1ページ構成の提案です。

## スコア根拠（prospect-scanner: 90点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- **`<iframe>` によるページ内埋め込み構成**。「この部分は iframe 対応のブラウザで
  ご覧ください」という 1990年代の注意書きが残っています
- 会社案内が `info_01.html` 〜 `info_05.html` に分割され、目次から辿る必要がある
- 文字コードが Shift_JIS
- 沿革ページの末尾に、テンプレートの雛形行（`＊＊年＊＊月　＊＊＊＊＊＊＊＊＊。`）が
  コメントアウトし忘れで残っています

内容そのものは充実しており、Copyright も 2026 年まで更新されています。
**器だけが古い**タイプの案件です。

## デザイン方針

### 色 — 二色を使い分けました
原サイトの CSS で最も多く使われているブランド色は `#0f218b`（深い青）で、
これを主色としました。あわせて `#0090b3`（シアン）を副色として引き継いでいます。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#0f218b` | `32.7% .173 266.7` | — |
| 本提案 `--ind` | `34% .16 267` | **0.3°** |
| 原サイト `#0090b3` | `60.6% .113 223.0` | — |
| 本提案 `--cyan` | `56% .105 223` | **0.0°** |

**同じ色相帯の他案件との差別化について。** 埼玉には 264〜275° の案件が複数あります
（吉野プレス 264°、ベルノ技研 264°、宮崎合金 273°）。本案が違って見えるのは、
**シアンとの二色使い**と、**角丸をすべて 0 にした**ことによります。
シアンは「光」の製品群と太陽光発電のセクションだけに使い、
インフラ設備メーカーらしい直線的な版面にしました。

### 構成の軸 — 通信インフラの末端
この会社がつくっているのは、光ファイバーが家に入ってくる一番端の部品です。
見出しを「家の壁の、その先をつくる。」としたのは、
製品名（光コンセント、ローゼット、端子板）だけでは何の会社か伝わらないためです。

**沿革を重視しました。**昭和8年の電話機部品から、国鉄の車両用電機器具、
電電公社の端子板、NTTのジャック式ローゼット、そして光コンセントへ。
通信インフラの変遷とそのまま重なる19項目です。NTT東西からの感謝状6件も、
この会社の信用を示す事実として個別に記載しました。

## 事実確認について

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。`<iframe>` はマップ以外に使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001/14001）／
  LocalBusiness **2件**（本社・吉川工場）／ WebSite ／ FAQPage
- MEO 対応: 本社と吉川工場それぞれに Google マップ埋め込み（API キー不要の `?output=embed` 形式）
