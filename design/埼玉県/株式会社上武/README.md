# 株式会社 上武 — トップページ リニューアル案

現行サイト（https://www.jo-bu.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個** |
| **メタディスクリプションが無い** | 検索結果の説明文をGoogleが本文から拾って生成している状態です |
| テーブルレイアウト | `<table>` **10個** |
| **画像のalt属性** | 画像65点中 **53点に alt が無い**（8割） |
| **トップページが休業案内の羅列** | 新着情報が2011年〜2021年の休暇告知で埋まっており、**何ができる会社なのかが最初に出てきません** |
| 最終更新 | 新着情報の最新が **2021年12月** |

**HTTPSには対応済みです。**
問題は、**トップページの構造**に集中しています。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは980px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 化学強化の断面

化学強化は「ガラス表面のナトリウムイオンを、より大きなカリウムイオンに
置き換えることで、表面に圧縮応力層をつくる」処理です。
これを**板ガラスの断面図**として描きました。
上下の表面に圧縮応力層（内向きの矢印で圧縮を示す）、内部に引張応力層があります。

上下の層は**厚み16px・完全対称**に配置し、
層の下端がガラス断面の下端と一致することを計算で照合しています
（矢印も各層の中心 y=68 / y=132 に配置）。
実描画は PC 406×254px（ガラス断面 345×102px、圧縮層 345×20px×2）。

### 型 ── ガラスの性質を構成に使う

現行サイトから画素採取した鈍色 `#444856` = `oklch(40.3% .024 272.7)` が基準です。
**彩度が .024 と極めて低く、ほぼ無彩色**なので、これを地と文字に使いました。
アクセントは、同じく現行サイトにある淡黄緑 `#f5ffb5`（hue 114）から
明度を落とした `oklch(48% .098 114)` です。

ガラスは「ほぼ無色だが、厚みと角度で色が出る」素材です。その性質を型にしました。

- 地はごく淡い青灰（無彩に近い）
- 区画の境界は塗りでなく**細い罫の重なり**で示す
- アクセントは面積を絞り、**数値と強調にのみ**使う

### 見出し

「ガラスの表面だけを、押し合う状態にします。」を h1 にしました。
現行サイトのトップは**キーワードの羅列**（「ケミカル強化 化学強化 ガラス加工
硝子加工 表面研磨 試作 強化硝子…」）から始まり、
そのあとが休暇のお知らせです。**何をする会社かが文章として書かれていません。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

断面図は**上下対称であることを計算で照合**しています。
化学強化はガラスの両面に等しく作用する処理なので、
**上下の層の厚みが違う図は、処理そのものを誤って説明することになります。**
見た目では数pxのずれに気づけず、検査もすべて通ってしまうため、
座標から検算しました。
