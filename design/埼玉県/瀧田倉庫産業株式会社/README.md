# 瀧田倉庫産業株式会社 — トップページ リニューアル案

現行サイト（http://www.takita-souko.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **980px**。ページ全体が **38%** に縮小されて表示されます |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **文字コードが Shift_JIS** | UTF-8 以前の文字コードです |
| **画像の alt 欠落** | 45点中 **21点** に alt がありません |
| **レイアウト目的のtable** | ページ内に **19個**のテーブルがあります |

### この業種では、スマホで見られないことの損失が直接的です

**貸倉庫や貸工場を探す人は、まず携帯で検索します。**
製造業の会社案内であれば「後でPCから見る」ことも起こりますが、
物件情報は探しているその場で見るものです。

**38%に縮小された物件情報は、面積も賃料も読めません。**

## 設計上の判断

### 署名的装置 ── 投資と、その先の賃料

この会社の提案は結局「いくら直せば、いくら入るか」です。

そこで、実例1の金額を**同一尺度の帯**で並べました。
修繕への投資100万円と、年間の賃料336万円。

**描画後の実測で、帯の比が 3.360 倍**であることを確認しています
（336÷100 = 3.36）。

また、**月額28万円×12 = 336万円**が原文の年額と一致することも
先に検算しました。**原文の数字どうしが矛盾していないことを確かめてから
図にしています。**

### 配色 ── 262だが、地と形で分ける

主色は現行サイトから画素採取した青 `rgb(0,59,169)` =
`oklch(40.2% .184 261.9)`。**色相差 0.1°**。

262近傍は既存提案に多い色域です。そこで次の軸で分けました。

- **地を無彩の白**に（青みを入れない）
- **数字を大きく右揃えで出す「収支」の形**を主要な形にする
- **製造業ではないので設備表を持たず、事例と数字で構成する**

### 見出し

「遊んでいる建物を、貸せる建物に。」を h1 にしました。
現行サイトの h1 は
「越谷市・春日部市・三郷市・八潮市・吉川市・川口市の倉庫（貸倉庫、賃貸倉庫）・
工場（貸工場）」という地名の羅列です。
**検索には効きますが、何をしてくれる会社かは伝わりません。**

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには物件写真とバリューアップの
  ビフォー・アフター写真があります。
  **特に実例1の改装前後の写真は、この提案の中心なので必須**です。
  元データのご提供をお願いします
- **物件一覧を本提案に含めていません。**
  物件は入れ替わるため、**トップページからは「物件を探す」導線だけを置き、
  一覧は別ページで随時更新する構成**をお勧めします
- **代表取締役の経歴が詳細に掲載されています**
  （学歴・職歴・所属団体・所有資格・共著書・趣味）。
  **政治家後援会の役職も含まれる**ため、
  **本提案では代表者名のみとし、経歴は含めていません。**
  掲載範囲についてご相談させてください
- **宅建業免許の有効期限が令和9年4月15日**です。更新後は表記の変更が必要です
- **所在地に「（2025年6月25日より）」という注記**があります。
  移転済みであれば注記を外せます
- **売上高・従業員数の記載がありません**
- **実例2以降の事例**があればご教示ください。実例1のみを掲載しています

### 原文の数字どうしの検算

図にする前に、**原文の金額が互いに矛盾していないか**を確かめました。

- 実例1: 月額28万円 × 12 = **336万円** → 原文の年額と一致
- 想定案: 月額60万円 × 12 = **720万円** → 原文の年額と一致

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。
