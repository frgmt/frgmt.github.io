# 株式会社東洋精工 — トップページ リニューアル案

現行サイト（http://toyo-seiko.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ページ全体が **38%** に縮小されて表示されます |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **h1 が無い** | トップページに見出し要素が1つもありません |
| **メタディスクリプションが無い** | 検索結果の説明文を検索エンジンが自動生成します |
| **画像の alt が全欠落** | **15点すべて**に alt がありません |

### 38%で読めなくなっているもの

このサイトの価値は、**製品一覧18点それぞれに書かれた公差**です。

- 流量制御バルブ用ニードル — **テーパー部円周振れ2μ以下**
- 光通信コネクター部品 — **内径レンジ5μ**
- 自動車部品各種 — **内径公差8μ（CPK）**

**μ（マイクロメートル）の単位が入った数値は、
38%に縮小されると桁が判別できません。**

### ナビゲーションが1文字ずつ分かれています

現行サイトのナビゲーションは
「HO ME 概 要 製 品 V A」のように**1〜2文字ずつ改行**されています。
見た目は縦組みですが、**スクリーンリーダーは1文字ずつ読み上げる**ため、
音声での利用が困難です。

## 設計上の判断

### 署名的装置 ── 測る側が、2桁上

精密加工の会社は「μ単位で加工できます」と言います。
**しかし、それを保証できるかは測定側の精度で決まります。**

そこで、対数軸の上に2つの点を置きました。
**加工公差2μと、超精密測長機の繰り返し精度0.03μ。**

目盛の位置は計算で置き、**7点すべてが対数式と一致すること**を照合しています。

### 配色 ── 261だが、地と形で分ける

主色は現行サイトから画素採取した紺 `rgb(0,54,144)` =
`oklch(36.8% .157 260.8)`。白地でそのまま使える暗さなので
`oklch(38% .150 261)` としています。**色相差 0.2°**。

261近傍は既存提案に多い色域です。そこで次の軸で分けました。

- **地を無彩の白**に（紺みを入れない）
- **製品を「公差つきの索引」として並べる形**を主要な形にする
- **区画見出しを英字のみの小さな標識**にする

### 見出し

「ミリの部品を、ミクロンで。」を h1 にしました。
現行サイトの
「ミリサイズの製品をミクロン単位の誤差で」という一文を短くしたものです。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには製品写真18点と
  検査風景の写真があります。
  **μ単位の部品は、写真がないと大きさが伝わりません。**
  元データのご提供をお願いします
- **画像15点すべてに alt がありません。**
  製品名と加工内容が本文にあるので、alt を付けるだけで
  **検索での見つかりやすさが変わります**
- **売上高の記載がありません**
- **超精密測長機のメーカー名・台数**が記載されていません
- **2026年4月に社長が交代**されています（前社長は会長に就任）。
  本提案では会社概要に現社長名と交代の事実を併記しましたが、
  **掲載の可否をご確認ください**
- **対応可能な材質・径・長さの範囲**が一覧されていません。
  製品ごとの材質は分かりますが、**「何が作れるか」の全体像**があると、
  問い合わせの質が変わります
- **ISO の認証番号**が記載されていません

### 書きかけの CSS を残しませんでした

作成中、`--key` の値に余分なセミコロンを入れてしまい、
一時的に**下に再定義を足して回避**していました。
**これは残骸になるので、元の宣言を直して重複を削除**しています。
`:root` は1箇所のみです。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。
