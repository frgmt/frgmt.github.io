## 設計上の判断

### 署名的装置 ── 蝶番がすること

蝶番は、**開いて閉じることだけを何万回も繰り返す部品**です。
だからこそ、芯の位置と羽根の精度がそのまま製品寿命になります。

そこで、固定羽根に対して可動羽根が芯を中心に回る図を描きました。
0°／45°／90°／135° の4段階で、**羽根の長さはすべて同じ92px**です。

描画後に `getTotalLength()` で測り、
**5本すべてが 92.0〜92.1px（差0.1px、浮動小数の丸め）であること**を確認しました。
**角度だけが変わり、長さは変わらない**——これが蝶番です。

### 配色 ── 232は空いている色相

主色は現行サイトから画素採取した青 `rgb(40,108,140)` =
`oklch(50.3% .084 232.4)`。白地用に `oklch(42% .080 232)`。**色相差 0.4°**。

**hue 232 はこのリポジトリでほとんど使われていません。**
色相そのもので分かれているため、他の軸で無理に分ける必要がありませんでした。

### 見出し

「開いて、閉じる。それだけを60年。」を h1 にしました。
現行サイトには h1 がなく、
**ごあいさつの「創業以来約60年」と、製品そのものの動きを組み合わせた**ものです。
