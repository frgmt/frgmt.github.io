
### 「タグが無い」のではなく「固定幅で書かれている」

多くのサイトは viewport タグ自体が無いために縮小されますが、
このサイトは **`width=1080` と明示的に固定幅が指定されています。**
`width=device-width` に変えるだけでは足りず、
中のレイアウトも合わせて組み直す必要があります。

## 設計上の判断

### 署名的装置 ── 良否で分かれる

この会社が作る装置の多くは、**検査して、分類して、収納する**ものです。
「良否を判定して終わり」ではなく、分けて収めるところまでが装置です。

そこで、1本の供給ラインが検査部で2本（良品／不良品）に分岐する図を描きました。
図の下に添えたタクトの範囲「1秒/個 から 75秒/セット まで」は、
**現行サイトのピックアップ9件に記載された値を全て拾い出し、
最小と最大を確認した上で書いています。**

### 配色 ── 264だが、地と組み方で分ける

主色は現行サイトから画素採取した濃紺 `rgb(0,2,122)` =
`oklch(26.4% .180 264.1)`。白地用に `oklch(29% .170 264)`。**色相差 0.1°**。

**264 はこのリポジトリで最も混み合う色相です**（12社以上が使用）。
しかもこの濃紺は**彩度 .180 と高く**、既存提案にも近い値の社があります。
色は現行サイトから採ったものなので動かさず、次の軸で分けました。

- **地を紺に寄せた極淡色** `oklch(98.6% .008 264)` に（他社は白または無彩）
- **実績63件を「番号つきの索引」として組む**（他社はカードまたは表）
- **区画の見出しを左に振り、本文と2段に割る**（他社は見出しが本文の上）

### 見出し

「検査して、分けて、収める機械を作る。」を h1 にしました。
現行サイトの h1 は「外観検査、画像処理検査、HALCON画像検査、表面検査、
自動化装置はノアエンジニアリングへ！」ですが、
**これは検索語を並べたもので、何を作る会社かが読み取りにくい**と考えました。

### 初回検査で見つけた不具合

**320pxで60px、375pxで6pxの横はみ出しが出ました。**

原因は、見出しを左に振る2段組み `.sec__g` の中に、
`min-inline-size:360px` を指定した設備表を置いていたことです。
**グリッド項目の `min-width` は既定で `auto`** のため、
表がグリッドのトラックを 362px まで押し広げ、
`overflow-x:auto` を付けていても外側が縮まりませんでした。

`.sec__g > *{min-inline-size:0}` を入れて解消しています。
**`overflow-x:auto` を付けただけでは、グリッドやフレックスの中では効きません。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。

### 実績63件の照合

**現行サイト4ページから実績名と分類を機械的に抽出し、
掲載した63件と1件ずつ突き合わせました。**

- 原文 63件 / 掲載 63件 — **過不足なし**

なお現行サイトの供給・分類装置は **No.10 が欠番**のため、
番号の最大値は13ですが件数は12件です。
**番号は原文のまま残し、欠番であることをページ上に明記**しています。
