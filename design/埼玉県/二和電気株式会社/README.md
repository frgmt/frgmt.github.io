# 二和電気株式会社 — トップページ リニューアル案

現行サイト（http://www.niwadenki.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグは正しいのに機能していない** | `width=device-width, initial-scale=1` と書かれていますが、`.container` が **1100px 固定**です。実機375pxでレイアウトビューポートが **1100px** に広がります |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **h1 が無い** | トップページに見出し要素が1つもありません |
| **画像の alt 欠落** | 22点中 **15点** に alt がありません |

### 縮小されないぶん、切れます

`width=device-width` と宣言しているため、
**ブラウザは「このページはスマホ対応済み」と判断し、縮小しません。**
ところが中身は1100px固定なので、**入りきらない部分が単に見切れます。**

実機のスクリーンショットで確認しました。

- キャッチコピーが **「カスタム電源システ」** で切れています
- ナビゲーションが **「製」**（製品紹介）の途中で切れています
- 事業紹介の **「非常用電」** が切れています

**viewportタグが無いサイトは全体が小さくなるだけですが、この型は情報が消えます。**

なお jQuery は 3.7.1 と新しく、お知らせも2023年まで更新されています。
**サイトの手入れ自体は続いており、レイアウトだけが取り残されている状態**です。

## 設計上の判断

### 署名的装置 ── 出力容量の対応範囲

この会社の特徴は「直流も交流も、小型から大型まで1社で作る」ことです。
そこで、対応容量を**対数目盛の帯**で示しました。

**単位をVAで統一できる3機種だけを載せています。**
風力発電用インバータは200**W**表記のため、同じ軸に載せると
単位の異なるものを並べることになります。**図から外し、その旨を明記**しました。

描画後の実測で、**3本の帯すべてが対数目盛の計算値と
小数第1位まで一致すること**を確認しています。

### 配色 ── 248だが、地と形で分ける

主色は現行サイトから画素採取した青 `rgb(51,122,183)` =
`oklch(56.4% .118 247.7)`。白地用に `oklch(44% .112 248)`。**色相差 0.3°**。

248近傍は既存提案に多い色域です。そこで次の軸で分けました。

- **地を無彩の白** `oklch(99% 0 0)` に（青みを入れない）
- **入出力仕様を「IN / OUT」の対**で並べる形を主要な形にする
- **区画見出しを英字の小見出しだけ**にする

### 見出し

「直流も交流も、1台から設計する。」を h1 にしました。
現行サイトには h1 がなく、メタディスクリプションの
「直流～交流、小型から大型まで電源装置をカスタムメイド致します」が
実質的なキャッチになっています。**この一文は良いので、
見出しとして正しく置き直しました。**

### 検査を通過した状態で見つかった不具合

**`verify-site.mjs` は「すべて通過」と報告していましたが、
`getBBox` で確認したところ「30〜120kVA」のラベルが
x=325 まで伸びており、viewBox（320）から5px はみ出していました。**

**SVG の中身は検査の対象外**なので、この種の切れは自動では捕まりません。
ラベルの位置を帯の上に移して解消し、
**スクリーンショットで実際に読めることも目視で確認**しました。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。
