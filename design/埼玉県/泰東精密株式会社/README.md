# 泰東精密株式会社 — トップページ リニューアル案

現行サイト（https://www.taitoh-d.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | iPhone はレイアウト幅を **980px** にフォールバック。実機390px に対し表示倍率 **40%** |
| **本文が実効 5.6px** | 14px の本文が iPhone 13 で 5.6px、iPhone SE（320px）では **4.6px** 相当に縮む |
| HTTPS | ✅ 対応済み |
| jQuery | ✅ 3.7.1（新しい） |
| h1 / meta description | ✅ どちらもあり |
| 画像の alt | ✅ 23点すべてに記述あり |

### 直すべきは1行、失っているものは大きい

このサイトは作りが古いわけではありません。HTTPSも通っていて、jQueryも新しく、
alt属性まで丁寧に入っています。**欠けているのは `<meta name="viewport">` の1行だけ**です。

しかしその1行が無いために、iPhone は 980px 幅のページを 390px の画面に押し込みます。
横スクロールは出ません。代わりに**すべてが40%に縮む**。

損失が最も大きいのは**設備一覧**です。

- 加工設備11台の、メーカー・機械名・X/Y軸ストローク・導入年月・備考
- 検査室のCNC三次元測定器（東京精密 XYZAX AXCEL PH／2023年3月導入）
- 五面加工機の最大ストローク 5,000×3,000

これは発注側が最も知りたい情報であり、同時に**最も検索されている語**でもあります。
それが実効5.6pxの表に閉じ込められ、ピンチしないと読めない状態にあります。

## この提案で変えたこと

### 1. 数字を、読める大きさで前に出す

現行サイトで最も強い事実は、文章ではなく数字の側にあります。

- 最大ワークサイズ **5,000 × 3,000 × 1,850mm**
- 平面精度 **0.01** 保証
- 寸法精度 **±1/100** 保証（1点ものだけでなく量産品も同値）
- 準恒温工場 **23℃±2℃** ／ 検査室 **23℃±1℃**

冒頭にこの4つを並べ、以降の節でそれぞれの根拠を示す構成にしました。

### 2. 「5m」がどれくらいかを、図で示す

最大ワークサイズは数字だけでは実感が湧きません。
**身長1,700mmの人影を同じ縮尺で並べた図**を冒頭に置きました。
ワークの高さ1,850mmは人の背丈の1.088倍にあたり、図もその比で描いています
（1mm = 0.052px。ワーク96.2px、人88.4px）。

### 3. 温度を「階層」として見せる

1/100mmを保証するには、削る場所と測る場所の温度を別々に管理する必要があります。
現行サイトはこれを別ページに分けて書いていますが、
**工場 23℃±2℃ → 検査室 23℃±1℃ → 保証精度 ±1/100** と
許容幅が狭まっていく並びにすると、一続きの理屈として読めます。

### 4. 設備表を、HTMLの表として組み直す

現行サイトの設備表を、ストローク・導入年月・備考まで含めてすべて転記しました。
検索エンジンが読める形式になり、スマホでは横スクロールする表として収まります。

## 事実の扱いについて

本文の数値・固有名詞49項目は、すべて現行サイトの記述と照合済みです。

ただし**1点、現行サイト内で数が合わない箇所**があります。

> 「大型MCを10台保有し、24時間体制で短納期対応」
> 「1Mを超えるマシニングセンターを8台保有し」
> — https://www.taitoh-d.co.jp/kouseido/

同サイトの設備一覧（2024年5月現在）を数えると、**加工設備は11台**、
X軸ストロークが1,000mmを超える機械は**9台**です。
2024年4月に5軸複合旋盤が入ったことで、文章側が追いついていない可能性があります。

本提案では**設備表の実数（11台／9台）のみを使い**、10台・8台という表現は採用していません。
実際の台数は、商談の際にご確認ください。

沿革についても、業態転換（オイルスイッチ→機械組立→機械加工）の年次が
現行サイトに書かれていないため、代表挨拶の記述どおり「先々代」「先代」と表記し、
年次を推測で埋めることはしていません。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,253文字）。
  スクロール演出は `.js` クラスが付いたときだけ有効になります
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認（設計時の配色計算では最小 6.13:1）
- タップ対象はすべて44px以上

## 配色について

基調の緑は、**現行サイトで実際に使われている色**
`rgb(44,138,83)` = `oklch(56.4% 0.122 153.7)` から採りました。
白地で本文コントラストがAAに届くよう明度のみ下げ（42%）、**色相は保持**しています。
地の白はわずかに暖色（hue 120）へ振り、恒温工場という主題に合わせています。
