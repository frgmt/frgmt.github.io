# 株式会社協栄製作所 — トップページ リニューアル案

現行サイト（http://www.neji-kyoeiseisakusyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **ズームが禁止されている** | viewport が `maximum-scale=1.0, minimum-scale=1.0`。**スマホで拡大できません** |
| **スマホ実表示 39%** | 実機UA（375px）で `scrollWidth` **969px** |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **jQuery 1.7.2** | **2012年**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |
| **画像の alt 欠落** | **6点すべて**に alt がありません |

### ズーム禁止は、拡大して読むという逃げ道も塞ぎます

39%に縮小されたページでも、拡大すれば読めます。
ところがこのサイトは `maximum-scale=1.0` と `minimum-scale=1.0` を指定しており、
**ピンチ操作で拡大できません。**

**JIS認証番号（JQ0507082 など）は、拡大しないと読めない大きさです。**

## 設計上の判断

### 署名的装置 ── CO₂排出量を、毎月出す

この会社の性格が最もよく出ているのは、
**排出量を拠点別・月別に、実数で公開している**ことだと考えました。

そこで、環境取組ページの実績表をそのまま積み上げ棒グラフにしました。
**目盛は 100t を 104px に写像**し、描画後の実測で
**6本すべてが計算値と小数第1位まで一致すること**を確認しています。

各月の合計（81.32 / 92.29 / 97.78）も、
**本社＋埼玉の和が原文の合計欄と一致すること**を先に検算しました。

### 配色 ── 254だが、地と形で分ける

主色は現行サイトから画素採取した青 `rgb(108,174,254)` =
`oklch(74% .135 254.1)`。白地の本文でAAを満たさないため
`oklch(44% .118 254)` まで明度を落としました。**色相差 0.1°**。

254近傍は既存提案に多い色域です。そこで次の軸で分けました。

- **地を無彩の白** `oklch(99% 0 0)` に（青みを入れない）
- **認証番号を等幅で並べる「登録簿」の形**を主要な形にする
- **区画の見出しを英字＋和文の2行組**にする

### 見出し

「ねじづくり一筋、80年。」を h1 にしました。
**「ねじづくり一筋」は現行サイトが繰り返し使っている言葉**で、
1946年創業から数えて80年にあたります。
