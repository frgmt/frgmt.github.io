# ベニー精工株式会社 — トップページ リニューアル案

現行サイト（http://www.benny.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで **100点（Aランク）** と判定された根拠。

## 設計上の判断

### 署名的装置 ── 加工径ごとの台数分布

自動旋盤は**「その径のバーが通るか」**で選ばれます。
そして同じ径に何台あるかが、そのまま**量産の余力**になります。

現行サイトの設備表は機種名の縦一列で、径ごとの分布が読み取れませんでした。
本案では機種を径で集計し直し、**横棒の長さで台数**を示しています。

```
Φ4    1台   ██
Φ12   7台   ██████████████
Φ16   6台   ████████████
Φ20  10台   ████████████████████   ← 最多
Φ23   1台   ██
Φ25   1台   ██
Φ32   3台   ██████
Φ45   3台   ██████
Φ50   3台   ██████
```

Φ12〜Φ20 の小径帯に 23台が集まっていることが一目で分かります。
この集計は現行サイトの機種一覧から計算したもので、合計は35台です。

### 機種名は削らず残す

同じ機械を使っている発注者なら、機種名を見れば条件出しの話が早く進みます。
そこで径ごとの分布とは**別に、機種名のままの表**も残しました。

### ウチヤ・サーモスタットと同色相であることへの対処

ウチヤ（28°）と本案（29°）はほぼ同じ赤です。別の軸で分けました。

| | ウチヤ | ベニー精工 |
|---|---|---|
| 明度 | .48（明るい赤） | **.41（暗い臙脂）** |
| 地 | 完全な無彩色 | **黄みの紙色（hue 70）** |
| 赤の使い方 | 注意喚起の枠に限定 | **罫・見出し・棒グラフに広く** |
| 署名的装置 | 製品比較表 | **径ごとの台数分布** |
| 書体 | Zen Kaku Gothic | **しっぽり明朝＋Noto Sans** |

ウチヤは「安全部品なので赤を絞る」判断でしたが、こちらは
ロゴが濃い臙脂（#780000）なので、暗く落として罫に使っています。

### 色 — ロゴとCSSの両方から採取

| 採取元 | 値 |
|---|---|
| CSS `common.css` | `#9b0000` = `oklch(43.3% .178 29.2)` |
| ロゴ画像の画素（953px） | `#780000`（同系統・より暗い） |

CSS値を基準に `--bar: oklch(41% .145 29)` — **色相差 0.2°**。

第二色として現行CSSの焦茶 `#5a482b` を採取し、
設備表の区分見出しにだけ使っています。

## データの出所

設備・沿革・品質管理はすべて**現行サイトから取得した実データ**です。

- 設備一覧（機種名・メーカー・最大径・台数） … `equipment.html` より
- 会社概要・沿革 … `company.html` より
- 三段階チェック・自社開発ソフト … `quality.html` より
- 環境方針 … `ecopro.html` より

**径ごとの台数分布は、機種一覧から当方で集計したもの**です。
現行サイトにこの集計はありません。合計35台になることを確認しています。

### 確認が必要な項目

- **郵便番号（鴻巣市上会下）が現行サイトに記載されていません**。
  桶川第二工場は 363-0004 と記載があります
- 従業員数（記載が無いため未掲載）
- ISO等の認証（品質方針・環境方針の記載はあるが認証の記載は無し）
- 営業時間（記載が無いため JSON-LD にも入れていません）
- 現行サイトの設備表には HTML コメント（`-->`）で**非表示にされた行**が
  混在していました。NM3FD、FA45、NP4W、フライス盤、コンターマシン、
  多軸ボール盤、油圧プレスなどです。本案では**表示・非表示を問わず
  記載のあるものを採録**しましたが、現役の設備かどうかご確認ください
