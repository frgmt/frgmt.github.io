# 赤心堂病院 サイトリニューアル — トップページ

既存サイト <https://www.sekishindo.or.jp/> のトップページを、**ページ構成と色相を維持したまま**モダンに再設計したもの。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

```
index.html          全コンテンツ
assets/style.css    デザイントークン + コンポーネント
assets/app.js       動く部分のみ（約50行）
robots.txt / sitemap.xml / llms.txt / icon.svg / site.webmanifest
```

## 技術構成

**Nuxt 版から静的HTMLへ書き換えました。**

| 項目 | 変換前 | 現行 |
|---|---|---|
| フレームワーク | Nuxt 4（SSG） | **なし（素のHTML）** |
| UI | Vue 3 SFC × 11ファイル | **HTML直書き** |
| CSS | Tailwind CSS v4（`@theme`） | **手書きCSS（CSS変数）** |
| Vue の役割 | 全ページを構築 | **モバイルメニュー開閉と地図の遅延読込のみ** |
| ビルド | `npm install` → `nuxt build` | **不要** |
| 容量 | 259MB | **644KB** |

フォントは Shippori Mincho（見出し）+ Noto Sans JP（本文）のまま。

### 書き換えの方針

- **デザインは変更していません。** トークン・配色・セクション順・余白はすべて元版のまま
- **内容はすべて HTML に実在します。** 元版は `useHospitalData.ts` の配列から描画していましたが、
  静的版では文字列を直接マークアップに書いています
- **文字の減光に `opacity` を使っていません。** `opacity` はコントラストが測定できなくなり、
  自動チェックで「非表示」と誤判定されるため、実際の色を指定しています
- 変換前の Nuxt 版は `.archive/` に保存（データの出典コメントが残っているため）

### 配色を白ベースに変更しました

**ダークモードを削除し、地色を純白に統一しました。** 病院サイトで黒基調は、
緊急性や重篤さを連想させ、第一印象として適さないという判断です。

元サイト（https://www.sekishindo.or.jp/）を実測し、その配色に合わせています。

| 実測した色 | 用途 | 本案での扱い |
|---|---|---|
| `#ffffff` | 地 | **そのまま純白を採用** |
| `#464646` | 本文 | `#333333`（可読性のためやや締めた） |
| `#f0ebe6` | 生成り | **面の切り替えに使用** |
| `#db2850` | 朱（ブランド色） | アクセント |
| `#501e0a` | 濃茶 | — |

OSがダークモード設定でも**白のまま**になることを実測確認しています
（`prefers-color-scheme: dark` のブロックを持たないため）。
CSSにはその旨のコメントを残し、再び追加されないようにしています。

## アートディレクション

> 和紙のような温かいクリーム地の上に、直交グリッドと明朝体セリフで組んだ「診察券のような端正さ」。朱色（赤心）は決定的な一点にのみ差す。

### 色の継承

既存サイトのCSSを実測し、コア3色を抽出して継承した。

| 役割 | 旧サイト実測値 | 本デザイン |
|---|---|---|
| ブランド朱 | `#d72850` | `oklch(56% 0.192 18)` |
| 構造の紺 | `#0a4691` | `oklch(36% 0.115 258)` |
| 地 | `#ffffff` / 生成り `#f0ebe6` | 白地 + 面の切り替えに生成り |

旧サイトはこれに橙 `#f0821e` / 緑 `#78c628` / 水色 `#1ebbcf` を加えた6色構成で視覚的に散漫だったため、**色相は維持しつつアクセントを朱1色に集約**した。病院サイトとして求められる「固さ」は、角丸を最大8pxに抑え、明朝体見出しと直交罫線グリッドで担保している。

## データの出典

`.archive/app/composables/useHospitalData.ts` に出典コメントが残っています。

- 受付時間 — `/reception.html` の実データ（診療科ごとに異なる）
- 所在地・電話 — `/access.html`
- ナビ構成 — トップページのHTML実測

**お知らせ5件は日付・タイトルともサンプルです。** 実運用時は実データに差し替えてください。それ以外（診療科・受付時間・住所・電話・アクセス）はすべて実サイトの値です。

## SEO / MEO / AIO

- **SEO** — title / description / canonical / hreflang / OGP全項目 / Twitter Card / robots。プレースホルダなし
- **MEO** — `Hospital` JSON-LD に `address` `geo` `openingHoursSpecification` `areaServed`。NAPは `<address>` でクロール可能なテキスト出力（画像化していない）
- **AIO** — `<main>` 冒頭に「何の施設か」を答える3文サマリー / 質問形見出し + 直後に回答 / `FAQPage` JSON-LD は画面文言と5件完全一致 / `llms.txt` 設置 / `GPTBot` `ClaudeBot` `PerplexityBot` は許可

### 変換中に見つけて直したもの

- **768px で42pxの横溢れ** — グループ施設グリッドが `repeat(3, 1fr)` で、
  施設名の長い列だけトラックが広がっていた（`1fr` の最小値は `auto`）。
  レイアウト用グリッドをすべて `minmax(0, 1fr)` に統一
- **コントラストが 1.01:1 と誤判定** — 罫線を `ul` の半透明背景で描いていたため、
  `li` の文字色が「罫線色」と比較されていた。`li` にも地色を敷いて背景の連鎖を切った
  （実際の比率は 10.65:1 で元から問題なし）
