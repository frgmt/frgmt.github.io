# 東成工業株式会社 — リニューアル提案サイト

埼玉県鴻巣市の塗装メーカー。既存サイト <http://www.touseikogyo.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 92点）

この案件は、これまで扱った他社と性質が違います。**内容は充実しており、
2020年に更新もされています。**問題は中身ではなく、器のほうです。

- HTTPS 未対応
- **`viewport` メタタグなし** → スマートフォンで PC 版が縮小表示される（最大の問題）
- HTML 4.01 Transitional、レイアウトに `<table>` を20個使用
- `JustSystems Homepage Builder Version 22.0.1.0` で生成
- CSS が `@charset "Shift_JIS"` のまま（HTML は UTF-8 なので不整合）
- 情報が9ページに分散し、スマートフォンでは辿るのが難しい

つまりこの提案の主眼は「情報を作り直す」ことではなく、
**すでにある良い情報を、スマートフォンで読める形にまとめ直す**ことです。

## デザイン方針

### 色 — ロゴから採色しました
CSS 内で最も多く使われている色は `#000066`（14回）ですが、これは
ホームページ・ビルダーのテンプレート由来の値です。実際に画面で目に入る
コーポレートカラーは、ロゴ画像 `logo_e11.jpg` の**シアンブルー**でした。

そこでロゴ画像をピクセル解析し、最頻色 `rgb(0,144,192)` を採色しました。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ実測 `rgb(0,144,192)` | `61.3% .123 230.9` | — |
| 原サイト `#b2e3ff`（見出し背景） | `89.1% .064 233.5` | 2.6° |
| 本提案 `--cy` | `50% .115 231` | **0.1°** |

明度のみ 61.3% → 50% に下げています。ロゴのままの明度では白地に置いた
小さな文字がコントラスト基準（4.5:1）を満たさないためです。
淡色 `--cy-md` は原サイトの `#b2e3ff` を引き継いでいます。

### 構成の軸 — 意匠
この会社が売っているのは「塗料を塗る作業」ではなく、**質感（意匠）**です。
原サイトの製品案内ページにも「塗装は多彩な意匠を表現します」と書かれています。

そこで **6種類の意匠を最初のセクション**に置き、それぞれに CSS グラデーションで
描いた見本を添えました。写真ではなくCSSで描いているのは、実際の塗装色は
案件ごとに変わるためで、あくまで「こういう質感が出せる」という目印です。

製品写真には**どの意匠で塗ったか**を必ず添えました。
原サイトでは製品名と意匠が別々の行に置かれていましたが、
「パネルセンター＝ピアノブラック」と結びつけて見せることで、
発注側が自分の部品に置き換えて考えやすくなります。

## 画像の扱い

原サイトの製品写真29点のうち **25点を採用**。除外した4点と理由：

| ファイル | 除外理由 |
|---|---|
| `hand2.jpg` / `mvc-2.jpg` | 作業中の従業員の顔が識別できる。公開前に本人確認が必要 |
| `emb3-2.jpg` | 他社ブランドのエンブレムが主題（取引先の明示になるため要確認） |
| `nw-1.jpg` | 149×106px と小さく、用途が判別できない |

また、4K サイズの画像3点（`PMLD` `SP1` `pnlc1`、計3.4MB）を長辺1400pxへ縮小しました。
画像フォルダ全体で **3.9MB → 928KB**。スマートフォンでの表示速度に直結します。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 「40年の実績」は原サイトの記載どおりです（トップページに40周年ロゴあり）
- 沿革16項目は原サイトの表をそのまま転記しました
- 品質方針・社是・経営理念は原文のまま掲載しています
- 原サイトの誤字（「プラスチック材j量」「持たため」「良好な関係で、、」）は
  それぞれ「材料」「持つため」「関係で」と修正しました
- 従業員数の記載は原サイトになく、掲載していません
- **ISO 9001 は平成17年に「2000年版」で取得した旨の記載しかありません。**
  現在の版（2015年版）への移行状況は未確認です

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。レイアウトに `<table>` は使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001）／ LocalBusiness **2件**（鴻巣・行田）／ WebSite ／ FAQPage
- MEO 対応: 本社工場と行田工場それぞれに Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- 横スクロール 0px（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上
- JavaScript 無効時も全テキストが読める
- 内部リンクはすべて相対パス
