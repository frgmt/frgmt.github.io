# ウチヤ・サーモスタット株式会社 — トップページ リニューアル案

現行サイト（http://www.uchiya.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで **103点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| CSSファイルが存在しない | レイアウトはすべて `<table>` と画像 |
| 文字コード | Shift_JIS |
| ファイル名 | `SeihinPageUB7_HTML.html` `KaisyaGaiyou.html` 等のローマ字 |

現行サイトは更新自体は活発です（2026年8月のニュース、月刊「おんど」の
最新号あり）。**中身は生きているのに器が古い**という典型例で、
リニューアルの費用対効果が高いケースです。

## 設計上の判断

### 署名的装置 ── 動作温度で選ぶ比較表

設計者がこの会社の製品を選ぶとき、最初に決めるのは
**「何度で切るか」**と**「どれだけ流れるか」**です。シリーズ名ではありません。

現行サイトは製品ごとに個別ページがあり、比較するには
5ページを行き来する必要がありました。本案は5シリーズを1つの表にまとめ、
**動作温度範囲を先頭列**に置いています。温度範囲は細い帯でも示し、
スクロールで左から伸びます。

### 「安全部品メーカー」としての色の使い方

ロゴから採取した赤 `#d81818` は強い色です。これを地に大きく使うと
「危険」の印象になります。安全部品のメーカーとしては逆効果です。

そこで**地は完全な無彩色**（`oklch(96.5% 0 0)`）にし、
赤は**罫・見出し・注意喚起の枠だけ**に絞りました。
面積を絞ることで、赤が出てきたときに意味を持ちます。

### アイテックと色相が近いことへの対処

アイテック（37°）と本案（28°）は9°差です。色相は動かさず別の軸で分けました。

| | アイテック | ウチヤ |
|---|---|---|
| 地 | 暖かい砂色（hue 60） | **完全な無彩色** |
| 署名的装置 | 温度レンジの帯（1本） | **5行の比較表＋帯** |
| 赤の面積 | 見出し・罫に広く | **注意喚起の枠に限定** |
| 書体 | Zen Antique（明朝） | **Zen Kaku Gothic + IBM Plex Mono** |

### 現行サイトの注意喚起を、そのまま載せた

現行サイトは「ネット販売を行っていない」「社長名を騙る不審なメール」という
**注意喚起を出しています**。これは会社が実際に困っている問題なので、
デザイン都合で省かず、赤枠の目立つ位置に置きました。

| 採取元 | 値 |
|---|---|
| 和文ロゴ `UCHIYAwabunRogo.gif` の画素 | `#d81818` = `oklch(56.2% .22 28.2)` |

## データの出所

製品仕様・会社概要はすべて**現行サイトから取得した実データ**です。

- 各シリーズの動作温度・開閉容量・用途・特長 … `OtherContet/SeihinPage*.html` より
- 会社概要・事業所 … `OtherContet/KaisyaGaiyou.html` より
- 注意喚起・ニュース … トップページより

### 確認が必要な項目

- 香港社・アイルランド社の**詳細な住所は現行サイトに記載が無い**ため、
  都市名のみ記載しています
- UI2の防爆規格取得は現行サイトのニュース欄で「2025年10月29日」付。
  本案では「2025年10月に取得」としています
- UP6の出荷実績「年間1,000万個超」は**2009年度の数字**です。
  現行サイトの記載のまま引用していますが、最新値への差し替えが望ましいです
- 従業員数（記載が無いため未掲載）
- ISO等のマネジメントシステム認証は現行サイトに
  「マネージメントシステム認証状況」ページへのリンクがありますが、
  **内容を取得できなかったため未掲載**です
- 営業時間（記載が無いため JSON-LD にも入れていません）
