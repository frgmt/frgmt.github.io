# 有限会社 三和テック — トップページ リニューアル案

現行サイト（http://www.sanwatec-co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個** |
| **メタディスクリプションが無い** | 検索結果の説明文をGoogleが本文から拾って生成している状態です |
| **画像のalt属性** | 画像19点中 **19点すべてに alt が無い** |

**この会社のサイトは、2023年のCopyright表記で内容も新しいものです。**
jQuery 3.4.1 と比較的新しいライブラリを使っており、
書かれている技術説明も具体的です（タンク容量、ミルのサイズ、充填量など）。
**問題は viewport タグが抜けていることに、ほぼ集中しています。**

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは981px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。
**「12.5〜25.0μm」「100L〜1,600L」といった数値が最も読めなくなります。**

## 設計上の判断

### 署名的装置 ── 分散の前後

この会社の仕事は「凝集した塊を、均一な微粒子にすること」に尽きます。
ファーストビュー右側に、**左が大小まちまちの凝集塊、右が均一に揃った微粒子**の
対比図をインラインSVGで置きました。

右側の24粒は**6列×4行の格子（間隔17px / 22px）に機械的に配置**しています。
規則性そのものが「均一分散」を意味するため、
目分量で置くと図が主張と矛盾します。
実測でも均一粒24個・凝集塊8個がすべて描画されることを確認しました。

### 配色 ── 橙を主役に

現行サイトから画素採取した橙 `#e87a19` = `oklch(69.2% .166 54.1)` が基準です。
面 `oklch(56% .142 54)`、文字 `oklch(47% .122 54)`。**色相差 0.1°**、明度を落として可読域へ。

同じく採取した紺 `#2e4b71`（hue 256）は既存提案に多い青域のため主役には採らず、
**罫と署名的装置の枠にのみ**使いました。

### 構成 ── 大きいものから小さいものへ

「分散」を構成原理にし、要素を**大きな塊から小さな粒へ**の順で並べています。
インキ製造の4工程（配合→調整→練肉→充填）も、この順に並ぶ工程です。

### 見出し

「塊を、均一な粒に。そこだけをやっています。」を h1 にしました。
現行サイトのトップは**4つのサービスがカードで並ぶだけ**で、
それらに共通する技術が何かは下層ページを読まないと分かりません。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトには
  **「分散前のセルロース拡大写真」**があり、
  **この会社の技術を示す最も直接的な素材**です。元データのご提供をお願いします。
  分散後の写真と並べられれば、署名的装置を実写に置き換えられます
- **郵便番号が現行サイトに記載されていません。**
  構造化データにも含めていません（推測で補完していません）。ご教示ください
- **従業員数・設備台数の記載がありません**
- **「セルロースナノクリスタル（ＣＮＦ）」と書かれている箇所があります**が、
  CNC（Cellulose Nanocrystal）とCNF（Cellulose Nanofiber）は別物です。
  本提案では文脈から**CNC**として扱いました。**現行サイトの表記修正をお勧めします**
- **親水性コーティング剤の特許について、出願番号・登録の有無が不明です。**
  「特許申請した」との記載のみです。登録済みであれば番号の明記をお勧めします
- 分散委託サービスの受託可能な最小ロット・費用の目安がありません。
  「1度限りの試験でも」と書かれているため、**条件を明示すると引き合いが増えます**
- 対応可能な原料の種類（樹脂、顔料、金属酸化物など）の記載がありません

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

### 検査で実際に見つけて直した誤り

**構造化データに、存在しない郵便番号を書いていました。**
現行サイトの全ページを郵便番号の正規表現で検索したところ、
**該当は電話番号（048-620-7088）の誤検出のみで、郵便番号の記載は無い**ことが分かりました。
所在地から推測した番号を入れていたため削除しています。
**推測した住所情報は、誤っていても誰も気づかないまま公開されます。**
記載が無いものは書かない、を徹底しました。

粒子の格子も**間隔が均等であることを計算で照合**しています。
この図は「均一に分散できる」という主張そのものなので、
不揃いに描くと図が主張を否定することになります。
