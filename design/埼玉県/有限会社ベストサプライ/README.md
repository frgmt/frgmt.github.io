# 有限会社ベストサプライ — トップページ リニューアル案

現行サイト（https://www.best-supply.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ページ全体が **38%** に縮小されて表示されます |
| **文字コードが Shift_JIS** | UTF-8 以前の文字コードです |

HTTPS には対応済みで、**画像11点すべてに alt があります。**
この点の状態は良好です。

### スマホ対応を一度やろうとした形跡があります

すべてのページが **`/pc/` 配下**に置かれています。
これは「PC用」と「スマホ用」を分ける構成の名残です。

ところが `/sp/` も `/m/` も **404** で、
**スマホのUAでアクセスしても `/pc/index.html` に飛ばされます。**

**スマホ対応に着手したものの、途中で止まっている状態**と見られます。

## 設計上の判断

### 署名的装置 ── 7台の型締力

従業員5人の工場で、ダイカストマシンが7台。
**しかも25tが3台、16tが2台と同じ能力を複数持っています。**

そこで、7台を型締力の順に並べた棒グラフを描きました。
**同じ能力の機械は同じ高さの棒が並ぶ**ので、
「複数持っている」ことが図から直接読めます。

棒の高さは型締力の平方根に比例させています
（線形にすると8tが40tの5分の1になり見えにくいため）。
**この点は図の中に明記**し、描画後の実測で
**7本すべてが `108 × √(t/40)` と一致すること**を確認しました。

### 配色 ── 276はほぼ未使用

主色は現行サイトから画素採取した紺 `rgb(54,60,103)` =
`oklch(37.2% .074 276.2)`。白地でそのまま使える暗さなので
`oklch(38% .090 276)` としています。**色相差 0.2°**。

**hue 276 はこのリポジトリでほぼ使われていません**（近いのは1社のみ）。
色相そのもので分かれているため、他の軸で無理に分ける必要がありませんでした。

なお、原サイトには緑 `rgb(17,161,85)` も使われていますが、
**緑域（143〜155）は既存提案に5社以上ある**ため、紺を採りました。

### 見出し

「亜鉛ダイカスト、一筋。」を h1 にしました。
**事業内容ページの「一貫して亜鉛ダイカスト製品の製造に従事して参りました」と、
ご挨拶の「亜鉛ダイカスト一筋に邁進しております」**から取っています。
