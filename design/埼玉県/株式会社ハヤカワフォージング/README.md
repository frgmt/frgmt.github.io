## 設計上の判断

### 署名的装置 ── ベベルギヤの歯形と鍛流線

この会社の主張は「削らずに鍛えるから強い」ことです。
ファーストビュー右側に、**18枚の歯を持つベベルギヤ**を楕円投影で描き、
その上に**鍛流線（メタルフロー）が歯形に沿って連続する様子**を重ねました。
切削では繊維流れが断ち切られ、鍛造では連続する——これが強度差の理由です。

歯の座標は `cx + rx·r·cos(a)`, `cy + ry·r·sin(a)` で機械生成し
（歯先 r=1.0／歯元 r=0.82、20度間隔）、
**18枚すべての歯先が式と一致することを計算で照合**しました（最大誤差 0.05px）。
実描画は PC 406×254px（歯形 168×70px、ハブ 61×25px、鍛流線3本）。

### 配色

現行サイトから画素採取した青 `#0066cc` = `oklch(52.2% .177 255.8)` が基準です。
面 `oklch(40% .128 256)`、文字 `oklch(34% .116 256)`。**色相差 0.2°**、彩度のみ抑制。

256° は既存提案に最も多い青域です。そこで**構成で分けました**。
数値は必ず「Φ40〜Φ280」のように**範囲＋単位**で示し、
見出しは**対句**（切削品と鍛造品の比較）を基本にしています。

### 見出し

「削らずに鍛えるから、20%強い。」を h1 にしました。
現行サイトのトップは会社名と一文のみで、
**20%という数字は下層ページにしかありません。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

歯形は**36点すべてを式から生成し、歯先18点が理論値と一致することを計算で照合**しています。
**ギヤは歯の等分性がそのまま製品の意味**であり、
不揃いに描くと製品の誤った表現になります。
