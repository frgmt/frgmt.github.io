# 群馬精工株式会社 — トップページ リニューアル案

現行サイト（https://gunmaseiko.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,030px**。ページ全体が **36%** に縮小されて表示されます |
| **jQuery 1.11.2** | **2014年**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |
| Copyright | **2015年**で止まっています |

HTTPS には対応済みで、h1 も1つ、メタディスクリプションも適切です。
**問題はスマホ対応に集中しています。**

### www の有無でリンク先が分かれています

`www.gunmaseiko.co.jp` を開くと、ページ内のリンクはすべて
`www` の無い `gunmaseiko.co.jp` を指しています。
**クローラから見ると同じ内容が2つのアドレスに存在する状態**です。
どちらかへ 301 リダイレクトで統一することをお勧めします。

### 36%で読めなくなっているもの

このサイトには、**工法置換の効果が数字で書かれています。**

- 溶接工程の廃止 → **製造コスト30%削減／品質20%向上／生産性20%向上**
- ステンレスの冷間鍛造化 → **材料歩留まり35%向上／生産能力300%向上／コスト28%低減**

**発注側が最も知りたいのは、この数字です。**
「冷間鍛造ができます」ではなく「置き換えるとコストが3割下がります」という話です。
それが3分の1のサイズで表示されています。

## 設計上の判断

### 署名的装置 ── 2ピースが1ピースになる

この会社の価値は「冷間鍛造ができること」ではなく、
**いま溶接や切削でやっていることを、まるごと不要にできること**です。

そこで、現行サイトのVA・VE事例をそのまま図にしました。
左に「プレス品＋溶接＋総切削品」、右に「冷間鍛造で1ピース」。

**同じ部品なので、従来と新で総幅を揃えています**（50.4 + 8 + 39.6 = 98）。
描画後の実測でも **両方とも 98.0px** であることを確認しました。
**幅が違うと「小さくなった」という別の話になってしまいます。**

効果の棒は削減率・向上率に比例させています（30%を基準に正規化）。

### 配色 ── 214は、ほぼ未使用の色相

主色は現行サイトから画素採取した水色 `rgb(69,177,199)` =
`oklch(70.7% .102 213.6)`。白地用に `oklch(45% .092 214)`。**色相差 0.4°**。

**このリポジトリで hue 196〜218 を使っているのは216帯の1社のみ**で、
214 は実質的に空いています。**色相そのもので分かれているため、
他の軸で無理に分ける必要がありません。**

### 見出し

「2ピースを、1ピースにする。」を h1 にしました。
現行サイトのキャッチは「冷間鍛造のパイオニア」ですが、
**「パイオニア」は自称であって、発注側の利益を説明しません。**

### 白文字を使っていません

前々案（島野精機）で、グラデーションの上に置いた白文字が
検査を通過しながら実際には読めないという不具合を出しました。
**今回は SVG 内に白文字を1箇所も使わず、すべて白地の上に暗色で配置**しています。
色の付いた矩形のラベルは、矩形の外（下）に置きました。

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。
