# 小田原紙業株式会社 — リニューアル提案サイト

埼玉県越谷市のプラスチック真空成形メーカー。既存サイト <http://www.odawara-s.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 100点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- テーブルレイアウト（`<table width="700">` 固定幅）
- `IBM WebSphere Studio Homepage Builder Version 8.0.0.0` で生成
- 文字コードが Shift_JIS、`<font>` タグと `bgcolor` 属性が現役
- Copyright 表記が 2004 年のまま（社名のローマ字綴りが `shigyou` と `shicyou` で不統一）

## 写真を一切使っていない理由

原サイトのフッターに次の記載があります。

> 本サイトに掲載されている写真および文章を含む全てのコンテンツに関して
> 無断で使用することはお断りしております。

したがって**写真は1点も転用していません**。文章についても、そのまま引き写すのではなく
提案用に書き直したうえで、事実関係（数値・固有名詞・沿革）のみを引き継いでいます。

写真がない制約は、この会社には不利に働きませんでした。自社を「黒子」と表現する会社であり、
製品も4系統の分類そのものが情報として価値を持つため、**活字だけで構成**しています。
実装時にはお客様から提供いただいた写真を製品セクションに差し込める構造にしてあります。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの地色 `#003366` を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#003366` | `32.3% .103 253.9` | — |
| 本提案 `--sea` | `34% .095 254` | **0.1°** |

原サイトはこの紺を**背景全面**に敷いていましたが、コーポレートサイトとしての清潔感を
優先し、地を白に反転させたうえで紺を「文字と罫の色」に移しました。
淡いミント（`--mint`）は原サイトのメニュー背景 `#ccffff` / `#99ffff` に由来し、
リード文の「黒子」のマーカーとして1箇所だけ使っています。

### 構成の軸 — 分類と時間
- **製品4系統**を2×2のグリッドで並べ、それぞれにタグを添える。写真がなくても
  「どの現場向けの会社か」が一目で分かる構造
- **沿革タイムライン** — 苗代の紙 → プラスチック という業種転換は、この会社にしかない
  物語です。社名に「紙業」が残る理由がここで解けます

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 勤務時間 8:00〜17:05 は採用ページの記載（`AM8:00〜PM5:05`）に基づく実データです
- 取引先11社は原サイトの一覧どおり（「その他」「敬称略」の注記も維持）
- 三菱東京UFJ銀行 → 三菱UFJ銀行 のみ、2018年の商号変更に合わせて表記を更新しました

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。画像ファイルは favicon 系のみ
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
