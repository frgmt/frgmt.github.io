# 春日技研電機株式会社 — トップページ リニューアル案

現行サイト（http://www.kgd.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **本文が10px** | 今回調査した中で最小です |
| **ズーム禁止** | `maximum-scale=1.0, minimum-scale=1.0`。拡大できません |
| **meta descriptionが無い** | 検索結果に表示される説明文がありません |
| **alt属性の欠落** | 画像5点のうち **4点** に alt がありません |
| **HTTPS未対応** | `https://www.kgd.co.jp/` は接続できません |
| lang属性 | ✅ `ja` が入っています |

### 10pxの本文を、拡大できません

このサイトは2022年4月にリニューアルされており、写真は非常に良質です。
社屋の写真は2560×1707の高解像度で撮影されています。

けれど本文が10pxで、しかもピンチ拡大が禁止されています。
若い人でも読みづらく、年配の方にはほぼ読めません。

## 一番もったいないのは、倉庫の写真です

現行サイトには、自社倉庫の写真があります。
黄色い支柱の棚に、三菱電機とオムロンの箱がぎっしり積まれた写真です。

サイトにはこう書かれています。

> お客さまが必要とする商品・情報を、必要な時に、必要な量を、
> スピーディにお届けする。わたしたちは即納体制です。

**この写真は、その主張の証拠です。**
商社にとって「在庫を持っている」ことは最大の差別化要因であり、
言葉より写真のほうが早く伝わります。

本提案では、この写真を冒頭に置きました。

## この提案で変えたこと

### 1. 「棚にあります」を見出しにする

```
必要な時に、必要な量を。棚にあります。
```

### 2. 御社の写真をそのまま使いました

- **冒頭**：自社倉庫（三菱・オムロンの箱が積まれた棚）
- **拠点**：本社社屋（三菱インバータ・オムロンの看板が写っています）
- **取扱商品**：シーケンサー、表示器、インバーターの製品写真3点

CG素材（ロボット、基板、電球、鉛筆のイラスト）は使っていません。
※ 実際に公開される際は、写真の使用可否をご確認ください。
　 製品写真3点はメーカーのカタログ画像のため、メーカー側の確認も必要です。

### 3. 取扱商品24分類をそのまま並べる

「シーケンサー」「ACサーボ」「圧着端子」など、
探している人が実際に打ち込む言葉が24個あります。
これを本文テキストとして並べました。

### 4. 沿革18項目をそのまま載せる

この会社の沿革には、珍しい記述があります。

> 1945年12月：前会長 天一慶三郎が、同年10月に**NHKを退社**し、
> 川口市金山町にて個人企業として春日無線電機商会を創業。**家庭電機製品の販売**を開始
>
> 1970年9月：制御部品の需要の増大に伴い、**家庭電気製品の販売を撤退**

ラジオ商から制御機器商社への転換が、25年かけて起きた記録です。
1982年の MELCOM80 導入、1990年の IBM AS400 増強という
情報化の記録も残っています。

## 事実の扱いについて

本文の数値・固有名詞71項目は、現行サイトの記述と照合済みです。

なお会社概要の建築総面積が現行サイトでは
「1,050m2（**(**310坪)」と括弧が重複しています。
本提案では「1,050㎡（310坪）」に整えました。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,173文字）
- **ピンチズームは禁止していません**。本文は約16px相当です
- 写真5点はすべて `width`/`height` 指定つき（合計約440KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の青は、**現行サイトで実際に使われている色**
`rgb(10,74,143)` = `oklch(41.4% 0.129 255.1)` から採りました。
ほぼそのまま（明度40%・彩度0.120）使える色でした。
地はごくわずかに青みのある白で、白い社屋の写真と地続きにしています。
