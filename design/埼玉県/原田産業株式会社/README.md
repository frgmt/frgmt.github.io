# 原田産業株式会社 — トップページ リニューアル案

現行サイト（https://www.haradasangyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,040px**。ブラウザが全体を約 **36%** に縮小して表示するため、本文がそのままでは読めません |
| **見出しタグが1つも無い** | `<h1>` **0個**、`<h2>` **0個**。文書構造が検索エンジンに伝わりません |
| テーブルレイアウト | `<table>` **6個** |
| 文字コード | **Shift_JIS**（UTF-8以前） |
| Copyright表記 | **2001年**のまま |
| トップの新着情報 | 最新が **FOOMA JAPAN 2023**（2023年6月）の出展告知 |

**HTTPSには2018年7月に対応済みです。**
現行サイトにはその旨の告知が「常時SSL化はセキュリティ強化だけでなく…」と
本文で説明されており、**セキュリティへの意識は高い会社**です。
一方でスマホ対応は行われていません。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは1,040px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 選別の分離図

この会社の仕事は「混ざったものを分ける」ことに尽きます。
ファーストビュー右側に、**1本の流れが選別部を通って2本に分かれる図**を
インラインSVGで置きました。
入口には大小の粒が混ざっており、出口では大粒（良品）と小粒（除去）に
分かれています。

`stroke="currentColor"` / `fill="currentColor"` で配色に追随します。
実描画サイズは PC 412×258px（選別部 54×77px、粒15個）／
スマホ375 302×189px／スマホ320 248×155px（実測）。

### 構成原理 ── 「分ける」

現行サイトから画素採取した濃紺 `#303050` = `oklch(32.5% .056 282.8)` が基準です。
面 `oklch(36% .072 283)`、文字 `oklch(31% .066 283)`。**色相差 0.2°**。
元の彩度が低い（.056）ため、**彩度を下げるのではなく少し上げました**。
下げると完全な無彩色になり、面として成立しなくなるためです。

283° は既存提案では埼玉部品工業（283°）のみで、青紫域は空いています。
構成原理は「選別」で統一しました。

- 事業は必ず**2つに分けて対置**する（食品／環境）
- 品質方針は8項目を等しく**分割したグリッド**で示す
- 上下の区画の境界を、罫線1本で明示する

### 見出し

「混ざったものを、分ける。」を h1 にしました。
現行サイトのトップは**展示会の告知から始まり**、
次が「《顧客満足度》最優先主義です」で、**何をつくる会社なのかが本文に出てきません**
（メタディスクリプションには「あらゆる選別をする専門メーカー」とあります）。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトの画像13点はすべてalt付きで
  管理されていますが小さいため、元データのご提供が必要です。
  **選別前後の比較写真（混ざった状態と分かれた状態）があれば最も効果的です**
- **納入先の企業名をそのまま掲載しています**（現行サイトの沿革の記載どおり）。
  トップページに一覧として出すことの可否を、**必ずご確認ください**。
  沿革の中に埋もれている状態と、一覧で前面に出す状態では意味が異なるためです
- **沿革が2020年で終わっています。**以降の実績をご教示ください
- **処理能力の数値がほとんど記載されていません。**
  沿革に「50トン/h」「60トン/h」「40〜60m3/h」といった記載が散見されますが、
  標準機のスペック表がありません。**選別機の引き合いでは処理量が最初に
  確認される項目なので、機種ごとの能力表の掲載を強くお勧めします**
- 資本金1,000万円に対し従業員56名・大手企業との取引という構成のため、
  **売上高の記載があると信用面で有利**です（現行サイトに記載なし）
- ISO等の認証取得の記載が現行サイトにありません。品質方針でQMSに言及があるため、
  取得済みであれば明記をお勧めします
- 「食品専用サイト」「環境専用サイト」への導線が現行サイトにありますが、
  本提案はトップページのみのため、リンク先の扱いは別途ご相談させてください

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

署名的装置は、外枠のサイズだけでなく**内部の要素（選別部の箱、粒15個、
出口2本のパス）が個別に実描画されているか**を測定しています。
SVGは指定を誤ると要素が0pxで描かれても検査を通ってしまうためです。
また、SVG内の文字は検査ツールが見ないため、
3つのラベルすべてについてコントラスト比を別途計算しています。
