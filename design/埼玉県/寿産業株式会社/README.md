# 寿産業株式会社 — リニューアル提案サイト

埼玉県上尾市の精密板金加工会社。既存サイト <http://kotobuki-san.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 85点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- 文字コードが Shift_JIS
- 見出しがすべて画像（`alt` 属性に「設備紹介|精密板金加工 寿産業株式会社」のような
  SEO 用の長文が入っており、抽出テキストにもそのまま漏れています）
- Copyright 表記が 2011 年のまま

## デザイン方針

### 色 — 原サイトからの継承（2トークン方式）
原サイトの主色 `#ff9900`（オレンジ）を継承しました。ナビゲーションの
斜めストライプ帯と見出しに一貫して使われている、明確なブランドカラーです。
製品写真にもオレンジ塗装のアルミケースがあり、色と実物が響き合います。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#ff9900` | `77.2% .174 64.6` | — |
| 本提案 `--or-br`（罫・面） | `72% .165 65` | **0.4°** |
| 本提案 `--or`（文字） | `52% .135 65` | 0.4° |

**最初から2トークンで設計しました。**これまでの4案件で「継承した hex を
そのまま小さな文字に使うとコントラスト未達になる」ことが繰り返されたためです。
`#ff9900` は白地で約2.2:1しか出ません。文字用は明度を52%まで下げ、
罫・面・ストライプには原色に近い明度を使っています。
その結果、**自動検証を初回で全項目通過**しています。

差し色の `--red`（`oklch(46% .17 29)`）は原サイトの `#990000` 由来で、
電話番号の表示のみに使っています（原サイトでも電話番号が赤でした）。

原サイトの**斜めストライプの帯**は、ヘッダー下とフッター上の細い帯として
引き継ぎました。CSS の `repeating-linear-gradient` によるもので画像は使っていません。

### 構成の軸 — 薄板と小ロット
原サイトに「主に薄板(0.1〜0.6ミリ程度)少ロット(1〜100)」という記述があります。
これはこの会社の**市場での立ち位置そのもの**です。量産工場が受けたがらない
「薄くて少ない」仕事を引き受ける、という宣言として読めます。

そこで見出しを「0.1ミリから、1個から。」とし、
**板厚とロットの2軸を大きな数字**で見せるセクションを最初に置きました。
説明文も「大きな工場が受けない仕事を。」と、立ち位置をそのまま言葉にしています。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 設備9行は原サイトの一覧どおりです
- 板厚・ロット・材質・生産品は原文の記載のままです

## 画像の扱い
原サイトの写真7点（製品5点・設備2点）をすべて採用しました。
272×205px と小さめのため、大きく引き伸ばさずグリッドで使っています。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
