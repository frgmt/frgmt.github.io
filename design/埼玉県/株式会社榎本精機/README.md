現行サイト（http://www.enomotosk.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

### 131台の設備が、PDFの中にあります

PDFを開くと、こう書かれています。

- **CNC自動旋盤 51台**：ミヤノ LX-01 が9台、LZ-01 が5台、LX-06 が4台……
- 専用機19台、自動旋盤11台、ボール盤11台、ベンチレース10台
- **加工設備 合計131台**、測定器9台

機種名・型式・台数・製造所名まですべて載っています。
これは同業や発注側が最も見たい情報です。

しかし**PDFの中身は検索結果に出てきません**。
「ミヤノ LX-01」で探している人にも、
「加須市 CNC自動旋盤」で探している人にも届きません。

本提案では、この一覧を**種別ごとに集計してHTMLの表**にしました。

## この提案で変えたこと

### 1. 「51台」を見出しにする

従業員51名に対してCNC自動旋盤51台。1人1台以上という設備集約度は、
量産を任せる相手を探している側にとって重要な情報です。

### 2. 御社の写真をそのまま使いました

製品写真5点を使用しています。**図やイラストは使っていません。**

現行サイトの製品写真は、どれも**青い台に部品を並べ、SDカードを一緒に置いて
大きさを示す**撮り方で統一されています。
この撮り方そのものが伝わるものなので、そのまま活かしました。

- ショックアブソーバ用焼結ピストン（冒頭・製品）
- 油圧機器製品用部品
- レシーバードライヤー
- 熱交換機器部品
- ブレーキ関係部品

CG素材（工場ロボットの絵、車の透視図）とヘッダー帯は使っていません。
※ 実際に公開される際は、写真の使用可否をご確認ください。

### 3. 沿革22項目をそのまま載せる

1964年の設立から2019年のリリーフバルブ組立ライン稼働まで、
取引開始と生産品目の追加が時系列で追えます。

## 現行サイトで見つかった問題（2件）

### 1. 英語ページの取引先が旧社名のままです

日本語ページと英語ページで、取引先の社名が食い違っています。

| | 日本語ページ | 英語ページ |
|---|---|---|
| | Astemo株式会社 | Showa Corp. |
| | マレリ株式会社 | Calsonic Kansei Co., Ltd. |
| | ハイリマレリジャパン株式会社 | Heili Calsonic Japan Co., Ltd. |
| | 三輪精機株式会社 | Sanwa Seiki Ltd. |

日本語側は社名変更後の**現行名**になっていますが、英語側は**旧社名のまま**です。
英語ページを見た海外の相手には、古い情報が伝わっている状態です。

本提案では日本語ページの記載（現社名）を採用しました。

### 2. 表記ゆれ

沿革の「リリーフ**バブル**(R/V)組立ライン」は、
リリーフ**バルブ**（relief valve）の誤記と判断し、訂正しています。

## 事実の扱いについて

本文の数値・固有名詞54項目は、現行サイトの記述と照合済みです。
設備の台数は、PDFの記載を種別ごとに合計したものです（加工設備131台・測定器9台）。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,394文字）
- **ピンチズームは禁止していません**
- `<html lang="ja">` を指定しています
- 写真5点はすべて `width`/`height` 指定つき（合計約460KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の紺は、**現行サイトで実際に使われている色**
`rgb(28,38,112)` = `oklch(31.3% 0.127 271.0)` から色相を採りました。
白地で使える明度37%・彩度0.145へ調整しています。
地は無彩に近い明るいグレーで、製品写真の青い背景を邪魔しないようにしています。
