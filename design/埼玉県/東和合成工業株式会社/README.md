現行サイト（http://www.towagousei.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

### 一番強い話が、下層の本文に埋もれている

現行サイトの `product/soft_vini/index.html` には、こう書かれています。

> 弊社の軟質塩化ビニールフィルム・シートは、安全性を重視し、
> 従来のフタル酸系可塑剤の含有量を限りなく０（ゼロ）におさえ、
> 非フタル酸系可塑剤のBASF社Hexamoll DINCHを中心に使用しております。

フタル酸系可塑剤6種は**欧州・米国・日本で乳幼児向け製品への使用が
規制されています**。それを避けた配合を採っていることは、
玩具・医療用品を作る顧客にとって決定的な選定理由になります。

ところがこの記述は、トップから2階層下の本文の中にありました。

## 設計上の判断

### 署名的装置 ── 3つの樹脂の使い分け表

シートの相談は「どの樹脂か」から始まります。現行サイトでは
3樹脂が別ページに分かれ、比較できませんでした。

本案は**材質・主原料・選ぶ理由・用途・指定できる項目**の5列で
1枚の表にしています。「選ぶ理由」の列を置いたのが要点で、
軟質塩ビ＝安全性、軟質ポリオレフィン＝加工性と環境性、
ポリスチレン＝透明性と印刷適性、と**一語で選べる**ようにしました。

そのすぐ下に**可塑剤の節**を淡い青の面で置いています。
規制対象6種（DEHP・BBP・DIDP・DBP・DINP・DnOP）を実名で挙げ、
なぜこの話を先にするのかを書きました。

### 色

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#023ba8` | 現行 CSS（大面積） | `oklch(40.2% .183 262.0)` | **採用**（面 `oklch(40% .155 262)`、色相差 0°） |
| `#0838a8` | ロゴ `header_01.gif` の画素 9,032px | `oklch(39.7% .185 263.2)` | 同系。上の裏付け |
| `#d4e9ff` | 淡い青の面 | `oklch(92.5% .037 249.5)` | 参考。本案の `--film-wash` に相当 |

彩度は `.183 → .155`（上限 .16）。明度は 40.2% のままで AA が出るため
落としていません。

### 青が何社目かであることへの対処

| 軸 | 他の青系社 | 東和合成工業 |
|---|---|---|
| 地の温度 | 暖灰(40/60)・冷灰(230/250)・板紙(80)・鋳肌(265)・緑灰(150)・黄み灰(95) | **わずかに赤みの灰（hue 20）**。青の補色側 |
| 署名的装置 | 台帳・レンジ・入れ子図・分岐図・回転数とトルクの対 | **3樹脂の使い分け表**（「選ぶ理由」の列を持つ） |
| 書体 | 明朝／角ゴ／丸ゴ／幾何学／可変 | **Zen Kaku Gothic Antique**（やわらかい角ゴ）。玩具・日用品の声 |
| 第二色 | 炉温・警告・受賞・納期・速さ | **なし**。青一色。安全性の節だけ淡い青の面にする |
| 角丸 | 0〜8px | **6px**。シートの巻きぐせ |

## データの出所

樹脂の仕様・事業所・会社概要はすべて**現行サイトから取得した実データ**です。

- 3樹脂の主原料・特徴・用途・指定項目 … `product/soft_vini/`、`product/soft_poly/`、`product/polystyrene/`
- 可塑剤とフタル酸系6種の規制 … `product/soft_vini/index.html`
- 屋根下地材3種の説明 … `product/index.html`
- 事業所4か所の住所・電話 … `factory/index.html`
- 会社概要・資本金・取引銀行 … `company/index.html`
- 防炎製品「モエレ」の認定、裁断加工の開始 … トップページの新着情報

### 確認が必要な項目

- **設立年・創業年の記載が現行サイトにありません**
- **従業員数の記載がありません**
- **栃木第一工場の電話・FAXの記載がありません**（住所のみ）
- **ISO等の認証取得の記載がありません**
- 新着情報に日付がなく、**「新社屋が完成」「裁断加工をはじめました」が
  いつのことか判断できません**。コロナ対策商品の告知が並んでいることから
  2020〜2021年頃と推測されますが、本案では年を書いていません
- 事業内容4「スポーツ教室の経営」は `company/index.html` の記載ですが、
  **サイト内に該当ページがありません**。本案では事業として名前のみ記載しました
- 直営ショップ（`/shop/`）と STORES.jp（towa021.stores.jp）へのリンクが
  トップにあります。**現在も稼働しているか確認が必要**です
- 防炎シート「モエレ」は**認定時期の記載がありません**
- ポリスチレンの「ベルトマシーン2機」以外に、**設備一覧がありません**
