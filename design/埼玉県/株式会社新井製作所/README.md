# 株式会社 新井製作所 — トップページ リニューアル案

現行サイト（http://www.araipres.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで **103点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |
| Dreamweaver由来のJS | `MM_preloadImages` |

**トップページに本文がほとんどありません**。`<title>` と画像だけで、
テキストは「株式会社 新井製作所 WEBサイト」のみです。

## 設計上の判断

### 署名的装置 ── 出力とトルクの選定表

モータは**機種番号ではなく、必要な出力（W）とトルク（mN・m）で選ばれます**。

現行サイトの `motor.htm` には23機種の表がありますが、
**機種番号順**に並んでおり、しかも3つの表に分割されていました。
「10W前後で使えるのはどれか」を知るには、3表を目で追う必要があります。

本案では**3表を統合し、出力の小さい順に並べ替え**ました。
0.1W から 65.0W まで一列に並ぶので、必要な出力の行を探すだけで済みます。

同じ機種でも極数でトルクが変わることも読み取れます
（8025 は 2極15.0W/55.0 に対し 4極11.0W/82.0）。

### 「一貫生産」を工程の矢印で示す

この会社の強みは**鉄芯 → ダイキャスト → 巻線・組立 → 完成品**を
社内で通せることです。平成13年に新晃電機の設備を移管して実現しました。

ヘッダー最上段にこの流れを矢印で置き、
四つの事業は等幅の帯として刻んでいます（カードにはしていません）。

### 青が続いたことへの対処 — 地を緑みに振る

採取色は 250°。潮工業（253°）、アスタム（242°）と近い青です。
色相は動かさず、**4軸で分離**しました。

| 軸 | 潮工業 | アスタム | 新井製作所 |
|---|---|---|---|
| 地の色相 | 青み（253） | 青み（242） | **緑み（150）** |
| 署名的装置 | 寸法票 | 口径レンジのバー | **出力順の選定表** |
| 書体 | しっぽり明朝 | Noto Sans | **M PLUS 2** |
| 律動 | 編集的二段組 | 番号付きリスト | **等幅の帯で刻む** |

地の色相を意図的に外したのは、青の地が続くと同じ工場の別ページに見えるためです。

### 色 — ロゴから採取

| 採取元 | 値 |
|---|---|
| ロゴ画像 `mian_image/logo.png` の画素（18,035px） | `#0060a8` = `oklch(48.2% .138 250.3)` |

`--core: oklch(44% .128 250)` — **色相差 0.3°**。

## データの出所

仕様・設備・沿革はすべて**現行サイトから取得した実データ**です。

- 小型モータの機種表 … `motor.htm` より（**出力順に並べ替え**）

- 会社概要・沿革 … `corporation.htm` より

- ウエストンローラーの外径・仕様 … `roller.htm` より

### 確認が必要な項目

- **売上高9.8億円・従業員50名は現行サイトの記載時点の数字**です。
  年度の記載が無いため、最新値への更新をお勧めします
- モータ鉄芯のサイズ表（`press.htm`）は寸法値に文字化け（`?`）が
  多数あり、**正確に読み取れなかったため掲載していません**。
  例：`?80x74`、`?42x?22`。原本をご提供いただければ追加します
- ISO9001は「2000」年版の記載です。**現在の認証年版をご確認ください**
  （2015年版への移行が一般的です）
- 株式会社新晃ロンドル（昭和46年設立）、浮谷工場（平成13年取得）は
  沿革に記載がありますが、現況が確認できないため沿革にのみ残しています
- 営業時間（記載が無いため JSON-LD にも入れていません）
