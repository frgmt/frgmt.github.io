# 株式会社エステック — トップページ リニューアル案

現行サイト（http://www.kkstec.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで **102点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| Copyright | **2013年**のまま |
| ナビゲーション | すべて画像（`btn_business.gif` 等）。テキストが無い |
| Twitter埋め込み | トップページの主要コンテンツが外部埋め込み |

**現行サイトの最大の問題は、いちばん良い中身が埋もれていることです。**

## 設計上の判断

### 署名的装置 ── 「どう考えて削ったか」

現行サイトの `products.html` には、**部品ごとに加工の考え方が書かれています**。

> 十字になっている部分は、交差の穴が開いており、中は空洞に近い状態になっています。
> 穴と溝の位置、角度が重要なので、加工によるゆがみには気を使いました。

これは町工場のサイトでは**きわめて珍しい記述**です。
できた形の写真だけを並べるサイトが大半のなか、この会社は
「何が難しく、どう対処したか」を書いています。発注側が読みたいのはこれです。

しかし現行サイトでは、トップページからは見えない下層に置かれています。
本案では**これを署名的装置**とし、幕開けの直後に極太罫で囲った区画として置きました。
公差や寸法は等幅フォントで組み、素材・数量・難所をタグで示しています。

### 設備も「使い分け」で書く

設備一覧は機種名の羅列になりがちですが、現行サイトは
**「どの機械がどの仕事に向くか」**まで書いています。これも残しました。

### アイテック・ウチヤと暖色が続いたことへの対処

採取色は **43.6°**。アイテック（37°）とは 6.6° 差です。
色相は動かさず、**構成そのもの**で分けました。

| | アイテック | ウチヤ | エステック |
|---|---|---|---|
| 区画の分離 | 地色（砂色） | 地色（無彩色） | **3px の極太罫** |
| 署名的装置 | 温度レンジの帯 | 製品比較表 | **加工事例の記述** |
| 角丸 | 8px | 6px | **2px（ほぼ直角）** |
| 書体 | Zen Antique | Zen Kaku Gothic | **M PLUS 1p** |

この会社は図面を見て削る会社なので、**罫で仕切る図面的な構成**にしています。
地色をほとんど使わず、太い実線で区画を切りました。

### セクション構成

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 短い宣言 |
| 01 | 加工事例 | **極太罫で囲った記述の列**（署名的装置） |
| 02 | 設備 | 使い分けを書いた一覧 |
| 03 | 会社概要 | 仕様書的 `<dl>` |
| 04 | 歩み | 縦のレール |
| 05 | 検査の姿勢 | 左罫のみの引用ブロック |
| 06 | 問い合わせ | `<details>` + 地図 |

### 色 — 現行サイトから採取

| 採取元 | 値 |
|---|---|
| `css/base.css` の `#f60` | `oklch(69.6% .204 43.5)` |
| ボタン画像 `btn_business.gif` の画素 | `#f06000` = `oklch(66.5% .195 43.6)` |

CSSの宣言値と画像の実測値がほぼ一致したため、確度の高い採取です。

`--cut: oklch(55% .155 44)` / `--cut-ink: oklch(46% .14 44)` — **色相差 0.5°**。

## データの出所

加工事例・設備・沿革はすべて**現行サイトから取得した実データ**です。

- 加工事例の記述 … `products.html` より（表現を整えたうえで内容は保持）
- 設備と使い分け … `machinery.html` より
- 会社概要・沿革 … `business.html` より
- 検査の姿勢 … `check.html` より

### 確認が必要な項目

- **郵便番号が現行サイトに記載されていません**。住所のみ掲載しています
- 資本金・創業時の資本金（記載が無いため未掲載）
- 第二工場の所在地（「戸田市に移転」とあるのみで詳細住所の記載が無い）
- 営業時間（記載が無いため JSON-LD にも入れていません）
- 加工事例の写真は現行サイトにありますが、**本案では画像を使っていません**。
  実装時にご提供いただければ差し込みます
