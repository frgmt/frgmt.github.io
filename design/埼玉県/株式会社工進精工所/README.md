# 株式会社 工進精工所 — トップページ リニューアル案

現行サイト（http://www.koshin-s.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **jQuery 1.8.0** | **2012年8月**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |
| **メタディスクリプションが無い** | 検索結果に表示される説明文をGoogleが本文から拾って生成している状態 |
| **ナビゲーションが全部JPEG画像** | ヘッダーのメニュー8点が画像。テキストではないため、検索エンジンから読めません |
| 製品ページが実質画像のみ | 「トラック用部品」ページは本文 **95文字**（画像14点）。「鉄道車輌用機器」ページも本文393文字で、製品名は画像のaltにしか入っていません |

**この会社は、サイトが古いのではなく「更新はしているのに土台が古い」ケースです。**
お知らせは2026年7月まで更新されており、健康経営優良法人の認定も5年連続で続いています。
にもかかわらずスマホで読めず、検索にも出にくい状態です。

### 縮小表示であって、横スクロールではありません

横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── シングルアームパンタグラフ

この会社を一言で表すのは「架線から電気を受け取る機構」です。
ファーストビュー右側に、**架線・集電舟・上下アーム・台枠**の線画を
インラインSVGで置きました。関節（回転対偶）は白抜きの丸で描いています。

`stroke="currentColor"` で配色に追随します。
実描画サイズは PC 433×271px（下アーム141×93px、集電舟130×9px）／
スマホ375 302×189px／スマホ320 248×155px（実測）。

### 配色と型 ── 青焼き図面

現行サイトから画素採取した紺 `#012681` = `oklch(32.1% .157 262.9)` を基準にしました。
面 `oklch(34% .128 263)`、文字 `oklch(30% .118 263)`。**色相差 0.1°**、彩度のみ抑制。

263° は既存提案に最も多い青域です。そこで**色ではなく「型」で分けました**。
1913年創業の鉄道車輌メーカーであることに合わせ、**図面（青焼き）の面持ち**で組んでいます。

- ファーストビューの地に34px方眼を敷く
- **角丸を一切使わない**（border-radius: 0）
- 区画を塗りで分けず、**罫線だけ**で分ける（4事業・数値・お問い合わせ）
- 年号・数値はすべて等幅（Roboto Mono）

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

署名的装置については、SVGを置いただけで満足せず、
**枠だけでなく内部の線分（アーム・集電舟）が実寸を持って描かれているか**を
個別に測定しています（inline width指定などで0pxになっても、検査は通ってしまうため）。
