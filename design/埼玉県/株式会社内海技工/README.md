# 株式会社内海技工 — トップページ リニューアル案

現行サイト（http://www.uchiumi-giko.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **981px**。ページ全体が **38%** に縮小されて表示されます |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **jQuery 1.7.1** | **2011年**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |
| **h1 が無い** | トップページに見出し要素が1つもありません |
| **メタディスクリプションが空** | タグはありますが `content=""` です |

### 空のディスクリプションは、無いより悪い

`<meta name="description" content="">` と書かれています。
**タグが無ければ検索エンジンは本文から適切な箇所を選びますが、
空のタグがあると「説明は不要」と解釈される場合があります。**

現在の h1 相当の位置にあるのは
「The special group of motorbike part manufacture.」という英文のみです。

### 何の会社かが、日本語で書かれていません

トップページの日本語本文は実質228文字です。
**本田技術研究所 二輪R&Dセンターとの取引も、
国際大会のレース用二輪車の開発も、下層ページにしかありません。**

## 設計上の判断

### 署名的装置 ── 「百分代」は、この桁

この会社が唯一書いている定量的な指標が「百分代の寸法誤差」です。
ところが**「百分代」という言葉は、業界の外では通じません。**

そこで、0.001mm から 10mm までの対数目盛の上に
**0.01mm の位置を1本の線で示しました。**

**実寸で描くことは検討して、やめました。**
1mm を 232px で描くと 0.01mm は 2.32px となり、線1本にもなりません。
対数目盛であることは図の中に明記しています。

目盛の位置は計算で置き、**5本すべてが対数式と一致すること**を照合済みです。

**溶接する材種を融点の順に並べる図も検討しましたが、こちらは採用しませんでした。**
融点は一般的な代表値であって、**現行サイトには書かれていない**ためです。

### 配色 ── 原サイトに色がありませんでした

現行サイトの描画色を集計したところ、**上位はすべて無彩色**でした
（最も彩度のある色でも `oklch(62% .023 232)`）。

そこで**ロゴ画像（logo01.gif）を canvas に描画して画素を採取**し、
紺 `rgb(16,32,80)` = `oklch(26.3% .091 266.3)` を得ました。
白地でそのまま使える暗さなので、明度をわずかに上げるだけの
`oklch(29% .095 266)` としています。**色相差 0.3°**。

266近傍は既存提案に多い色域なので、
**地を無彩の白**にし、**溶接を「手／ロボット」の対で並べる形**を主要な形にして分けました。

### 見出し

「図面に忠実に、百分代で組む。」を h1 にしました。
**現行サイトの「図面に忠実な物作りをモットーとしています」という一文を、
測れる数字と組み合わせたもの**です。
