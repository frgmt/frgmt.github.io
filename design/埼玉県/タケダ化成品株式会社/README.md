# タケダ化成品株式会社 — トップページ リニューアル案

現行サイト（http://www.takeda-kaseihin.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **982px**。ブラウザが全体を約 **38%** に縮小して表示するため、本文がそのままでは読めません |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **jQuery 1.7** | **2011年11月**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |
| **「創業50年」の表記が実態と合っていない** | 1966年創業なので、2026年時点では **60年**です |

**この会社のサイトは、書かれている内容が非常に良いものです。**
h1が1つ、h2が4つあり、画像25点中24点にalt属性があります。
アウトソーシングの説明は3,000字を超え、**業務の流れが7段階で具体的に書かれています**。
問題は**スマホ対応**と、**その良い内容がトップページから見えないこと**です。

### 縮小表示であって、横スクロールではありません

viewportタグが無いため、iPhoneは982px幅のページを375pxの画面に押し込みます。
横にはみ出してはいませんが、**文字が約1/3のサイズになる**ため、
指で拡大しない限り読めません。

## 設計上の判断

### 署名的装置 ── 「50 × 200 × 100」

**この会社は、自社の強みを既に式で表現しています。**
それをそのまま組版として見せることにしました。
3つの数を同じ大きさ・同じ間隔で並べ、間に × を置いています。

他社の提案ではSVGで図を描いていますが、**ここは図にする必要がありません**。
式そのものが図だからです。
実測では3つの数値が**同じ行に同じ幅（PC 120px / スマホ375 85px / 320 67px）で並び**、
×記号2つも含めて320pxまで崩れないことを確認しています。

### 構成 ── 「掛け算」で分ける

現行サイトから画素採取した紺 `#264d7a` = `oklch(41.5% .088 253.5)` が基準です。
面 `oklch(38% .092 253)`、文字 `oklch(32% .084 253)`。**色相差 0.5°**。
元の彩度が低い（.088）ため、彩度はほぼそのままに明度のみ調整しました。

253° は既存提案に最も多い青域です。そこで**構成原理で分けました**。
「3つの要素の積」という自社の説明に合わせ、**節を3分割で通しています**
（選ばれる理由3つ、業務案内3列×2段）。

### 見出し

「塗料も、工場も、選ぶところから任せられます。」を h1 にしました。
現行サイトのキャッチは「工業塗装・塗料の専門商社」で、
**商社であることは分かっても、何を任せられるのかが分かりません。**

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

- **写真を1点も使っていません。**現行サイトの画像は管理フォーマット類が中心のため、
  塗装現場・製品の写真をご提供いただけると効果的です
- **「創業50年」「50×200×100」の表記について。**
  1966年創業なので2026年時点では60年です。ただし
  **「50×200×100」は既にブランド表現として定着している**と判断し、
  本提案では式をそのまま用いつつ、創業年（1966年）を併記しました。
  **「60×200×100」に更新されるか、式は据え置くかをご指示ください**
- **塗料メーカー数「約200社」、塗装工場数「100社超」は現行サイトの記載です。**
  現在値をご確認ください
- **久喜営業所（1973年開設）が沿革にありますが、
  会社概要の住所欄には記載がありません。**現存するかご確認ください
- 取引銀行は現行サイトに記載がありますが、本ページには掲載していません
- **お客様事例・ビジネスパートナー・社員紹介のページが現行サイトにありますが、
  本提案はトップページのみのため反映していません。**
  特に**お客様事例はトップに要約を置く価値があります**
- 「工業塗装ノウハウ集」（塗装方法・機能性塗料・塗装トラブル対策・用語集）は
  **検索流入の資産になり得る**ため、リニューアル後もトップから導線を張ることをお勧めします
- 従業員数・売上高の記載が現行サイトにありません

| タップ領域 44px | 不足 **0件** |
| JavaScriptエラー | **0件** |
| **JS無効時の本文可視** | **3,424文字すべて可視** |

| **署名的装置の実描画** | 3数値が同一行・同一幅（PC 120px / 375px時 85px / 320px時 67px）、×記号2つとも描画 |

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

署名的装置がSVGではなくHTMLの組版であるため、
**3つの数値が本当に1行に等幅で並んでいるか**を要素の座標から検証しています
（`top` が3つとも一致すること、幅が3つとも同一であること）。
グリッドは指定を誤ると縦積みになったり幅が不揃いになったりしますが、
検査ツールはそれを問題として報告しないためです。
