## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグは正しいのに機能していない** | `width=device-width, initial-scale=1.0` と書かれていますが、中のレイアウトが **862px 固定グリッド**です。実機375pxでレイアウトビューポートが **882px** に広がります |
| **HTTPS未対応** | `http://` のみ。Chrome のアドレスバーに「保護されていない通信」と表示されます |
| **jQuery 1.7** | **2011年**のリリース。1.x系はサポート終了しており、既知の脆弱性が残っています |

### これは「タグが無い」型より厄介です

viewportタグが無いサイトは、ブラウザがページ全体を縮小して表示します。
小さくはなりますが、**全体は見えています。**

このサイトは `width=device-width` と宣言しているため、
**ブラウザは「このページはスマホ対応済み」と判断し、縮小しません。**
ところが中身は862px固定なので、**入りきらない部分が単に見切れます。**

実機のスクリーンショットで確認したところ、
**社名「北陸軽金属工業 株式会社」の右端、ナビゲーション、
ヒーロー画像のキャッチコピーが、いずれも画面の右で切れていました。**

「独創の鋳造技術で試作品製造を変える」というキャッチが、
**「独創の鋳造技術で試作品製造を変」までしか読めません。**

## 設計上の判断

### 署名的装置 ── 工程が消える

この会社の短納期は「速く作る」からではなく、**工程が要らなくなる**からです。

従来の7工程と、RP砂積層造型の4工程を**同じ尺度の帯**で並べ、
消える3工程（木型製作・罫書検査・非接触測定検査）を淡色で示しました。

**帯の長さは工程数を表す模式であり、実際の工数比ではありません。**
現行サイトに各工程の所要時間は書かれていないためです。
**この点は図の中と説明文の両方に明記しています。**

なお、模式であっても短縮率が原文と食い違っては意味がないので、
**描画後の実測で 151.9 / 257.8 = 41.1% となり、
原文の「従来比約4割減」と整合することを確認**しています。

### 配色 ── 赤を主色に

主色は現行サイトのキャッチコピーから画素採取した赤 `rgb(230,0,18)` =
`oklch(58.1% .238 27.9)`。白地の本文でAAを満たさないため
`oklch(46% .190 28)` に。**色相差 0.1°**。

**このリポジトリの104社を調べたところ、
赤（hue 20〜45）を主色に据えた提案は1つもありませんでした。**
アクセントとしては使われていますが、主色は青・緑・紺が大半です。
**色相そのもので分かれているため、他の軸で無理に分ける必要がありません。**

### 見出し

「木型を作らない。だから4割速い。」を h1 にしました。
**この会社の一番の売りを、理由と結果の2文で言い切れます。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良を仕込んだページを同じ検査にかけ、**12件すべてを検出**することを
確認した上で本番を測定しました。

### 沿革の照合 — 9件の取りこぼしを発見

**最初に書いた沿革は21件でしたが、原文と機械的に突き合わせたところ
32件あることが分かりました。**

クロールしたテキストの後半が読み取れておらず、
平成27年10月以降の11項目を落としていました。
**その中には「経済産業省 地域未来牽引企業に選定」（平成29年12月）や
「全国健康保険協会 健康優良企業 銀の認定」（平成29年6月）といった、
提案上とても重要な項目が含まれていました。**

全32件を追加し、**年月ごとに1件ずつ突き合わせて集合として一致することを確認**しました。

なお、**現行サイトでは「平成29年」の項が平成27年10月〜平成28年10月より前に
置かれています。**本ページでは年月順に並べ替え、
**その旨をページ上に明記**しています（項目数・内容は原文と同じです）。
