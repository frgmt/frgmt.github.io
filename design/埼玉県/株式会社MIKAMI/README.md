# 株式会社MIKAMI — トップページ リニューアル案

現行サイト（https://mikami-co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | iPhone はレイアウト幅を **980px** にフォールバック。実機390px に対し表示倍率 **40%** |
| **本文が実効 6.4px** | 16px の本文が iPhone 13 で 6.4px、iPhone SE（320px）では **5.2px** 相当 |
| **alt属性の欠落** | 画像17点のうち **14点** に alt がありません |
| **HTTPSが徹底されていない** | 証明書はあり `https://mikami-co.jp/` は開きます。ただしサイト内リンク61本のうち **15本が `http://`**、トップページで**混在コンテンツ警告が4件**出ます |

「HTTPS未対応」ではありません。**証明書はすでにあり、リンクの書き換えが済んでいない**状態です。

## 現行サイトで見つかった不具合（2件）

提案とは別に、すぐ直したほうがよい箇所が2つあります。

### 1. 採用ページのメールアドレスが壊れています

```
syusyoku@mikami-co.j    ← 末尾の p が抜けています
```

現在「製造グループ 正社員2名」等を募集中のページに書かれているため、
応募メールが届いていない可能性があります。

### 2. 環境ページで数値が矛盾して見えます

同じページに、2組の数値が説明なく並んでいます。

| | 森林換算 | 石油換算 |
|---|---|---|
| 太陽光発電の実績値 | 40,467 ㎡/年 | 10,431 ℓ/年 |
| 2015年度の実施計画 | 40,101 ㎡ | 11,838 ℓ |

実績と目標という別物ですが、区別が書かれていないため読者は混乱します。
本提案では**実績値のみ**を採用しました。

## この提案で変えたこと

### 1. 台数を、数えられる形にする

「加工機52台」と書いても実感が湧きません。
**1台を1つの四角として、13個×4行の格子**で示しました。
塗りつぶした46個が旋盤、枠だけの6個がマシニングセンターです。
数えれば合っていることが確認できます。

### 2. 「全数検査」を前に出す

このサイトで最も強い事実は、設備の台数ではなく**検査の考え方**です。

> 製品検査では、検査機が加工機と連動して作動するシステムを、
> メーカーと協力して作り上げました。熱による変形や歪みなどを
> 製造過程で感知して、即座に自動補正を行っています。

月3〜4万個を全数測定する。この一文が品質管理ページの奥にあるので、
冒頭に持ち出しました。

### 3. 検査設備と試作実績を、表として組み直す

検査設備8機種（型式・測定サイズ付き）と、試作実績22例（分野・用途・材質）を
HTMLの表にしました。Ti-6Al-4V、Ni-Ti、Ti-Ta、SUS316L といった
削りにくい材質の実績は、探している相手には強い情報です。

## 事実の扱いについて

本文の数値・固有名詞67項目は、すべて現行サイトの記述と照合済みです。

台数「52台」は、現行サイトの主要設備一覧54行から**洗浄器2台を除いた集計値**です。
表そのものが更新されていないため（上記のとおり）、
**実際の保有台数はこれより多い可能性があります**。商談の際にご確認ください。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,878文字）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
  （設計時の配色計算では最小 6.12:1、図中の緑は白地に対して 7.68:1）
- タップ対象はすべて44px以上

## 配色について

基調の緑は、**現行サイトで実際に使われている色**
`rgb(18,134,0)` = `oklch(53.9% 0.180 141.7)` から採りました。
白地でAAに届くよう明度43%・彩度0.125へ落とし、**色相は保持**しています。
地は同じサイトの青灰 `rgb(51,77,85)`（hue 219）側へわずかに振りました
（既存の緑系ビルドがいずれも白〜暖色の地を使っているため、
色相ではなく地の温度で分けています）。
