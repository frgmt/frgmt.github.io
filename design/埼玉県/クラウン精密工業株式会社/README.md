# クラウン精密工業株式会社 — トップページ リニューアル案

現行サイト（http://www.crown-screw.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **viewportタグが無い** | スマホ実機UA（375px）で `scrollWidth` **1,268px**。ブラウザが全体を約 **30%** に縮小して表示します。**今回調査した中で最も縮小率が大きい**（他社は980〜1,010px＝37〜38%） |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| **メタディスクリプションが「。」の1文字** | 句点のみが設定されています。検索結果に何も説明が出ません |
| 画像のalt属性 | 画像5点中 **5点すべてに alt が無い** |
| **トップページの本文が短い** | 実質 **325文字**。製品も企業情報も別ページで、トップからは何ができるか分かりません |

### 1,268pxを375pxに押し込むということ

viewportタグが無いため、iPhoneはPC用の1,268px幅のページを375pxの画面に縮小します。
横スクロールは発生しませんが、**文字が約1/4以下のサイズ**になります。
**「デルタイト®」「ポリウェーブ®」といった自社ブランド名が読めません。**

## 設計上の判断

### 署名的装置 ── ねじ山の断面

ねじメーカーの提案なので、**三角ねじのねじ山断面**を
ファーストビュー右側にインラインSVGで置きました。
外径・谷径・軸線の補助線と、1ピッチ分の寸法線を添えています。

山と谷の座標は `x = 24 + i × 17` で機械的に生成し、
**半ピッチがすべて17pxで均等**であること、
**寸法線（41→75 = 34px）が実際の1ピッチと一致する**ことを計算で照合しました。
実描画は PC 406×254px（ねじ山パス 345×61px）。

### 型 ── 「ねじ山」を構成に通す

現行サイトから画素採取した濃紺 `#051489` = `oklch(30.4% .184 265.3)` が基準です。
面 `oklch(34% .132 265)`、文字 `oklch(29% .120 265)`。**色相差 0.3°**、彩度のみ抑制。

265° は既存提案に最も多い青域です。そこで**型で分けました**。
**すべての見出しの下に、ねじ山状の三角波の罫**を敷いています
（`repeating` ではなく2枚の `linear-gradient` を6pxずらして重ねる方法。
実測で 88×6px に描画されることを確認済み）。

### 見出し

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・`#999` on `#fff` = 2.85:1・幅1600px固定・20pxのタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

ねじ山は**ピッチが均等であることと、寸法線が実際のピッチと一致することを
計算で照合**しています。**ねじにおいてピッチは規格そのもの**なので、
不揃いに描いたり寸法線がずれたりすると、製品の誤った表現になります。

また、**登録商標の数（8種）は目視ではなく ® の出現回数を数えて確認**しました。
company.html の該当セクションで ® は8回出現します。
自社ブランドの数を少なく書くことは、実績の過小申告になるためです。
