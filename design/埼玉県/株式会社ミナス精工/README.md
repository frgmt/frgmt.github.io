# 株式会社ミナス精工 — リニューアル提案サイト

埼玉県戸田市のダイカスト金型製作専業メーカー。既存サイト <http://www.e-minas.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 87点）

**この案件は他と毛色が違います。**原サイトは HTML5 で書かれ、テーブルレイアウトも
Flash も使っておらず、デザインも2019年時点としては十分に整っています。
指摘されているのは次の4点です。

- HTTPS 未対応
- **`viewport` メタタグなし** → スマートフォンで PC 版が縮小表示される
- **jQuery 2.2.4**（サポート終了。既知の脆弱性の懸念）
- **2019年11月7日で更新停止**（Copyright 表記・Last-Modified ヘッダーとも）

つまり「作り直す」というより「**手当てする**」タイプの案件です。
本提案はフルスクラッチの参考案として、jQuery を外し、レスポンシブにし、
情報の並べ方を整理し直したものになります。

なお原サイトのトップページには「2018.00.00 TOPICS テキストが入ります。テキストが
入ります。」という**ダミーテキストが残ったまま**公開されています。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの主色 `#284994`（CSS 内で16回）を継承しました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#284994` | `42.4% .13 263.9` | — |
| 本提案 `--nv` | `41% .155 264` | **0.1°** |
| 原サイト `#3877e4` | `58.7% .178 260.5` | — |
| 本提案 `--nv-br`（面・大要素） | `58.7% .178 260` | 0.5° |
| 本提案 `--nv-ac`（小さな文字） | `50% .165 260` | 0.5° |

**同じ色相の他案件との差別化について。** 埼玉には 264° がすでに2件あります
（吉野プレス工場 `.125`、ベルノ技研 `.19`）。本案は**その中間の `.155`** を取りました。
落ち着いた works navy と明快な tech blue の間で、金型メーカーらしい実直さを狙っています。

**コントラストで2回、手を入れました。** `#3877e4` をそのまま小さな文字に使うと
白地で **4.27:1**（要4.5）にしかならず、13件が未達となりました。明度を 58.7% → 50% に
落とした `--nv-ac` を追加し、面と大きな要素には元の明度を残しています。
工程番号バッジ（09・13）も同じ理由で `--nv-ac` に変更しました。

### 構成の軸 — 13の工程
この会社の強みは、**金型づくりの全工程を分けずに持っている**ことです。
原サイトの業務フローは1から13まで丁寧に書かれていましたが、
縦に長い1本の流れとして置かれていたため、全体像が掴みにくい状態でした。

本提案では**4列のグリッド**に組み直しました。説明の長い09（仕上げ・組み付け／MK処理）
と13（アフターサービス）だけ2列ぶんを使い、リズムをつけています。

なお、罫を背景色で作ると行が埋まらないときに空セルが灰色の塊として残るため、
セル側に罫を持たせています（13は4の倍数ではないため必ず余りが出ます）。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 13工程の説明、設備一覧、沿革は原サイトの記載どおりです
- **業務内容の記載に食い違いがあります。**トップページと会社案内は「80t〜500t」、
  事業案内ページは「90t〜500t」と書かれています。本提案では**2ページで一致する
  80t〜500t** を採用しました。**公開前にご確認ください**
- 原サイトの誤記「有限会社ミナス精エ」（工の誤り）は「精工」としました
- 「日立金属工具綱」は「工具鋼」の誤記と判断し、正しい表記にしています
- 沿革は原サイトの22項目から、**設備投資・組織変更・移転・補助金採択**を中心に
  18項目へ整理しました（区画整理による地番変更など、事業内容に関わらない項目を省略）
- ISO 認証の記載は原サイトになく、掲載していません
- **「所属団体」の表記に揺れがあります。**会社案内ページは「社団法人日本金型工業会」、
  トップページは「一般社団法人日本金型工業会」。現在の正式名称である
  **一般社団法人**を採用しました

## 画像の扱い
原サイトの金型写真4点と工程写真3点を採用しました。
**金型に貼られたラベルは、原サイトの時点ですでにぼかし処理**が施されています。
発注元の情報を伏せるための処理と判断し、そのまま使用しています。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。**jQuery は使用していません**
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`memberOf` に日本金型工業会）／ LocalBusiness ／
  WebSite ／ FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
