# 株式会社ハイクレー — トップページ リニューアル案

現行サイト（http://www.highclay.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

### 34%に縮小されるということ

viewportタグが無いため、iPhoneは1,094px幅のページを375pxの画面に押し込みます。
横スクロールは出ませんが、**文字が3分の1のサイズ**になります。

問題は、このサイトの**中身が非常に濃い**ことです。

- 国連環境計画（UNEP）からの表彰
- 第11回グリーン購入大賞 大賞
- 国土交通省 NETIS 登録
- 神宮球場・横浜スタジアム・福岡Yahoo!JAPANドームでの採用実績
- JIS に準じた5種の試験＋自社の風洞試験による配合決定

**これだけの実績が、スマホでは読めない大きさで置かれています。**
公共工事の担当者や学校の施設管理者がスマホで検索したとき、
この会社の強みは事実上、伝わっていません。

## 設計上の判断

### 署名的装置 ── 土の三相構造

この会社の技術の核心は、現行サイト「泥濘防止対策」に書かれた
**三相構造（固相・液相・気相）の釣り合い**という説明にあります。
劣化とは、その釣り合いが崩れて固相だけが残る現象です。

ファーストビュー右側に、この三相を積み上げた断面をインラインSVGで置きました。
比率は原文の記述そのままです。

| 柱 | 固相 : 液相＋気相 | 出典 |
|---|---|---|
| 黒土（健全） | 1 : 1 | 「黒土は、（液相＋気相）と固相との割合が約１：１」 |
| 砂質土（健全） | 2 : 1 | 「砂質土などは１：２の比率」 |
| 劣化した土 | ほぼ固相のみ | 「液相、気相が減少し、概ね固相のみになってしまいます」 |

各柱の3区画の高さは比率から計算し、**3本とも合計が132pxちょうどになること**を
照合しています。実描画は PC 438×287px、9つの矩形すべてが実サイズで描かれることを
ブラウザで確認しました（90:45:45、120:30:30 と比率どおり）。

### 配色 ── 地の温度で分ける

主色は現行サイトから画素採取した淡い水色 `rgb(205,233,244)` =
`oklch(91.7% .033 223.4)` が基準です。白地で読ませるため明度を落として
`oklch(41% .088 223)`。**色相差 0.4°**。

ただし 223〜226 は既存提案（大谷技研）と近接します。そこで**地の温度で分けました**。
土を扱う会社なので、地を白ではなく土の色に寄せています（`oklch(98.4% .010 75)`）。
既存の暖色地の提案はいずれも彩度 .003〜.006 の実質白ですが、
ここは .010 まで上げ、青緑の主色と対比させています。

### 構成

区画も三相の考え方で並べました。
**何であるか（ソイレックス）→ なぜ壊れるか（劣化の3段階）→ 何を持っているか（製品）
→ どう決めるか（試験）→ どこで使われたか（実績）**の順です。

「土を捨てずに、土のまま直す。」を h1 にしました。
現行サイトのキャッチは「スポーツグラウンド用土壌のパイオニア」ですが、
**パイオニアであることは、何を解決するかを説明しません。**

### 検査自体が機能していることの確認

「0件」が**検査の故障**による0件でないことを、先に確かめています。
既知の不良（viewportタグ無し・低コントラスト・幅固定・小さいタップ対象）を
仕込んだページを同じ検査にかけ、**12件すべてを検出**することを確認した上で本番を測定しました。

実際、この案の初回検査では**コントラスト不足9件**（4.16:1）が出ています。
`--key-br` の明度を 58% から 47% に落として解消しました。
また `opacity` で減光していた4箇所を実色指定に置き換えています
（**alpha が掛かった文字は、コントラストを機械的に測定できないため**）。

### 球場名の照合

実績の球場名は、**原文の2つの一覧（アンツーカBB用・クレーベース用）を
それぞれ機械的に抽出し、掲載した名前と突き合わせています。**

- アンツーカBB: 原文7件 / 掲載7件 — 過不足なし
- クレーベース: 原文12件 / 掲載12件 — 過不足なし

どの製品がどの球場に使われたかという情報が失われるため、原文どおり分けました。**
なお両方の一覧とも末尾に「他」とあり、これがすべてではない旨をページ上に明記しています。
