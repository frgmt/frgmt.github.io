# 株式会社吉野プレス工場 — リニューアル提案サイト

埼玉県東松山市の金属プレスメーカー。既存サイト <http://www.yoshino-press.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 100点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- テーブルレイアウト（`<table width="702">` 固定幅）、Dreamweaver の `MM_swapImage` による画像ロールオーバー
- 文字コードが Shift_JIS
- Copyright 表記が 2004 年のまま

## デザイン方針

### 色 — 原サイトからの継承
原サイトの構造色 `#000066`（`bgcolor` として12回出現）を基調としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#000066` | `23.1% .16 264.1` | — |
| 本提案 `--nvy` | `30% .125 264` | **0.1°** |

淡色 `--nvy-md` は原サイトの `#ccccff`（同じく12回出現、285°）に由来します。
地は白（`oklch(100% 0 0)`）、パネルは `oklch(98% .004 264)` の極淡色で、
コーポレートサイトとしての清潔感を優先しました。

### 構成の軸 — 「深さ」
この会社の技術的な核は深絞りです。そこで**深さ**を全体の主題に置きました。

- 見出し「一枚の鋼板を、どこまで深く。」
- **能力ラダー**（この案件固有の見せ場）— ストレートサイドプレス10基を能力順に並べ、
  バーの長さで加圧能力を示す。深絞り専用の川崎油工 DP-500 のみ色と背景を変えて強調。
- 深絞りの4工程を「材料を選ぶ → 押さえながら絞る → 工程を重ねる → 接合し、仕上げる」
  として言語化（原サイトにない説明だが、掲載設備から導ける範囲に限定）

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす。
  `opacity` は触らないため、JS 無効でも未スクロール部分が消えることはない
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
