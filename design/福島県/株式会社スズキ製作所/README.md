# 株式会社スズキ製作所 — トップページ リニューアル案

現行サイト（http://www.suzukissf.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

### メニューに「空き」が残っている

現行サイトのグローバルナビには、`HOME｜会社概要｜保有設備｜保有測定機｜
取扱素材｜環境方針｜**空き**｜**空き**` と、**未使用のメニュー枠が2つ**
そのまま出ています。テンプレートの仮置きが残ったまま公開された状態です。

`gaiyou.html`（会社概要）、`setubi.html`（保有設備）、

## 設計上の判断

### 署名的装置 ── 金属と樹脂の対

加工屋はふつう、**金属屋か樹脂屋のどちらか**です。
この会社は1973年に**樹脂加工メーカーとして創業**し、そこから金属へ広げたため、
両方を同じ工場で削れます。これは珍しく、強い差別化要因です。

ところが現行サイトの `zaishitsu.html` は、金属22種と樹脂20種を
**表の中に並べているだけ**で、この構造が伝わりませんでした。

本案は左右に**金属側（紺）と樹脂側（臙脂）**を並べ、
それぞれ材質を分類ごとにチップで示しています。
樹脂側には **PEEK・PTFE・PPS などのスーパーエンプラ**があり、
これが「金属加工屋にはできないこと」だと分かるように書きました。

その下に**工程の鎖**を置いています。設計 → 金属加工 → 樹脂加工 →
金属溶接 → 樹脂接着・溶接 → 彫刻・印刷 → 組立。
金属工程を紺、樹脂工程を臙脂に塗り分けたので、
**1本の鎖の中で材質が行き来している**ことが見えます。

現行サイトの「工程を各工場に委託すると納期管理に苦労し、
運送費や時間が余計にかかる」という説明は、この図の根拠なので残しました。

### 色 ── 暗すぎる紺を、明度だけ上げて使う

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#000033` | 現行 CSS | `oklch(14.5% .101 264)` | **主色に採用**。ただし面 `oklch(40% .11 264)` へ**明度を大きく上げた** |
| `#800000` | 現行 CSS（見出しの罫） | `oklch(37.7% .155 29.2)` | **第二色に採用**（`oklch(40% .145 29)`）。樹脂側の識別に |
| `#0000ee` | リンク | — | 不採用。ブラウザ既定色 |

明度 14.5% のままでは**白地で「黒」に見え、色として機能しません**。
色相を保ったまま 40% まで上げています。

### hue 264 が野口金型製作所と同じであることへの対処

**色相では分離できない**ので、4軸で分けました。

| 軸 | 野口金型製作所 | スズキ製作所 |
|---|---|---|
| 地の温度 | 黄み灰（hue 95） | **暖かい灰（hue 55）**。より赤寄り |
| 署名的装置 | 回転数とトルクの対 | **金属と樹脂の対**＋工程の鎖 |
| 書体 | Shippori Mincho B1（太明朝） | **Zen Maru Gothic**（丸ゴシック）。樹脂を扱う会社なので角を落とす |
| 第二色の使い方 | 標語の赤を「速さ」側に | **臙脂を「樹脂」側に**（材質の識別） |
| 角丸 | 2px | **12px**。今回のバッチで最大 |
| 幕開けの造り | 楕円の等高線 | **斜めに割った二層の面**（金属と樹脂） |

## データの出所

設備・材質・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- 立形マシニングセンタ11行、複合加工機・NC複合旋盤9行、その他設備 … `setubi.html`
- 金属22種・樹脂20種の材質一覧 … `zaishitsu.html`
- 会社概要・沿革 … `gaiyou.html`
- 「万能な小回り」「工程を各工場に委託すると…」 … トップページ
- 拠点3か所の住所・電話 … トップページ

### 確認が必要な項目

- **所在地は福島県です**。見込み客リストでは栃木の走査結果に入っていましたが、
  本社工場・塙工場とも福島県東白川郡、営業所は山形と関東です
- **関東営業所の住所・電話が現行サイトにありません**。
  沿革に「2010年 東京営業所を関東営業所に変更し現在地へ移転」とあるのみで、
  トップページの拠点一覧にも掲載がありません
- **ISO の認証機関・登録番号の記載がありません**（取得年のみ）
- 従業員69名・資本金3,000万円は**時点の記載がありません**
- **沿革の最終記載が2013年**（塙工場 第2新社屋完成）です。13年分が反映されていません
- 現行サイトのナビにある「**保有測定機**」「**自社製品 簡易プレス機**」は
  ページが存在しますが、**本文が薄い**ため本案には含めていません。
  内容が得られれば節を足せます
- 設備表の「電気炉」は現行サイトで**行の途中で切れており**、
  型式・台数が読み取れませんでした。本案では省いています
- 現行サイトの表記「SUPPER QUICK TURN 15MS」は
  **SUPER の誤記**と判断し、本案では SUPER としています
