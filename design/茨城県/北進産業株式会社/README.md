## 設計上の判断

### 二事業を、対で立てる

この会社は**機械メーカー**と**受注加工業者**の二つの顔を持ちます。
どちらかを従にすると実態を誤って伝えるため、幕開けの直後に
**左右対等の二段組**で並べました。片方に寄せていません。

しかもこの二つは無関係ではなく、「自社の成形機の中枢部品を自分で削ってきたから
加工設備が社内に残った」という因果があります。その筋を本文に書いています。

### 署名的装置 ── 保有設備の台帳

受注加工の問い合わせで最初に確かめたいのは
**「その加工ができる機械があるか」**です。
現行サイトでは「部品加工」ページの下部に埋もれていた設備表を、
**機種名・行程・台数・メーカーのまま**、暗い帯の中の全幅の表に起こしました。

`X2500 / Y1750 / Z1400` のような行程は等幅フォントで組み、
機械の種別ごとに行グループ（`<th scope="rowgroup">`）で区切っています。

### セクション構成

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 短い宣言 |
| 01/02 | 二事業 | **対比の二段組**（左右対等） |
| 03 | 保有設備 | **暗い帯の全幅台帳**（署名的装置） |
| 04 | 認証 | 2枚の証書カード |
| 05 | 取引先 | 単純な `<dl>` の列挙 |
| 06 | 会社概要 | 仕様書的 `<dl>` |
| 07 | 問い合わせ | `<details>` + 地図 |

これまでの3社（全幅の表／数値対の帯／グラデーション帯）と重複しない構成です。

### 色 — 現行サイトから採取

現行サイトは CSS に色指定を持たず、色は HTML の `bgcolor` 属性にありました。

| 採取元 | 値 |
|---|---|
| `bgcolor="#3399CC"`（見出し帯） | `oklch(64.8% .119 235)` |

`--sky: oklch(52% .105 235)` / `--sky-ink: oklch(43% .095 235)` — **色相差 0°**。
明度のみ下げています（採取値は白地の文字で AA 未達のため、面用と文字用に分離）。

前3社との差：中央総業 260°、潮工業 253°、本案 235°。同じ「青」でも
色相で 18〜25° 離れており、彩度も .105 と控えめにしています。

### 検証中に直した不具合

台帳の行グループ見出しに `background: oklch(100% 0 0 / .07)`（半透明の白）を
使っていたところ、**コントラスト判定が 1.61:1 で不合格**になりました。

実際の見た目は暗い地の上の明るい文字で問題ありませんが、
判定器は祖先を遡って「白」を拾うため、**測定不能な状態**になっていました。
これは「透明度で色を作ると計測できなくなる」という既知の落とし穴です。

見た目が変わらない**不透明の実色**（`oklch(28% .026 235)`）に置き換えて解決しました。

## データの出所

設備一覧・認証・取引先・会社概要はすべて
**現行サイトから取得した実データ**です。

- 保有設備（機種名・行程・台数・メーカー）… `process.html` より
- 会社概要・取引先・工場面積 … `profile.html` より
- 認証情報 … トップページより
- 成形機のラインナップ … `products.html` より

### 確認が必要な項目

- 営業時間（記載が無いため JSON-LD にも入れていません）
- 設備表は現行サイトの主要機種を採録したもので、**全数ではありません**
  （現行サイトも「主要設備配置図（pdf）」へ誘導しています）
- `TAC 800` `TAC 650` は現行サイトで行程違いが別行になっていましたが、
  本案では機種ごとにまとめ、台数を合算しています
