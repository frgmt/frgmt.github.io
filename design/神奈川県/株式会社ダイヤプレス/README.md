# 株式会社ダイヤプレス — リニューアル提案サイト

プレス金型の設計製作とプレス部品加工。既存サイト <http://www.diapress.co.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 90点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- **Flash 依存**。トップページに「当サイトをご覧いただくためには Flash Player が必要です。
  Flash Playerは Macromedia 社から無償で配布されています。」という案内が残っています
  （Macromedia は2005年に Adobe に買収され、Flash 自体も2020年末に配信終了）
- ホームページ・ビルダーの `HpbImgPreload` によるロールオーバー JavaScript
- Copyright 表記が 2005 年のまま
- 「From2005.8.1 Thank you for your coming!!」というアクセスカウンター的な表示
- 情報が15ページ以上に分散

一方で**新着情報は 2023年8月まで更新**されており、従業員数も 2022年7月現在の値です。
中身は生きているのに、器が2005年で止まっている案件です。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの `bgcolor` で最も多い有彩色 `#004080`（12回）を主色、
`#ff8000`（7回）を差し色として継承しました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#004080` | `37.6% .123 254.7` | — |
| 本提案 `--nv` | `37% .12 255` | **0.3°** |
| 原サイト `#ff8000` | `73.2% .186 53.0` | — |
| 本提案 `--or-br`（罫・面） | `60% .155 53` | **0.0°** |
| 本提案 `--or`（文字） | `52% .145 53` | 0.0°（明度のみ調整） |

**橙は2段階に分けました。** 初稿では `oklch(60% .155 53)` の1色でしたが、
自動検証で**コントラスト 4.16:1（要4.5）が22件**検出されました。
小さな文字に使うには明るすぎたためです。色相を保ったまま明度を 52% まで下げた
文字用トークンを追加し、罫や面には明るい方を使い分けています。

**同じ色相帯の他案件との差別化について。** 埼玉の小田原紙業も 254° です。
本案は**橙の差し色**があること、角丸を 2px と最小にしたこと、
そして**写真主体**（あちらは写真ゼロ）であることで、別物として読めます。

### 冒頭の構成を作り直しました
初稿では左に文章・右に製品写真1点の2分割としていましたが、同時期に制作した
八光電機製作所と版面の骨格が同じになってしまいました。そこで本案は
**製品写真4点を全幅の帯**として並べる構成に変更しています。
この会社は写真そのものが主張なので、1点だけ見せるより、
超深絞り・インコネル・医療精密部品・マグネシウムを並べたほうが速く伝わります。

### 構成の軸 — 材料
この会社の際立った点は、**扱う材料の難しさ**です。
パーマロイ（磁性材）、インコネル600（耐熱合金）、板厚0.06mmのステンレス、
そしてマグネシウム・チタン。いずれも普通鋼のようには伸びません。

そこで冒頭を「絞りにくい材料を、絞ります。」とし、
「難材のプレス」を最初のセクションに置きました。
製品情報では**材質・板厚・工程・用途**をカード内の定義リストとして併記し、
発注側が自分の図面と突き合わせられる形にしています。

## 画像の扱い
原サイトの製品写真12点と工場写真3点を採用しました。
製品写真は白背景で撮られており、`object-fit: contain` で全体が見えるようにしています。
医療関連部品はスケールと一緒に撮影されているため、実寸が伝わります。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。Flash は使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO 9001/14001）／
  LocalBusiness **3件**（川崎事務所・岩手工場・岩手第二工場）／ WebSite ／ FAQPage
- MEO 対応: 3拠点それぞれに Google マップ埋め込み（API キー不要の `?output=embed` 形式）
