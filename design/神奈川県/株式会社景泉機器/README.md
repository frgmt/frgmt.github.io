## 設計上の判断

### 署名的装置 ── 作れるシリンダの径

「φ35〜φ160」と書かれても、その幅がどれくらいかは伝わりません。
そこで、**最大径と最小径のシリンダを同じ縮尺の断面で並べました。**

**径の比 160÷35 = 4.571 倍**を、描画でもそのまま保っています
（実測 4.577、誤差 0.13%）。

**長さについては、小径側の値が現行サイトに書かれていません。**
そのため図では**両方とも同じ長さで描き、径だけを変えて**います。
無い数字を勝手に置かないためです。
また**径と長さで縮尺が異なる**（同一にすると35φが1.4pxになり見えない）ことも、
図の中に明記しました。

### 配色 ── 139は未使用の色相

主色は現行サイトから画素採取した黄緑 `rgb(51,153,0)` =
`oklch(60% .191 139.4)`。白地用に `oklch(43% .130 139)`。**色相差 0.4°**。

**このリポジトリで hue 139 は未使用**です（最も近いのは140の1社）。
その1社は地が純白なので、こちらは**地に緑を薄く含ませて**分けました。

### 見出し

「φ35からφ160まで。長さ5mまで。」を h1 にしました。
現行サイトには h1 がなく、`<title>` に相当する位置に
「横浜　油圧シリンダ　精密加工」という検索語の並びが置かれています。
**発注側が知りたいのは地名と業種ではなく、作れる寸法です。**
