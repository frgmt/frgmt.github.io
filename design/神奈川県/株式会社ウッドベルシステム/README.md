# 株式会社ウッドベルシステム — リニューアル提案サイト

神奈川県横浜市南区のソフトウェア開発会社。既存サイト <http://www.wbs-web.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 87点）

この案件は他と性質が異なります。**サイトは生きています。**
トップページのお知らせは「2026.05.01 横浜本社事務所を移転しました」、
情報セキュリティポリシーは 2024年6月1日付、ISO も 27001:2022（最新版）です。
問題は中身ではなく、器のほうです。

- HTTPS 未対応
- `viewport` メタタグなし
- **横スクロールが 512px 発生**（幅390pxで実測）。スマートフォンで横に振らないと読めない
- XHTML 1.0 Transitional
- **DOCTYPE の DTD URL が誤っています**：
  `http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitiona.dtd`
  （正しくは `xhtml1-transitional.dtd`。末尾の `l` が欠落）
- ナビゲーションと見出しが画像（`nav.gif` / `h2_con.gif` / `h3.gif` / `h4.gif`）
- Copyright 表記がページによって 2010 年と 2013 年で不統一

**IT企業のサイトがスマートフォンで崩れている**という状態は、
この会社にとって他業種以上に不利です。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの CSS で最も多く使われている `#006cd8`（11回）を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#006cd8` | `54.4% .185 255.9` | — |
| 本提案 `--bl`（文字・面） | `48% .19 256` | **0.1°** |
| 本提案 `--bl-br` | `54.4% .185 256` | 0.1°（原サイトそのまま） |
| 原サイト `#003399` | `37.1% .173 262.1` | — |
| 本提案 `--bl-dp` | `37% .17 262` | 0.1° |

文字用は白地とのコントラストを確保するため明度を 54.4% → 48% に下げています。

### 構成の軸 — 何でも屋であること
この会社の特徴は、**扱う範囲の広さ**です。ソフトウェアを書き、
サーバーを入れ、LANを敷き、IP電話を工事し、机と椅子を納め、トナーと伝票用紙も届ける。

普通なら「一貫体制」と抽象化するところですが、それでは伝わりません。
そこで見出しを「つくるのも、入れるのも、直すのも。」とし、
**3部門を並列に見せる**構成にしました。サプライ部門（文具やトナー）も
隠さずに書いています。これが実際の強みだからです。

### 構成の軸 — 実績マトリクス
原サイトの「事業実績」ページは、業種と導入システムの対応表でした。
流通10システム、製造2、金融2、不動産3、通信2、病院1。

本提案では**業種ラベル＋システム名のタグ群**という形に整理しました。
「不動産 物件管理システム 開発」のような検索に対応でき、
発注側が自分の業種を見つけやすくなります。

## 写真について
原サイトに写真は1点もありません（画像はすべてナビゲーションと見出しの GIF）。
本提案も**写真なしで構成**しています。実装時にオフィスや作業風景の写真が
提供されれば、冒頭と部門紹介に配置できる構造にしてあります。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 導入実績22システムは原サイトの表をそのまま転記しました
- 情報セキュリティポリシーの4項目とその細目は原文のとおりです
- 原サイトの誤字「必要であるとゆう認識」（という）は引用箇所に含まれないため、
  該当部分は要約して掲載しています
- **住所は移転後のものです。**トップページに「2026.05.01 横浜本社事務所を移転しました」
  とあり、会社概要ページの住所（横浜市南区大岡二丁目7番18号）が更新済みと判断しました。
  本文にもその旨を注記しています
- **「関連会社」の項目が原サイトの会社概要にありますが、中身が空欄**のため
  掲載していません
- 採用情報（募集職種・キャリアプラン・募集要項3種・採用プロセス）と
  個人情報保護方針、労働者派遣事業マージン率は今回の収録範囲外です

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（`hasCredential` に ISO/IEC 27001:2022）／
  LocalBusiness ／ WebSite ／ FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- **横スクロール 0px**（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
  ※ 原サイトは幅390pxで512pxの横溢れ
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上

- 内部リンクはすべて相対パス
