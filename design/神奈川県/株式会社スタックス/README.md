# 株式会社スタックス — トップページ リニューアル案

現行サイト（http://www.stax-tqs.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。
※ 地図は Google Maps の埋め込みのため、`file://` では表示されません。
ローカルで確認する場合は `python3 -m http.server` 等で配信してください。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **ズーム禁止** | `user-scalable=no, maximum-scale=1` でピンチ拡大ができません |
| **HTTPS未対応** | `https://www.stax-tqs.co.jp/` は接続できません |
| **h1が0個** | 見出しの最上位がありません。検索エンジンがページの主題を掴めません |
| alt属性の欠落 | 画像3点のうち **2点** に alt がありません |
| jQuery | **2.2.4**（2016年） |
| Copyright | **2017年**のまま |

### 一番の問題は、書いてあることの強さと見せ方が釣り合っていないこと

このサイトには、こう書かれています。

> 惑星探査人工衛星機部品／H2ロケット搭載部品

> 0.01t〜の薄板板金加工、特殊な筐体製造を得意としており、
> 高品質である事が必須な人工衛星の部品や医療機器筐体などを手掛けています。

板厚0.01mmは、髪の毛のおよそ8分の1です。
そこから加工でき、しかも**1個だけの注文を歓迎している**会社は多くありません。

この2つはトップページの見出しになるべき情報ですが、
現在は事業内容ページの本文中に置かれています。

## この提案で変えたこと

### 1. 「0.01mm」と「1個から」を見出しにする

```
板厚 0.01mm から、1個でも承ります。
```

探している相手（試作1個を頼める先を探している設計者）に、
最初の1行で該当することを伝えます。

### 2. 御社の写真をそのまま使いました

現行サイトには、質の高い写真が33点ありました。
このうち11点を使っています。**図やイラストは使っていません。**

- **冒頭**：銅・真鍮・ステンレスの薄板部品（0.01tの説明より、現物のほうが伝わります）
- **加工技術**：切断・曲げ・溶接・仕上げまで社内で行った部品
- **工程**：受注→ブランク加工→バリ取り→曲げ→溶接→検査の6点
- **薄板の節**：職人が手作業で仕上げている写真
- **実績**：完成した筐体4台
- **工場**：スタックス十日町（廃校の体育館を使った工場）

※ 実際に公開される際は、これらの写真の使用可否をご確認ください。

### 3. 工程を6枚の写真で見せる

現行サイトは「受注／ブランク加工／バリ取り／曲げ加工／溶接加工／検査」の
6工程それぞれに写真を持っていますが、詳細ページへのリンクとして小さく並んでいます。
番号と一行説明を添えて、**この順で作っている**ことが分かる形にしました。

## 現行サイトで見つかった誤り（2件）

### 1. 勝浦工場の電話番号

```
TEL. 047-076-3115
```

千葉県勝浦市の市外局番は **0470** です。正しくは `0470-76-3115` と思われます
（FAXの `047-076-3116` も同様）。
このままではかけ間違いが起きます。

**本提案では、確証が取れないため勝浦の電話番号を掲載していません。**
正しい番号をお知らせいただければ追記します。

### 2. 「設立から60年を超える歴史」

代表メッセージの一節です。設立が1953年ですので、2026年時点では**73年**になります。
本提案では「70年を超える」に改めました。

なお実績一覧の「多孔式放熱板（**ヒートシング**）」は
ヒートシンクの誤記と判断し、訂正しています。

## 事実の扱いについて

本文の数値・固有名詞65項目は、現行サイトの記述と照合済みです。

創立年について、現行サイトには2つの記述があります。

| | 記述 |
|---|---|
| 会社情報 | 創立年月日 **昭和8年（1933年）3月1日** |
| 沿革 | **1953年（昭和28年）** ㈱スタックス前身のエッキス製薬株式会社設立 |
| トップページ | **1953年設立** |

矛盾ではなく「創立1933年・設立1953年」と解釈できるため、
**両方をそのまま掲載**しています。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,908文字）
- **ピンチズームは禁止していません**
- 写真11点はすべて `width`/`height` と `aspect-ratio` 指定つき（レイアウトのずれ防止）。
  2枚目以降は `loading="lazy"`。元画像より大きく引き伸ばさないよう上限を設定
- 画像は合計約1.0MB（元の2.0MBから再圧縮。拡大はしていません）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の紺は、**現行サイトで実際に使われている色**
`rgb(40,67,126)` = `oklch(39.4% 0.105 263.8)` から採りました。
白地でAAに届くよう明度38%・彩度0.100へ整え、色相は保持しています。
地はほぼ無彩の淡いグレーで、写真の色を邪魔しないようにしています。
