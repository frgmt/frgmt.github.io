# アスタム株式会社 — トップページ リニューアル案

現行サイト（http://www.astam.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **100点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | **スマホでは980px幅の画面として描かれ、全体が約38%に縮小表示される**（後述） |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |

現行サイトの更新は活発です（2026年7月のお知らせあり）。中身は生きています。

### 「はみ出していない」が「読めない」— 実機での測定

端末のUAで再測定したところ、**横のはみ出しは0px**でした。
しかしこれは問題が無いという意味ではありません。

`viewport` タグが無いページをスマホのブラウザで開くと、
**幅980pxの仮想的な画面としてレイアウトしてから、画面幅に合わせて縮小**します。

| 測定項目 | 実測値 |
|---|---|
| 指定した表示幅 | 375px |
| 実際の `window.innerWidth` | **981px** |
| 表示倍率 | 375 / 981 ≒ **38%** |

つまり全体が **38%に縮んで**表示されます。はみ出さないのは
「画面に収まっている」からではなく「縮小されているから」です。

現行サイトの本文フォントは **10px**。38%に縮むと画面上は
**約3.8px相当**になり、拡大しなければ実質的に読めません。

## 設計上の判断

### 署名的装置 ── 口径レンジのバー

バルブは**呼び径で決まります**。設計者は「うちの配管は250Aだが、
どのシリーズが対応するか」を知りたい。

現行サイトはシリーズごとに製作範囲を文章で書いており、
比較するには5つの数値範囲を頭の中で並べる必要がありました。

本案は**同じ対数目盛の上に5シリーズのバーを並べました**。
バーの位置がそのまま対応口径です。VF-737 が大口径側にだけ伸びていることが
一目で分かります。目盛の位置は実際の口径から計算しています。

```
VF-730 ウェハー形    40A–1000A  left:0%     width:94.6%
VF-733 ラグ形        40A– 600A  left:0%     width:79.6%
VF-737 フランジ形   350A–1000A  left:63.8%  width:30.8%
VF-9XX 二重偏心形    50A– 600A  left:6.6%   width:73.0%
VF-8XX 三重偏心形    80A–1200A  left:20.4%  width:79.6%
```

### 色 — ヘッダー帯の画素から採取（CSSの値ではなく）

ここは**判断が分かれるところ**でした。

| 候補 | 出所 | 値 |
|---|---|---|
| `#ff5a27` | CSS `common.css` の宣言 | `oklch(68.3% .21 36.6)` |
| **`#0090d8`** | **ヘッダー帯画像の画素（最頻出）** | **`oklch(62.5% .148 241.7)`** |

CSSの宣言値だけを見れば橙になりますが、**ヘッダー帯の画像を画素解析すると
青が圧倒的多数**（13,154画素）でした。橙はリンクや強調に使われる補助色です。

面積で見れば青がブランド色と判断し、**青を主色、橙を第二色**として採用しました。
橙は口径の数値と本文中の強調にだけ使っています。

`--flow: oklch(50% .145 242)` — **色相差 0.3°**。

### 関東熱処理と同色相であることへの対処

関東熱処理（241°）と本案（242°）はほぼ同じ色相です。
スキルの指示どおり**彩度で分けました**。

| | 関東熱処理 | アスタム |
|---|---|---|
| 彩度 | **.108**（重工業の落ち着いた紺） | **.145**（流体の鮮やかな青） |
| 署名的装置 | 炉のカード＋温度帯 | **口径レンジのバー** |
| 角の形 | 6px | **ボタンは全円（pill）** |
| 第二色 | 炉温の fire 系 | **橙（採取どおり）** |
