# 大谷技研株式会社 — リニューアル提案サイト

神奈川県厚木市の吸着パッド商社。既存サイト <http://www.ohtani-eng.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 88点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- **Microsoft Word から書き出した HTML**。`<o:p>` などの Office 名前空間タグ、
  `mso-` プレフィックスのスタイルが大量に残っています
- そのため1ページのファイルサイズが肥大（製品一覧ページは 333KB）
- ナビゲーションが画像（`home.gif` / `homeinv.gif` の2枚差し替え式）
- Copyright 表記が 2005 年のまま
- 情報が20ページ近くに分散

## この案件の価値：技術情報が本物

商社のサイトは「取扱商品を並べただけ」になりがちですが、この会社は違います。

- **材質7種の特性比較表**（硬度・色・使用温度範囲・機械的特性・化学特性・適応ワーク）
- **吸着力の計算方法**（吸着の向きによる違い、有効パッド面積の求め方）
- **応答時定数の考え方**（エジェクタの流量特性、配管の圧損、時定数の支配項）

これは選定を助ける実務的な内容で、「吸着パッド 材質 比較」「吸着力 計算」といった
検索に対して価値のあるページになります。原サイトではこれが Word 由来の重い HTML に
埋もれていました。

本提案では**材質比較表を7列21行の `<table>` として再構築**し、
機械的特性・化学特性・適応ワークをグループ行で区切って読めるようにしています。

もうひとつ拾ったのが、応答の説明にある**トレードオフ**です。

> 漏れが大きい場合で到達圧力を確保したいときは、太い配管が効果的です。
> しかし……全体としては、配管径を太くすると時定数は増加します。

吸着力を取るか応答速度を取るかで配管径の要求が逆になる、という実務的に重要な指摘です。
原サイトでは別々の段落に書かれていたため見落とされやすく、本提案では
**注意書きとして明示**しました。

## デザイン方針

### 色 — バナー画像から採色しました
原サイトの CSS にブランド色の指定はありません（`bgcolor` は白のみ）。
そこでヘッダーのバナー画像 `titlebanaohtani.jpg` をピクセル解析し、
最頻色 `rgb(128,208,240)` を採色しました。

| | OKLCH | 色相差 |
|---|---|---|
| バナー実測 `rgb(128,208,240)` | `81.8% .09 225.6` | — |
| 本提案 `--sky`（文字・面） | `48% .105 226` | **0.4°** |
| 本提案 `--sky-br`（罫） | `66% .13 226` | 0.4° |

明度は 81.8% → 48% まで下げています。バナーの水色は背景として使われていたもので、
そのままでは文字にもボタンにも使えません（白地で 1.4:1）。

**実装中に1件、コントラスト不足を検出しました。** ロゴ脇の「OHTANI」チップに
`--sky-br`（66%）を背景として使ったところ、白抜き文字で **3.00:1**（要4.5）でした。
`--sky`（48%）に変更して解消しています。

### 構成の軸 — 選定
この会社が売っているのは「2万種類の中から、あなたのワークに合う1つを選ぶこと」です。
そこで冒頭を「そのワーク、どのパッドで吸いますか。」とし、
**タイプ表 → 材質表 → 吸着力 → 応答**という、選定の手順そのままの順序で並べました。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- パッド12タイプの種類数とサイズ範囲、材質7種の特性表は原サイトの記載どおりです
- **計算式そのものは掲載していません。**原サイトでは数式が画像化されており、
  変数の定義（記号の意味）も画像内にあるため、正確な転記ができませんでした。
  考え方のみをテキスト化し、「計算式と図は原資料に掲載されています」と注記しています
- **電話番号に食い違いがあります。**トップページには「フリーダイヤル 0120-972-303
  （046-280-6066）」「TEL 046-280-6066／FAX 046-280-6067」とあり、
  会社案内ページには「電話 046-280-6066／携帯 090-8053-1489」とあります。
  本提案では**両ページに共通する 046-280-6066 のみ**を掲載し、
  フリーダイヤル・FAX・携帯は載せていません。**要確認事項に挙げています**
- 設立年・資本金・従業員数の記載は原サイトになく、掲載していません
- **FIPA社との取引関係の性質（正規代理店か否か）は原サイトに明記がない**ため、
  「FIPA社の製品を扱っています」という原文の表現を維持しています

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。Office 由来のタグは使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）
