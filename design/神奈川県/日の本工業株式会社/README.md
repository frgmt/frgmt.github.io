# 日の本工業株式会社 — トップページ リニューアル案

現行サイト（http://www.hinomoto-kogyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **80点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| WordPress | テーマ・プラグインとも更新が止まっている |
| PHPの記述漏れ | HTML内に `?php echo home_url('/contact'); ?>` がそのまま出力されている |
| WassUp 1.9.2 | 2013年で開発が止まった解析プラグインが稼働中 |

**リンク切れが実害として出ています**。`href="?php echo home_url('/contact'); ?>"`
というPHPの生ソースがHTMLにそのまま出ており、そのリンクは機能しません。

## 設計上の判断

### 署名的装置 ── 通し番号つき設備台帳

試作板金への相談で確かめたいのは
**「その形状を作れる機械があるか」**です。

現行サイトの設備一覧は34行の表で、番号・機械名・加工能力・台数・
メーカー・備考が並んでいます。この**通し番号をそのまま活かし**、
縦一列の台帳として組み直しました。表の横スクロールを避け、
加工能力を等幅で目立たせています。

前14社では「表」「棒グラフ」「カード」を使ってきたので、
今回は**番号を軸にした縦の台帳**という別の形にしています。

### 「まだ一台しかない車」

この会社は量産をしません。開発車両・改造車両という
**世に一台しかない車**の板金をやってきた会社です。
手加工板金で1個から作れることが最大の差別化なので、
幕開けの見出しをそこに置きました。

### 赤が3社目であることへの対処

採取色は 20.9°。ウチヤ（28°）、ベニー精工（29°）とは 7〜8° 離れていますが、
赤系が3社目なので分離軸を明示します。

| 軸 | ウチヤ | ベニー精工 | 日の本工業 |
|---|---|---|---|
| 地の色相 | 完全な無彩色 | 黄み（70） | **青み（240）** |
| 署名的装置 | 製品比較表 | 径ごとの棒グラフ | **通し番号の台帳** |
| 見出し書体 | Zen Kaku（ゴシック） | しっぽり明朝 | **Noto Serif JP（明朝）** |
| 律動 | 表 | 棒 | **番号を振った縦一列** |

### 色 — ロゴから採取

| 採取元 | 値 |
|---|---|
| ロゴ画像 `site_id.png` の画素（1,224px） | `#f03048` = `oklch(62.3% .224 20.9)` |

`--sun: oklch(50% .16 21)` — **色相差 0.1°**。彩度 .224 → .16（上限まで抑制）。

社名の「日の本」に対して赤は素直な選択であり、ロゴもその赤です。

## データの出所

設備・取引先・沿革はすべて**現行サイトから取得した実データ**です。

- 設備一覧（34行・通し番号のまま） … `/machine` より
- 会社概要・取引先・経営理念・沿革 … `/company` より
- できること（10項目） … トップページより

### 確認が必要な項目

- **従業員数の記載が現行サイトにありません**
- 沿革は昭和54年（三次元測定器導入）以降が現行サイトで途切れており、
  **平成期の記載を取得できていません**。llms.txt には
  取得できた範囲のみ記載しています
- 現行サイトの設備表 09 番のメーカーは「ENSYU」表記でしたが、
  一般的な社名表記の「遠州」としました
- 設備 26番の「（ニューコロナ）」は現行サイトでも括弧付きで、
  メーカー名か通称かが判別できませんでした
- 東北工場の稼働は2019年3月のお知らせより。**現況をご確認ください**
- 営業時間（記載が無いため JSON-LD にも入れていません）
