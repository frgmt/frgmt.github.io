## 設計上の判断

### 署名的装置 ── 置ける広さと、吊れる重さ

物流を委託する側が最初に確かめるのは、この2点です。

1. **どれだけ置けるか**（倉庫面積）
2. **どれだけ吊れるか**（クレーン・フォークの能力）

現行サイトでは、この情報が会社概要ページの表の中に
テキストとして埋もれていました。

本案では倉庫3棟の面積を**面積比の帯**で、クレーン・フォークを
**能力別の棒**で示しています。本社3,000m² に対し菖蒲沢・第三が
各1,000m² であることが、数字を読まなくても分かります。

### 「一坪単位」を最上段に置く

この会社は**一坪単位で預かる**と明言しています。
これは小口の荷主にとって決定的な情報なので、ヘッダー最上段に出しました。

### 木材を第二色で示す

木箱・木製パレットはこの会社の出発点であり主力商材です。
現行CSSから採取した金色 `#daa520` 系を第二色とし、
**木材を扱う2節だけ**に地色と左罫で使っています。
資材の性質が節ごとに読み分けられます。

### 色 — 本バッチで初めての緑

| 採取元 | 値 |
|---|---|
| CSS `TTtop.css` | `#004000` = `oklch(32.2% .11 142.5)` |
| ボタン画像 `bt_01.png` の画素 | `#009030`（同系統で裏付け） |
| CSS の第二色 | `#daa520` = `oklch(75.2% .147 84)` |

`--pine: oklch(42% .12 143)` — **色相差 0.5°**。
採取値は暗すぎて面に使うと沈むため、**明度のみ上げています**。

これまで16社は青・赤・橙・紫に集中していたため、
緑は色相だけで十分に分離できます。

### 検証ツールの取りこぼしを1件修正

本サイトの検査で `lib/audit.mjs` が「棒グラフ類なし」と報告しました。
**バーは正しく描画されていた**のですが、検出をクラス名
（`fill` / `bar` / `track`）で行っていたため、
`lot__box` `lift__f` という命名が引っかからなかったためです。

「文字を持たず、背景が塗られた、高さ40px以下で幅が高さの2倍以上」
という**形状ベースの検出**に変更しました。
壊れたバーを検出できることはカナリアで再確認しています。

## データの出所

設備・拠点・取引先はすべて**現行サイトから取得した実データ**です。

- 会社概要・拠点・設備・取引先・加盟団体 … `profile.html` より
- 梱包資材の仕様 … `buffer.html` / `Palette.html` より
- ロジスティックサービス … `distribution.html` より

### 確認が必要な項目

- **段ボール箱・紙管・紙製品の詳細**は `paperproduct.html` にありますが、
  取得できていないため概要のみの記載です
- 木箱・木枠梱包の詳細も `woodenbox.html` を取得できていません
- ISOのページ（`iso.html`）は認証取得の事実のみで、
  **認証番号や登録範囲の記載がありません**
- 環境保全への取り組み・社長メッセージは未掲載です
- 営業時間（記載が無いため JSON-LD にも入れていません）
