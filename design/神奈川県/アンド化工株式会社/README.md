# アンド化工株式会社 — トップページ リニューアル案

現行サイト（http://www.andkakou.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **100点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |
| `<title>` が空 | **検索結果にURLしか出ない** |
| トップページの内容 | 社員旅行の写真が主要コンテンツ |

**`<title>` が空**なのは実害が大きく、検索結果でクリックされません。

## 設計上の判断

### 署名的装置 ── 三つの加工を段差で並べる

この会社の強みは、**同じ樹脂を三つの方法で扱えること**です。

- 板加工（型が要らない。少量・一品物・大型に）
- 成形加工（型を使う。数量が出るほど有利）
- 機械加工（削り出す。精度とエンプラに）

発注側から見れば「どれで作るのが安いか」を相談できる相手ということです。
これは工法をひとつしか持たない会社にはできません。

現行サイトでは `gyoumu.htm` に三列の表として置かれているだけでした。
本案では**三つの区画を段差にして並べ**、それぞれに「どんなときに向くか」を
書き添えています（段差は板材の重なりに見立てたものです）。

### 設備数を、表のまま出す

現行サイトの `kikai.htm` は設備名と台数の羅列です。これは削らず、
**工場ごとに分けた表**として残しました。プレス成形機6台が
**すべて自社製**であることは、この会社の性格をよく表しています。

### 色 — ロゴから採取

| 採取元 | 値 |
|---|---|
| ロゴ画像 `logo1.gif` の画素（最頻出 8,115px） | `#3018ff` = `oklch(47.4% .299 270)` |

`--form: oklch(45% .15 270)` — **色相差 0°**。

**彩度を .299 → .15 と大きく下げています**。採取値は sRGB の端にある
非常に鮮やかな青紫で、白地に置くと目に振動します。
スキルの上限（約 .16）まで抑えました。色相＝識別子は動かしていません。

中央総業（260°）とは 10° 差ですが、彩度（.155 vs .15）はほぼ同じため、
**構成で分けました**。中央総業は全幅の資格台帳、こちらは三区画の段差構成です。

### 検証ツールの不具合を1件修正

ロゴの画素採取で `rgb(48,24,264)` という**あり得ない値**が出ました。
量子化の `Math.round(v/24)*24` が 255 を 264 に押し上げていたためです。
`Math.min(255, …)` で頭打ちにして修正しました。

これは黙って壊れる類の不具合で、**採取した色が実際より鮮やかに出ます**。
以前サンプリングした他社の値も確認しましたが、
最頻出色が 255 付近でなかったため影響はありませんでした。

## データの出所

- 三つの加工系統 … `gyoumu.htm` より
- 設備一覧（工場別・台数） … `kikai.htm` より
- 会社概要・納品先・仕入先 … `gaiyou.htm` より

- 事業所 … `zigyousyo.htm` より
