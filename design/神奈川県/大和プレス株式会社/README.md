# 大和プレス株式会社 — トップページ リニューアル案

現行サイト（http://yamato-press.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **88点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |

現行サイトは情報量が多く、英語ページも用意されています。**器だけの問題**です。

## 設計上の判断

### 署名的装置 ── トン数のはしご

プレス屋への相談で最初に決まるのは**能力（トン数）**です。

現行サイトの主要設備表は種別・機械名・能力・メーカー・台数の一覧で、
プレスだけでも11行あり、**どのトン数に厚みがあるか**が読み取れませんでした。

本案は 80t〜1,500t を**同じ対数目盛**に並べ、右に台数を添えています。
110t が5台あること、400t 帯が3台（メカ2＋トランスファー1）あることが
一目で分かります。目盛の下端は 60t に取り、最小の 80t でもバーが
見える幅（8.8%）になるようにしました。

### 一貫生産を「鎖」として見せる

この会社の主張は**設計から輸送まで途中で他社に渡さない**ことです。
ヘッダー最上段に7工程を矢印で並べ、本文では番号付きの鎖として展開しました。
矢印の色には現行CSSの赤 `#e70014` 系を使っています（現行サイトでも
警告・強調に限定使用されていた色です）。

### 青が続いたことへの対処

採取色は 251.4°。潮工業（253°）、新井製作所（250°）とほぼ同じです。
4軸で分離しました。

| 軸 | 潮工業 | 新井製作所 | 大和プレス |
|---|---|---|---|
| 地の色相 | 青み（253） | 緑み（150） | **紫み（300）** |
| 署名的装置 | 寸法票 | 出力順の選定表 | **トン数のはしご** |
| 欧文書体 | — | M PLUS 2 | **Archivo（数値専用）** |
| 第二色 | なし | なし | **赤（工程矢印のみ）** |

### 色 — ロゴとCSSの両方で裏付け

| 採取元 | 値 |
|---|---|
| ロゴ画像 `img/common/logo.png` の画素（1,074px） | `#3078c0` = `oklch(56.3% .132 251.4)` |
| CSS `common.css` | `#2e6aac` = `oklch(51.8% .122 253.1)` |

CSSには赤 `#e70014` もありましたが、**ロゴは青一色**だったため
青を主色と判断しました。赤は工程矢印にのみ使っています。

`--steel: oklch(46% .125 251)` — **色相差 0.4°**。

## 検証中に見つけた不具合（2件）

### 1. 320px で横溢れ 28px

トン数の行で機種の但し書きが行幅を押し広げていました。
320px 以下では但し書きを目盛の下へ回すように修正しています。

### 2. バーが 0px 幅で描かれていた（重大）

`<span class="rung__fill" style="width:98%">` が **幅0px** で
描画されていました。span は `display:inline` で、
**インライン要素には width / height が効かない**ためです。

問題は、**どの検査にも引っかからなかった**ことです。
横溢れなし、コントラスト達成、JSエラーなし——空の要素は
「正しく空」なので、すべての検査を通過します。

同じ不具合が**ベニー精工の加工径分布**にもありました。
こちらはページの主役そのものが見えていない状態でした。

`lib/audit.mjs` に**バーの実測**を追加し、
壊れたバーを検出できることをカナリアで確認したうえで、
本セッションの全19サイトを一括再検査して他に無いことを確かめています。

## データの出所

設備・認証・取引先はすべて**現行サイトから取得した実データ**です。

- 主要設備（種別・機械名・能力・メーカー・台数） … `equipment.html` より
- 会社概要・認証・取引先・環境方針 … `company.html` より
- 拠点情報 … `bases.html` より
- 一貫生産の工程 … トップページより

**トン数別の集計は当方で作成**しました（現行サイトは種別順の一覧）。

### 確認が必要な項目

- 溶接機の台数「約90台」は現行サイトの各行を合算した概算です
  （スポット38＋プロジェクション29＋ポータブル13＋その他）。
  現行サイトに合計値の記載はありません
- 現行サイトの設備表は末尾（「2連 溶接機」以降）が途切れており、
  **全設備を取得できていません**
- 沿革ページ（`company.html` の沿革）は本案では未掲載です
- 営業時間（記載が無いため JSON-LD にも入れていません）
