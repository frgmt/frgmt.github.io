# 中央総業株式会社 — トップページ リニューアル案

現行サイト（http://chuo-sogyo.com）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **1位（110点）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホ対応の宣言が無い |
| **スマホ表示** | **PC版は545pxはみ出す。実機では別URLのモバイル専用サイトへ転送**（後述） |
| Flash残存 | 2020年サポート終了済み |
| jQuery 1.4.2 | 2010年リリース。サポート終了・脆弱性の懸念 |

### スマホ表示の実態（端末UAで再測定）

当初「スマホで545pxはみ出す」と記載していましたが、**実機のUAで再測定して
訂正します**。iPhone のUAでアクセスすると `/smarts/index/1/` という
**別URLのモバイル専用サイトへ転送**されます。

| 測定条件 | 結果 |
|---|---|
| デスクトップUA + 375px幅 | 545px はみ出し（PC版がそのまま出る） |
| iPhone UA | モバイル専用サイトへ転送・はみ出し27px |

つまり**崩れているのではなく、PC版とスマホ版を別々に維持している**状態です。
モバイル版の viewport は `width=320, user-scalable=0` で**ズームが禁止**されており、
弱視の方が拡大できません。

提案の根拠は「崩れている」ではなく次の2点になります。

1. **二重管理をやめられる** — 1つのHTMLでPC・スマホ両方に対応できる
2. **ズーム禁止を解消できる** — アクセシビリティ上の問題（WCAG 1.4.4 違反）

## 設計上の判断

### この会社の資産は「人数」である

同業他社との差は、工法の説明文ではなく**有資格者628名**という数字にあります。
第2種あと施工アンカー施工士355名、第1種200名、技術管理士54名。
これは現行サイトでは表の一部として埋もれていました。

そこで**署名的装置を「資格台帳」**とし、ブランドカラーの全幅帯の中に
`<table>` として置きました。カードではなく表にしたのは、これが本質的に
数値の一覧だからです（`<th scope>` 付き）。

### セクション構成（カード網は使っていない）

| # | 節 | archetype |
|---|---|---|
| — | 幕開け | 数の宣言（写真無し・罫のグリッド） |
| 01 | 資格台帳 | **全幅の表**（署名的装置） |
| 02 | 取扱工種 | **番号付き縦索引**（`<ol>`・大きな番号を左に振る） |
| 03 | 対応地域 | **横スクロール帯**（scroll-snap） |
| 04 | 会社概要 | **仕様書的 `<dl>`**（key: value） |
| 05 | 採用 | **一枚の言明**（`<blockquote>`） |
| 06 | 問い合わせ | `<details>` + 地図 |

同一のカード網は 1つも使っていません。要素は表・`ol`・`dl`・`blockquote`・`details` と
内容に応じて変えています。

### 色 — 現行サイトから採取

現行CSS（`/files/design/tmplate/7/css/design.css` ほか）から採取：

| 採取元 | 値 | 本案での扱い |
|---|---|---|
| 現行のブランド青 | `#004bb4` = `oklch(44.5% .179 259.7)` | `--brand: oklch(45% .155 260)` |
| 現行の明色 | `#3cb9eb` | `--brand-lift`（下線の伸長のみ） |

**色相差 0.3°**（規定の±10°以内）。彩度のみ .179 → .155 に抑制しています。
白地に対して .179 は目に振動して見えるためで、色相＝ブランドの識別子は動かしていません。

文字用には暗い兄弟トークン `--brand-ink: oklch(38% .142 260)` を別に立てています。
面と罫には `--brand`、文字には `--brand-ink`。1トークンで兼ねると小さな文字が
コントラスト不足になります（白地で実測 10.26:1 を確保）。

地は純白 `oklch(100% 0 0)`。全幅の暗い帯は使わず、区画の分離は淡い青みの
`--paper`（96.6%）で行っています。

### ヘッダー — 「連絡先を最上段に置く二段組」

現行サイトの最大の資産は**フリーダイヤル 0120-07-1222**です。
そこで上段にブランド色の帯を敷き、許可番号と通話無料の電話を置きました。
社名は和文のまま組んでいます（ロゴ画像が無いため、
ラテン文字の社名表記を捏造することはしていません）。

### 動き（3種・カテゴリ違い）

1. **進入** — スクロールで段階的に立ち上がる（60/120/180ms のずらし）
2. **状態** — ヘッダーの影、罫が左から伸びるホバー、`<details>` の矢印回転
3. **スクロール連動** — 台帳の数字の下線が視界進入に応じて伸びる
   （`animation-timeline: view()`、非対応環境では何も起きないだけ）

`prefers-reduced-motion: reduce` で変形とループを止め、**内容はすべて可視**のままにします。
初期状態の `opacity:0` は `<head>` の同期スクリプトが付ける `.js` が有る時だけ適用され、
さらに2.6秒の保険タイマーで必ず可視化します（隠したままにするくらいなら動きを捨てる）。
