# 多田プレス工業株式会社 — リニューアル提案サイト

自動車部品のプレスメーカー。栃木工場が鹿沼市にあります。
既存サイト <http://www.tadapress-t.co.jp/> の公開情報のみを使って再構成した、
1ページ構成の提案です。

## スコア根拠（prospect-scanner: 45点）
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- **Flash 残存**（2020年にサポート終了済み）
- **スマートフォンで横に595pxはみ出し**（実測）— 今回扱った案件中で最大の溢れ幅
- jQuery 依存（ddsmoothmenu / lightbox）

**内容は非常に充実しています。**沿革は2023年の新本社工場まで、
設備一覧は3工場すべて、顧客名も具体的。スコアが低いのは器の問題だけです。

なお調査中に判明しましたが、**画像は既に HTTPS へリダイレクトされます**
（`http://` へのリクエストが `https://` に301）。サーバー側は対応済みで、
HTML内のリンクが http のままという状態と思われます。

## デザイン方針

### 色 — 原サイトからの継承
原サイトの主色 `#1f3d71` を継承しました。

| | OKLCH | 色相差 |
|---|---|---|
| 原サイト `#1f3d71` | `36.6% .097 260.6` | — |
| 本提案 `--nv` | `37% .1 261` | **0.4°** |

トラック部品のメーカーらしく、**罫を4pxと太く**しています。
ヘッダー下、数値帯の上、製品カードの画像下、拠点カードの見出し下。
他案件が1pxの細い罫で軽さを出しているのに対し、この案件は重心を低くしました。
フッターも紺のベタ地です。

### 構成の軸 — 厚物
「板厚0.6ミリから12ミリまで」は原サイトの冒頭にある一文ですが、
**12mmという上限**がこの会社の立ち位置を決めています。薄板を抜ける工場は多くても、
12mmを抜ける工場は限られる。そこで「12ミリの鉄板を、プレスで抜く。」を
独立したセクションの見出しにしました。

いすゞ自動車の**直納指定認定工場**（1981年〜）という肩書きも、
この分野では強い信用の証明なので、認証バッジとして並べています。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 設備一覧（本社18行・栃木20行・タイ22行）は原サイトの表から集計し、
  本文では拠点ごとの要約として記載しました。全項目は llms.txt に転記しています
- 「グループ従業員379名」は3拠点の合計（159＋90＋130）です。
  原サイトに合計値の記載はありません
- 製品の材質・板厚・工程は、ギャラリー画像内の仕様表を拡大して書き起こしました
- **原サイトの表記ゆれを整理しました。**「ISUZU MOTER CO,(THAILAND)LTD」は
  綴りの誤りと判断し「ISUZU MOTORS (THAILAND)」としています。
  住所の「曾屋」「曽屋」の混在は「曽屋」に統一しました
- **2014年6月の沿革は「ISO9001認証取得予定」**と原文にあり、その後の取得可否が
  記載されていないため、タイ工場のISO取得は掲載していません
- 新本社工場の投資額（8.4億円）と溶接能力3割増は、原サイトが引用している
  日刊工業新聞2023年9月4日付の記事内容です。**出典を明記して引用**しました

## 画像の扱い
原サイトのギャラリーから製品写真6点（448×500px）を採用しました。
写真下部の焼き込み仕様表はトリミングし、`object-position: top` で
製品部分のみを表示しています。仕様はHTMLとして別に記述しました。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。**Flash / jQuery は使用していません**
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（ISO9001・エコアクション21・栃木県フロンティア企業）／
  LocalBusiness **2件**（本社・栃木工場）／ WebSite ／ FAQPage
- MEO 対応: 本社と栃木工場に Google マップ埋め込み（API キー不要の `?output=embed` 形式）

`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：
