# 株式会社コートク — リニューアル提案サイト

神奈川県高座郡寒川町の電子機器製造（EMS）。既存サイト <http://www.kohtoku.jp/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 95点）
- HTTPS 未対応
- `viewport` メタタグなし → スマートフォンで PC 版が縮小表示される
- **Flash 依存**。トップページに「Couldn't load plugin.」と表示される領域があります
  （「動画で観るコートクのテクノロジー」の再生枠）
- 見出し・バナー・ナビゲーションがすべて画像
- Copyright 表記が 2010 年のまま
- 情報が10ページ以上に分散

## この案件で最も価値のある変更：価格表を HTML にした

原サイトの「4つのプラン」は **680×552px の1枚の JPEG**（`common/img/4plan.jpg`）でした。
その中に、この会社で唯一の**具体的な価格情報**が入っています。

| | ロット | 単価 |
|---|---|---|
| 表面実装 | 50〜2,000台/LOT | 1点あたり @0.8 より |
| 自動挿入 | 100〜5,000台/LOT | 1点あたり @1.0 より |
| ディスクリート部品 | 手挿入 or 手半田付け | 1点 @5.0 より |

実装の外注先を探す担当者が最初に知りたいのは価格です。それが画像に閉じ込められている限り、
「基板実装 単価」といった検索には決して載りません。本提案では全行を書き起こし、
`<dl>` として実装しました。

## デザイン方針

### 色 — ロゴから採色しました
CSS 内で最も多い色は `#0817a9`（青）ですが、これは枠線とナビゲーションの装飾色です。
画面を開いて最初に目に入るのは、**赤地に白抜きの KOHTOKU ワードマーク**でした。
そこでロゴ画像をピクセル解析し、最頻色 `rgb(224,0,16)` を主色としました。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ実測 `rgb(224,0,16)` | `57.0% .233 28.0` | — |
| 本提案 `--red-br`（面で使用） | `57% .233 28` | **0.0°** |
| 本提案 `--red`（文字で使用） | `48% .19 28` | 0.0°（明度のみ調整） |

面に使う色はロゴのまま、文字に使う色は白地とのコントラストを確保するため
明度を 57% → 48% に下げています。

副色の `--navy`（`oklch(38% .16 266)`）は原サイトの `#0817a9` 由来で、
**工程・設備の説明と研究室向けセクションだけ**に使いました。
「営業の話」を赤、「技術の話」を紺で分けています。

### 構成の軸 — 4つのプラン
この会社の際立った点は、**顧客の困りごとの形で入り口を分けている**ことです。
数量が中途半端（中ロット）、予算が決まっている、納期が間に合わない、LED・SMD実装。
実装を外注する側の悩みが、そのまま4つのプラン名になっています。

さらに「ご予算提示プラン」の説明文が率直です。

> 「予算を提示する!?」、ユーザー様の中には、違和感を感じられた方も多くいらしたことと思います。
> （中略）安かろう悪かろうでは、どうにもなりません。

この姿勢は書き換えず、そのまま活かしました。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- 中ロット限定プランの単価3行は、原サイトの画像を拡大して書き起こしました。
  **通貨単位が画像に明記されていないため「@0.8」のまま表記し、「※ 単価は目安です」
  と注記しています。**（円と推定されますが断定しませんでした）
- 工程・設備8項目の説明文は、原サイトの `equipment` ページの記載どおりです。
  設備の**メーカー名・型式は原サイトに記載がなく**、掲載していません
- 原サイトの誤字「大幅な率化」（効率化と思われる）は「効率化」としました。
  「各主調整」は「各種調整」としています
- **早稲田大学 素粒子物理学実験 寄田研究室**への納入実績が原サイトのバナーに
  ありますが、**本提案では研究機関名を掲載していません。**大学名の掲載可否は
  相手方の許諾が必要なためです。「大学研究室からのご依頼」という一般的な記述に
  留めました。**要確認事項に挙げています**
- ISO 認証マークが原サイトのヘッダーに表示されていますが、**取得規格・認証機関・
  登録番号の記載がどこにもない**ため、認証について記載していません
- 設立年月日・資本金の記載は原サイトになく、掲載していません

## 画像の扱い
原サイトの画像はほぼすべてが文字を焼き込んだバナー・見出し・ナビゲーションボタンで、
写真として使えるものは実装ラインの帯画像（680×229px）1点のみでした。これを冒頭の
全幅バンドとして使用しています。工程・設備セクションは**写真なし・活字のみ**の構成です。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。Flash は使用していません
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 所在地に Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- 横スクロール 0px（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）

- 内部リンクはすべて相対パス
