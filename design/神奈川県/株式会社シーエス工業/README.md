# 株式会社シーエス工業 — トップページ リニューアル案

現行サイト（http://www.cs-kogyo.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **スマホで横に604pxはみ出す** | 実機UA（375px）で `scrollWidth` **979px**。viewportタグはあるので、**これは実際の横スクロール**。右側の6割強が画面外 |
| **ズーム禁止** | `user-scalable=no, maximum-scale=1`。はみ出した部分を指で拡大して読むこともできない |
| HTTPS非対応 | `http://` のみ。Chromeで「保護されていない通信」と表示される |
| `<h1>` が無い | **0個** |
| Copyright表記 | **2017年**のまま（サイトのリニューアル告知は2021年） |
| jQuery | 3.1.1（2016年リリース） |

**この会社のはみ出しは、前2社とは性質が違います。**
昭和工業・東洋電源機器はviewportタグが無く縮小表示されていましたが（読みにくいが全体は見える）、
シーエス工業はviewportタグがあるため**本当に604px分が画面の外にあります**。
しかも `user-scalable=no` でズームも禁止されているため、
**スマートフォンでは右側の内容に到達する手段がありません。**

## 設計上の判断

### 署名的装置 ── 曜日の帯

この会社の価値は「他社が止まっている土日に動いていること」です。
ファーストビュー右側に、**1週間の時間軸**を線画で置きました。
金曜に矢印が入り、土日の区間が太く塗られ、月曜に矢印が出ていきます。
文章を読む前に、何が違う会社なのかが伝わります。

インラインSVG。`stroke="currentColor"` なので配色に追随します。

### 配色 ── 橙

神奈川県内の既存提案（青系・深緑）と分けるため、無彩の淡灰の地に橙のアクセントとしました。
稼働と速さの色です。

### 見出し

「金曜に届いた基板が、月曜には出ていく。」を h1 にしました。
現行サイトのキャッチは「当社自慢の顧客支援サービス」で、何の会社か分かりません。

## 未確定・要確認

提案時に先方へ確認が必要な項目です。**推測で埋めていません。**

  現行サイトには「土日祝日通常営業」としか記載がありません

  登録番号・認証範囲が記載されていません
- 「30期 経営方針発表会」（2020年2月）から逆算していません。現在の期数をご確認ください
- 2019年6月に新社屋が竣工しています。新社屋の写真があれば大きく使えます
