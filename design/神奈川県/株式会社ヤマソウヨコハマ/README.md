# 株式会社ヤマソウヨコハマ — トップページ リニューアル案

現行サイト（http://www.yamaso-yokohama.co.jp/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| **表が画面に入らない** | 会社案内の表は **858px**。iPhone 13（390px）に対し **483px が画面外**（表の56%） |
| **HTTPS未対応** | `https://www.yamaso-yokohama.co.jp/` は接続できません |
| **画像のalt** | 28点すべてに alt がありません |
| viewport | ✅ `width=device-width, initial-scale=1.0`（正しい） |
| h1 / lang / description | ✅ すべてあり |

表は横スクロールできる器に入っているため、指で送れば読めます。
ただし**会社概要・許可資格・加入団体という最も見られる情報の半分以上が、
最初は画面の外**にあります。

## 一番の資産は、TVカメラの画像です

現行サイトには、**同じ管の施工前と施工後**のTVカメラ画像があります。

| | |
|---|---|
| 施工前 | 管の断面いっぱいに木の根が広がり、奥が見えない |
| 施工後 | 根が除去され、管の内壁と奥の接合部まで見通せる |

画面には `MH.1〜上流 陶管 φ250 L=19.80 下〜上` と表示されており、
**どの管をどう直したかが特定できます**。

下水道管の中は地上からは見えません。だからこそ、この2枚には
「見えないところで何が起きているか」を一瞬で伝える力があります。

本提案では、この2枚を並べて冒頭に据えました。

## この提案で変えたこと

### 1. 「道路を掘らずに、下水道管を直す」を見出しにする

更生工事は、道路を開削せず、今ある管の内側から特殊な化学樹脂を
熱硬化・光硬化させて補修する工法です。
発注する自治体や施設管理者にとって、これは**通行止めの有無**という
具体的な違いになります。

### 2. 御社の写真をそのまま使いました

現行サイトの写真9点を使用しています。**図やイラストは使っていません。**

- **冒頭・調査**：TVカメラ画像（施工前・施工後）
- **事業内容**：マンホール清掃、カメラ投入、調査機材、更生工事、側溝清掃、中央分離帯清掃
- **CSR**：石積み護岸の水路

※ 実際に公開される際は、写真の使用可否をご確認ください。
※ 一部の写真に入っている緑色のぼかし（現場表示板）は、
　 現行サイト側の処理をそのまま使用しています。

### 3. 採用情報を本文テキストにする

給与217,650円〜316,450円、皆勤手当月10,000円、
新卒への準中型・中型免許の取得費用全額負担。
ここまで具体的に書かれている求人は多くありません。
検索で見つかる形にしました。

## 事実の扱いについて

本文の数値・固有名詞53項目は、現行サイトの記述と照合済みです。

管の仕様（陶管 φ250、L=19.80m）は本文ではなく**TVカメラ画像の画面表示**から

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,536文字）
- 表は横スクロールする器に入れ、ページ本体は動かないようにしています
- 写真9点はすべて `width`/`height` 指定つき、**altも記述済み**（合計約656KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の青は、**現行サイトで実際に使われている色**
`rgb(50,115,193)` = `oklch(55.3% 0.138 254.8)` から色相を採りました。
白地でAAに届く明度42%に調整しています。
地はごくわずかに水色寄りの白にしました。水を扱う会社だからです。
