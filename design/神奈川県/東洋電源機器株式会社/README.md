## なぜ作り替えるのか（現行サイトの実測値）

| シグナル | 実測 |
|---|---|
| viewportタグ無し | スマホ実機UA（375px）で `scrollWidth` **980px**。等倍では収まらず縮小表示 |
| `<h1>` が無い | **0個**。見出しの階層が機械に伝わらない |
| テーブルレイアウト | トップページで `<table>` **18個**。CSS以前の組み方 |
| Copyright表記 | **2010年**のまま |

**「はみ出し 0px」は健全という意味ではありません。**viewportタグが無いため、
ブラウザが980px幅を375pxに縮小しているだけです（shrink-to-fit）。
指で拡大しないと本文が読めません。

## 設計上の判断

### 署名的装置 ── 波形

この会社の仕事は「電力の形を変える」ことです。
ファーストビュー右側に、**直流（直線）→交流（正弦波）** と
**50Hz→60Hz（周期の違う正弦波）** の2段を線画で置きました。
何をする会社かが、文章を読む前に伝わります。

インラインSVG。`stroke="currentColor"` なので配色に追随します。

### 配色 ── 深緑

神奈川県内の既存提案（青・藍が多い）と地の温度で分けるため、
緑みの地（oklch 150°）に深緑のアクセントとしました。

### 構成 ── 変換の向きを明示

製品節では各製品に「直流 → 交流」「50Hz ⇔ 60Hz」の入出力バッジを付けました。
電源機器は種類が多く、何を何に変える装置なのかが分かりにくいためです。
