# やまと工業株式会社 — トップページ リニューアル案

現行サイト（http://www.yamato-industry.co.jp）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで神奈川県内 **100点（Aランク）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| HTTPS非対応 | Chromeで「保護されていない通信」と表示される |
| viewportタグ無し | スマホで表示が崩れる |
| テーブルレイアウト | CSS以前の組み方 |
| 文字コード | Shift_JIS |
| Copyright | 2009年 |
| **トップページに連絡先が無い** | 住所も電話も `map.html` にしか無い |
| Flash動画 | 「Javascriptを有効にして下さい」の注記つき映像 |
| QuickTime | 動画3本が QuickTime Player 必須 |

## 設計上の判断

### 署名的装置 ── 線径カバレッジ

バネ屋への相談で最初に決まるのは**線径**です。

現行サイトの設備リストは9台が縦に並び、各行に
「φ2.8〜6.3」のような範囲が書かれています。しかし
**「φ3.0を巻けるか」を知るには9行を目で追う必要がありました**。

本案は8台の対応範囲を**1本の対数目盛に重ねました**。
φ0.3 から φ12.0 まで**切れ目なく覆えている**ことが一目で分かります。
これは「うちならどんな線径でも受けられる」という、この会社の
最も強い主張を図にしたものです。目盛の位置は実際の線径から計算しています。

### 埋もれていた海外拠点を出した

現行サイトの `map.html` には、国内2工場に加えて
**タイの合弁会社と中国の独資会社**が載っています。
これは中小のバネメーカーとしては大きな資産ですが、
トップページからは見えませんでした。

本案では拠点の節を設け、**5拠点すべてに地図**を付けています
（実測 513×320px ×5）。

### 青が7社目であることへの対処

採取色は 249°。本バッチで7つ目の青です。分離軸を明示します。

| 軸 | 潮工業 | 新井製作所 | 大和プレス | やまと工業 |
|---|---|---|---|---|
| 地の色相 | 青み(253) | 緑み(150) | 紫み(300) | **暖かい灰(40)** |
| 第二色 | なし | なし | 赤（矢印のみ） | **赤（線径の強調）** |
| 書体 | しっぽり明朝 | M PLUS 2 | Noto+Archivo | **Zen Maru（丸ゴシック）** |
| 角丸 | 8px | 4px | 3px | **6px** |
| 署名的装置 | 寸法票 | 出力順の表 | トン数のはしご | **線径カバレッジ** |

丸ゴシックを選んだのは、**バネという製品の性格**（線を曲げる、丸める）
に合うためです。他の青系6社はすべて角ゴシックか明朝です。

### 色 — 現行CSSから採取（ロゴは採らなかった）

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#0d3f69` | 現行 `style.css` 最頻出 | `oklch(35.9% .089 249)` | **採用** |
| `#0000ff` | ロゴ画像の画素 | `oklch(45.2% .313 264)` | 不採用 |
| `#e60012` | 現行 CSS | `oklch(58.1% .238 27.9)` | 第二色に採用 |

**ロゴは純青（#0000ff）でしたが採りませんでした**。彩度 .313 は
sRGB の端にあり、白地では目に振動します。またロゴが小さく（135×53px）、
サイト全体では紺 `#0d3f69` が実際の基調色として機能していました。

`--wire: oklch(41% .105 249)` — **色相差 0°**。
彩度はわずかに上げています（.089 では白地でほぼ灰色に見えるため）。

## データの出所

設備・線径・拠点・資格はすべて**現行サイトから取得した実データ**です。

- 設備リスト（機種・メーカー・線径） … `list.html` より
- 製品の種類と線径 … `profile.html` より
- 有資格及び受講者一覧 … `topil.html` より
- 拠点（国内3・海外2） … `map.html` より
- エコアクション21 認証 … `eko.html` より

**線径カバレッジの図は当方で作成**しました（現行サイトに図はありません）。

### 確認が必要な項目

- **設立年・資本金・従業員数・代表者名の記載が現行サイトにありません**
- 有資格者一覧のうち「バネ技能検定1級」「KYT講習」「玉掛け」は
  **0名と記載**されていました。本案では0名の項目は掲載していません
- 求人ページには給与例（180,000〜270,000円）や休暇実績（113日）の
  記載がありますが、本案は採用の節を設けていません
- 株式会社朋有は現行サイトで「国内」の枠に並んでいますが、
  **子会社か協力会社かが判別できません**。拠点として並記しています
- CFX-8 の線径は現行サイトで「φ2.3〜φ5.0(8.0)」と括弧付きでした。
  図では 5.0 までで描き、注記で (8.0) を残しています
- 営業時間（求人ページに 8:00〜17:00 の記載はあるが
  会社の営業時間としては明示が無いため JSON-LD に入れていません）
