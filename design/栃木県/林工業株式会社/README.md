## アートディレクション

> 「手の平サイズの金属加工」を、100円硬貨と並べた1枚で証明する。写真は拡大せず、数字に空間を与える。

### 画像方針

この会社が持っている写真は実質4点で、うち3点が**硬貨と並べた加工品**、1点が振盪機です。
海外の精密系サイトを実測した結果から方針を決めました。

| 参照 | 実測した事実 | 本案での適用 |
|---|---|---|
| NOMOS Glashütte | 全製品写真を `#F7F7F7` のプレートに載せ、品質差を吸収 | `--pg2: #f7f7f7` のプレートに全写真を載せた |
| Adafruit / Arm | 310×233 の画像を 0.99倍で描画。小さい画像を拡大しない | 硬貨写真は実寸 **270px 上限**。box を画像に合わせた |
| Teenage Engineering | 白いページの中に黒い面を1つだけ置く | 暗い振盪機写真を `--isl: #0e1013` の「黒い島」に隔離 |
| Vitsœ | トップに10点だけ、全て同一比率 | 比率を `270/203` に固定 |

**ダークテーマにはしていません。** 暗い写真は面を分けて解決しています。

### 写真の説明文について

キャプションと `alt` は、**写真を実際に見て書いています**。当初は撮影内容を推測して
「曲げ加工」「絞り加工」等と書いていましたが、確認したところ硬貨も 500円ではなく
**100円硬貨（直径22.6mm）** でした。現在の記述はすべて画像から確認できる内容のみです。

## 構造装置（前7社と重複させないための選択）

1. **コイン写真を核にした開幕** — 写真を小さく置き、周囲を数字が占める
2. **二事業を 50/50 の「二つの扉」に** — 金型／理化学機器を混ぜない（ZEISS の前例）
3. **理化学機器は McMaster 方式の均一行リスト** — 62px 固定行 + 「他N種」の件数表示
4. **由来の帯** — 二事業が交差する唯一の場所（1950年のミシン部品から現在まで）

## モーション

| 挙動 | 種別 | 実装 |
|---|---|---|
| セクションの出現 | Entrance | `animation-timeline: view()` + `.js` ゲート |
| 数値の下線が伸びる | State | `transition` |
| メニュー開閉 | State | Vue（開閉のみ） |

`prefers-reduced-motion: reduce` で transform とループを停止。内容は全て可視のまま。
**JS 無効でも本文3,635文字がすべて表示されます**（実測）。
