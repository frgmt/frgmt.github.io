# 株式会社すずらん本舗 — リニューアル提案サイト

栃木県宇都宮市の和菓子店。既存サイトの公開情報のみを使って再構成した、
1ページ構成の提案です。

## この案件の特徴

これまで扱ってきた製造業と違い、**来店してもらうことが目的**の商売です。
そのため設計の重心が変わります。

- 型式や加工範囲ではなく、**店舗情報（住所・電話・営業時間・定休日・駐車場）** が主役
- 4店舗それぞれ品揃えも定休日も違うため、**店ごとにカードを分けて併記**
- 商品は「季節でお出しするものが変わります」と明記したうえで一覧に

## デザイン方針

### 色
主色は `oklch(40% .135 18)` の深い紅。本店の目印が「赤い看板」であること、
和菓子屋として小豆・苺・梅といった赤系の商材が中心であることから採りました。
地は白（`oklch(100% 0 75)`）、パネルは `oklch(96.5% .012 25)` のごく淡い暖色です。

初期版では連絡先カードを濃い臙脂の地に白抜き文字にしていましたが、
周囲のセクションを白基調に変更した際にコントラストが崩れたため、
**白地＋紅の枠線＋紅の電話番号**に改めています。

### 構成の軸 — 4店舗
和菓子店を探す人が最初に知りたいのは「どこにあるか」「今日開いているか」です。
そこで店舗セクションに**住所・電話・営業時間・定休日・駐車場台数**を必ず併記し、
各店に Google マップを埋め込みました（計8枚。店舗一覧とFAQの両方に配置）。

定休日の書き分けには特に注意しています。本店・双葉店は「なし（元日のみ店休）」、
南那須店は「水曜（元日も店休）」、東武大田原店は「百貨店カレンダーによる」。
この違いは実際に足を運ぶ人にとって重要な情報です。

## 事実確認について

掲載した数値・固有名詞はすべて既存サイトの記載に基づきます。**推測で補った情報はありません。**

- 商品名は季節商品を含めて原文どおり。「季節でお出しするものが変わります。
  詳しくは各店へお問い合わせください。」を商品セクションの冒頭に明記しています
- 通販の支払方法・配送業者・返品条件は原文のまま掲載しています
- グループ会社2社（株式会社アミノ、有限会社こめの里本舗）も記載しました。
  南那須店が「グループ会社 株式会社アミノ敷地内」にあるためです

## 写真の扱い
商品写真5点（あさつき塩まめ大福、あんみつ、水ようかん、水まんじゅう、
宮れもんまんじゅう）を WebP と JPEG の両方で用意し、`<picture>` で出し分けています。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし
- JavaScript はモバイルナビの開閉のみ
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization / LocalBusiness / WebSite / FAQPage
- MEO 対応: 4店舗すべてに Google マップ埋め込み（API キー不要の `?output=embed` 形式）

## 検証結果
`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過：

- JS エラーなし
- 横スクロール 0px（320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920px）
- コントラスト比 WCAG AA 準拠（ホバー時も含めて検証済み）
- タップ対象 44px 以上
- JavaScript 無効時も全テキストが読める
- 内部リンクはすべて相対パス
