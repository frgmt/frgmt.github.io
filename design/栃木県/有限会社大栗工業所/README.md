## 設計上の課題 — 二つの性格

この会社は**下請けの重工業**と**設計された自社製品**を併せ持ちます。

1. **受注製作（B2B・重量物）** — 製缶・板金・溶接。産業機械と環境プラントの大型鋼構造物
2. **自社製品（意匠）** — ジャケットテーブル。商標登録・実用新案登録、経済産業省奨励賞

前回JOSの「二事業」とは質が異なります。片方は図面ベースの受注生産、
もう片方は寸法と材質を見せる商品です。

### 採った解 — 区画を分け、記法を共有する

海外10社超を調べた結論は「**混ぜず、別の区画に分ける。ただし諸元の書き方は共通にする**」でした。

- Zieta は製法（FiDU）と製品カタログを別セクションにしつつ、寸法体系は1つ
- Vitsœ は 606 システムのページと components/prices を分けている
- Emeco と Apparatus は工場の話を製品の傍らの本文に置き、競合するセクションにしていない

**求める相手が違う**からです。板厚で絞り込む調達担当と、イペ材とSUS304の寸法を知りたい設計者は、
同じページを見ません。一方で、**200tプレスと1500×800×720の天板が同じ書式で並ぶ**ことが、
「この製品はあの工場から出てきた」ことの証明になります。

## 実装方針

**HTMLが主、Vueは従。**

Vueが担当するのは**モバイルメニューの開閉のみ**（約20行）。
設備一覧・FAQ的な開閉はすべて**ネイティブ `<details>`**、進捗バーと出現は**CSSのみ**です。

**受け入れ基準**: JavaScriptを切ってもページの全文が読め、全リンクが動く。
