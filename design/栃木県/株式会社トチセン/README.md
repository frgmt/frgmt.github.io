## この提案で変えたこと

### 1. 「日本で唯一」を見出しにする

```
水で染める。だから染まらない素材が染まる。
```

水溶媒による染色は低温で加工できるため、
溶剤染色では不可能なポリカーボネート・アクリル・ナイロン・TACにも着色できます。
これは他社にできないことであり、探している人が確実にいます。

### 2. 御社の写真をそのまま使いました

現行サイトの実写7点を使用しています。**図やイラストは使っていません。**

- **冒頭**：色とりどりに染色されたフィルムのロール
- **染色フィルム**：扇状に広げた透過色板（透明性を保った着色が一目で分かります）
- **鹸化処理**：加工ラインのフィルムロール
- **防曇フィルム**：フェイスガードの装着例
- **C-Mal**：施工車両
- **企業情報**：本社の赤煉瓦工場と富山工場

UVカット加工の画像は青空の素材写真だったため、使用していません。
※ 実際に公開される際は、これらの写真の使用可否をご確認ください。

### 3. 光学特性表84マスをHTMLの表にする

3表すべてを転記しました。検索エンジンが読める形式になり、
スマホでは表だけが横にスクロールします。

### 4. 沿革53項目をそのまま載せる

1914年の「足利織物株式会社」設立から2026年1月の役員交代まで、
現行サイトの沿革を1項目も落とさず掲載しています。

この会社の沿革は、単なる社史ではありません。

- 1955年：**火災で生産設備の3分の1を消失**（損害約7,000万円）
- 1961年：自主研究で硬質フィルムの加工方法を開発、染色機一号機を完成
- 1964年：東京オリンピック協賛、**日の丸100万枚**を加工
- 1978年：オイルショック後、繊維からフィルム加工へ**事業転換を決断**
- 1999年：本社レンガ工場2棟が**国登録有形文化財**に
- 2024年：**世界初のプラスチックフィルム太陽光発電の開発**で特別賞

織物の街の会社が、火災と石油危機を越えてフィルムメーカーになった記録です。
そのまま読ませる価値があります。

## 事実の扱いについて

本文の数値・固有名詞125項目（光学特性84マスを含む）は、
すべて現行サイトの記述と照合済みです。
沿革は出典の53項目に対し**53項目**を掲載しています（過不足なし）。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（5,746文字）
- **ピンチズームは禁止していません**
- 写真7点はすべて `width`/`height` 指定つき。2枚目以降は `loading="lazy"`。
  元画像より大きく引き伸ばさないよう上限を設定（合計約430KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の赤は、**現行サイトで実際に使われている色**
`rgb(53,2,1)` = `oklch(21.0% 0.081 29.4)` から色相を採りました。
そのままでは暗すぎるため、白地で使える明度40%・彩度0.130へ引き上げています。

本社の赤煉瓦工場と地続きの色でもあります。
