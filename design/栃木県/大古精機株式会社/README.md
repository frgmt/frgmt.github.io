## ご要望への回答 — 画像について

**今回は実用に足る写真素材（700×300、10点）がありました。** 4点を採用しています。

熱処理炉の赤熱、切削油の流れるねじ研削盤、輪郭形状測定機、工場の空撮。
いずれも**この会社が実際に撮った写真**で、借り物の素材ではありません。

### 制約と、その扱い

**すべての画像に文字が焼き込まれており、消せません**（「製品づくりへの情熱」など）。
したがって**画像の上に文字を重ねる構成は取れません**。

調査でこの制約への答えが見つかりました。Vitsœ と MoMA を実測したところ、
**23個の figure すべてがキャプションを画像の「下」に置いていました**（重ねはゼロ）。

本案も同じ形にしています。`<figure>` + `<figcaption>`、本文と同じインク色。
**制約に合わせた妥協ではなく、確立された編集手法です。**

焼き込まれたラベル（「熱処理」「ねじ研削盤」）は、毎回同じ位置に置くことで
**技術記録の図版番号のように読めます**。

### 解像度への対処

700×300 を全幅1680pxに伸ばすと**2.4倍**になり甘くなります。
そこで**帯幅を1000pxに抑えました（1.43倍）**。実測で確認済みです。

余白を広く取ることで、拡大に頼らず構図を持たせています。

## アートディレクション

> ミクロの目を通して、オリジン（源）から。（社長の言葉）

### 前回と違う3点（スキルの要求）

**1. 構造装置 — 巨大な「1 μm」を図版として組む**

調査で決定的な発見がありました。同業3社（Mahr・Starrett・Vermont Gage）のトップページを
実測したところ、**仕様表が1つも無く、大きな精度の数字も1つも無い**。
Starrett の最大の数字は24pxで、しかも製品名でした。

**つまり「1ミクロン」を大きく組むだけで、この業種では際立ちます。**
90年の歴史と0.5秒のオートコリメータを持つ会社には、その資格があります。

**2. セクション類型 — 前4社で未使用**

| セクション | 器 |
|---|---|
| つくるもの | **能力の幅を横軸として描く**（表ではなく図） |
| 画像帯 | **本文の合間に4回、リズムとして挿入** |
| 測定の条件 | 恒温恒湿室と測定器を「測定の条件」として1つの塊に |

**3. モーション — 業界の実測に合わせる**

調査で候補6件を実測したところ、**スクロール連動のパララックス／ズームは1件も見つかりませんでした**
（Apple も Klim も transform は固定のまま）。業界は state-based の reveal に移行済みです。

それに合わせ、動きは控えめにしました。ただし**能力の軸だけはスクロールで伸びます**——
1箇所だけの見せ場です。

### 海外リファレンス

| # | リファレンス | 国 | 借用した機構 |
|---|---|---|---|
| 1 | **Vitsœ** | 英 | **11/11 の figure がキャプションを画像の下に**。14px、本文と同じ黒 |
| 2 | **MoMA** | 米 | 比率は自由、**高さを固定**して揃える。12/12 がキャプション下 |
| 3 | TRUMPF | 独 | 3.00:1 の帯。1680pxの箱に1697pxの画像（1.01倍）で端の隙間を防ぐ |
| 4 | Dezeen | 英 | `aspect-ratio` + `cover` を **img 自身に**かけて比率を統一 ※本案では不採用 |
| 5 | Caterpillar | 米 | `margin-left: -840px` による全幅の抜き方 |
| 6 | Patagonia | 米 | 画像の blur-up（1500ms/1000ms、DocumentTimeline＝**state-based**） |
| 7 | Basic Agency | 米 | マスク reveal。`translateY(103%)` の**3%オーバーシュート**で端の隙間を防ぐ |
| 8 | **Mahr** | 独 | 同業。**異なる比率の設備写真を258×194に正規化**して1つのグリッドに |
| 9 | **Starrett** | 米 | 同業。高さ465px固定、比率自由。仕様表ゼロ |
| 10 | **Vermont Gage** | 米 | 同業（まさにゲージメーカー）。仕様表ゼロ、精度の数字ゼロ |

**#4 Dezeen の手法は意図的に採用しませんでした。** `cover` は画像を切ります。
本案の画像は文字が焼き込まれているため、切ると日本語ラベルが欠けます。
代わりに #2 MoMA の「切らない」方式を採りました。
