# 株式会社雀宮産業 — サイトリニューアル提案

栃木県宇都宮市のウォータージェット形状切断・機械加工メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（https://suzumenomiya.jp/）からの実データです。
既存サイトは **Shift_JIS**。5つの事業内容・設備一覧・沿革・3拠点の住所電話・
認証内容は原文のまま採用しました。

**重要 — 使わなかった素材があります。**
既存サイトには航空機写真が40点掲載されていますが、
「全ての写真の版権は真野プロカメラマンに帰属し複製や転載は法律により堅く禁じます」
と明記されているため、**1点も使用していません**。第三者の著作物なので当然です。
本番化の際も、この写真群を流用することはできません。

## デザイン

**アートディレクション**: 加圧された水。落ち着いたスレート地に、
ジェットシアン1色だけが切り込む構成です。

**シグネチャ**: ファイブレーン・ボード。この会社の特徴は
「切る・削る・接合する・設計する」を1社で通せる幅の広さなので、
5事業を並列のレーンとして置き、主力のウォータージェットだけ
枠を2pxにして色地に反転させています。

**5件目としての差別化（ヘッダーは全件別パターン）**:

| | ヘッダー | シグネチャ | 配色 |
|---|---|---|---|
| 佐藤精機 | ブランド上ユーティリティ行 | 測定レール | 暖グレー＋青 |
| テツカ | カタカナ2段署名 | 数値フィギュア | 紺＋赤 |
| 栃澤金型 | 対応範囲ストリップ | スケールスパン | チタン＋ティール |
| 栃木ALC | 社名＋所在地2段 | トン数ラダー | 青灰＋青 |
| 雀宮産業（本件） | **中央寄せ** | **5レーンボード** | **スレート＋シアン** |

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#aa0000` |
| 本サイトの色相 | OKLCH 29° |
| 色相差 | **0.2°** |

既存サイトのレッド。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 検証結果（実測）

```
✅ JSエラーなし
✅ 横溢れ 0px — 320〜1920 の10幅
✅ コントラスト 全AA達成
✅ タップ対象 すべて44px以上
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（2,905文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在
✅ 非表示要素 0件・画像8点すべてロード成功
✅ clamp() の演算子スペース欠落 0件（前回の不具合を受けて追加した確認）
```

今回は一発で全項目通過しました。前回の栃木ALCで見つけた
`clamp(...1.4rem+3.2vw...)` の不具合を踏まえ、書く段階で
スペースを入れる運用に変えたためです。

## 素材の制約

使える自社写真は工程写真5点（160×120px）と工場外観3点（250×167px）のみ。
本番化には撮影が必須です。特に「国内最大級のウォータージェット機」は
この会社の最大の武器なので、その大きさが伝わる写真が1枚あるだけで
サイトの説得力が変わります。

## 営業上の注意

**このサイトは内容が非常に充実しています。**特許庁の成長支援先、
経産省の工場視察、自社医療機器の開発と、話題に事欠きません。
スコア93は「情報がない」ではなく「情報が届いていない」状態です。

1. **Shift_JIS** — 文字コードが古い
2. **`.html` 直書きの静的サイト**でページが分散し、内容が探しにくい
3. **スマホ最適化なし** — 実測で横スクロールが発生
4. 医療機器やフロントガードなど新事業の情報が、
   古い枠組みの中に埋もれてしまっています
