### 白地で平坦にならないための3つの仕掛け

10件に共通していたのは、装飾を足すのではなく**構造で密度を作る**という方針でした。

1. **アクセントは1色のみ** — 操作要素と計器の読み値にだけ使う。それ以外は無彩色
2. **反転（ダーク）ブロックを2箇所だけ置く** — ヒーロー直下の実績帯と、お問い合わせ。
   白地の中で視線の重心になり、単調さを断ち切る
3. **面の分離は影ではなく1pxのヘアライン** — 角丸も最小（2px）。柔らかさを出さない

### v1 からの主な変更

- 地を near-black → **オフホワイト** `oklch(98.4% …)`。大面積の純白は安く見えるため僅かに温かみを持たせ、カード面のみ純白にして面を分離
- アクセントを**深いアンバー** `oklch(52% 0.13 62)` に。v1 の明るいアンバーは白地では約2:1でAA未達のため、そのままでは使えませんでした
- **方眼紙グリッド** — 18px細目＋72px太目の二重グリッドで製図用紙を想起させる
- **認定カードを大幅強化**（Protec由来）— 発行機関を小さく、認定名を主役級のサイズに、登録番号は枠で囲って「書類の証拠」として提示。左端にアクセント罫
- セクション見出しを一段大きくし、番号の下に索引罫を追加

### 和文の行長（重要な修正）

当初 `ch` 単位で行長を指定していましたが、**`ch` は欧文の「0」の字幅が基準**のため、
和文（約2倍の字幅）では意図の半分程度の幅にしかならず、
ヒーロー本文が 1240px の親要素の中で **485px しか使わず5行に折り返す**状態でした。

`em` 基準に変更し、和文で読みやすい 1行 38〜45字に調整しています。

| 箇所 | 変更前 | 変更後 | 結果 |
|---|---|---|---|
| ヒーロー本文 | `46ch`（485px） | `58em`（**1102px**） | 5行 → **2行** |
| セクションのリード文 | `62ch`（551px） | `46em`（736px） | 2行 → **1行** |

ヒーロー本文は見出しの実幅（1089px）と右端が揃うよう `58em ≈ 1102px` にしています。
一般に和文の可読行長は45字程度までとされますが、ここは3文だけの導入文で、
**見出しと一体の塊として見せる**ことを優先しました。
本文が続く箇所（FAQ・会社概要）は従来どおり `--measure`（42em）に抑えています。

あわせて `word-break: auto-phrase` と `line-break: strict` を指定し、
「防犯カ / メラ」のような**単語途中での分断を解消**しました
（文節単位で折り返す。非対応ブラウザでは従来動作に落ちるだけで無害）。

## 実装方針

**HTMLが主、Vueは従。** スキル `global-web-design` の方針に従っています。

Vueが担当するのは3つだけ。

| 箇所 | 内容 |
|---|---|
| モバイルナビ | クラス1つの開閉。リンクはHTMLに実在 |
| 施工実績の絞り込み | カードはHTMLに実在し、`v-show` で隠すだけ |
| スクロール表示 | IntersectionObserver。`prefers-reduced-motion` 対応 |

FAQは**ネイティブ `<details>`**で、JSを一切使っていません。

**受け入れ基準**: JavaScriptを切ってもページの全文が読め、全リンクが動く。
→ 実測で施工実績6件すべて表示、本文2,808文字すべて到達可能。

### 検証中に見つけて直したもの

**v1（ダーク版）で発見**
- `--color-fg-faint` が **4.15:1** で AA 未達だった → 明度を上げて解消
- ロゴとフッター電話番号のタップ高さが44px未満 → `min-block-size` を付与

**v2（ライト版）で発見**
- v1 のアクセント `oklch(78% 0.16 78)` は白地では **約2:1** で全く使えなかった →
  `oklch(52% 0.13 62)` に置換。**明度の制約がダーク版とは逆向きになる**ため、
  `--color-fg-faint` も「62%以上」から「48%以下」へ条件が反転している（CSSにコメント記載）
