# 株式会社コーラス — サイトリニューアル提案

栃木県那須烏山市のイベント会社。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（https://www.ko-rasu.com/）からの実データです。
会社概要・事業内容7項目・企業理念・電話番号は原文のまま。

**この会社の一番の資産は「文章」です。**
映像ページの「大体の流れが出来ていて、あとはそれに写真と音を当てはめて完成。
というような仕事がコーラスにはできません」、デザインページの
「お客様が求めるデザインはひとつではありません。ならば、それにお応えする
デザインもひとつでは無理」——この語り口は、他社が真似できません。
書き換えず、引用として大きく置いています。

## 配色について（元サイトからの継承）

既存サイトのCSSには**グレーしかありませんでした**（`#666`・`#999`・`#fff`）。
ブランド色はナビゲーション画像の中に焼き込まれていたため、
**画像のピクセルを直接デコードして抽出**しました。

| 項目 | 値 |
|---|---|
| 抽出元 | `images/index/event_bo02.jpg` のラテン文字部分 |
| 元サイトの色 | `#0c6cb4`（出現382px、最頻の彩度色） |
| OKLCH | (52%, 0.138, **249°**) |
| 本サイトの色相 | **249°** |
| 色相差 | **0.0°** |

紙のテクスチャ（トップ画像のくしゃくしゃの紙）と手描きロゴという
既存の世界観もそのまま引き継ぎ、地色を温かみのあるペーパーにしています。

## デザイン

**アートディレクション**: 既存サイトは「くしゃくしゃの紙に写真を貼った」世界観。
これを捨てずに、そのまま設計の軸にしました。

**シグネチャ**: テープドボード。4つの事業を、実際に貼り出すように
少しずつ角度をつけたノートとして並べています。スクロールで水平に落ち着きます。

**7件目としての差別化**:

| | ヘッダー | 地色 | シグネチャ |
|---|---|---|---|
| 佐藤精機 | ユーティリティ行 | 暖グレー | 測定レール |
| テツカ | カタカナ2段 | スレート | 数値フィギュア |
| 栃澤金型 | 対応範囲ストリップ | チタン | スケールスパン |
| 栃木ALC | 社名＋所在地 | 青灰 | トン数ラダー |
| 雀宮産業 | 中央寄せ | スレート | 5レーンボード |
| デュプラス | インラインタグライン | 温紙 | プロダクト調書 |
| コーラス（本件） | **社名＋理念インライン** | **紙（ペーパー）** | **テープドボード** |

製造業6件と違い、**唯一のBtoC寄り・クリエイティブ業種**なので、
数値テーブルではなく言葉と写真で構成しています。

## 素材について

使用したのは既存サイトのトップコラージュ画像1点のみです。

**注意**: このコラージュには実在の人物が多数写っています。
既存サイトが自ら公開している合成画像をそのまま使っているため、
新たに個人を切り出すことはしていません。本番化の際は、
被写体の方々の掲載可否をあらためて確認してください。

1. **テキストが画像に焼き込まれている** — 見出しもナビも本文の一部も画像。
   検索エンジンが読めるテキストがほとんどありません。この会社は
   文章力が最大の武器なのに、その文章が検索に一切引っかかっていません
2. **Copyright 2012** のまま
3. **レスポンシブ非対応** — スマホでの閲覧が主流のイベント業では致命的です
4. 事業が5つ（イベント／映像／デザイン／雑貨／セミナー）に分かれているのに、
   トップページからは何の会社か分かりにくい構成になっています
