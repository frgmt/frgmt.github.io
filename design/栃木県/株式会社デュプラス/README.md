# 株式会社デュプラス — サイトリニューアル提案

栃木県宇都宮市の商品開発企画会社。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（http://www.duplas.co.jp/）からの実データです。UTF-8のCMSサイト。
組織概要・事業内容・商品一覧・開発企画の全文を反映しました。

**「ごあいさつ」と社是は原文のまま引用しています。**
「どこの企業人よりも／どこの会社よりも／当社が一番／足を運び／知恵を絞り／
そして創り出す」——この文章は既存サイトのトップに置かれていますが、
装飾のない小さな文字で流されていました。書き換えるより、
きちんと見せることのほうが価値が高いと判断し、ヒーロー右側に置いています。

### 1件、数値の要確認事項があります

膝掛けのサイズが既存サイトでは **「120mmX90mm 一般、大」** と表記されています。
12cm×9cm はひざ掛けとして明らかに桁が合わないため、cm→mm の誤記と判断し、
**10倍（1200mm×900mm）で記載したうえで、その旨をページ上に注記しました。**
勝手に直して黙っているのは危険なので、注記を残しています。
先方に確認のうえ、注記を消すか数値を直してください。

## デザイン

**アートディレクション**: 加工屋ではなく「企画会社」なので、
これまでの5件と登録（レジスター）を変えています。丸ゴシック、
大きめの角丸、ピル型ボタン、温かみのある紙色。硬さより発想を出す方向です。

**シグネチャ**: プロダクト・ドシエ（製品調書）。
この会社は素材配合・寸法・試験結果まで持っているので、
商品ごとに「写真＋仕様リスト＋出所タグ」の形式で並べました。
「自治医科大学との共同出願中」「特許取得」は、この会社の一番の資産です。

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#993366` |
| 本サイトの色相 | OKLCH 353° |
| 色相差 | **0.0°** |

既存サイトのプラム。当初は竹繊維からグリーンを採っていたが、ブランド色ではないため差し替え。地色もプラム寄りに再調整。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 素材について

**この会社は6件中はじめて、まともな解像度の写真を持っています**
（1152×864px など）。縫合シミュレータ、タオル、膝掛け、浄水プレート。
そのままリサイズして使えました。撮り直さなくても成立します。

## 営業上の注意

1. **HTTPS非対応** — お問い合わせフォームだけ別ドメインのSSL（prm-ssl.jp）に
   飛ばしており、ユーザーから見ると不審な挙動です
2. **PC版とスマホ版が別URL**（`/sp/index.html`）— 2019年リニューアルとありますが、
   この構成自体が当時すでに時代遅れでした。レスポンシブ1本にすべきです
3. **商品の情報が非常に濃いのに、レイアウトが平坦** — 特許、大学との共同出願、
   公的試験機関の試験結果という「third-party の裏付け」を持っているのに、
   本文に埋もれています。これは競合が簡単には真似できない資産です
