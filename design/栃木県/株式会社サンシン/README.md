## ご要望への回答 — スライドについて

> メニュー配下にスライドを入れるか、途中に画像を入れるなどの努力を

**画像は入れました。スライドは「メニュー直下」ではなく、ヒーローの下に置いています。**

理由を測定でご説明します。海外の良質サイトを実測したところ、**メニュー直下のカルーセルは1件も見つかりませんでした。**

| サイト | メニュー直下 | 最初のレールの位置 | スライダーlib |
|---|---|---:|---|
| Bang & Olufsen | 静的ヒーロー | **825px** | なし |
| Eurocircuits | 静的ヒーロー | **3026px** | なし |
| Adafruit | 静的 | — | なし |
| ASML | 静的ヒーロー | 7010px | なし |
| Apple | 静的ヒーロー | 818px | なし |

私自身が独立に再測定し、B&O 825px・Eurocircuits 3026px・Adafruit ゼロを確認しています。
**5社すべてスライダーライブラリを使っていません。**

Nielsen Norman Group の調査でも、利用者はカルーセルを「すぐスクロールして通り過ぎる」ため
2枚目以降がほぼ見られないと報告されています。

**本案の構成**: 静的ヒーローで1つのメッセージ（0.18ミリ）を伝え、
その下（**996px**）に**利用者が操作する横スクロールレール**を置きました。

- CSS の `scroll-snap-type: x mandatory` のみ。**JSライブラリ不使用**
- **JSを切っても動きます**（ネイティブスクロール）
- **キーボードで操作できます**（実測: 矢印キーで281px＝カード1枚分移動）
- タッチでもそのまま動きます

自動で流れるスライドより、**お客様であるソニーやリコーの技術者に対しては
「操作できるレール」のほうが適切**だと判断しました。
0.18ミリを測る会社が回転バナーを置くと、テンプレートに見えます。

ご希望があれば自動送りに変更できます。その場合は B&O が実装している
**一時停止ボタン**（アクセシビリティの最低要件）を必ず付けます。

## 画像の扱い

現行サイトから **36点の画像を発見し、うち6点を採用**しました。

**すべて約300pxで、解像度が足りません。** そこで実測に基づく方針を採りました。

| 参考 | 元画像 | 表示 | 倍率 |
|---|---|---|---|
| Adafruit | 310×233 | 308×231 | **0.99倍** |
| Arm | 400×330 | 401×327 | **約1.0倍** |

**良質なサイトは小さい画像を引き伸ばしません。** 箱を画像に合わせています。

本案でも同じ方針です。

1. **拡大しない** — カードは280px幅。図版は実寸に近い箱に収める
2. **暗いプレートに載せる**（Adafruit の `rgb(34,34,34)` 相当）— 小さい写真も「意図」に見える
3. **図面は `object-fit: contain`、写真は `cover`** — CAD図と回路図は情報。切ると意味が壊れる
4. **ヒーローはCAD図を「敷く」** — 259×265のまま繰り返しタイルにし、
   不透明度16%＋`mix-blend-mode: screen`。**この使い方なら解像度が問題になりません**

**採用しなかった画像**: `cir-b1jpg.jpg` は技術的内容のない装飾グラデーションだったため、
実際の測定ベンチ写真（`cir6.jpg`）に差し替えました。

借り物の工場写真ではなく、**自社のCAD図・回路図・設備**を使っています。
1978年から続く実力の証拠として、そのほうが誠実です。

## アートディレクション

> 0.18ミリの間隔で部品を載せる会社を、0.18ミリの精度で組む。

### 前回と違う3点（スキルの要求）

**1. 構造装置 — 自社CAD図のフルブリードテクスチャ**

ヒーロー全面に基板パターン図を実寸タイルで敷き、暗地に `screen` で線だけ浮かせています。

**2. セクション類型 — 前3社で未使用**

| セクション | 器 |
|---|---|
| できること | **横スクロールレール**（scroll-snap） |
| 納期 | **2つの表**（この会社の売りは日数そのもの） |
| 図版 | **暗プレートの図版グリッド**（figure + figcaption） |

**3. モーション — 業種の実測に合わせる**

調査した電子機器5社は**scroll-driven animation を1つも使っておらず**、
0.15〜0.3秒の古典的 transition で動いていました。それに合わせつつ、
出現だけ CSS の `view()` を足しています（非対応環境は静止で無害）。

### 既存3案との差分

| 比較対象 | 共通クラス |
|---|---:|
| 中川電気 | 0個（0.0%） |
| 日本オイルサービス | 2個（2.6%） |

### 検証中に見つけて直したもの

- **工程番号が 1.98:1 で AA 未達**だった → 罫線色を流用していたのが原因。実テキストなので明度を調整
- **装飾グラデーション画像を使ってしまっていた** → 実際の測定ベンチ写真に差し替え
- **一括リネームでCSSプロパティを壊した** — `top: 100%` が `banner: 100%` に置換されていた。
  クラス名の機械的置換は、同名のCSSプロパティを巻き込む危険があります
