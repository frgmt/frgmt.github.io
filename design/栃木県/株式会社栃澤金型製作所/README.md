# 株式会社栃澤金型製作所 — サイトリニューアル提案

栃木県下野市の航空宇宙部品・金型メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

すべて既存サイト（http://www.tochizawa.co.jp/）からの実データです。
既存サイトは **EUC-JP** で、そのまま読むと文字化けします（`iconv -f EUC-JP` で変換して取得）。

会社概要・沿革（18項目）・設備表（7台の型式と加工範囲）・主要受託先・仕入先・
FAQ全文は、既存サイトの記載をそのまま使用しています。
**FAQは特に、会社自身の言葉をほぼ原文のまま採用しました。**
「削る事が可能な材料であれば、お断りは致しません」「大量発注には
申し訳ございませんがご対応いたしかねます」といった率直な言い回しは、
書き換えるより残したほうが強いためです。

**製品写真は意図的に載せていません。** 既存サイトに
「※契約の都合上、写真（製品）はぼかしてあります」と明記されており、
ぼかした写真を並べても訴求にならないと判断しました。代わりに設備・認定・
対応範囲で判断していただく構成です。

## デザイン

**アートディレクション**: 「引き受けられる範囲で自らを測る工場」。
硬さ（難削材）・大きさ（マッチ棒〜5m）・ロット（1個から）という3つの
レンジがページの背骨です。

**シグネチャ**: スケールスパン。「マッチ棒の先程の小物から5m×2.5mもの大物」
という会社自身の言葉を、目盛りバーとして図にしました。スクロールで線が伸びます。

**3件目としての差別化**:

| | 佐藤精機 | テツカクリエート | 栃澤金型（本件） |
|---|---|---|---|
| ヘッダー | ブランド上にユーティリティ行 | 2段カタカナ署名 | ブランド＋**対応範囲ストリップ** |
| 見出し書体 | ゴシック | ゴシック | **明朝（Zen Old Mincho）** |
| 配色 | 暖グラファイト＋青 | 紺＋シグナルレッド | **チタングレー＋切削液ティール** |
| 主役 | 実物写真バンド | 数値フィギュア | **スケールスパン＋難削材インデックス** |
| 数字 | 特大ティック | モノスペース寸法 | 年号レール |

明朝体は創業1967年・ボーイング感謝状という「積み重ね」に合うと判断しました。
ティールは切削液の色から採っています。

**モーション**: reveal は transform のみ（opacity は一切animateしない）。
実測で `hidden-on-load: 0` を確認済みです。

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#042059` |
| 本サイトの色相 | OKLCH 258° |
| 色相差 | **3.9°** |

既存サイト css/contents.css のネイビー。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 検証結果（実測）

```
✅ JSエラーなし
✅ 横溢れ 0px — 320 / 375 / 414 / 600 / 768 / 900 / 1024 / 1280 / 1440 / 1920
✅ コントラスト 全AA達成
✅ 見出し階層 h1×1・スキップなし
✅ タップ対象 すべて44px以上
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（3,351文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在
✅ 非表示要素 0件・画像10点すべてロード成功
```

制作中に実測で見つけて直した不具合:

- **ナビの間隔が全幅で0pxだった** — `gap: clamp(.75rem,.2rem+1.2vw,1.35rem)` が
  効かず全リンクが密着。`column-gap: 1.25rem` に変更して全幅20px確保を実測確認。
  スクリーンショットを見るまで気づかず、`gaps:[0,0,0,0,0,0]` の実測で確定しました。
- **対応範囲ストリップとナビの衝突** — 表示開始を86remに上げ、
  1280/1376/1440/1920 で `overlap: false` を確認。

## 素材の制約

既存画像は最大560×180px（設備写真は200×150px）。原寸版は存在しません。
表示上限を切ってボケを防いでいますが、本番化の際は撮り直しを推奨します。

## 営業上の注意

このサイトも情報自体は充実しています（設備の型式・加工範囲まで公開）。
問題は**器**です。

1. **EUC-JP** — 2026年にこの文字コードはほぼ絶滅しており、環境次第で文字化けします
2. **HTTPS非対応** — Chromeで「保護されていない通信」
3. **スマホで425pxはみ出す** — 実測
4. **Copyright 2008 のまま** — 実際は2019年に新工場を建てているのに、
   サイトを見た人には「止まっている会社」に見えます。これが一番もったいない点です
