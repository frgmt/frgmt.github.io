# ゼビオプラスト株式会社 — サイトリニューアル提案

栃木県さくら市の水処理・空調用プラスチック製品メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（http://www.xepla.co.jp/）からの実データです。
既存サイトは **WordPress 5.1.19**（2019年系）で、UTF-8・クリーンURL。
会社概要・3工場の設備と敷地・有資格者12種・沿革・製品カテゴリの品目数を
そのまま採用しました。

**品目数（38/33/26/11/7/7/7/4）は既存サイトのカテゴリ表示から取得した実数**です。
合計133品目。これがこの会社の一番の資産だと判断し、
ページの中心に置きました。

## 検証結果（実測）

```
✅ JSエラーなし
✅ 横溢れ 0px — 320〜1920 の10幅
✅ コントラスト 全AA達成
✅ タップ対象 すべて44px以上
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（2,644文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在
✅ 非表示要素 0件・画像1点ロード成功
✅ clamp() 演算子スペース欠落 0件
```

制作中に実測で見つけて直した不具合:

- **カタログバーの数字が読めなかった** — 品目数をバーの内側に置いていたため、
  4品目・7品目のカテゴリではバーが短すぎて数字が切れ、
  さらにスクロールアニメーション中は潰れて判読できませんでした。
  数字をバーの外に出し、塗りだけを疑似要素でアニメーションさせる構造に変更。
  短いカテゴリでも常に数字が読めることを確認しています。

## 素材について

**使える写真がほぼありません。** 既存サイトの製品画像は遅延読み込みで
HTMLに含まれず、取得できたのはバナー画像1点（420×150px）のみでした。
本番化には撮影が必須です。133品目もあるので、
代表的な10点程度を撮るだけでもサイトの説得力が大きく変わります。

## 営業上の注意

**このサイトは「情報は充実、器が古い」の典型です。**
Copyrightは2026年、WordPressで運用されており、放置ではありません。

1. **HTTPS非対応** — WordPressサイトなのにSSLが入っていません。
   管理画面のログインも平文で飛んでいる可能性があります（セキュリティ上の実害）
2. **viewportタグ無し** — レスポンシブ用のCSSがあってもスマホで効きません。
   実測でスマホ横に **625px はみ出し**
3. **WordPress 5.1.19** — 2019年系。サポート終了バージョンで、
   既知の脆弱性が残っている可能性があります
4. 133品目という品揃えが、カテゴリの数字としてしか表現されていません
