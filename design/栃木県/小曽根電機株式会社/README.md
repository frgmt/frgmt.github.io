# 小曽根電機株式会社 — サイトリニューアル提案

栃木県栃木市藤岡町の電機部品メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（http://www.ozone-elec.co.jp/）からの実データです。
既存サイトは **frameset + Shift_JIS**。会社概要・沿革19項目・
3拠点の住所電話・ごあいさつ・トップの詩は原文のまま採用しました。

### 元サイトの記述が途中で切れています（要確認）

会社概要ページの最終行が **「本社 敷地面積 594」で途切れています**。
単位も、栃木工場・藤岡工場の面積も記載がありません。
勝手に補完せず、**該当箇所に注記を入れたうえで数値を省いています**。
先方に確認して追記してください。

なお、この会社のサイトは **Last Update 2026/3/13** と表示されており、
現在も更新されています。放置サイトではありません。

## 配色について（元サイトからの継承）

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#6699ff`（`bgcolor` として19回＝最頻の構造色） |
| 同系の濃色 | `#0000a0`（OKLCH H 264°） |
| OKLCH | (69.4%, 0.16, **263°**) |
| 本サイトの色相 | **263°** |
| 色相差 | **0.0°** |

トップの「一滴の水」の画像も青。**この会社のアイデンティティは水と青**なので、
地色から罫線まで青系で統一しました。

見出しに使われていた緑 `#67ce00`（OKLCH H 136°）は、
**沿革のマイルストーン印だけ**に残しています。元サイトでの使われ方
（見出しのアクセント）に近い役割です。明度は4.5:1を満たすよう下げました
（実測で3.82:1だったため）。

## デザイン

**アートディレクション**: 既存サイトのトップは、水滴が波紋を広げる写真と
「一滴の水」の詩。これを捨てずに軸にしました。深い青と、静かな横帯の構成です。

**シグネチャ**: プロダクションカウンター。ヒーロー直下の全幅バンドに
数値を4つ並べています。この会社の主張は結局「250万台」の一語なので、
それをページで一番大きな要素にしました。

**8件目としての差別化（ヘッダーは全件別パターン）**:

| | ヘッダー | シグネチャ |
|---|---|---|
| 佐藤精機 | ユーティリティ行 | 測定レール |
| テツカ | カタカナ2段 | 数値フィギュア |
| 栃澤金型 | 対応範囲ストリップ | スケールスパン |
| 栃木ALC | 社名＋所在地 | トン数ラダー |
| 雀宮産業 | 中央寄せ | 5レーンボード |
| デュプラス | インラインタグライン | プロダクト調書 |
| コーラス | 社名＋理念インライン | テープドボード |
| 小曽根電機（本件） | **社名＋3拠点ライン** | **プロダクションカウンター** |

## 営業上の注意

**このサイトの問題は「見つからないこと」です。**

1. **frameset** — 検索エンジンは各ページを個別に扱えず、
   「クリーンルーム 栃木」「ギヤードモーター 栃木」で上がってきません
2. **Shift_JIS**
3. **設備ページの中身が画像** — 「クリーンルーム 630㎡」という
   一番の強みが、テキストとして存在していません
4. **2024年の医療機器製造業登録証**という大きなニュースが、
   沿革の1行として埋もれています。これは営業上の武器です
