# 有限会社愛和精密製作所 — トップページ リニューアル案

現行サイト（http://www.aiwa-ss.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

## なぜ作り替えるのか（現行サイトの実測値）

現行サイトは**中身が非常に濃い**サイトです。画像74点すべてにaltが入っており、
その内容も「インコネル切削加工品：宇宙航空関係部品」のように具体的です。
h1もlangもmeta descriptionもあります。

問題は viewport の指定だけです。

```
target-densitydpi=device-dpi, width=1000, maximum-scale=1.0, user-scalable=yes
```

| シグナル | 実測 |
|---|---|
| **width=1000（固定値）** | `width=device-width` ではないため、iPhoneが1001px幅で組みます |
| **表示倍率 39%** | 実機390pxに対し1001px。本文13pxが**実効5.1px**（iPhone SEでは4.2px） |
| **ズームも禁止** | `maximum-scale=1.0` |
| **HTTPS未対応** | `https://www.aiwa-ss.com/` は接続できません |
| h1 / lang / description | ✅ すべてあり |
| 画像のalt | ✅ 74点すべてに記述あり |

### 直すべきは1行、失っているものは大きい

インコネルの羽根車、64チタンの複雑形状、5軸同時制御の設備一覧。
これだけの情報があって、**本文が実効5.1pxで表示されています**。

## この提案で変えたこと

### 1. 「インコネルも、64チタンも」を見出しにする

難削材の試作を探している設計者に、最初の1行で該当することを伝えます。

### 2. 御社の写真をそのまま使いました

現行サイトの写真8点と、ISO認証マークを使用しています。
**図やイラストは使っていません。**

- **冒頭**：インコネルの羽根車（宇宙航空関係部品）
- **難削材**：インコネル自動車部品、ステアリングナックル、位置決め治具
- **超短納期**：ウォータージェットが文字を切り抜いている写真
- **現場**：マシニング加工、ワイヤーカット、段取り

※ 実際に公開される際は、写真の使用可否をご確認ください。

### 3. 設備一覧を、5軸から順に並べる

現行サイトの設備表は型番順ですが、本提案では**5軸制御機を先頭**に置きました。
探している人が最初に見たいのはそこだからです。

マシニングセンタ13台・NC旋盤5台・その他の加工機・測定器・プログラム作成機を、
ストロークまで含めてすべて転記しています。

## 現行サイトで見つかった問題（2件）

### 1. マシニングの台数が2ページで食い違います

| ページ | 記述 |
|---|---|
| features.html | 「5軸を含む**14台**のマシニング」「汎用機として使ってるマシニングが**14台**」（3か所） |
| facilities.html | 見出し「マシニングセンタ **13台**」、表の合計も**13台** |

1台ずれています。本提案では**表の実数（13台）**を採用しました。
5軸4台は両ページで一致しています。正しい台数をご確認ください。

### 2. 画像のalt属性に、社名の誤記があります

titan.html の見出し画像 `h_titan.png` の alt が、

> 純チタン・64チタンの切削なら**愛輪精密**へ

となっています（正しくは**愛和**精密）。
altは検索エンジンが読む場所なので、社名の誤記は影響が大きい箇所です。
本文テキストには出てこないため、画面を見ているだけでは気づけません。

なお同じ画像には、画像内テキストとして「**Tttan**」（Titanの誤り）が
焼き込まれています。こちらは画像の差し替えが必要です。

## 技術メモ

- 単一HTML。フレームワーク・ビルド不要
- CSSは1ファイル、JSは1ファイル（約1KB）
- **JavaScriptを切っても本文は全文読めます**（3,824文字）
- **`width=device-width` を指定し、ピンチズームも禁止していません**
- 写真9点はすべて `width`/`height` 指定つき。元画像より大きく引き伸ばさないよう
  上限を設定しています（合計約284KB）
- `prefers-reduced-motion: reduce` で演出は停止します
- 320〜1920px の10段階で横溢れ0px を確認済み
- コントラストは検証ツールで全ペア WCAG AA 達成を確認
- タップ対象はすべて44px以上

## 配色について

基調の紺は、**現行サイトで実際に使われている色**
`rgb(0,63,147)` = `oklch(39.0% 0.150 258.8)` から採りました。
ほぼそのまま（明度36%・彩度0.140）使える色でした。
地は無彩に近いごく淡いグレーで、金属部品の色を邪魔しないようにしています。
