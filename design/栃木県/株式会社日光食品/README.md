# 株式会社日光食品 — リニューアル提案サイト

栃木県日光市のゆば専門メーカー。既存サイト <http://www.nikko-syokuhin.com/> の
公開情報のみを使って再構成した、1ページ構成の提案です。

## スコア根拠（prospect-scanner: 48点）
- HTTPS 未対応
- **ズーム禁止設定**（`user-scalable=no` 相当。アクセシビリティ上の問題）
- jQuery 1.11.0（サポート終了・脆弱性の懸念）
- スマートフォンで横に 225px はみ出し（実測）

**このサイトは他の案件と違い、内容がよく生きています。**お知らせは2026年8月の
QVC放映まで更新され、FOODEX・スーパーマーケットトレードショーへの出展も
毎年続いています。写真も2000px級の良質なものが揃っています。
直すべきは器（HTTPS・ズーム禁止・横溢れ・古いjQuery）だけ、という案件です。

## デザイン方針

### 業種が違えば、サイトの文法も違う
これまでの提案は製造業（B2B）でしたが、この会社は**食品のB2C**です。
発注担当者に仕様を伝えるサイトではなく、**食欲と信頼に語りかける**サイトが要ります。

- 見出しを**明朝体**に。手仕事の食品の温度を出します
- 冒頭は**煮物の写真を大きく**、下端を地色に溶かして「豆と、水と、手。」の一行へ
- 地色はごくわずかに温かい白（`oklch(99.4% .004 85)`）
- ナビゲーションの右端は問い合わせボタンではなく**電話番号そのもの**。
  この会社への注文はお電話が主要導線だからです

### 色 — ロゴの金
主色はロゴから採色した金 `rgb(176,144,80)` です。**ゆばそのものの色**でもあり、
パッケージの金の円とも揃います。

| | OKLCH | 色相差 |
|---|---|---|
| ロゴ実測 `rgb(176,144,80)` | `66.9% .091 83.4` | — |
| 本提案 `--gd-br`（罫・面） | `66.9% .091 83` | **0.4°** |
| 本提案 `--gd`（文字） | `48% .085 83` | 0.4° |

最初から2トークンで設計し、自動検証を初回で全項目通過しています。
フッターはパッケージの黒（`--sumi`）を使った濃色にし、
食品ブランドらしい締めにしました。

### 構成 — こだわり → お品書き → 買い方
原サイトの「こだわり」ページには、大豆・水・製法の三本柱がきちんと
書かれていました。これを**三枚の写真カード**にして、商品より先に置いています。
食品は「誰がどう作っているか」が価格の説明になるからです。

商品は6品を「お品書き」として並べ、**それぞれの食べ方**
（わさび醤油で、おでんで、炊き込みご飯で）を原文から引き継ぎました。

## 事実確認について

掲載した数値・固有名詞はすべて原サイトの記載に基づきます。**推測で補った情報はありません。**

- **郵便番号が原サイト内で食い違っています。**会社概要ページは「321-2335」、
  フッターは「321-2355」。日本郵便の郵便番号体系では日光市森友は 321-2335 のため
  こちらを採用しましたが、**公開前にご確認ください**
- 沿革の原文に「2023年12月26日(木)〜」を「2024年12月」の欄に記す混在が
  ありましたが、これはお知らせ欄のことで沿革には影響しません
- 商品説明・食べ方・支払い条件（後払い手数料550円等）は原文のままです
- 玉子加工食品（くんせいたまご）は「その他」の記載として言及に留めています
- オンラインショップのURLは原サイトの外部リンク先が未確認のため、
  導線のみ用意しリンクは設定していません

## 画像の扱い
原サイトの写真11点を採用しました（商品6・こだわり3・直売所1・料理1）。
2000px級のスライド画像は1600pxへ、1000px級は900pxへ縮小し、
画像フォルダ全体を1.1MBに収めています。QVCや店舗出店の告知に
含まれる人物写真は使用していません。

## 技術構成
- HTML + 手書き CSS。ビルド工程なし。**jQuery は使用していません**
- **ズームは禁止していません**（`user-scalable` 指定なし）
- JavaScript はモバイルナビの開閉のみ（`assets/app.js`、約30行）
- スクロール演出は `animation-timeline: view()` で **transform のみ**を動かす
- 構造化データ: Organization（ISO 22000）／ **FoodEstablishment（直売所）** ／
  WebSite ／ FAQPage
- MEO 対応: 直売所に Google マップ埋め込み（API キー不要の `?output=embed` 形式）。
  観光地・日光の店舗検索で地図表示は特に重要です

`docs/prospect-scanner/_v.mjs` による自動検証をすべて通過（**初回で全項目通過**）：

  ※ 原サイトはスマホで225pxの横溢れ
