### PC版とスマホ版が別々にある

現行サイトは `https://www.shinosei.com/` と
`https://www.shinosei.com/pc/index.html` の**2系統**で作られています。
2010年代前半に一般的だった作りですが、現在は1つのHTMLで
画面幅に応じて出し分けるのが標準です。

2系統あると更新が二重になり、実際に**トップ（スマホ版）の新着情報は
2011年11月で止まっています**。

## 設計上の判断

### 署名的装置 ── 受けられる仕事の幅

この会社の珍しさは、**受注の粒度が極端に広い**ことです。

- 部品 **1個**（試作・小ロット、各研究機関から高い評価）
- 板金加工・アッセンブリー（塗装・配線・梱包まで）
- 省力化機械・機械装置（**海底調査用機器**などの特殊機器も）
- **土質・アスファルト試験機**（自社製品・60年のノウハウ）

現行サイトは営業品目8つを箇条書きで並べるだけで、
「1個から装置まるごとまで」という幅が読み取れませんでした。

本案は**粒度の小さい順**に5段階で並べ、自社製品には赤い印を付けています。
「金属業界のコンビニエンス」という現行サイトの自称は、
この並びを見て初めて意味が分かります。

### 色 ── 鋼色の青と、試験機の赤

| 候補 | 出所 | 値 | 判断 |
|---|---|---|---|
| `#336699` | 現行 CSS（構造色） | `oklch(49.9% .099 250.4)` | **採用**（面 `oklch(42% .098 250)`、色相差 -0.4°） |
| `#911f21` | 現行 CSS（見出しの赤） | `oklch(43.2% .150 25.4)` | **第二色に採用**。自社製品（試験機）側の識別に |
| `#c0c0c0` | 罫・地 | — | 無彩色 |

彩度 `.099` は既に上限以下なので据え置き、明度のみ落として AA を取りました。

### hue 250 が4社目であることへの対処

第一パック（252）、協栄金型（253）、日新精機（249）と同じ帯です。
ただしこの色は**彩度 .099 の鋼色**で、他3社（.108〜.155）より鈍い。
それでも色相では分離できないので、以下で分けました。

| 軸 | 他の hue 250 系 | 篠原製作所 |
|---|---|---|
| 地の温度 | 板紙(80)・紫み灰(300)・鋳肌(265) | **緑みの灰（hue 130）**。青の反対側 |
| 署名的装置 | 箱の索引・磨き番手の表・納期の物差し | **受けられる仕事の幅**（粒度順の5段階） |
| 書体 | Shippori Mincho／Zen Antique Soft／M PLUS 1 | **M PLUS 2**。試験機メーカーの実直な声 |
| 第二色 | 受賞の金／なし／納期の赤 | **試験機の赤を自社製品側にだけ** |
| 幕開けの造り | 斜めの縞／放射／点描 | **水平の層**（地層。試験機メーカーなので） |
| 角丸 | 3px／10px／1px | **5px** |

## 検証結果（実測）

```
verify-site.mjs:
✅ 横溢れ 0px — 320〜1920 の全10幅
✅ コントラスト 全AA達成／見出し階層 h1×1／タップ対象44px以上
✅ スキップリンク フォーカス時 51px（"本文へ移動"）
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（3,480文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在

lib/audit.mjs:
✅ カナリア: 判定関数は正常
✅ 段階表示の残留なし（375/768/1440）／節の余白は非ゼロ
✅ 地図 表示あり（栃木県鹿沼市東町2-1-22）
✅ hover すべて AA以上

_font.mjs:
✅ --ff-d = M PLUS 2 が実際に読み込まれている
```

320px で 45px の横溢れが出ました。**原因は表ではなく、
取引銀行の列挙（`.gear__v`）に掛けていた `white-space:nowrap`** でした。
「みずほ銀行 駒込支店／三菱UFJ銀行 大塚支店」が1行 317px になり、
表とは無関係に紙面を押し広げていました。

最初は `overflow-x:auto` の表を疑って容器側をいじりましたが、
`.grid` の中を除外して測り直したところ一発で特定できました
（`_ovf3.mjs` を追加）。**nowrap は短い値のためのもの**で、
長い列挙に掛けてはいけません。

## データの出所

設備・事業内容・沿革・会社概要はすべて**現行サイトから取得した実データ**です。

- 設備一覧19行 … `/pc/equipment.html`
- 事業の3つの柱（部品加工・省力化機械・試験機） … `/pc/business.html`
- 会社概要・沿革・関連会社 … `/pc/company.html`
- 「金属業界のコンビニエンス」「イメージから図面化」「フロンティア企業」 … `/pc/index.html`
- 関連会社（東京篠原）の資本金・設立・沿革 … `/pc/free01.html`

### 確認が必要な項目

- **創業年と設立年が資料内で食い違います**。会社概要の「設立年月日
  1952年4月8日」に対し、沿革は「昭和23年（1948年）3月 創業／
  昭和27年（1952年）4月 有限会社に組織変更」。
  本案では**創業1948年・設立1952年**として両方を併記しました
- **「創業から60年」の表記**が事業内容にあります。1948年創業から数えると
  78年になるため、更新が必要と思われます。本案では試験機の
  ノウハウの年数としてのみ「60年」を残し、社歴には使っていません
- **ISO等の認証取得の記載がありません**（栃木県フロンティア企業の認証のみ）
- **新着情報が2011年11月3日「設備関係を更新しました」で止まっています**。
  15年分の設備投資が反映されていない可能性があります
- 設備一覧の「三本ロール」は**能力・型式が空欄**でした。原文のまま「—」としています
- **製品紹介ページ（`/pc/sample.html`）の本文が薄く**、
  具体的な製品名・仕様が得られませんでした。写真が主体のページのため、
  本案には個別の製品事例を含めていません
- 関連会社「株式会社東京篠原」は**骨材・コンクリート試験機の販売**が
  業務内容です。所在地は東京都文京区（番地の記載なし）
