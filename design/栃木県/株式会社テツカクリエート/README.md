# 株式会社テツカクリエート — サイトリニューアル提案

栃木県上三川町の航空宇宙向け複合材部品メーカー。1ページ構成。

## 開く

```
open index.html
```

ビルド不要。パスはすべて相対パスです。

## 掲載情報の出典

すべて既存サイト（http://www.tetsuka-create.co.jp/）からの実データです。
会社概要・沿革（15項目）・設備一覧（全24行の能力値）・主要取引先・
電話番号・メールアドレスは、既存サイトの記載をそのまま使っています。

**この提案の最大の中身は「画像の中の情報をHTMLに出したこと」です。**
既存サイトでは製造工程の6ステップが `seihinkakougaiyo.jpg`（980×980px）という
1枚の画像に焼き込まれており、検索エンジンもAIも1文字も読めません。
同様に設備能力の表も画像ではなくHTMLの `<table>` として組み直しました。
「プリプレグ」「オートクレーブ硬化」「φ2500×5000mm」といった、
この会社を検索で見つけるための語がすべてテキストになっています。

## 素材の制約（重要）

**既存サイトの画像は最大470px、多くは200〜240pxしかありません。**
原寸版は存在せず（`<a href>` のリンク先も確認済み）、これが取得できる全てです。
そのため:

- 写真を主役にしたヒーローは**作れません**。代わりに数値（オートクレーブ内寸、
  ウォータージェット最大寸法、3Dスキャナ精度）を主役に据えました。
- 製品写真は `max-width: 22rem` で表示上限を切り、拡大によるボケを防いでいます。

本番化の際は**写真の撮り直しが最優先**です。オートクレーブから出てくる大型パネル、
レイアップ室での積層作業は、それ自体が強い絵になります。

## デザイン

**アートディレクション**: 「飛ぶものの技術データシート」。写真が弱い以上、
数値がページを牽引する。

**前回（佐藤精機）との違い**:

| | 佐藤精機 | テツカクリエート |
|---|---|---|
| ヘッダー | ブランド上のユーティリティ行 | 左寄せ2段（社名＋業種）／NOMOS系 |
| 配色 | 暖色グラファイト＋マーキングブルー | クールネイビー＋シグナルレッド |
| ヒーロー | 実物写真（スケール入り） | 数値4点のフィギュアストリップ |
| 主役 | 横スクロール作品バンド | 24行の能力テーブル |
| 数字 | 特大ティック数字（01〜07） | モノスペースの寸法値 |

シグナルレッドは、この会社が自分で航空機写真に描き込んでいる「◯」の色から
採っています。勝手に決めた色ではありません。

**セクション構成**: 数値ヒーロー → 工程（6分割グリッド）→ 製品（対比ペア）→
能力テーブル → 沿革（タイムラインレール）→ 会社概要＋取引先インデックス →
FAQ → 連絡先。カードグリッドは0箇所です。

**モーション**: reveal は **transform のみ**。前回の実測で
`animation-timeline: view()` + `fill: both` が下方要素を `opacity: 0` に
固定することが分かっているため、opacity は一切animateしていません。
今回は実測で `hidden-on-load: 0` を確認済みです。

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#000066` |
| 本サイトの色相 | OKLCH 264° |
| 色相差 | **0.1°** |

既存サイトが構造色として12回使用しているネイビー。当初は航空機写真の赤丸から赤を採っていたが、あれは写真家の注記であり社のブランド色ではないため差し替え。地色は競合しないよう低彩度スレートに変更。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 営業上の注意

このサイトも**放置されていません**。2026年の組織図画像（`soshikizu2026.gif`）が
あり、認証も更新されています。スコア105点は「更新が止まっている」ではなく
「土台が古い」だけです。切り口は次のとおり:

1. **スマホで645pxはみ出す** — 実測・スクリーンショットあり
2. **HTTPS非対応** — Chromeで「保護されていない通信」と表示される
3. **工程・設備の情報が画像の中にあり検索されない** — これが最も金額的な損失。
   「CFRP オートクレーブ 栃木」で見つからない状態です
