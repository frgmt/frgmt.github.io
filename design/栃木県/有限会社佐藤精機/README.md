# 有限会社佐藤精機 — サイトリニューアル提案

栃木県那須烏山市の精密部品加工会社向け、1ページ構成の提案サイト。

## 開く

```
open index.html
```

ビルド不要。`index.html` を直接開けば動きます。パスはすべて相対パスなので、
`file://` でもサブディレクトリ配信でもそのまま動作します。

## 構成

```
index.html            本体（コンテンツはすべてHTML内。JSには入れていません）
assets/style.css      手書きCSS（デザイントークン + 全コンポーネント）
assets/app.js         モバイルナビ / ヘッダー状態 / reveal フォールバックのみ
assets/img/           製品写真8点・設備写真14点（JPEG + WebP）
favicon.ico / icon.svg / apple-touch-icon.png
robots.txt / sitemap.xml / llms.txt / site.webmanifest
```

## 掲載情報の出典

**すべて既存サイト（http://www.sato-seiki.co.jp/）から取得した実データです。**
会社概要・設備一覧・加工実績のキャプション・電話番号・ISO登録番号は、
既存サイトの記載をそのまま使っています。写真も既存サイトの原寸画像を取得し、
リサイズ・WebP化したものです。

事実確認できなかった項目は**意図的に載せていません**:

- **メールアドレス** — 既存サイトに記載がないため、JSON-LD からも削除しました。
  問い合わせ導線は電話のみにしています。
- **緯度・経度** — 「那須烏山市三箇」の正確な座標を確認できなかったため、
  `GeoCoordinates` は入れていません。住所はテキストで完全に記載しているので、
  MEO 上の不利はほぼありません。
- **創業年の西暦併記** — 「昭和49年9月」は既存サイトの記載どおり。
  1974年は換算値として併記しています。

既存サイトにあって本ページに入れていないもの: 営業日カレンダー、ブログ、
問い合わせフォーム、個人情報保護方針の全文。いずれも1ページ提案の範囲外です。
本番化する場合は別ページとして用意することになります。

## デザイン

**アートディレクション**: 「測られた文書」。この会社の写真は、どれも花崗岩の定盤の上に
スケールを添えて撮られている。その姿勢をページの構造そのものに移しています。

**シグネチャ**: 測定レール — 左の余白に走る極細罫と、定規の目盛りのような
特大の数字（01〜07）。セクションはそこから非対称にぶら下がります。

**セクション構成**（前回までの6サイトとは意図的に変えています）:

| # | セクション | アーキタイプ |
|---|---|---|
| 01 | 冒頭 | 画像先行ヒーロー（スケール入り実物写真） |
| 02 | できること | ナンバードガター（`<ol>` + 特大数字） |
| 03 | 加工実績 | 横スクロールバンド（`<figure>`／暗転） |
| 04 | 設備一覧 | スペックテーブル（実物の `<table>` + `rowspan`） |
| 05 | 会社概要 | スペックシート（`<dl>`）+ 拠点 aside |
| 06 | よくあるご質問 | ピン留めスプリット（`<details>`／JSなし） |
| 07 | ご相談 | 電話番号を主役にしたCTA |

カードグリッドは設備写真の1箇所のみ。他はすべて別の要素・別の構造です。

**ヘッダー**: ブランドの**上**にユーティリティ行（一貫生産の訴求 / ISO番号 / 電話）
を置くパターン。ロゴを持たない会社なので、ラテン文字の社名は**創作していません**
（`EST. 1974` のような擬似ワードマークは作らない）。日本語社名を組むことで対応しています。

**モーション**（4挙動・3カテゴリ）:

1. スクロール連動 — レールの罫が左→右に引かれる（`animation-timeline: view()`）
2. エントランス — 各項目が 1rem 分せり上がる
3. ステート — ヘッダーの圧縮、ナビ下線の描画、`<details>` の＋→×回転
4. アテンション — 冒頭の写真が一度だけ落ち着く（1要素のみ）

**reveal は `opacity` を一切animateしていません。** `animation-timeline: view()` は
`fill: both` の下でビューポート下方の要素を 0% キーフレームに固定するため、
`opacity: 0` を始点にすると「スクロールしない人には見えない」状態が発生します
（実測: 12/12要素が opacity 0）。そのため transform のみを動かしています。
最悪でも「1rem下にある」だけで、内容は必ず読めます。

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#003366` |
| 本サイトの色相 | OKLCH 245° |
| 色相差 | **8.9°** |

既存サイトのネイビー。マーキングブルーとして使用しています。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 既知の制約

- 問い合わせフォームはありません（静的ページのため）。電話導線のみです。
- 営業日カレンダーは未実装。既存サイトの手動更新運用を引き継ぐなら別途検討が必要です。
- 画像は既存サイトの原寸をリサイズしたものです。本番化の際は撮り直しを推奨します
  （特に設備写真は現場スナップの域を出ていません）。製品写真は定盤＋スケールの
  構図が一貫していて質が高いので、この撮り方は続けたほうがよいです。
