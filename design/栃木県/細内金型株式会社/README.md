# 細内金型株式会社 — サイトリニューアル提案

栃木県宇都宮市のプラスチック射出成形金型メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（http://www.hosouchi.co.jp/）からの実データです。
既存サイトは **frameset + Shift_JIS + Adobe GoLive 5 生成**という構成。
会社概要・加工機30台以上の一覧・成形機3台・CAD/CAM構成・
データ送信の容量制限まで、原文の数値をそのまま採用しました。

## 配色について（元サイトからの継承）

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#ada3fa`（`bgcolor` として34回＝最頻の構造色） |
| 同系の濃色 | `#4b50e2`（H 274°）、`#cecfff`（H 284°） |
| OKLCH | (75.8%, 0.124, **288°**) |
| 本サイトの色相 | **288°** |
| 色相差 | **0.0°** |

ロゴ画像（`img_menyu/Logo.gif`）は中身が白紙だったため、
表組みの背景色として実際に34回使われている `#ada3fa` を採用しました。
ペリウィンクル（藤色）系という、8件の中で唯一の色相です。

## デザイン

**アートディレクション**: 金型屋に発注できるかどうかは、
結局「型重量」と「成形機サイズ」の2つで決まります。
その2つを最初に置き、通過できるかを判断してもらう構成にしました。

**シグネチャ**: トネージゲート。7ton と 1300ton を2本の柱として立て、
その間をスクロールで伸びる梁でつないでいます。

**9件目としての差別化（ヘッダーは全件別パターン）**:

| | ヘッダー | シグネチャ |
|---|---|---|
| 佐藤精機 | ユーティリティ行 | 測定レール |
| テツカ | カタカナ2段 | 数値フィギュア |
| 栃澤金型 | 対応範囲ストリップ | スケールスパン |
| 栃木ALC | 社名＋所在地 | トン数ラダー |
| 雀宮産業 | 中央寄せ | 5レーンボード |
| デュプラス | インラインタグライン | プロダクト調書 |
| コーラス | 社名＋理念インライン | テープドボード |
| 小曽根電機 | 社名＋3拠点ライン | プロダクションカウンター |
| 細内金型（本件） | **社名＋一文（区切り罫つき）** | **トネージゲート** |

同じ「金型」の栃澤金型とは、色相（258° vs 288°）、書体（明朝 vs ゴシック）、
シグネチャ（水平スパン vs 2本柱ゲート）で分けています。

## 素材について

使えた写真は社屋外観1点（500×375px）と成形機2点（280×167px / 300×132px）のみ。
本番化には撮影が必要です。特に「金型を作ってその場で成形できる」という
最大の強みは、金型と成形機が並んだ1枚があれば一発で伝わります。

## 営業上の注意

1. **frameset + Adobe GoLive 5** — 2000年代前半のオーサリングツールで、
   2003年のCopyrightのまま。検索エンジンが各ページを個別に扱えません
2. **Shift_JIS**
3. **「自社で成形トライができる」という強みが埋もれている** —
   成形機は設備ページの3階層目にあり、トップからは辿り着けません。
   金型屋を探している人が最初に知りたい情報です
4. **求人情報が現役** — 金型設計者を緊急募集中、外注協力会社も随時募集。
   採用目的でもサイトが機能していない状態です
