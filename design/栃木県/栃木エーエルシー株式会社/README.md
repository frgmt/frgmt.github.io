# 栃木エーエルシー株式会社 — サイトリニューアル提案

栃木県高根沢町のフィルム・テープ抜き加工メーカー。1ページ構成。

## 開く

```
open index.html
```

## 掲載情報の出典

既存サイト（http://www.tochigi-alc.co.jp/）からの実データです。
**既存サイトは frameset + Shift_JIS** という2000年代前半の構造で、
コンテンツは `contents/` 配下の3ページに分かれています。
会社概要・設備一覧（9項目）・事業目的・沿革・用途は原文のまま採用しました。

「ごあいさつ」の一文は引用として `<blockquote>` で残しています。
書き換えるより、会社自身の言葉のほうが伝わると判断しました。

## デザイン

**アートディレクション**: 抜き加工の会社なので、ページ自体を「切れた縁と重なる面」で
構成。影を使わず、罫線とフラットな面だけで組んでいます。

**シグネチャ**: トン数ラダー。設備の主役がプレス12台（5t〜60t）なので、
トン数の比をそのままバーの長さにしました。スクロールで伸びます。

**4件目としての差別化**:

| | 佐藤精機 | テツカ | 栃澤金型 | 栃木ALC（本件） |
|---|---|---|---|---|
| ヘッダー | ユーティリティ行 | カタカナ2段 | 対応範囲ストリップ | **社名＋所在地2段** |
| シグネチャ | 測定レール | 数値フィギュア | スケールスパン | **トン数ラダー** |
| 配色 | 暖グレー＋青 | 紺＋赤 | チタン＋ティール | **青灰＋サンプル写真の青** |
| 影 | あり | あり | 一部 | **なし（フラット）** |

アクセント色は、既存サイトのサンプル写真の背景の青から採りました。

## 配色について（元サイトからの継承）

既存サイトの実際の配色を抽出し、**アクセント色相を元サイトから±10°以内**に保っています。

| 項目 | 値 |
|---|---|
| 元サイトの色 | `#0066ff` |
| 本サイトの色相 | OKLCH 261° |
| 色相差 | **0.2°** |

既存サイト alc.css のブルー。サンプル写真の背景も同系。

明度・彩度はコントラスト比4.5:1を満たすよう調整しています（色相は動かしていません）。
これは不具合の修正であって、デザインの変更ではありません。

## 検証結果（実測）

```
✅ JSエラーなし
✅ 横溢れ 0px — 320〜1920 の10幅
✅ コントラスト 全AA達成
✅ タップ対象 すべて44px以上
✅ reduced-motion 内容はすべて可視
✅ JS無効時も全文可視（1,910文字）
✅ ローカル参照はすべて相対パス／参照ファイルはすべて実在
✅ 非表示要素 0件・画像2点ロード成功
```

制作中に実測で見つけて直した不具合を2件記録します。どちらも
スクリーンショットだけでは見落としていた可能性が高いものです。

1. **`clamp()` が全滅していた** — `clamp(2.125rem,1.4rem+3.2vw,4rem)` のように
   `+` の前後に空白がないとCSSの計算式として無効になり、宣言ごと捨てられます。
   結果、H1が本文と同じ16pxで表示されていました（実測 `h1: "16px"`）。
   スペースを入れて `h1: 64px` を確認。同じ不具合が栃澤金型にも3箇所あったため
   そちらも修正済みです（`h1: 62px` を確認）。
2. **モバイルで8pxの横溢れ** — ハンバーガーの `margin-inline-end:-.5rem` が
   コンテナ外にはみ出していました。320〜900の全幅で発生。負のマージンを撤去。
   なお同じ記述が他3サイトにもありますが、そちらは実測で0pxのため
   （コンテナの余白が吸収）変更していません。

## 素材の制約

既存サイトの画像は2点のみ（500×270px、500×267px）。
本番化の際は撮影が必要です。特に「抜いた部品のサンプル」は
この会社の実力が一番わかる被写体なので、きちんと撮り直す価値があります。

## 営業上の注意

1. **frameset** — 2000年代前半の構造。検索エンジンが個別ページを正しく扱えません
2. **Shift_JIS** — 文字化けのリスク
3. **HTTPS非対応**
4. スマホ実測のはみ出しは0pxでしたが、これはframesetのため
   スキャナが内側のページを測れていない可能性があります。
   実機では横スクロールが発生するはずです
