# 株式会社日本オイルサービス — トップページ リニューアル案

現行サイト（http://www.josplant-inc.com/）のリニューアル提案。トップページのみ。

## 見る

```
open index.html
```

ビルド不要。そのままブラウザで開けます。

```
index.html          全コンテンツ
assets/style.css    デザイントークン + コンポーネント
assets/app.js       動く部分のみ（約50行）
robots.txt / sitemap.xml / llms.txt
```

## なぜ作り替えるのか（現行サイトの実測値）

見込み客スキャナで栃木県225社中 **2位（123点）** と判定された根拠。

| シグナル | 実測 |
|---|---|
| Flash残存 | 2020年サポート終了済み |
| 文字コード | Shift_JIS |
| レイアウト | テーブルレイアウト |
| **スマホ横はみ出し** | **341px**（実サイトで再実測） |

黄緑のテーブルレイアウトで、スマホでは社名が画面に収まりません。

## 設計上の最大の課題 — 二つの事業

プラントエンジニアリングと環境エンジニアリング。現行サイトは左メニューに全項目を
平坦に並べており、どちらの会社なのか伝わりません。

### v1（不採用）の反省

初版は中川電気の構成をほぼそのまま流用してしまいました。機械的に測ると
**クラス名の69%が共通、セクション構成もほぼ同一**で、配色と文言を変えただけの状態でした。
`.archive/v1-template/` に残してあります。

そこでスキル `global-web-design` に
「前回と違う3点の明示」「セクション類型メニュー」「モーションのPhase化」を追加し、
その基準で作り直したのが本案です。

## アートディレクション

> 「環境保全とエンジニアリング」を、装飾ではなく **監査可能な記録** として提示する。
> 器は台帳であって広告ではない。

### 前回と違う3点（スキルの要求）

**1. 構造装置 — 左に固定する index rail**

読んでいる位置が常に画面にある。法定点検の会社にふさわしい「計器の針」の比喩です。
1024px 以上でのみ出現し、それ未満では通常のヘッダーに切り替わります。

**2. セクション類型 — 3つとも中川で未使用**

| セクション | 器 | 中川での使用 |
|---|---|---|
| 事業 | **ピン留めスプリット**（左固定・右スクロール） | なし |
| 認証台帳 | **全幅の表**（thead 固定） | なし |
| 沿革 | **タイムライン・レール**（自己延伸する線） | なし |

**カードグリッドは1つも使っていません。** 中川はカード中心だったため、ここが最大の差です。

**3. モーション — 「計測」を感じさせる**

派手さではなく、進捗と計測。詳細は下記。

### 書体 — 3つの役割に分ける

和文4書体を同一条件で組んで比較し、**Zen Old Mincho** を採用しました。
50年の規制産業に必要な「権威」が出るのは明朝でした。

| 役割 | 書体 |
|---|---|
| 権威（見出し） | Zen Old Mincho（明朝） |
| 可読（本文） | Noto Sans JP |
| 証拠（番号・年） | IBM Plex Mono |

Arup（68px / -4.76px トラッキング）で確認した「セリフが権威を、サンセリフがデータを担う」
分業を和文に適用したものです。中川はゴシック1系統だったので、ここも明確に異なります。

アクセントは**検査の朱** `#a8442a` 1色のみ。点検済みの印を想起させる色です。

| 2 | Our World in Data | 英 | 14カラムグリッド、本文 span-12・破り出し span-14 |

| 6 | Arup | 英 | 12×112.656px の背骨、見出しを 1/span 7 に掛ける |
| 7 | **Burckhardt Compression** | 瑞 | `::before` の border-left で自己延伸するタイムライン |
| 8 | Wikipedia | — | 100行超に対する `<thead>` 固定 |
| 9 | Ramboll | 丁 | フレーム単位のスクロール連動出現 |

## モーション（Phase 3）

4カテゴリのうち**3カテゴリ**から実装しました。

| # | 種別 | 内容 | 実装 |
|---|---|---|---|
| 1 | スクロール連動 | 上部の読了メーター | `animation-timeline: scroll()` — **JS不要** |
| 2 | スクロール連動 | 視界に入る間の出現・60ms ずらし | `animation-timeline: view()` — **JS不要** |
| 3 | 状態 | 下線が引かれる／行が寄る | CSS transition |
| 4 | 注目 | 計測値3つのカウントアップ | JS（`prefers-reduced-motion` で無効化） |

**内容の可視性はモーションに依存させていません。** 出現アニメーションの初期状態
（`opacity:0`）は `.js` が付いたときだけ効かせ、`<head>` で同期的に付与しています。
JSが動かない環境では**最初から全文が見えたまま**になります。

## 実装方針

**HTMLが主、Vueは従。** スキル `global-web-design` の方針に従っています。

| 箇所 | 内容 |
|---|---|
| モバイルナビ | クラス1つの開閉。リンクはHTMLに実在 |
| スクロール表示 | IntersectionObserver。`prefers-reduced-motion` 対応 |

FAQは**ネイティブ `<details>`**、認証一覧は**素の `<table>`** で、いずれもJSを使っていません。

**受け入れ基準**: JavaScriptを切ってもページの全文が読め、全リンクが動く。
→ 実測で本文3,382文字すべて到達可能。

### 中川電気との差分（リスキンでないことの確認）

スキルが要求する「前回との差分測定」を実施しました。

| 指標 | v1（不採用） | **v2（本案）** |
|---|---:|---:|
| クラス名の共通率 | **69%** | **1%** |
| 共通するクラス | 53個 | **1個**（`open` = Vueの状態変数） |
| カードグリッド | 2箇所 | **0箇所** |
| 中川と共通のセクションID | 3個 | **0個** |

### 検証中に見つけて直したもの

- **JS無効時に8要素が不可視だった** — `animation-timeline: view()` はJSが無くても動作するが、
  スクロールしない限り `opacity:0` のまま。**内容の可視性がアニメーションに依存していた**ため、
  `.js` が付いたときだけ隠す方式へ変更
- **全幅の表がページ全体を横スクロールさせていた** — `100vw` はスクロールバーを含むため
  負のマージンが過大になっていた。`body{overflow-x:hidden}` が見た目上は隠していたが、
  文書は実際に横に溢れていた。10段階の幅で0pxを確認
- **全幅の表が左レールに重なっていた** — レールは sticky で同じグリッド行にあるため、
  左へ伸ばすと衝突する。右方向にのみ逃がし、レールに `z-index` を付与
- **モバイルに左右余白が無かった** — `.frame` の padding が 1024px 以上にしか無く、
  文字が画面端に接していた

## データの出所

**掲載内容はすべて現行サイトからの実データです。捏造した数値・実績はありません。**

会社概要・沿革・4事業・保有認証・製品名について、全項目を出典と機械的に照合済みです
（`ＦＳ508300` 等の全角表記も正規化して確認）。

| 項目 | 出所 |
|---|---|
| 会社概要・許認可一覧 | `info.htm` |
| 経営理念・ISO適用範囲 | `rinen.htm` / `idea.htm` |
| 沿革・受賞歴 | `history.htm` |
| 事業内容 | `engineering.htm` / `maintenance.htm` / `environment.htm` |
| 製品 | `showroom.htm` |

和暦→西暦の変換も検証済み（昭和50年=1975年、平成18年=2006年 ISO取得、平成27年=2015年 消防長官表彰）。
